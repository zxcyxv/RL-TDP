# 먼 미래의 설계

`guidelines.md`의 최종 목표와 설계 원리를 따른다. 당장 구현할 설계가 아니라, 학습 → 증류를 반복하는 단계 (최종 목표 2, 3)에서 필요해질 구조를 적어 둔다. 바탕은 `design_draft1.md`다.

## 왜 필요한가

- 후속 특징 Ψ는 행동 뒤에 따를 정책을 가정한 값이다. 그 정책을 느린 행위자 E_θ로 정의하면, 증류로 E_θ가 바뀔 때마다 Ψ도 새 E_θ 기준으로 다시 학습된다.
- 그러면 새 과제로 증류할수록 E_θ와 Ψ가 새 과제 쪽으로 옮겨 가고, 원래 과제로 돌아왔을 때 예전 행동을 잊을 수 있다 (최종 목표 3과 충돌).
- 행위자 하나가 서로 다른 보상의 과제들을 동시에 최적화하려면 지금이 어떤 맥락인지 알아야 한다. 그래서 Ψ와 E_θ를 맥락 c로 조건화한다.

## 구조

### 맥락 c

- c는 기억에서 읽는다. 과제 이름표가 아니라 에이전트가 겪은 이력에서 만들어지는 표현이다.

### 맥락이 질의하는 후속 특징

- x(s, a): 상태·행동 표현.
- Ψ(s, a | c) = W_o [ (W_v c) ⊙ silu(W_g x(s, a)) ]. 맥락은 SwiGLU의 선형 항에, 상태·행동은 게이트에 둔다.
- (s, a)를 고정하면 Ψ(s, a | c) = A(s, a)·c, A(s, a) = W_o diag(silu(W_g x(s, a))) W_v. 상태·행동이 정하는 행렬을 맥락이 질의해 읽는 꼴이다.
- Ψ^E의 정의가 맞으려면 행위자도 같은 맥락으로 조건화한다: E_θ(a | s, c).

### 빠른 선호와 행동

- 빠른 선호 u는 초안 1과 같다. 세션 안에서 r_{t+1} ≈ uᵀφ_{t+1}를 역전파 없이 갱신한다.
- Q_t(a) = uᵀΨ(s_t, a | c_t), π_t(a) ∝ E_θ(a | s_t, c_t) · exp[κ Q_t(a)].

### 증류

- 빠른 시냅스의 읽기 (M·k)와 Ψ의 맥락 읽기 (A(s, a)·c)가 같은 꼴이다. 세션 안에서 시냅스가 배운 보정을 느린 A(s, a) 안으로 옮기는 것으로 증류를 정의할 수 있다.
- 원래 과제로 돌아오면, 기억이 그 맥락을 다시 만들어 내고 느린 망이 그 맥락의 Ψ와 정책을 꺼낸다.

## 열린 문제

1. **어떤 기억에서 c를 읽는가.** GRU 상태인지 시냅스 기억인지.
2. **느린 망이 문맥 적응을 대신 배울 위험.** c가 기억에서 오면, 느린 망이 이력에서 지금 보상을 추론하는 법을 배워 빠른 선호 u의 몫을 가져갈 수 있다. 각 단계에서 빠른 쓰기를 끈 대조로 몫을 잰다.
3. **맥락 선형성의 한계.** Ψ가 c에 선형이므로, 섞인 맥락에서는 Ψ도 선형으로 섞인다. 맥락마다 정책이 크게 다르면 섞인 맥락의 Ψ는 실제 어떤 정책의 후속 특징과도 맞지 않는다. 맥락이 분리되어 있으면 문제없다.
4. **증류의 정의.** 초안 1의 "u를 보상 머리로 옮기고 비운다"를 이 구조에 맞게 다시 정한다.
