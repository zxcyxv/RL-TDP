# 능동적 추론의 그림으로 월드 모델과 정책을 통합하는 안

작성 2026-11-12. 설계 제안이고, 구현하지 않았다. 표기: **[표준]**, **[유도]**(이 논의에서 유도, 수치 확인 전), **[기억]**(서지를 기억에 의존, 원문 미대조).

## 1. 지금의 구조

DreamerV3 골격의 두 모듈이 번갈아 학습된다 (`fepoc/agent/run.py`, `ac.py`, `efe.py`).

| | 줄이는 양 | 학습 신호 | 연결 |
|---|---|---|---|
| 월드 모델 | F (관측의 변분 자유에너지) | 재현 버퍼의 관측 | 믿음 상태 [h_t, emb(o_t)]를 정책에 준다 |
| 정책·가치망 | G (기대 자유에너지), KL[π ‖ softmax(Q/α)] | 월드 모델이 한 스텝 상상한 Q | 월드 모델을 고정된 시뮬레이터로 쓴다 |

- 기울기는 서로 넘어가지 않는다. 월드 모델은 F로만, 정책·가치망은 Q(= −G)로만 학습한다.
- 행동할 때는 정책망을 한 번 통과할 뿐이고, 월드 모델의 예측은 쓰지 않는다.
- 정밀도는 세 가지로 나뉜다.
  - 관측 정밀도: 디코더의 분산.
  - 상태 전이 정밀도: 없다. 기억이 결정론적이다.
  - 정책 정밀도: γ_π = 1/α (`--ent`)로 고정되어 있고, 추론하지 않는다.

능동적 추론의 원래 그림에서는 상태와 정책을 모두 숨은 변수로 둔 하나의 F를 줄인다. G는 정책의 사전분포 P(π) ∝ exp(−γG)로 들어간다 [표준]. 지금 구조는 이것을 두 모듈로 나눠 상각한 것이다.

## 2. 핵심: critic을 월드 모델의 예측 머리로 바꾼다

정책과 무관한 위험률 1−γ로 끝나는 생성 모델(기하분포 수평선)에서, 결과에만 선호를 걸면 다음이 성립한다 [유도].
```
G(b, a) = −(1/(1−γ)) · Σ_y P_K(y | b, a) · ln C(y),     K ~ 기하분포(1 − γ)
```
P_K는 "기하분포로 뽑은 미래 시점의 결과" 예측분포다. G에 필요한 것은 미래 결과의 예측분포뿐이다. 이것은 월드 모델의 예측과 같은 종류의 양이다(기하 수평선 예측 모델, Janner et al. 2020의 γ-모델 계열 [기억]).

이 예측 머리는 결과 채널의 우도(F)로 학습하고, 목표는 시간차 방식으로 만든다 [유도].
```
목표(y) = 원-핫(y_{t+1})                                         y_{t+1}이 종료일 때 (흡수 상태)
        = (1 − γ)·원-핫(진행) + γ·P̄_K(· | b_{t+1}, a_{t+1})      진행일 때 (P̄: 느린 목표망)
손실   = 교차엔트로피(목표, P_K(· | b_t, a_t))
```
이 점화식은 `ActorCriticKL`의 Q 식(흡수 종료, 진행이면 γ·V̄)과 같은 형태다. critic이 "가치를 회귀하는 망"에서 "미래 결과를 예측하는 월드 모델의 머리"로 바뀐다.

## 3. 통합된 구조

```
하나의 생성 모델 (공유 기억: TDP 또는 GRU)
 ├─ 관측 머리:        p(o_t | b)              대각 가우시안 (docs/memory_energy_theory.md 10절),  F*_관측
 └─ 미래 결과 머리:   P_K(y | b, a)           범주 3개,                                          F_결과 (2절의 시간차 목표)

정책 = 추론 (따로 학습하는 망 없음)
   π(a | b) = softmax_a( −γ_π · G(b, a) ),   G는 미래 결과 머리에서 계산 (행동 3개 → 3번 평가)

정밀도
   관측 정밀도 σ_θ: 맥락에서 예측. 필요하면 감마 켤레로 추론
   정책 정밀도 γ_π: 감마 사전 + 갱신 (처음에는 고정)
```
- **학습은 모두 F(우도)다.** actor와 critic이 따로 없다.
- **행동은 추론이다.** 매 스텝 월드 모델의 예측으로 G를 계산하고 softmax로 고른다. Q(π) = σ(−γG)를 상각하지 않고 직접 계산한다. 상상 롤아웃도 필요 없다.
- **PoC에 유리하다.** 행동이 월드 모델의 예측에서 바로 나오므로, 월드 모델을 바꿨을 때의 차이가 actor-critic의 학습 동역학에 가려지지 않는다.

## 4. 남는 것과 위험

1. **탐색이 없다.** G가 실용 항뿐이라, 성공을 본 적 없으면 P_K(성공) ≈ 0이고 회전 고착이 그대로 생긴다. 통합은 탐색 문제를 풀지 않는다.
2. **정책 정밀도의 갱신 규칙.** 이산 정식화에는 감마 사전을 두고 정책 사후분포와 사전분포의 차이로 갱신하는 규칙이 있다 [기억]. 정확한 식은 원문과 대조해야 하므로, 처음에는 고정으로 둔다.
3. **시간차 목표의 안정성.** 미래 결과 머리가 자기 예측으로 목표를 만들므로(부트스트랩), soft Q-learning과 같은 종류의 불안정이 있을 수 있다. 느린 목표망(EMA)을 둔다.
4. **수평선 너머의 계획이 없다.** 미래 결과 머리가 상각된 예측이라 "오래 생각해서 더 나은 행동 찾기"가 없다. 행동이 3개인 지금은 문제가 되지 않는다.
5. **정책 의존성.** P_K는 현재 정책 아래의 미래 예측이므로 정책이 바뀌면 다시 맞춰야 한다. 정책 반복과 같은 동역학이다.

## 5. 확인할 것

- 2절의 G 식과 시간차 목표가 `ActorCriticKL`의 Q와 상수 차이 없이 같은지를 작은 예시로 수치 확인한다.
- 행동 시점에 G를 직접 계산하는 정책과 지금의 상각 정책을 같은 월드 모델에서 비교한다.
