# 명세: 월드 모델 + 시냅스 동시 학습 (사전학습 없음), 2026-11-17

바탕: [`spec_q8_r0_pipeline.md`](spec_q8_r0_pipeline.md) (환경·관측·시냅스·키·판정은 그 문서와 같다). 코드 `scripts/world/diag_20261117/synapse_wm_joint.py`.

## 목적

시냅스는 월드 모델의 유일한 기억 (순환 상태)이다. 지금까지는 시냅스 읽기가 예측에 더해지기만 했다 (ŷ = μ⁰ + M z). 이번에는 **읽기가 월드 모델의 입력으로도 들어가** 지금 장면의 해석을 고치게 한다. 월드 모델 사전학습 없이 처음부터 함께 학습한다.

## 바뀌는 것

- 예측: ŷ = F₀(o, a) + m + G(o, a, m)
  - F₀(o, a): 기억 없는 예측 (102 → 256 ReLU → 96). **무작위 초기화, 함께 학습** (사전학습 없음).
  - m: 시냅스 읽기, 칸마다 M_p z_p (쓰기 전). 예측에 그대로 더한다 (지름길).
  - G(o, a, m): 기억을 입력으로 받는 망 (198 → 256 SiLU → 96), **마지막 층 0** (처음에는 ŷ = F₀ + m).
- 학습 목적: 순차 NLL Σ_t Σ_p ½ [‖y_p − ŷ_p‖² / S_p + 8 log S_p], S_p = R₀ + R_p + z_pᵀ P_p z_p (칼만 예측 분산 그대로).

## 그대로인 것 (12.11의 실패를 피하는 조건)

- **쓰기 값 = 기억 없는 예측의 잔차** r = y − F₀(o, a). 시냅스는 이번 세계에만 해당하는 사실을 담는다. (12.11은 쓰기 값을 관측 그대로로 바꿔 실패.)
- **쓰기 규칙 = 칼만** (P + qI, 이득 P z / S, M ← M + (r − m) gᵀ). G는 쓰기에 들어가지 않는다. 쓰기 크기는 σ², R, q, P로만 정한다. (12.11은 쓰기 크기를 기억을 본 월드 모델 분산에서 가져와 실패.)
- **흔적은 월드 모델에 넣지 않는다.** 흔적은 시냅스 주소에만 쓴다. 지난 일의 정보는 m을 거쳐서만 월드 모델에 들어간다. (12.11은 흔적을 직접 넣어 월드 모델이 기억을 무시하고도 도착 시점을 맞힘.)
- 칸별 키 (synapse_cellkey와 같은 꼴, 초기 = 고정 난수 키), 칸별 칼만, R₀ 8비트, 8비트 양자화 텍스처.
- 자료·배치·판정 세계: 앞 명세와 같다. lr: 키 1e-3, 월드 모델 (F₀, G) 1e-3, 칼만 0.05. 10,000반복, 최저 검증 NLL 시점 채택.

## 판정 (세 가지 읽기, 같은 절차)

- syn: 시냅스 읽기 m (지금까지의 판정과 같음)
- wm: 월드 모델의 기억 몫 m + G(o, a, m)
- wm_memoff: 기억을 끈 G(o, a, 0) (기억을 실제로 쓰는지 확인용. 우연 수준이어야 한다)

## 비교와 한계

- 출발점이 완전히 달라 (월드 모델 무작위), 앞 명세의 기준선 (70.7%)과 직접 비교할 수 없다. 함께 기록한다.
- 초기에는 F₀가 아무것도 모르니 잔차가 관측 거의 전부이고 시냅스가 공통 규칙까지 떠안는다. F₀가 배울수록 시냅스 몫이 이번 세계의 사실로 줄어들 것으로 예상한다.
