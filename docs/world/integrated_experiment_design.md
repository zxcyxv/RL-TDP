# 네 요구를 같은 세션에서 검사하는 지연 채집 과제

작성: 2026-11-15, Codex. **실험 설계다. 구현·학습 결과가 아니다.**
표기: [표준] 알려진 결과, [확인] 코드·원문 대조, [유도] 가정 아래 계산,
[가설] 실행 전에 고정할 예측. 미대조 기억에 의존한 성능 주장은 없다.

## 0. 판단과 하나의 권고

**권고는 ‘지연된 채집 결과와 바뀌는 의뢰’를 한 픽셀 세계에서 계속 처리하는 과제다.**
세계 지도, 채집처의 산출물, 보상 함수를 각각 새로 외우게 한다.
이미 본 산출물이 나중에 처음으로 보상이 된다.
그 뒤 한 채집처만 바뀐다. 세션과 기억은 계속된다.

핵심 선택은 다음이다.
**새 보상이 무엇인지 한 번 확인하고, 방금 보상을 받았던 채집처가 바뀐 것을 확인한 직후,
오래전에 보았지만 보상을 받은 적은 없는 다른 채집처로 가는가.**
이 선택에는 네 요구가 동시에 필요하다.
결과는 이동·무관한 상호작용 뒤에 도착한다. 결과 화면에는 출발지가 없다.
같은 종류를 내는 채집처를 둘씩 두므로 두 문 과제의 배제 추론으로 풀리지 않는다.

| 빠진 요구 | 핵심 선택에서 나타나는 실패 |
|---|---|
| 기억 | 보상을 받은 적 없는 다른 B 채집처를 모름 |
| 공 배정 | C 결과를 나중에 조작한 곳에 쓰고 b0는 여전히 B라고 믿음 |
| 새 보상 적응 | 사실을 기억해도 A의 과거 가치만 따라감 |
| 국소 수정 | b0를 고집하거나, 전체 초기화로 유효한 b1까지 잃음 |

하나의 최종 checkpoint가 다음을 모두 통과해야 한다.

1. 같은 경험을 준 검사에서 기억·공 배정·새 보상·부분 수정이 모두 성립한다.
2. 같은 과제의 자율 실행에서도 경험을 모으고 그 기억으로 행동한다.
3. 긴 세션에서도 기억 크기와 스텝당 계산 상한이 늘지 않는다.
4. 평가 중 느린 가중치의 경사 갱신은 0회다.

각각 다른 모델의 최고 점수를 합치지 않는다. 평균 보상만으로 통과시키지도 않는다.
Dreamer보다 높은 점수는 통과 조건이 아니다.
더 단순한 방법이 통과하면 그것을 채택할 근거가 된다.

이 시험은 Minecraft의 필요조건을 작게 검사한다.
Minecraft의 다이아몬드 획득이나 긴 제작 사슬을 입증하지는 않는다.
지각·이동·제작까지 모두 격자 크기만 키우면 해결된다는 주장도 하지 않는다.

환경의 실제 상태와 에이전트가 학습할 상태 표현은 별개다.

## 2. 과제: 지연 채집과 바뀌는 의뢰

### 2.1 고정 설정

| 항목 | 기본값 |
|---|---|
| 격자 | 25×25. 바깥 테두리는 벽 |
| 시야 | 자기 중심 3×3. 절대 좌표·방문 지도 입력 없음 |
| 픽셀 | 타일 7×7×3, 기존 무늬 생성기 재사용 |
| 행동 | 동·서·남·북·상호작용·대기, 총 6개 |
| 채집처 | 8곳. 겉모습은 같음 |
| 산출물 | 4종. 처음에는 종류마다 2곳, 배정은 세계마다 독립 추첨 |
| 결과 지연 d | 느린 학습 {4,8}, 주 평가 8, 외삽 평가 16 |
| 동시 작업 | 1개. 작업 중 다른 채집처 조작은 새 작업을 만들지 않음 |
| 결과 표시 | 도착한 관측 1개에만 산출물 그림 표시. 출발지·좌표는 없음 |
| 보상 | 현재 의뢰에 맞는 산출물의 첫 도착에 +1. 그 외 0 |
| 소비·자동 이동 | 채집처는 남음. 순간 이동·자동 귀환 없음 |
| 세션 | 기본 T=4,096. T=2,048 / 16,384도 검사 |
| 초기화 | 새 세계에 들어가는 t=0 한 번만. 이후 `is_first=False` |

방향은 화면에 고정한다. 충돌은 이동 실패로 보인다.
자원 종류는 도착 전에는 채집처의 픽셀에서 알 수 없다.
같은 세계에서 채집처가 바뀌기 전에는 산출물이 결정적이다.
관측의 장식 잡음과 산출물의 불확실성을 섞지 않는다.

### 2.2 세계 생성: 경로와 주소도 이번 세계의 사실이다

구현할 첫 생성기는 다음으로 고정한다.

1. 내부 칸을 벽 확률 .15로 추첨한다. 가장 큰 연결 성분이 내부의 80% 미만이면 재추첨한다.
2. 그 성분에서 보급소와 채집처 8곳을 뽑는다.
   보급소에서 각 채집처까지 최단 거리는 6–24다.
   채집처끼리는 체비쇼프 거리 4 이상이다.
   그중 한 쌍은 실제 경로 거리 4–5로 둔다. d=8 안에 뒤 채집처 조작을 넣을 수 있어야 한다.
3. 각 채집처 옆 접근 가능한 칸 하나에 무관한 조작판을 둔다.
   조작판을 누르면 그 판의 불빛만 바뀐다. 산출물은 만들지 않는다.
4. 바닥은 12종 무늬다. 채집처 두 곳의 3×3 모양을 복사해 국소 관측을 같게 만든다.
   복사할 두 창의 벽·접근 구조도 같아야 한다. 불가능하면 위치부터 재추첨한다.
5. 두 창 바깥 거리 2–3에는 서로 다른 표지를 둔다.
   공통 방문 경로가 그 표지를 지나도록 한다. 이력으로는 구별 가능해야 한다.
   표지를 거친 접근 경로도 24스텝 이하여야 한다.
6. 마지막에 산출물의 다중집합 {0,0,1,1,2,2,3,3}을 독립적으로 섞는다.
   무늬·지형·방문 순서와 산출물 배정의 난수 스트림을 분리한다.

재추첨 기준은 에이전트 실행 전에만 적용한다.
성공한 세계만 남기거나 평가 중 경로를 쉽게 바꾸지 않는다.
훈련·검증·평가의 세계 seed 범위는 겹치지 않는다.
‘종류마다 두 곳’은 초기 데이터 생성 조건이다. 에이전트 입력에 정답 개수를 주지 않는다.
부분 변경 뒤에는 이 개수가 달라진다.
교사 행동열을 미리 만들어 §3.3의 실제 길이 상한도 확인한다.
경로·조작·대기를 모두 합쳐 넘으면 실행 전에 세계를 재추첨한다.

국소 창 두 개가 같다고 원리적으로 불가능한 과제를 만들지는 않는다.
표지 노출을 뺀 완전 대칭 세계는 별도 음성 대조다.
그 조건의 실패를 기억 알고리즘의 실패로 세지 않는다.

### 2.3 관측과 내부 정답의 경계

렌더링은 5×3 패치, 즉 35×21×3 이미지다.
아래 3×3은 세계, 위 2×3은 HUD다.
패치 인터페이스에서는 `[15,147]`이다. 이미지 CNN에는 같은 픽셀을 그대로 준다.
텍스처 seed는 0으로 고정한다. ID 0은 벽, 1–12는 바닥,
13은 채집처, 14는 조작판, 15는 보급소, 16–19는 산출물 그림이다.
20–31은 빈 칸·카드 뒷면·도장·불빛·장식에 쓴다.
ID의 의미를 모델 입력으로 주지는 않는다.

| HUD 칸 | 보이는 것 |
|---|---|
| 의뢰 카드 | 공개 의뢰이면 목표 산출물 그림. 비공개이면 같은 카드 뒷면. 의뢰 없으면 빈 칸 |
| 도착함 | 이번 관측에 도착한 산출물. 없으면 빈 칸 |
| 완료 도장 | 현재 의뢰를 완료했는가 |
| 나머지 3칸 | 고정 테두리·장식. 하나는 확률 .1로 바뀌는 무관한 무늬 |

진행 중 작업의 출발지·타이머·작업 중 여부는 HUD에 주지 않는다.
이 상태도 자신의 행동과 결과로 추론해야 한다.
이것을 제공하는 더 쉬운 대조는 가능하지만 본 관문 점수로 쓰지 않는다.
보상 스칼라와 직전 실제 행동은 모든 방법에 준다.

타일 ID, 자원 ID, 보급소 좌표, 채집처 번호는 로거 내부 정답이다.
에이전트는 그림만 받는다. 목표 역시 같은 자원 그림으로 전달한다.
평가용 `seen`, 변경 플래그, 구간 번호, 원인 행동 번호를 모델 입력에 넣지 않는다.

### 2.4 전이와 보상: 모호하지 않은 갱신 순서

환경은 에이전트에게 숨긴 `pending=(origin,item,due)` 한 칸을 갖는다.
이것은 물리 구현용이다. 에이전트의 잠재 분해를 지정하는 변수가 아니다.

스텝 t의 관측을 받은 뒤 행동 a_t를 적용한다.

1. 이전 도착 그림을 지운다. 이동이면 충돌을 반영한다.
2. 채집처 위 상호작용이고 pending이 비었으면 작업을 시작한다.
   이때의 산출물을 고정하고 `due=t+d`로 둔다.
3. pending이 차 있으면 다른 채집처 조작은 이를 바꾸지 않는다.
   조작판 상호작용은 불빛만 바꾼다. 대기는 아무 작업도 시작하지 않는다.
4. 관측 시각 t+1이 due이면 산출물이 도착하고 pending을 비운다.
   따라서 a_t로 시작한 결과는 정확히 o_(t+d)에 처음 보인다.
5. 도착 시점의 의뢰 효용을 적용한다. 맞으면 +1과 완료 도장을 낸다.
6. 보급소에서 상호작용하면 다음 의뢰를 받는다. 도장을 지운다.
   pending이 있으면 이 동작은 무효다. 의뢰 사이에서 carry를 초기화하지 않는다.

의뢰 변경 요청은 pending이 비었을 때 적용한다.
공통 경험 검사에서는 세계 변경도 작업이 없는 대기 중에 한다.
자율 실행에서 작업 도중 세계가 바뀌면 이미 시작한 작업은 시작 시점의 산출물을 낸다.
변경 뒤 시작한 첫 작업부터 새 산출물이 나온다.
목표 전환은 선호 변화다. 채집처 변경은 물리 사실 변화다.
둘의 시간과 위치를 훈련에서 독립적으로 무작위화한다.

의뢰 하나당 보상은 한 번이다. 같은 의뢰에서 같은 채집처를 눌러 점수를 쌓지 못한다.
반복 비공개 의뢰는 보급소로 돌아와서 요청한다.
외부에서 온 공개 목표 변경은 HUD로 바로 전달된다. 둘 다 훈련에서 경험하는 일반 규칙이다.
공개 검사에서 목표를 바꿀 때도 새 의뢰로 도장을 지운다.
의뢰가 없어도 표본은 채집할 수 있다. 사전 관찰은 보상 없이 가능하다.

### 2.5 두 종류의 새 목표

**공개 의뢰:** 현재 원하는 자원의 그림을 준다.
예전에 보상 0으로 보았던 자원도 즉시 찾아야 한다.
현재 목표와 일치하는가가 효용의 의미다. 특정 경로의 가치를 알려 주는 입력은 아니다.

**비공개 의뢰:** 카드 뒷면은 같다. 보상으로 지금 무엇이 좋은지 알아낸다.
의뢰 효용은 4종 중 하나만 +1인 함수다. 느린 학습에서 이 가족은 경험한다.
평가에서 새 종류의 양성 보상 한 번은 이 가족 안에서 현재 효용을 식별한다.
임의의 미지 보상 함수를 한 번의 스칼라로 복원한다는 주장은 아니다.

훈련에서 4종 모두 산출물로 보인다. **양성 보상은 종류 0·1에만 준다.**
평가의 B는 {2,3}에서 균등 추첨한다. C는 나머지 미보상 종류다.
A는 {0,1}에서 추첨한다.
새 지각 개념 학습과 이미 본 것의 새 보상화를 분리한다.
새 모양까지 주는 외삽은 이번 주 판정에 섞지 않는다.

## 3. 한 세션의 시험 순서

### 3.1 같은 경험을 주는 통합 검사

이것은 기억의 기회를 보장하는 검사다.
교사는 경로와 행동만 정한다. 에이전트는 자신의 실제 행동을 받고 평소처럼 갱신한다.
교사 경로의 source ID와 정답 표는 넘기지 않는다.
검사 사이에 θ, 상태 믿음, 시냅스, 공분산, 흔적을 초기화하지 않는다.

| 구간 | 같은 세계에서 일어나는 일 | 다음 선택에 필요한 것 |
|---|---|---|
| 관찰 | 의뢰 없이 8곳을 각 1회 방문. 모든 지연 산출물을 봄 | 보상 없는 사실 기억 |
| 익숙한 의뢰 | 비공개 A 의뢰 4회. 같은 A 채집처를 반복 이용 | 가치 캐시에 유리한 이력도 제공 |
| 새 보상 | 비공개 B 의뢰. B 채집처 b0에서 산출물과 첫 +1을 1회 봄 | 효용을 즉시 바꾸고 과거 B 사실을 읽음 |
| 보존 | 보급소 주변의 장식·이동·조작을 D스텝 겪음. 채집처 결과는 없음 | 중요한 사실을 방해와 시간 너머 유지 |
| 부분 변경 | 대기 중 b0의 산출물만 B→C. 카드·타일 모양은 그대로 | 변경 전에는 알 수 없어야 함 |
| 변경 증거 | b0를 1회 재방문. 이동·무관한 조작 뒤 C와 보상 0을 봄 | 이 결과를 b0에 귀속. 다른 주소는 보존 |
| 핵심 선택 | B 의뢰를 계속 수행. 첫 유효 채집 행동은 자율 | 처음 관찰한 다른 B 채집처 b1을 재사용 |
| 이후 | 공개 A/B/C 의뢰를 섞어 총 16개 기회 제공 | 수정한 사실과 보존한 사실을 함께 이용 |

b1에서는 초기 관찰 때 보상 0인 산출물을 보았을 뿐이다.
B 보상도 변경 뒤의 새 관찰도 b1에 주지 않는다.
그러므로 b0의 최근 양성 가치만 저장해서는 핵심 선택을 맞히기 어렵다.
다른 종류는 여러 곳에 있으므로 ‘예전에 보상받은 곳 말고 아무 곳’도 통하지 않는다.

각 채집 작업 뒤 교사 경로에는 산출물 도착 전 무관한 상호작용을 넣는다.
보급소로 돌아오는 도중 결과가 도착하도록 한다.
d=8에서는 인접 조작판 조작과 다른 채집처의 작업 중 조작을 나누어 사용한다.
후자가 불가능한 지형에서는 조작판을 사용하고, 로거에 그 비율을 남긴다.
별도 공 배정 분기 검사에서는 두 종류 모두 충분히 넣는다.
첫 B 완료 뒤에는 보급소에서 **새 비공개 B 의뢰**를 받는다.
완료 도장을 지우고 D를 시작한다. 변경 재관찰의 0보상이 완료 도장 때문이어서는 안 된다.
보존 구간은 같은 보급소 주변 경로를 반복한다. 새 채집처나 새 사실은 추가하지 않는다.
순수 대기만 하는 짝 대조로 시간 경과와 반복 방해의 효과도 분리한다.

교사 방문 순서는 매 세계 섞는다.
노출 순서로 종류를 맞히거나 고정된 몇 번째 행동을 원인으로 쓰지 못하게 한다.
‘남은 곳 방문’처럼 다음 행동이 이력상 완전히 예측되는 방문도 절반 포함한다.
행동 확률이 1이어도 실제 산출물을 만든 행동이다.

### 3.2 목표만 바꾸는 A→B→A 검사

초기 관찰 직후, B의 첫 양성 보상 뒤, 변경 증거 뒤에 각각 snapshot을 둔다.
각 snapshot의 물리 상태·carry를 복제한다.
**동일한 출발 snapshot에서** 공개 목표 A, B, A를 각각 물어본다.
C 및 네 번째 종류의 질문도 함께 한다.
순서를 섞은 B→A→B 대조를 같은 수만큼 둔다.

순수 질문은 환경 시간을 진행시키거나 새 관측으로 쓰지 않는다.
목표별 행동을 계산할 때 쓴 일시적 recurrent carry는 버린다.
원본 carry와 빠른 사실 기억의 바이트가 그대로인지 검사한다.
GRU·Dreamer도 같은 원본 carry에서 각 목표 그림을 처리할 기회를 받는다.
반환 행동만을 위해 필요한 고정 계산은 모두 센다.
질문 API는 사실 갱신을 호출하지 않는다. 목표 그림은 현재 선호 입력으로만 바꾼다.
목표 조건부 GRU·Dreamer에는 같은 목표 그림의 공유 임베딩을 정책 입력에도 연결한다.
이 입력 경로는 훈련부터 사용한다. 평가 때 새 목표 해석 머리를 붙이지 않는다.

한 이동 행동만으로 어느 채집처를 고른 것인지 단정하지 않는다.
각 분기에서 최대 64스텝 실제로 움직여 **처음 시작한 채집 작업의 출발지**를 채점한다.
그 전의 다른 산출물은 없고, 새 결과를 이용한 재선택은 첫 선택 점수에 들어가지 않는다.
이 분기에서 얻은 경험은 원래 세션에 합치지 않는다.
먼저 물어본 B가 원래 비공개 의뢰의 정답을 누설하지도 않는다.

같은 A 질문의 행동 분포가 돌아오는가와 A·B의 목적지가 각각 맞는가를 함께 본다.
목표를 왕복했을 때 같은 오답이 돌아오는 것은 적응 성공이 아니다.
같은 snapshot의 같은 질문이 같은 분포를 내는 것은 구현 일관성 검사다.
능력의 증거는 각 목표의 첫 목적지가 실제로 맞는가다.

### 3.3 길이 예산과 변경 시각

관찰 8회 + A 4회 + 첫 B 1회, 총 13회 작업을 쓴다.
각 회의 교사 경로는 `2×24 + d + 3`스텝 이하로 생성한다.
d=8이면 767스텝 이하다. 앞 구간을 896스텝으로 고정하고 남는 칸은 보급소 대기로 채운다.
끝 구간은 변경 재관찰 64 + 자율 의뢰 16×64 = 1,088스텝, 예산 1,152 이하다. [유도]

| T | 중간 보존 D=T−2,048 | 의미 |
|---|---:|---|
| 2,048 | 0 | 짧은 세션 대조 |
| 4,096 | 2,048 | 주 판정 |
| 16,384 | 14,336 | 훈련 세션 길이 밖 보존 |

d=16의 앞 구간도 871스텝 이하라 같은 예산을 쓴다.
남는 끝 구간은 대기로 채운다. 목표 질문 분기는 주 세션의 시간을 쓰지 않는다.
분기 평가의 환경 스텝과 계산량은 평가 비용으로 따로 보고한다.

변경은 중간 대기 중 균등한 시각에 한다. D=0에서는 변경 방문 직전에 한다.
그 위치와 시각은 입력에 없다. 변경 유무를 짝지은 대기 관측은 완전히 같아야 한다.
변경 전후를 나타내는 `done`, `reset`, 모델 호출 차이도 없다.

64스텝 내에 의뢰를 완료하지 못하면 그 기회는 실패다.
다음 기회를 위해 순간 이동시키지 않는다.
교사는 준비 구간에서만 개입한다. 자율 구간의 실제 위치와 실패를 그대로 이어간다.
다음 공개 의뢰는 정해진 기회 경계에서 제공하되 pending이 비면 적용한다.
경계에 pending이 있으면 완료까지의 지연도 해당 기회 예산에 포함한다.
이 평가 기회 변경은 세계·기억의 초기화 신호가 아니다.

### 3.4 처음부터 자율적인 실행도 최종 관문에 포함

공통 관찰만 통과하면 ‘주어진 경험을 활용한다’까지 말할 수 있다.
‘스스로 처음 들어간 세계에서 배운다’는 결론에는 다음 실행도 요구한다.
환경·모델·가중치는 같다. 교사 행동만 없앤다.

T=4,096을 고정한다. 0–1,023에는 A, 1,024 이후에는 비공개 B 의뢰를 준다.
같은 종류의 다음 의뢰는 보급소에서 받는다.
2,048–2,559 중 추첨한 시각에 B 채집처 하나를 C로 바꾼다.
3,072부터는 공개 A/B/C 의뢰를 64스텝 기회로 섞는다.
시간·전환표는 모델 입력에 주지 않는다. 느린 학습에서도 이 시간표는 사용하지 않는다.

첫 B 양성 보상의 시각 τ+와 변경 뒤 시작한 작업의 첫 C 도착 시각 τc를 로그에 남긴다.
그 증거를 얻기 전에는 새 효용·변경 내용을 안다고 요구하지 않는다.
다만 증거를 얻지 못한 실행을 빼고 자율 성공률을 계산하지도 않는다.
전체 성공률, 탐색으로 증거를 얻은 비율, 증거 뒤 적응률을 모두 낸다.

각 요구가 필요한 기회를 자기 경험으로 만들었는지도 센다.
특히 B의 양성 보상 전에 다른 B 위치를 보았는지,
변경 뒤 아직 유효한 곳을 재발견 없이 재사용했는지를 센다.
검사 가능한 경험이 부족하면 자율 관문은 미통과다. 관찰을 강제로 보충해 성공으로 바꾸지 않는다.

## 4. 측정과 인과 개입

### 4.1 공통 행동 지표

`Acc(g)`는 목표 g를 물었을 때 64스텝 안에 처음 시작한 작업의 산출물이 g인 비율이다.
잘못된 곳에서 먼저 작업하면, 나중에 맞혀도 이 지표는 0이다.
계속 대기하거나 작업을 시작하지 못해도 0이다.
경로 탐색과 사실 선택을 혼동하지 않도록 정답 주소 선택과 이동 성공을 따로 로그에 남긴다.

우연 기준 b는 해당 시점 실제 산출물별 채집처 비율이다.
초기에는 2/8이다. B→C 뒤 B는 1/8, C는 3/8이다.
`S=(Acc−b)/(1−b)`도 보고하되 주 판정은 원래 Acc로 한다.
공개된 숫자 b를 에이전트가 사용하는 것은 아니다.

같은 정보 이력을 받은 정답 기억 에이전트의 완료 스텝을 L*라 둔다.
성공까지 실제 스텝 L, 후회 `L−L*`, 제한 시간 내 완료율을 함께 낸다.
정답 상한이 모르는 미관찰 변경을 미리 피하는 경로는 L*에 쓰지 않는다.
평균 보상은 보조 지표다. 첫 선택·보존·수정을 대체하지 않는다.

### 4.2 요구별 핵심 측정

| 요구 | 주 지표 | 최소 개입 |
|---|---|---|
| 기억 | 무보상 관찰 사실을 새 목표에 재사용한 첫 선택 Acc. D별 저하 | 사실 기억 삭제, 같은 지도에서 산출물 내용만 바꾼 기억 교환 |
| 공 배정 | 지연 뒤 원인 채집처의 예측·다음 선택 정확도. 최근 무관한 주소로의 오귀속률 | 원인 조작 생략/교환, 뒤 조작 생략/교환, 믿음의 흔적 차단 |
| 새 보상·목표 | τ+ 뒤 경사 0회의 첫 B 선택. 양성 보상 전 공개 B 선택. A→B→A 정확도 | 목표만 교환, 효용 추론만 고정, 가치 캐시와 사실 기억을 따로 교환 |
| 증거 망각 | b0의 새 C 이해, b1의 B 보존, 다른 6곳의 재사용. 증거 전후 차이 | 변경 없는 짝 세계, 전역 초기화·시간 감쇠·증거 수정 대조 |

변경 b0를 C로 이해했는지는 ‘B에서 피했다’만으로 판정하지 않는다.
b0에 서 있는 동일한 물리 snapshot에서 공개 C를 물어본다.
다른 C 채집처는 4스텝 이상 떨어져 있다.
현재 채집처에서 즉시 작업하는 비율과 C 예측을 기록한다.
틀린 곳을 블랙리스트에 넣기만 하는 방법과 실제 내용을 수정하는 방법을 가른다.

미변경 사실 보존은 한 종류의 쉬운 채집처 하나만 고르는 것으로 판정하지 않는다.
원래 snapshot을 복제해 채집처별 공통 접근 경로를 실제로 걷고,
산출물을 새로 보지 않은 채 맞는 목표와 틀린 목표를 각각 물어본다.
맞는 목표이면 그곳에서 작업하고, 틀린 목표이면 그곳을 건너뛰어야 한다.
변경 없는 짝과 비교해 미변경 7곳의 주소별 첫 선택 저하를 계산한다.
자원 예측을 제공하는 모델은 그 예측도 기록하되 진단 전용 분류 머리는 만들지 않는다.

### 4.3 공 배정에 필요한 짝 개입

평가자가 같은 checkpoint와 같은 난수에서 분기한다.
기본 분기는 ‘원인 채집처 조작 → 이동 → 뒤 조작 → 공통 도착 장소’다.
두 원인 후보의 경로 길이를 대기로 맞춘다. 뒤 장면과 뒤 조작은 같게 한다.
결과 도착 시 눈앞의 채집처나 조작판을 원인으로 외우면 오답이 된다.

| 분기 | 환경의 참 인과 관계 | 기대하는 변화 |
|---|---|---|
| 원인 조작을 대기로 바꿈. 뒤에는 조작판만 누름 | 작업 자체가 없음 | 예정 시각의 산출물·보상이 사라짐 |
| 원인 조작 생략. 뒤에는 다른 채집처를 누름 | 뒤 조작이 새 원인이 됨 | 뒤 채집처의 산출물이 그 행동 d스텝 뒤에 도착하고 그곳에 귀속 |
| 원인 채집처를 바꿈 | 산출물이 바뀔 수 있음 | 결과는 바꾼 원인 주소에 저장되어야 함 |
| 뒤 조작만 생략 | 산출물은 같음 | 원인 주소의 학습과 다음 선택은 보존 |
| 뒤 조작의 장소만 교환 | 산출물은 같음 | 그 장소에 잘못된 사실이 생기지 않아야 함 |
| 방문 순서만 예측 가능하게 만듦 | 물리 인과는 같음 | 행동 놀라움이 0이어도 공 배정이 유지 |

원인 행동을 생략하면 해당 결과가 없어지는 것은 환경 구현의 검사이기도 하다.
뒤에 실제 채집처를 누른 분기는 뒤 조작이 새 작업을 만들 수 있다는 규칙까지 반영한다.
항상 첫 상호작용에 쓰는 지름길도 이 분기에서 드러난다.
그 사실만으로 모델이 원인을 배웠다고 결론 내리지 않는다.
개입 뒤 실제 기억 읽기와 다음 재사용까지 맞아야 한다.
상호작용 버튼을 가장 최근 눌렀다는 규칙과, 가장 큰 관측 오차에 쓰는 규칙도 대조한다.

모든 행동이 개입이라고 해서 모든 행동이 결과의 원인은 아니다.
여기서는 무작위로 정한 행동 분기가 식별 자료를 준다.
F를 최소화한다는 선언만으로 그 인과 관계를 배웠다고 보지 않는다.

### 4.4 기억 자체에 하는 개입

동일 지도·무늬·행동열, 서로 다른 산출물 배정으로 학습한 쌍을 만든다.
질문 직전에 물리 상태는 유지하고 빠른 사실 파라미터를 교환한다.
공동 사후를 쓰면 그 파라미터에 속한 정밀도·교차 통계도 일관되게 교환한다.
단순히 행렬을 깨뜨린 개입과 구별한다.

판정은 성능 하락만이 아니다.
**받은 내용에 맞는 다른 채집처로 선택이 이동하는가**를 검사한다.
주소 대응이 불분명한 잠재에서는 먼저 입력 경험의 산출물 교환으로 방향을 검증한다.
잠재 정렬이 실패한 파라미터 교환의 붕괴를 기억 기여의 증거로 삼지 않는다.

빠른 시냅스만 삭제, recurrent carry만 삭제, 둘 다 삭제를 분리한다.
삭제 후에도 recurrent carry가 모든 사실을 갖고 있으면
그 실행은 세션 안 기억의 증거일 수 있지만 시냅스 기억의 필요성을 보인 것은 아니다.
흔적은 결과가 도착하기 직전에만 차단한다.
이미 저장된 사실 기억을 지우는 개입과 섞지 않는다.

### 4.5 증거로만 고친다는 것의 조작적 뜻

변경 세계와 변경 없는 세계를 같은 행동·난수로 짝짓는다.
b0의 새 결과를 보기 전에는 이미지·보상이 같아야 한다.
그때의 행동 분포도 같아야 한다. 차이가 나면 정답 누출이다.

관측 없는 동안 평균 사실 내용이 시간 때문에 지워지는지도 검사한다.
위험률 때문에 불확실성이 커지는 것과, 내용을 0으로 감쇠하는 것은 구별한다.
정당한 불확실성 증가 자체를 실패로 세지 않는다.
새 증거 뒤에는 b0의 내용이 바뀌고, b1 및 다른 사실의 재사용은 유지되어야 한다.

목표 변경만으로 세계 사실이 초기화되면 실패다.
새 효용을 배운 것은 허용한다. 그것을 지형 변화와 동일시하지 않는다.
사실·효용·관측 잡음의 원인이 구별되지 않는 모형의 한계는 그대로 드러내야 한다.

## 5. 비교군

모든 비교군은 같은 픽셀·행동·보상을 받는다.
평가 준비 경로, 분기 snapshot, 난수, 의뢰 순서도 짝짓는다.
수동 좌표·정답 종류를 받는 방법은 정답 상한으로만 분류한다.

| 이름 | 구성 | 가르는 것 |
|---|---|---|
| 무작위 / 반응형 | 무작위, 픽셀 MLP 정책 | 과제 난이도와 관측 누출 |
| GRU / RL² | 목표·직전 행동·보상을 받는 GRU 128, 512 두 크기 | 순전파 활성 상태만으로 가능한 범위 |
| Dreamer 고정 | 실제 RSSM·정책·가치·보상 모델, θ 고정. RSSM carry는 계속 갱신 | 경사 없는 기존 세계 모델의 능력 |
| Dreamer 경사 적응 | 위와 동일한 시작점, 새 보상 관찰 뒤 경사 갱신 | 필요한 갱신·데이터·시간 비용 |
| tdpc 가치 캐시 | 동일 주소 표현, 스칼라 TD(λ) 기억 | 이전 보상 가치만 빠르게 쌓는 경우 |
| 목표별 가치 은행 / HER | 고정 크기의 목표 조건부 표, 관찰한 결과를 목표별로 재표기 | 단일 가치 캐시를 약하게 잡아 생기는 허위 우위 방지 |
| SF + 빠른 효용 | 벡터 후속 특징, 즉시 학습하는 효용 계수, 고정 정책 집합의 GPI | 기존의 보상 분리만으로 충분한가 |
| 단순 사실 KV | 학습된 주소, 고정 지수 흔적, Hebb 또는 delta/RLS, 현재 목표로 읽기 | 복잡한 공동 추론이 필요한가 |
| ours / ours_surp 이식 | 이전 RLS 계열, 행동 놀라움 가중 유무 | gate의 성공 조건이 자율 세계에서도 남는가 |
| F 기반 빠른 세계 모형 | 세션 안 행동 조건부 사실 추론·믿음의 흔적·현재 선호 읽기 | 앞 문서의 연구 후보 |
| 관찰 기억 상한 | 경험한 사실만 정확히 기억. 정답 위치·원인 ID로 저장 | 추론/주소 오류를 없앤 같은 정보 상한 |
| 전지 상한 | 미관찰 변경·효용도 앎 | 생성기·보상·최단 경로 검사. 공정 성능 비교에는 제외 |

단순 KV는 사실을 모든 스텝에 쓰는 판과 예측 오차·정밀도로 쓰는 판을 비교한다.
주소가 현재 장면만 보는 판과 일반 상태 믿음을 보는 판도 구별한다.
`ours_surp`의 행동 확률은 같은 훈련 행동열의 이력 조건부 행동 예측자로 얻는다.
현재 정책 확률과 교사의 강제 행동 확률을 혼동하지 않는다.
평가 시각별 정답 빈도 표는 주지 않는다. 행동 놀라움은 비교 대상 편향이지 권고한 쓰기 규칙이 아니다.
태스크별 `if source`, `if receipt`, `if choice`로 입력을 거르는 판은 진단 상한이다.
현재 ours의 스텝별 세계 평균·분산 표도 새 환경의 후보에게 주지 않는다.
쓸 경우 ‘이상적 느린 모델’ 상한으로 따로 적는다.

고정 용량의 에피소드 기억이나 관측으로 만든 위상 지도도 합법적인 단순 대안이다.
관측을 셀 좌표로 변환한 정답 지도를 주어서는 안 된다.
용량·검색·계획 상한을 공개하고, 같은 픽셀에서 주소를 얻어야 한다.
이 방법이 네 요구를 통과하면 더 복잡한 가소 모형의 필요성이 줄어든다.

### 5.1 Dreamer를 잘못 대조하지 않는다

공식 구현의 `policy()`는 매 관측에 RSSM을 갱신하고 그 특징으로 행동한다.
따라서 **가중치 고정 ≠ 기억 없음**이다. [확인]
새 목표나 보상을 recurrent state로 처리할 가능성도 실험한다.
‘Dreamer는 어떤 새 목표도 경사 없이는 절대로 처리하지 못한다’는 명제를 전제하지 않는다.
다만 새로운 보상 함수를 느린 보상·정책·가치 가중치로 학습하는 적응 비용을 측정한다.
근거: [공식 agent.py](https://github.com/danijar/dreamerv3/blob/main/dreamerv3/agent.py).

작은 과제의 주 대조는 공식 `size1m` 설정이다.
픽셀 입력 크기와 6행동, 목표/비공개 카드, 직전 보상 관측을 맞춘다.
보상 스칼라는 모든 방법이 받도록 RSSM 입력에도 명시적으로 연결한다.
이는 기본 관측에서 reward를 제외하는 구현에 대한 공개된 비교 조건이다.
목표 조건부 판에는 목표 그림을 모든 훈련 의뢰에서 같은 방식으로 제공한다.
`size12m`은 크기에 따른 음성 결과인지 확인하는 확대 대조다.
Minecraft 크기 모델과 같다고 부르지 않는다.
설정 근거: [공식 configs.yaml](https://github.com/danijar/dreamerv3/blob/main/dreamerv3/configs.yaml).

새 보상 첫 증거 이후 같은 snapshot에서 갱신 수
`K={0,1,4,16,64,256}`을 각각 시험한다.
한 갱신은 실제 최적화기 호출 1회, 배치 16×길이 64로 고정한다.
모델·보상·행동·가치의 최적화기 호출을 따로 세고 합계도 낸다.
한 번 학습 함수 호출을 여러 최적화기 갱신과 혼동하지 않는다.

두 적응 곡선을 낸다.

- **같은 자료:** τ+까지 관찰한 고정 길이 4,096 replay만 재사용. 이후 자료는 사용하지 않음.
- **온라인 자료:** 이후 새 환경 스텝 `E={0,64,256,1,024,4,096}`도 허용.
  데이터 수집 중 받은 보상과 소요 시간까지 비용으로 셈.

보상 decoder와 actor·critic만 갱신하는 판, 세계 모델까지 갱신하는 판을 분리한다.
기존 replay의 과거 보상을 새 보상으로 몰래 재표기하지 않는다.
공개 목표에 대한 합법적 hindsight 재표기는 별도 강한 대조에 허용한다.
새 보상이 무엇인지 비공개 상태에서 정답 w를 주는 것은 금지한다.
목표 Acc .85에 처음 도달한 `(K,E,벽시계 시간)`을 낸다.
도달하지 않으면 예산 초과로 보고한다. 유리한 종료점만 보고하지 않는다.

## 6. 에이전트의 최소 구성과 제거 검사

이 절은 새 알고리즘을 완성했다고 주장하는 절이 아니다.
과제를 통과할 후보가 제공해야 할 기능을 고정한다.
`insession_design.md`의 공동 믿음 필터는 한 구체 후보다.
그 필터의 성공·고정 계산 읽기·느린 학습 가능성은 아직 확인되지 않았다.
실험 설계가 이 빈칸을 손으로 만든 채집처 키로 메워서는 안 된다.

| 구성 | 느린 쪽 / 빠른 쪽의 최소 역할 | 필요한 요구 | 제거하면 예상되는 실패 [가설] |
|---|---|---|---|
| 일반 픽셀 표현과 상태 추론 | 느린 표현·일반 전이. 빠른 이력 믿음. 숨은 상태는 학습된 하나의 공간 | 기억·공 배정 | 같은 창의 두 장소 혼동 |
| 행동 조건부 사실 모형 | 느린 물리 사전. 이번 지도·산출물·전이는 빠른 KV 충분통계 | 기억·새 목표 | 방문했던 곳도 새 목표에 재사용 불가 |
| 결과까지 남는 인과 문맥 | 모형에서 나온 상태 민감도·공분산 흔적 또는 동등한 충분통계 | 공 배정 | 결과 도착 장소·뒤 조작에 잘못 씀 |
| 현재 효용의 추론/입력 | 공개 목표는 즉시 입력. 비공개 효용은 세션 안 증거로 갱신 | 새 보상 | 과거 A 값만 따라감 |
| 현재 선호로 결정하는 읽기 | 빠른 사실에서 고정 예산의 예측/후속 특징을 읽음 | 새 목표 | A→B→A 왕복이 느린 가치 재학습에 의존 |
| 국소 정밀도·변화 추론 | 일반 잡음·위험률 사전. 새 증거가 해당 통계를 수정 | 증거 망각 | b0 고집 또는 b1까지 삭제 |

이 여섯 기능이 여섯 개 별도 신경망을 뜻하지 않는다.
하나의 상태공간 모형과 그 충분통계로 겹치는 기능을 수행할 수 있다.
별도 중요도 머리·사실 선택 손실·수동 쓰기 문턱은 넣지 않는다.
흔적 없이 충분한 상태 믿음으로 결과를 올바르게 귀속한다면,
별도 지수 흔적을 추가할 필요도 없다. 반대로 오래 기다렸다는 이유로 사실 M을 감쇠하지 않는다.

F 기반 후보의 감사 대상은 다음이다.

\[
p_\theta(s_{t+1},o_{t+1},r_{t+1}\mid s_t,a_t,M,u),
\qquad
F_t=\mathbb E_{q_t}[-\log p_\theta(o_t,r_t\mid s_t,M,u)]
+D_{\rm KL}(q_t\Vert q^-_t).
\]

M은 이번 세계의 사실, u는 현재 효용에 대한 빠른 통계다.
q_t는 현재의 공동 믿음이다. q^-_t는 이전 믿음과 행동 조건부 전이,
일반 변화 사전에서 예측한 믿음이다.
둘은 의미 상태를 손으로 ‘문/장면’으로 나누라는 지시가 아니다.
모형이 물리 결과와 선호를 구별해야 한다는 확률적 역할이다.
관측 외적과 오차 계수, 정밀도 갱신이 이 모형의 어떤 조건부 추론인지 명시해야 한다.
수치 경사는 느린 훈련에만 쓴다. 평가 쓰기는 도출한 폐형식·재귀 통계의 순전파다.
반복된 증거·장식 잡음·새 산출물에서 쓰기 계수가 어떻게 달라지는지 기록한다.
정밀도를 상수로 고정한 제거 검사로 그 통계의 필요성을 확인한다.
큰 오차이면 무조건 크게 쓰는 문턱을 추가하지 않는다.

예를 들어 공동 가우시안 후보에서는 믿음의 흔적이

\[
E^-_t=A_tE^+_{t-1}+G_tP_{MM},\qquad
\Delta M\;\propto\;(E^-_t)^\top C^\top S_t^{-1}(x_t-\hat x_t)
\]

형태다. G는 실제 행동을 조건으로 한 전이의 민감도다.
`−log p(a)`가 아니다. 정확한 차원·모멘트·근사 한계는 앞 문서 4–5절을 따른다.
원시 지수 흔적 위 RLS를 F라고 다시 이름 붙이는 것만으로 모형 오지정이 고쳐지지는 않는다.

선호 재평가의 단순 대조는
`Q_u(h,a)=ψ(h,a)ᵀu`다. 여기서 ψ는 보상과 분리한 후속 특징이다. [표준]
ψ의 정책 의존성과 학습한 특징 범위를 명시한다.
한 행동 정책의 ψ가 모든 새 목표의 최적 정책을 보장한다고 쓰지 않는다.
고정 수 정책의 GPI 또는 정해진 횟수의 짧은 계산을 허용한다.
긴 세션 때문에 탐색 깊이·반복 횟수가 늘면 본 요구를 어긴다.
근거: [Successor Features for Transfer](https://arxiv.org/abs/1606.05312).

### 6.1 느린 학습의 허용 범위

훈련 세션은 최대 512스텝이다. BPTT 조각은 64다.
조각 사이 forward carry는 유지한다. 긴 평가 대기까지 역전파할 수는 없다.
짧은 범위의 일반 동역학·표현을 배우고 긴 보존은 빠른 메커니즘이 담당하는지 검사한다.

세계는 매번 새 지도·새 산출물 배정이다.
채집처 수는 {4,6,8}, 지형 크기는 {15,21,25}, 지연은 {4,8}로 섞는다.
반복 무늬·작업 중 조작·무관한 조작·독립적인 한 곳 변경을 모두 경험한다.
종류마다 두 곳인 조건은 평가용이다. 훈련은 중복 개수도 섞는다.
훈련 의뢰 순서·전환·변경 시각은 무작위다. 평가의 고정 구간표는 학습하지 않는다.
평가의 d=16, T>512, 종류 2·3의 양성 보상은 학습 자료에 없다.

F 기반 후보의 느린 목적은 관측·행동 조건부 생성 모형과 그 추론이다.
평가의 특정 경로 가치나 보상 순위는 느린 가중치에 저장하지 않는다.
일반 선호를 받아 움직이는 능력과 지역 이동은 배울 수 있다.
지도 좌표, 채집처 ID, 미래 필요 순서로 감독하지 않는다.
Dreamer·GRU·TD 비교군의 가치 학습은 비교 대상으로 허용하고 명시한다.

한 최종 checkpoint를 모든 T·목표·변경 조건에 재사용한다.
읽기나 수정에 실패했다고 평가 전용 머리, 손실, 경로 템플릿을 추가하지 않는다.
같은 과제에서 더 오래 훈련할 경우 새 실험 버전으로 사전 등록한다.

## 7. 사전 예측과 실패 기준

### 7.1 표본과 판정 규칙

훈련 seed 5개를 고정한다. 세계는 seed마다 평가용 256개다.
훈련 seed는 0–4, 검증 세계 seed는 50,000–50,255로 고정한다.
훈련 seed s의 평가 세계는 `100,000 + 1,000s + i`, i=0–255다.
훈련 세계는 별도 접두 난수 스트림을 써서 이들과 겹치지 않게 한다.
공통 경험 검사는 모든 T, d=8에서 한다. d=16은 T=4,096에서 추가한다.
완전 자율 검사는 T=4,096에서 같은 256개 세계로 한다.
주장에는 5개 seed를 모두 포함한다. 최고 seed·최고 checkpoint를 고르지 않는다.
세계와 개입은 방법 간 짝짓는다. seed별 값, 전체 평균, 계층적 부트스트랩 95% CI를 낸다.

아래 기준은 성능 예측이자 통과 기준 [가설]이다.
주 성공 지표는 CI 하한, 허용 저하량은 CI 상한으로 판정한다.
예외는 결정적 동일성 검사와 예산 검사다.

| 검사 | 실행 전에 고정할 기준 |
|---|---|
| 무보상 사실 재사용 | 초기 공개 B·C 및 오래된 사실의 첫 선택 Acc≥.85 |
| 지연 공 배정 | d=8 Acc≥.85, 뒤 무관한 주소로의 오귀속≤.10 |
| 예측 가능한 원인 | 방문 순서가 예측 가능해져도 Acc 저하≤.05 |
| 뒤 행동 개입 | 뒤 조작 생략·장소 교환에 따른 원인 재사용 Acc 저하≤.05 |
| 한 번의 새 보상 | 첫 B 양성 증거 1회 뒤, 경사 0회 첫 B 선택 Acc≥.85 |
| 목표 왕복 | A·B 각 Acc≥.85. 같은 A 질문의 총변동거리≤10⁻⁶. 원본 사실 통계 불변 |
| 변경 내용 수정 | 새 증거 1회 뒤 b0에서 C 선택≥.90 |
| 핵심 결합 선택 | 변경 뒤 B의 첫 작업이 보존된 b1인 비율≥.85 |
| 국소 보존 | 다른 사실 재사용 Acc의 변경 없는 짝 대비 저하≤.05 |
| 긴 보존 | T=2,048→16,384에서 같은 유효 사실 부하의 Acc 저하≤.05 |
| 더 긴 결과 지연 | d=8→16에서 공 배정 Acc 저하≤.10 |
| 증거 전 동일성 | 변경 유무 짝의 입력 및 행동 분포 차이≤10⁻⁶ |
| 순전파·예산 | θ hash 불변, 최적화 0회, carry와 최대 호출 수의 T 의존 증가 0 |

위 수치는 이미 확인된 성능이 아니다. 단순 방법도 넘기 어려울 수 있다.
기억 삭제로 모든 수행이 무너지는지도 무조건 요구하지 않는다.
대신 빠른 시냅스가 핵심이라는 주장은 내용 교환의 방향성과 삭제 효과가 함께 뒷받침해야 한다.
효과가 없으면 가소성 기여는 입증되지 않은 것으로 적는다.

### 7.2 같은 실행에서의 결합 성공

각 세계에서 다음 네 개의 지정된 첫 선택을 뽑는다.

- 초기 관찰에서만 본 무보상 종류의 공개 목표 선택.
- 무관한 뒤 조작을 포함한 지연 결과 뒤 원인 사실 재사용 선택.
- 첫 B 양성 보상 뒤의 첫 B 선택.
- 변경 증거 뒤 b1로 가는 첫 B 선택.

질문 분기는 같은 지속 세션의 각 snapshot에서 시작한다.
네 개를 모두 맞힌 세계의 비율을 `J`로 정의한다.
주 공통 경험 조건에서 `J≥.60`을 요구한다.
각 요구의 개별 기준도 모두 넘어야 한다. J로 나머지 실패를 상쇄하지 않는다.

자율 실행은 다음을 함께 요구한다.

| 항목 | 기준 [가설] |
|---|---|
| 경험 기회 확보 | 3,072스텝까지 위 네 요구를 채점할 자기 경험을 확보한 실행≥.80 |
| 증거 뒤 적응 | τ+·τc 뒤 처음 가능한 B 선택 각각 Acc≥.85 |
| 실제 수행 | 마지막 공개 의뢰 구간의 제한 시간 내 완료율≥.75 |
| 결합 | 자기 경험만으로 네 선택을 모두 맞힌 실행 J_auto≥.50. 기회 미확보도 실패에 포함 |

자율 조건이 실패하면 결과는 ‘공통 경험을 받은 기억 장치’까지다.
Minecraft로 넘어갈 관문은 통과하지 못한다.
조건부 적응은 좋아도 탐색이 실패한 경우와, 관찰 후에도 쓰기·읽기가 실패한 경우를 구별한다.

### 7.3 방법별 사전 예측

| 방법 | 예측 [가설] | 반증되면 바꿀 판단 |
|---|---|---|
| 반응형 | 관측이 같은 원인 분기와 오래된 사실에서 실패 | 성공하면 정답 누출·지형 상관부터 검사 |
| GRU / 고정 Dreamer | 짧은 세션에서 적응할 수 있음. 긴 보존·새 효용 동시 조건이 관건 | 모두 통과하면 가소성의 필요성을 주장하지 않음 |
| 스칼라 TD 캐시 | A 반복은 유리. 무보상 B와 변경 뒤 b1에서 약함 | 통과하면 내부 보상 분리·배제 추론 여부 확인 |
| 목표 은행 / SF | 새 목표 적응은 강할 수 있음. 지연 오귀속과 국소 수정은 별도 문제 | 전부 통과하면 더 단순한 기존 방법을 채택할 근거 |
| ours_surp | 예측 가능 방문에서 이득이 줄 수 있음 | 유지되면 ‘행동 놀라움이면 반드시 실패’라는 강한 주장을 기각 |
| F 기반 후보 | 네 요구의 결합을 목표로 함. 성공은 미확인 | 공 배정 실패를 느린 평가 그래프 학습으로 복구하지 않음 |
| Dreamer 경사 적응 | 갱신·경험을 허용하면 일부 회복할 수 있음 | 적은 비용이면 그 수치를 그대로 보고 |

어느 비교군이 더 나쁠 것이라는 가설은 그 비교군을 약하게 구현할 근거가 아니다.
정답 상한이 64스텝 내에 성공하지 못하는 생성기는 평가 전에 고친다.
그 수정은 물리 가능성 확인이지 에이전트 성능에 맞춘 난도 조정이 아니다.

## 8. Claude가 구현할 때 고정할 인터페이스와 산출물

### 8.1 환경과 에이전트 API

```text
reset(world_seed) -> hidden_env_state, pixels
step(hidden_env_state, action) -> hidden_env_state, pixels, reward, terminal

init_carry(theta) -> carry                  # 실제 세계 진입 1회만
act(theta, carry, pixels, prev_action, prev_reward)
    -> new_carry, action, optional_diagnostics

snapshot / restore                         # 평가자가 분기용으로 복제
goal_query(snapshot, goal_picture)          # 원본에는 쓰지 않음
```

`step`의 로거 정답은 별도 경로로 수집한다. `act`에 같은 dict로 넘기지 않는다.
`terminal=True`는 세션 끝뿐이다. 목표 완료·부분 변경에서는 False다.
준비 구간의 교사 행동도 실제 `prev_action`으로 입력한다.
에이전트가 고른 것처럼 가짜 행동 확률을 만들어 쓰지 않는다.

F 후보를 구현한다면 앞 문서의 갱신 순서를 유지한다.
이전 실제 행동으로 예측 → 현재 관측의 오차·정밀도 계산 → 사실/믿음의 통계 쓰기
→ 현재 효용 처리 → 현재 목표로 읽기 → 실제 행동 선택 순이다.
그 관측을 query마다 독립 증거로 다시 쓰지 않는다.
도착 아이콘의 1프레임 표시도 여러 Dirichlet 표본으로 늘리지 않는다.

### 8.2 크기와 계산 예산

| 항목 | 공통 규약 |
|---|---|
| 픽셀 | uint8 `[35,21,3]` 또는 완전히 같은 `[15,147]` |
| 행동 | 0 동, 1 서, 2 남, 3 북, 4 상호작용, 5 대기 |
| 정책 선택 | 본 점수는 학습 때와 같은 확률 정책. 순수 질문의 분포는 동일 난수로 비교 |
| 간단한 KV 대조 | 주소 128, 패치 특징 8, 특징 결과 15×8. 행동별 주소 |
| KV 기본 상수 | M=0, e=0, P=q0 I. α=2^(−1/8), R=.01. SF 대조 γ=.99, λ=.8, β=.5 |
| 온라인 carry | 상한 64 MiB/환경. h·M·P·흔적·보조 캐시 전부 포함 |
| 추가 용량 곡선 | 1 / 8 / 64 MiB. T를 늘릴 때 차원을 늘리지 않음 |
| 온라인 지연 | 동일 GPU batch 1, 에이전트 계산 p95≤50 ms. 첫 컴파일은 별도 보고 |
| 반복·계획 | 구현 전에 고정한 최대 반복 수. 예: 고정 16회 계획은 허용, 수렴할 때까지 반복은 금지 |
| 저장·검색 | 늘어나는 경험 목록·무한 KV cache 금지. 고정 슬롯·고정 replay만 허용 |

50 ms와 64 MiB는 이번 시험의 운영 예산이다. 신경계나 Minecraft의 보장값이 아니다.
느린 가중치 크기·훈련 replay·온라인 carry를 따로 보고한다.
메모리를 맞춘다고 불필요한 빈 배열을 비교군에 넣지 않는다.
추가 계산이나 메모리가 필요한 알고리즘은 그 비용 곡선에서 비교한다.

첫 후보의 수치형·모형 차원·공분산 근사·계획 횟수도 평가 전에 고정한다.
KV의 q0는 훈련 자료의 잔차 분산 / 평균 흔적 제곱 크기로 정한다.
평가의 종류·위치·시각별 통계로 다시 맞추지 않는다.
앞 문서의 큰 공동 공분산 기준형을 그대로 쓰면 비용이 클 수 있다.
이 문서의 작은 KV 차원을 그 기준형과 동일한 알고리즘으로 간주하지 않는다.
비용 안에 들어가지 못한 경우도 실패 결과다. 평가 때만 긴 시뮬레이션으로 보충하지 않는다.

한 스텝의 관측 갱신, EFE/후속 읽기, 계획, 메모리 검색을 모두 시간에 포함한다.
구간 시작 때 하는 고가의 ‘컴파일’도 최대 스텝 비용에 포함한다.
평균 처리량 뒤에 큰 재계획 정지를 숨기지 않는다.
새 목표의 query가 세션 길이만큼 과거를 다시 읽어야 한다면 고정 계산 실패다.

### 8.3 필수 로그

```text
run: code_commit, design_commit, theta_hash, seed, model_size, carry_bytes
step: t, pixels_hash, actual_action, reward, goal_mode, optimizer_calls
truth_only: source_of_job, item, due, changed_source, first_seen_times
event: first_positive_B, first_new_evidence, first_job_after_query, correct
diagnostics_if_available: predictive_loglik, precision, write_norm, changed_address
cost: observation_update_ms, query_ms, planning_ms, peak_bytes, update_count
```

진단을 위해 새 학습 머리를 추가하지 않는다. 이미 계산하는 추론량만 기록한다.

로거의 source 번호·좌표는 에이전트 호출과 물리적으로 분리한다.
목표 전환, 변경 시각, 결과 지연의 정답을 에이전트가 읽는 설정 파일에도 넣지 않는다.
같은 입력으로 reset 횟수·호출 횟수·통계 형태를 검사하는 누출 검사를 먼저 한다.

## 9. 구현 비용과 실행 순서

### 9.1 비용 추정

새 환경은 기존 격자·텍스처·행동 scan 위에 pending 한 칸,
계약·부분 변경·별도 로거·분기 평가를 더하는 규모다.
모형 연구까지 포함한 전체 구현이 단순한 환경 확장과 같은 비용은 아니다.

| 작업 | 예상 인력 시간 [가설] |
|---|---|
| 환경·픽셀·교사 경로·상한 | 1–2일 |
| 지표·내용 교환·분기·누출 검사 | 1–2일 |
| 기존 GRU/TD/KV 이식 | 1–2일 |
| 공식 Dreamer 연결·적응 비용 계측 | 2–4일 |
| 새 공동 추론 후보 | 별도 연구 비용. 위 시간에 성공을 포함하지 않음 |

현재 장비는 RTX 5090, 메모리 약 32 GiB다. 읽기 전용 조회로 확인했다.
실측 처리량은 아직 없다. 다음은 처리량을 가정한 산술 예산이다.
최종 느린 학습 예산은 **방법·seed당 5천만 환경 스텝**이다.
같은 데이터 예산과 별도로 실제 gradient 수·처리 시간도 보고한다.

| 가정한 종단 처리량 | 5천만 스텝/seed의 시간 [유도] |
|---|---|
| 작은 JAX GRU/KV 2천–1만 step/s | 약 1.4–6.9시간 |
| 작은 Dreamer 200–1천 step/s | 약 14–69시간 |

컴파일·평가·I/O·5개 seed 비용은 별도다.
Dreamer 추정은 이 장비에서 측정한 수치가 아니다.
작은 후보군을 여러 개 학습하면 하루 이상, 공식 비교와 5개 seed를 모두 포함하면
여러 날에서 수 주를 예약할 수 있다. 큰 공동 필터는 이 범위를 넘을 수 있다.

공통 경험의 세 T만 합쳐도 방법당
`5×256×(2,048+4,096+16,384)=28,835,840` 평가 스텝이다. [유도]
자율·d=16·내용 개입·목표 분기·경사 비교는 여기에 추가된다.
전부를 ‘몇 분의 시험’으로 부르지 않는다.
이번 문서 작성에서 실행한 것은 이 예산의 산술 확인뿐이다.

### 9.2 실행 전에 봉인할 것과 중단 기준

1. 환경 상태 전이와 정답 상한부터 확인한다.
   원인 생략·뒤 행동 생략·변경 전 관측 동일성·64스텝 가능성을 검사한다.
2. 검증 전용 세계에서 2백만/1천만 스텝 점검을 한다.
   공개 목표·지연 0의 쉬운 이동조차 안 되면 지각/제어 문제로 중단한다.
   본 평가 결과로 훈련 길이나 기준을 바꾸지 않는다.
3. 입력·갱신식·차원·정밀도·계획 횟수·학습률·seed·정지 시각을 파일로 봉인한다.
   마지막 5천만 스텝 checkpoint만 본 평가에 쓴다.
4. 공통 경험과 자율 실행을 같은 최종 checkpoint로 평가한다.
5. 표 7.1의 실패 위치를 먼저 보고한다. 평균 보상·좋은 영상은 그 뒤다.

정답 상한이 실패하면 환경/측정 문제다.
공통 경험의 원인 개입부터 실패하면 공 배정 모형의 문제다.
공통 경험은 통과하고 자율 실행이 실패하면 지각·탐색·행동 읽기의 결합 문제다.
긴 대기에서만 실패하면 보존·간섭·정밀도 갱신을 의심한다.
변경 뒤 다른 사실까지 망가지면 국소 수정 주장은 실패다.
새 보상만 실패하면 사실→효용 재평가 또는 효용 추론이 부족하다.

실패를 고치기 위해 정답 source mask, 지연 정답, 행동 놀라움 가중,
새 과제 전용 손실·머리를 덧붙이면 이 관문을 통과한 것으로 세지 않는다.
다음 설계로 보고 다시 사전 등록한다.

## 10. 해석의 범위

| 결과 | 말할 수 있는 것 | 말할 수 없는 것 |
|---|---|---|
| 공통 경험만 통과 | 같은 입력에서 세션 안 기억·재평가·수정 가능 | 스스로 유용한 경험을 모은다 |
| 자율 검사도 통과 | 새 세계에서 경험을 모으고 네 기능을 함께 사용 | Minecraft의 제작·탐색 문제 해결 |
| 단순 SF/목표 은행도 통과 | 이 과제에는 그 정도 구조로 충분 | F 기반 후보만의 새 능력 |
| GRU/고정 Dreamer도 통과 | 경사 없는 활성 상태 적응도 충분할 수 있음 | 빠른 시냅스가 필수 |
| F 후보만 통과 | 고정 예산에서 해당 결합의 실증적 근거 | F 자체가 인과 식별과 최적 행동을 보장 |
| 시간만 늘려도 실패 | 장기 세션 요구는 아직 미충족 | 더 큰 세계에서 해결될 것 |

| 이번 과제의 구조 | Minecraft에서 같은 역할 |
|---|---|
| 부분 시야·이번 세계의 무늬와 길 | 지형·동굴·자원 위치의 세션 안 기억 |
| 조작 뒤 이동·다른 조작을 거쳐 도착한 결과 | 채굴·제작·사용 뒤 인벤토리/환경에 나타난 효과 |
| 보상 없던 산출물이 새 의뢰의 목표가 됨 | 현재 도구·제작 진행·새 목표에 따라 바뀌는 자원 효용 |
| 채집처 하나만 바뀜 | 채굴한 광맥·소모한 물체·국소 환경 변화 |
| 원본 사실은 유지하고 현재 선호로 읽음 | actor·critic 전체를 다시 학습하지 않는 목표 재평가 |

Minecraft로 가져갈 것은 과제 전용 source 키가 아니다.
픽셀·실제 행동·산출물에서 학습한 주소와 인과 문맥,
선호와 분리한 사실 통계, 새 증거에 따른 국소 수정, 고정 예산 읽기다.
일반 제작 규칙·긴 행동 사슬·새 지각 개념은 다음 검증 축으로 남는다.
공식 Minecraft 설정의 세션 길이 36,000은 후속 길이 검사 기준으로 삼을 수 있다.
다이아몬드 성취 자체는 별도 최종 실험이다.
