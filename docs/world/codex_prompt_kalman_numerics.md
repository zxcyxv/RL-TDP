# Codex 조사 요청: 칼만 시냅스의 수치 붕괴, 근본 원인과 해법 (2026-11-17)

## 질문

이 레포의 빠른 시냅스 (칸별 칼만/RLS 연상 기억)를 학습하면 float32에서 수치가 깨진다. **보통의 딥러닝 모델 (선형 어텐션, DeltaNet류 빠른 가중치, RNN, 트랜스포머)은 이런 문제가 거의 없는데, 이 모델에서는 왜 생기는가?** 근본 원인을 밝히고, 원리를 지키면서 빠른 해법이 있는지 조사해 달라.

## 모델 (요약)

자세한 명세: `docs/world/spec_q8_r0_pipeline.md`, `docs/world/spec_wm_joint.md`. 코드: `scripts/world/diag_20261117/synapse_wm_joint.py`, `synapse_cellkey.py`.

- 칸 p마다 M_p ∈ R^{8×256}, P_p ∈ R^{256×256} (공분산형, float32). 세션 시작 M = 0, P = I.
- 매 스텝: P ← P + q_p I; z = σ_p [k; e]; S = R₀ + R_p + zᵀPz; g = Pz/S; M ← M + (r − Mz) gᵀ; P ← P − (Pz)(Pz)ᵀ/S.
- σ_p, R_p, q_p와 키 망 (와 동시 학습 판에서는 월드 모델)을 순차 예측 NLL Σ ½[‖r − Mz‖²/S + 8 log S]로 세션 전체 역전파 학습 (`jax.checkpoint`로 스텝마다 재계산, 세션 518스텝, 배치 8).
- R₀ = 1.34e-6: 관측 (8비트 양자화 텍스처)의 양자화 잡음 바닥.

## 관측된 것 (사실)

1. R₀ 없이 월드 모델 고정, 키 학습: 3160반복에서 NaN. 직전 체크포인트 진단 (`docs/world/results/synapse_layer_20261117/nan_diag_P_vs_R.json`): 시야 칸 학습된 R ≈ 1e-13, S 최소 ≈ 5e-11–1e-10, zᵀPz 음수 0회, 세션 끝 P 최소 고유값 −1e-7–−4e-7.
2. R₀ 넣고 월드 모델 고정, 키 학습: 1만 반복 NaN 없음.
3. R₀ 넣고 **월드 모델을 사전학습 없이 동시 학습**: 958반복에서 NaN. 900반복 체크포인트 진단 (`wm_joint_diag_P.json`): 시야 칸 R ≈ 4e-9, S 최소 ≈ R₀, **zᵀPz 음수 발생 (최저 −3.1e-8, 64세션 중 6세션)**, 세션 끝 P 최소 고유값 최저 −3.4e-6, ‖z‖² 최대 약 9.
4. 같은 판에서 Pz를 TF32 대신 FP32로 계산: 915반복에서 NaN (효과 없음).
5. 시도와 비용: 제곱근형 (P = SSᵀ, Potter 쓰기 + 과정 잡음마다 촐레스키)은 맞지만 반복당 약 14배 느림. 칼만 상태만 float64는 약 6배 느림 (소비자용 RTX 5090). 매 스텝 대칭화 (P + Pᵀ)/2는 역전파에서 P 덩어리 (518 × 8 × 12 × 256 × 256 float32 ≈ 13GB)의 전치 복사를 만들어 메모리 부족. 행렬곱 Joseph 형식은 스텝당 256³.

## 바라는 답

1. 근본 원인. 예: 공분산형 빼기 갱신의 조건수/동적 범위 (사전 1 대 사후 1e-8)와 float32 정밀도, 학습이 R → 0과 결정적 관측으로 몰아가는 구조, 역전파와의 상호작용 등. 무엇이 주원인이고 무엇이 아닌지 근거와 함께.
2. 보통의 딥러닝 모델 (특히 DeltaNet, Gated DeltaNet, Longhorn, Kalman 계열 선형 어텐션 등 공분산·전처리 행렬을 쓰는 것 포함)이 이 문제를 어떻게 피하거나 겪는지. 문헌은 원문을 확인한 것과 기억에 의존한 것을 구분.
3. 해법 후보와 각자의 비용·원리 보존 여부. 특히 스텝당 O(d²), GPU 친화적, (가능하면) 시간 병렬과 양립하는 것. 정확한 칼만과 달라지는 근사라면 무엇이 달라지는지.
4. 이 레포의 원리 (칼만 이득 = 정밀도, 손 장치 금지, 경험적 베이즈)와 맞는 권고 하나와 그 이유.
