# 명세: 양자화 + R₀ 칸별 키 시냅스, 전체 학습 과정 (2026-11-17)

이 문서만 읽고 실험 전체를 이해하고 재현할 수 있게 쓴다. 코드: `scripts/world/diag_20261117/synapse_cellkey.py`, 환경 `rltdp/world/errand.py`·`env.py`, 월드 모델 `rltdp/world/errand_prec.py`. 결과: `docs/world/results/synapse_layer_20261117/q8_*`.

## 1. 무엇을 보려는 실험인가

에이전트가 **한 세션 안에서 겪은 사실을 기억해 두었다가, 나중에 다른 경로로 다시 갔을 때 꺼내 쓸 수 있는가**를 본다. 기억은 신경망의 역전파가 아니라 순전파 중에 쓰이는 빠른 시냅스 (선형 연상 기억, 칼만 필터로 갱신)다. 느린 가중치 (월드 모델, 키를 만드는 망, 칼만 매개변수)는 여러 세계로 미리 학습하고, 평가 중에는 고정한다.

## 2. 환경: 지연 채집 (errand)

### 2.1 세계

- 11 × 11 격자. 가장자리는 벽. 바닥 칸은 12종 무늬 중 하나 (무작위).
- 보급소 1곳, 채집처 5곳 (서로 체비쇼프 거리 3 이상, 보급소와 맨해튼 거리 4 이상).
- 채집처마다 산출물이 정해져 있다: A, A, B, B, C를 무작위로 섞어 배정.
- 역할 이름: **a0** = A 채집처 중 하나, **b0**·**b1** = B 채집처 둘. 세션 중간에 **b0의 산출물이 B → C로 바뀐다.** b1은 끝까지 B.
- 세계는 시드 하나로 정해진다. 세계마다 지도·배치·배정이 다르다.

### 2.2 행동과 규칙

- 행동 6개: 이동 4 (동·서·남·북), **상호작용**, **대기**.
- 채집처에서 상호작용하면 작업이 시작되고, **8스텝 뒤** 그 채집처의 산출물이 "도착" 칸에 나타난다 (그 사이 에이전트는 어디로 가도 된다).
- 보상 (이 실험에서는 쓰지 않음): 도착한 산출물이 현재 의뢰와 같으면 +1.

### 2.3 관측

- 매 스텝 **칸 12개**를 본다.
  - 시야 9칸: 에이전트 중심 3 × 3 지도.
  - HUD 3칸: 의뢰 카드 (이 실험에서는 뒷면만 보임), **도착 칸** (방금 도착한 산출물, 없으면 빈칸), 도장 칸.
- 칸 하나는 **7 × 7 픽셀 RGB 타일** (147개 값). 타일 종류는 25개 (벽, 바닥 12, 채집처, 보급소, 산출물 A·B·C, 카드 뒷면, 빈칸, 도장 등). 같은 종류는 언제나 같은 그림이다.
- 타일 그림 = 타일마다 색 하나 (균등난수) × 0.6 + 픽셀별 고정 난수 무늬 × 0.4. 벽은 0.05로 채운 어두운 칸.
- **8비트 양자화 (이번 판부터):** 픽셀값을 k/255로 반올림한다 (`env.py` `textures`). 실제 게임 화면 (Craftax, Minecraft)처럼 만들기 위함이다. 이전 판은 반올림 없는 float32였다. 양자화가 바꾼 픽셀값은 최대 1/510.
- **특징:** 칸마다 147개 픽셀값에 고정 난수 사영 We (147 → 8, 성분 N(0, 1/147), 시드 900)을 곱하고, 25종 타일 특징의 평균을 뺀다. 칸 하나 = 8차원, 장면 = 12 × 8.

### 2.4 교사 세션 (학습과 판정에 쓰는 경험)

에이전트가 직접 행동하지 않는다. 정해진 교사 경로를 따라가며 관측을 받는다. 순서:

1. **관찰:** 채집처 5곳을 무작위 순서로 한 번씩 방문. 방문마다 "보급소 → 채집처로 이동, 상호작용, 보급소로 복귀, 시작 후 9스텝이 될 때까지 대기". 그래서 모든 채집처의 산출물을 한 번씩 본다 (b1의 B도 여기서 한 번 본다).
2. **A 의뢰 4번:** 매번 a0에 다녀온다.
3. **B 의뢰:** b0에 다녀온다 (B를 본다).
4. **보존 256스텝:** 보급소 주변을 맴돈다 (이동과 대기). 이 구간 중간에 b0의 산출물이 C로 바뀐다 (관측으로는 보이지 않음).
5. **변경 증거:** b0에 다녀온다. **C가 도착한다.**

세션 길이는 약 450–500스텝. 짧은 세션은 대기로 채워 길이를 맞춘다 (학습 자료 518스텝).

## 3. 모델

### 3.1 월드 모델 μ⁰ (느린, 사전학습 후 고정)

- 입력: 지금 장면 특징 (12 × 8 = 96) + 행동 원-핫 (6).
- 구조: 102 → 256 (ReLU) → 칸별 다음 특징의 평균 μ⁰ (12 × 8) + 칸별 로그 분산 (12).
- 목적: 칸별 가우시안 음의 로그우도 (다음 장면 특징). **기억 없이 한 스텝만 보고 예측한다.**
- 자료: 학습 세계 512개 (시드 50,000–50,511)의 교사 세션 전체.
- 최적화: Adam lr 1e-3, 기울기 노름 1로 자름, 배치 32세션, 400반복.
- **저장:** 학습한 μ⁰를 `wm_q8.npz`로 저장하고 이후 모든 실행이 그대로 불러 쓴다. (실행마다 다시 학습하면 GPU 비결정성 때문에 μ⁰가 달라지고, 같은 설정의 판정이 54–85%로 흔들린다는 것을 확인했다.)

### 3.2 빠른 시냅스 (칸마다 하나, 세션 안에서만 갱신)

시냅스가 담는 것은 **월드 모델이 못 맞힌 몫 (잔차)** 이다.

- 값: 칸 p의 잔차 r_p = 다음 장면 특징_p − μ⁰_p (8차원).
- 상태: 칸마다 M_p (8 × 256, 내용)와 P_p (256 × 256, 내용의 불확실성). 세션 시작마다 M = 0, P = I.
- 주소 (= 질의): z_p = σ_p · [k_p; e_p] (256차원). k_p는 지금 스텝의 키, e_p는 키의 흔적 (3.3절).
- 예측: 잔차 평균 M_p z_p, 분산 S_p = **R₀** + R_p + z_pᵀ P_p z_p.
- 한 스텝의 갱신 (표준 칼만 필터, 칸마다):
  1. 과정 잡음: P_p ← P_p + q_p I (오래된 내용일수록 덜 믿게 됨)
  2. 예측 오차: δ = r_p − M_p z_p
  3. 이득: g = P_p z_p / S_p
  4. 쓰기: M_p ← M_p + δ gᵀ,  P_p ← P_p − (P_p z_p)(P_p z_p)ᵀ / S_p
- 칸별 매개변수 (12칸 × 3 = 36개, 느린 학습으로 맞춤): σ_p² (기억 몫의 사전 분산), R_p (관측 잡음), q_p (과정 잡음).
- **R₀ (관측 잡음 바닥, 고정):** 8비트 양자화 잡음. 픽셀당 분산 (1/255)²/12를 We에 통과시킨 특징 차원당 분산 = 평균 ‖We 열‖² × (1/255)²/12 ≈ **1.34e-6**. 이 바닥이 없으면 결정적인 관측 (같은 타일은 늘 같은 값)에서 학습이 R_p → 0으로 가며 우도가 −∞로 발산하고, 수치가 깨진다 (NaN).

### 3.3 키와 흔적 (느린 망이 만드는 주소)

- 시야 특징 w = 시야 9칸 특징 (72차원). HUD 3칸은 주소에 넣지 않는다.
- 칸 p의 키 (칸마다 다르다, 망은 공유):
  - u_p = w + MLP([w; 칸 위치 원-핫 p]),  MLP 84 → 128 (SiLU) → 72, 마지막 층 0으로 초기화
  - k̂_p = W_k[a] u_p,  W_k[a] ∈ R^{128 × 72} (행동마다 하나, 초기값 = 고정 난수)
  - ℓ_p = 선형([w; 행동 원-핫; 칸 위치 원-핫]) (초기 0)
  - k_p = exp(ℓ_p) · k̂_p / ‖k̂_p‖ (크기 exp(ℓ)를 학습)
- 흔적 (칸마다): e_p ← α e_p + k_p,  α = sigmoid(θ_α) (모든 칸 공유, 초기 반감기 8스텝).
- 주소: x_p = [k_p; e_p] (256), z_p = σ_p x_p.
- 흔적이 있어서, 8스텝 늦게 도착한 산출물이 상호작용하던 순간의 키에 이어진다.
- 초기값에서는 모든 칸의 키가 같고 크기 1, 즉 "고정 난수 키"와 같다.

## 4. 느린 학습 (여러 세계, 역전파)

- **목적: 교사 세션 전체의 순차 예측 음의 로그우도.** 스텝마다 쓰기 전 예측 (평균 M z, 분산 S)으로 실제 잔차의 가우시안 NLL을 재고, 그다음 쓴다. 세션 끝까지, 12칸 모두 더한다.
  - Σ_t Σ_p ½ [‖r_p − M_p z_p‖² / S_p + 8 · log S_p]
  - 이 선형 가우시안 기억 모형에서 이 합은 정확한 음의 로그 주변우도 (증거)다. 그래서 "경험적 베이즈"라 부른다.
- 기울기는 칼만 재귀 (M, P)를 거쳐 키 망과 σ, R, q로 흐른다. 세션 전체를 역전파하고, 스텝마다 재계산 (`jax.checkpoint`).
- 자료: 학습 세계 1,024개 (시드 50,000–51,023), 검증 세계 128개 (51,024–51,151). 판정 세계와 겹치지 않는다.
- 최적화: Adam. 키 망 lr 1e-3, 칼만 매개변수 lr 0.05. 배치 8세션.
- 100반복마다 검증 NLL. **최종 결과는 검증 NLL이 가장 낮은 시점**의 가중치로 정한다 (판정 결과로 고르지 않는다). 500반복마다 판정을 기록만 한다.

### 4.1 두 단계로 실행

1. **기준선 (키 고정):** 키는 초기값 (고정 난수)으로 묶고 σ², R, q만 학습한다. 1,000반복. 칼만 매개변수 초기값은 이전 연구 (12.13)에서 맞춘 값. 같은 μ⁰ 위에서 "학습된 키 없이" 얼마나 되는지의 기준. 결과 `q8_base_frozen_1k.*` (최저 검증 NLL 500반복).
2. **키 학습:** 기준선의 σ², R, q에서 출발해 키 망과 칼만 매개변수를 함께 학습한다. 5,000반복. 결과 `q8_learned_5k.*`.

두 단계는 같은 μ⁰ (`wm_q8.npz`)를 쓴다. 그래서 두 결과의 차이는 키 학습의 효과다.

## 5. 판정 (평가, 학습에 쓰지 않음)

- 판정 세계 256개 (시드 1,000–1,255)의 교사 세션을 그대로 돌리며 기억을 쓴다. **C가 도착한 순간 이후로는 쓰지 않는다** (그때의 기억을 평가).
- 그 기억을 고정한 채, 채집처 5곳마다 "보급소 → 채집처 이동, 상호작용, 복귀하며 도착까지 대기"를 흉내 낸다. 환경은 실제로 진행하고 (관측을 받음), 키와 흔적도 같은 식으로 계산한다. 기억에는 쓰지 않는다.
- 흉내 낸 경로의 도착 스텝에서 도착 칸의 기억 읽기 ŷ = M_도착칸 z를 얻는다.
- 점수 = cos(ŷ, g_B), g_B = B 타일 특징 − (A, B, C 타일 특징 평균). "여기서 하면 B가 온다"고 기억이 말하는 정도.
- 점수가 가장 높은 채집처를 고른다 (동점은 무작위). **정답은 b1** (B가 그대로인 곳). b0을 고르면 바뀐 사실 (C)을 반영하지 못한 것, 그 밖은 엉뚱한 곳.
- 지표: b1 / b0 / 다른 곳 비율 (세계 256개, 비율 1점 ≈ 2.6세계). 세계별 승패도 기록해 짝지어 비교한다.

## 7. 알려진 한계

- 학습 목적 (교사 경로의 다음 잔차 예측)과 판정 (오래전 사실을 다른 경로로 다시 읽기)이 다르다.
- 교사 세션에는 오래 지난 뒤에도 그대로인 사실을 다시 확인하는 구간이 없다 (b1은 관찰 단계에서 한 번만 본다).
- 시드 1개 (판정·학습 세계 집합, 초기화 각각 하나).
- 학습은 C 도착 뒤 귀환·대기 구간에서도 기억을 쓰지만, 판정은 C 도착에서 쓰기를 멈춘다.
