## 1. 목표와 문제

- **최종 장면**: 처음 보는 세계에 들어간 에이전트가 그 세계에서의 경험으로 **바로** (추론 중 경사 갱신 없이, 순전파 안의 기억 갱신으로) 배워 눈에 띄게 잘하게 되는 것. 고정 크기 기억, 스텝당 고정 계산으로. **본격적인 실험대는 마인크래프트** (세션 최대 36,000스텝, DreamerV3 다이아몬드 설정)다.
- **이번 요청의 범위**: 마인크래프트를 바로 풀라는 것이 아니다. 그곳에서 필요한 **성질들의 계층을 쌓고, 각 성질을 작은 규모의 과제에서 보이는 것**이다. 모든 성질을 한 구조가 동시에 만족하는 것이 작은 과제에서 확인되면 마인크래프트로 넘어간다. 그래서 작은 과제의 설계 기준은 **"규모만 키우면 그대로 마인크래프트의 요구가 되는가"**다.
- **해석 가능성**: 각 성질이 어느 기제 (어느 신호, 어느 흔적, 어느 시냅스) 때문에 성립하는지 보여야 한다. 성능 숫자만으로 성질을 보였다고 하지 않는다.
- **인과 사슬 (가설, 마인크래프트 단계의 주장)**: 세션 안 기억 → 한 에피소드가 더 멀리 감 (재탐색 감소, 더 높은 단계 성취) → 느린 학습이 받는 신호 증가 → 같은 스텝에서 학습 곡선이 빨리 오름. 지금은 이 사슬의 앞쪽 고리를 작은 과제에서 측정할 수 있게 설계하면 된다.
- **기준선**: DreamerV3는 1억 스텝 동안 행동하며 계속 학습하지만 (재현 버퍼, 작은 학습률) 한 번의 경험이 다음 행동을 바꾸지 못한다. 세션 안 적응 수단은 RSSM의 GRU 상태뿐이다 (짧은 학습 조각). 마인크래프트 수준 에이전트에는 "세션 안 한 번의 경험으로 배우는 장치"가 비어 있다.
- **TD(λ) 빠른 기억이 확장되지 않는 이유 (Claude의 정리, 검토 대상)**: forage에서 tdpc (에피소드마다 비우는 선형 TD(λ) 빠른 가중치)가 된 것은 전제 넷 덕분이고 마인크래프트에서는 넷 다 깨진다. (1) 같은 상황의 반복 (2) 같은 보상의 반복 (3) 보상까지 짧은 거리 (4) 상황 특징이 겹치지 않음. 구조적 원인 둘: 지금 목표에 대한 **가치를 캐시**한다 (재방문·목표 유지가 있어야 맞다), **쓰기를 고르지 않는다** (간섭이 사건이 아니라 스텝 수로 는다). 맞는지, 빠진 것이 있는지 판단해서 고쳐 쓴다.

## 2. 이전 시도 (architecture_design.md)의 문제: 피해야 할 것

- **가소성을 뺐다.** K개 슬롯 베이즈 사실 기억 + 매 스텝 후보 비교 + 결정 손실로 쓰기·퇴거를 고르는 구조가 됐다. 그 결과 쓰기의 기준인 **"미래 필요 분포"가 원리에서 나오지 않아 빈칸**으로 남았고 (첫 과제에서는 과제 법칙으로 고정 = 사실상 정답 주입), 후보 비교라 실시간·고정 계산이 위태롭고, Craftax로 그대로 옮겨진다는 조건을 통과하지 못한다.
- **ET (적격 흔적)를 1스텝으로 줄였다.** 사건 직전 맥락을 사건과 잇는 흔적이 없어졌다.
- **살릴 것**: 가치 대신 세계 사실, 주소는 결정 시점 정보로만 · 내용과 분리, 정밀도 가중 갱신, 인과 개입 (기억 교환·삭제)이 붙은 검증, "더 단순한 것과 같으면 그것을 채택"하는 반증 기준.

## 3. 큰 틀과 경유할 길

**큰 틀은 자유에너지원리와 능동적 추론이다.** 기억 = 생성 모델의 빠른 파라미터, 쓰기 = 정밀도 가중 믿음 갱신, 읽기 = 추론, 관련성 = 기대 자유에너지의 실용·인식 가치, 망각 = 변동성, 행동 = 기대 자유에너지 최소화. 쓰기·유지/망각·읽기·행동의 기준은 이 틀에서 유도한다.

**그 틀을 구현하는 경로로 가소성과 적격 흔적을 경유하라.** 토대는 이미 단단하다:
- 선형 어텐션 = **이종 연상 Hebb 기억**: 시냅스 M = Σ_t v_t k_tᵀ (KV 외적의 누적합), 읽기 M q. (softmax를 뺀 어텐션 = 빠른 가중치. 엄밀한 동등성.)
- TDP = 그 누적합에 **시간차 창 텐서**를 곱한 것: W = Σ_{s,t} v_t Λ(t − s) k_sᵀ. 대역별 흔적의 곱이 쌍 STDP 이중적분과 **정확히** 같다 (조건 ρ = 1 − |z|², a = c̄, b = c; 이 저장소에서 수치 확인 오차 5.6e-16).
- 선형 어텐션 ICRL이 하는 계산은 LSTD 충분통계이고, A가 같은 시각 외적 − γ·지연 외적, 즉 STDP 꼴이다 (`icrl_memory_gate.md`). TD 자체가 시간차 창을 가진 Hebb 시냅스로 쓰인다.

**TDP를 그대로 보존하라는 것이 아니다.** 이 토대 (KV 외적 누적 = 시냅스, 시간차 창 = STDP)에서 출발해 다음 방향으로 확장하라:
- **좋았던 보상을 기억한다**: 조절 신호가 적격 흔적 (흔적의 곱)을 장기 시냅스로 옮기는 3요소 규칙. 신호의 출처와 크기를 자유에너지원리에서 정한다 (정밀도 가중 예측 오차, 기대 자유에너지의 실용·인식 가치).
- **이전 관측·행동의 적격 흔적에 공을 돌린다 (credit assignment)**: 키 선행 반창 (b = 0 또는 학습된 비대칭), 공 배정 창과 보존 시간의 분리 (band_product는 한 극점에 묶임, `tdp_plasticity_rl.md` 2.5절; 36,000스텝 보존 극점은 창 반감기 72,000스텝, 8스텝 창 극점은 보존 반감기 4스텝).
- **가치 캐시가 아닌 세계 사실**: 같은 Hebb·STDP 시냅스가 전이 (k_s → v_t, 시차 창)를 담으면 예측 기억 (다음 관측, 후속 표상류)이 된다. 가치를 읽을 때 지금의 선호로 계산한다면 무엇이 필요한지.
- 1차 설계의 "미래 필요 분포"가 이 구조에서 **무엇으로 대체되는지** 명시하라 (가설: 흔적 × 사건 신호의 국소 일치가 "중요한 사건을 예측한 것 = 미래에 쓸모 있을 것"의 근사다).

**BTSP는 수단 중 하나다.** 사건이 일으키는 한 번 덮어쓰기·가중치 의존 방향이 유도된 기준을 구현하는 데 유용하면 쓰고, 아니면 쓰지 않는다. 쓴다면 왜 필요한지 (빼면 무엇이 무너지는지) 보인다. 다른 가소성 규칙 (3요소, 델타 규칙 등)도 같은 기준으로 판단한다.

**제약**: 스텝당 고정 계산, 국소 갱신, 후보 비교·미래 시뮬레이션 없음, 추론 중 경사 없음, 고정 기억 크기. 자유 파라미터는 원리로 정하거나 실험 전 고정한다. 손으로 문턱·손실·머리를 덧붙이지 않는다 (ROADMAP 원칙 5).

## 4. 해 줄 것

1. **문제 정의**: 주어지는 것, 예산, 기억의 세 결정 (쓰기·유지/망각·읽기)을 식으로. TD(λ) 빠른 기억 / NEC / RL² (GRU) / DreamerV3 GRU / 선형 어텐션 ICRL이 어디까지 하고 어디서 원리적으로 못 하는지. 새로운 것을 한 문장으로. 반증 가능한 형태로.
2. **성질의 계층**: 마인크래프트의 세션 안 적응에 필요한 성질들을 기초부터 쌓아 정리한다 (예: 결정 시점 주소, 방향성 있는 공 배정, 보존과 창의 분리, 선택적 쓰기, 증거에 의한 수정, 가치 대신 사실. 이 예시는 검토 대상이다. 빠진 것을 더하고 불필요한 것은 뺀다). 각 성질이 TD(λ) 빠른 기억의 확장 불가능 원인 중 무엇에 대응하는지, 앞 성질 위에 무엇을 더하는지.
3. **아키텍처를 유도의 사슬로**: KV 외적 시냅스 → 시간차 창 (TDP) → 각 확장. 계층의 각 성질을 어느 확장이 만족시키는지 대응표로. 만족시키지 못하는 성질은 그렇다고 쓴다. 느린 가중치 (역전파) 대 빠른 시냅스 (가소성)의 분업, 각 조절 신호의 출처, 행동 선택.
4. **성질별 작은 과제**: 각 성질을 forage의 손잡이 하나로 시험한다 (예: 보상 한 번씩, 목표가 차례로 바뀜, 반복 무늬 큰 격자, 긴 거리). 쌓는 순서와 첫 과제를 권고한다. 비교군 (tdpc = TD(λ), GRU/RL², 원래 TDP, 정답 상한)과 사전 예측·실패 기준. 마지막으로 **모든 성질을 함께 요구하는 작은 종합 과제** (마인크래프트로 넘어가는 관문)를 정의한다.
5. **이전**: 종합 과제에서 Craftax·마인크래프트 (패치 81개, 행동 17~25개, DreamerV3 RSSM 결정론 경로)로 갈 때 규모·난이도 외에 바뀌는 것이 있는지. 인과 사슬의 각 고리를 어떻게 측정하는지.
6. **선행 연구**: 3요소 학습, 빠른 가중치, 후속 표상, 에피소드 제어, 문맥 내 RL, 능동적 추론 등과 대조. 원문 확인 [확인] / 기억 [기억] 표기. 겹치면 무엇이 다른지.
