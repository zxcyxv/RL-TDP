# Codex 보충 요청: 세션 안 학습을 중심으로 다시 (같은 세션, 2026-11-15)

방금 쓴 `docs/world/state_inference_design.md`의 맥락은 그대로 쓴다. 다만 그 설계는 **공 배정을 느린 구조 학습으로 넘겨서**, 이 연구가 풀려는 문제 (DreamerV3의 한계)로 되돌아갔다. 이번 요청이 앞의 요청들보다 우선한다.

## 1. 사용자가 원하는 것 (Claude가 정리하고 사용자가 확인함)

**처음 들어간 세계에서, 그 세계에서 겪은 것으로 바로 배워 더 잘하게 되는 에이전트.** 경사 갱신이 아니라 순전파 안의 시냅스 가소성 (TDP 계보의 KV 외적 누적이 토대), 고정 기억·스텝당 고정 계산, 자유에너지원리 안에서 원리로 (손으로 넣은 편향 없이, 왜 되는지 보이게). 최종 무대는 Minecraft, 그 전에 작은 과제에서 성질을 하나씩.

세션 안에서 해야 하는 네 가지:
1. **기억**: 본 것과 겪은 것 (어디에 무엇이, 무엇을 했더니 무엇이).
2. **원인에 잇기**: 나중에 온 결과를 그 원인이 된 과거 선택에 잇는다. 앞에 있었다는 이유만으로 잇지 않는다.
3. **새 목표에 바로 적응**: 새 과제나 보상이 주어지면 재학습 없이 그 기억으로 바로 맞춘다.
4. **증거로만 잊기**.

필수가 아닌 것:
- 느린 학습이 오래 걸리는 것 (DreamerV3처럼 1억 스텝 BPTT)은 괜찮다. **다만 느린 학습이 배우는 것은 세계의 일반 구조와 표현이어야 하고, 특정 과제의 가치나 과제 전용 구조여서는 안 된다.** DreamerV3가 새 보상에 못 따라가는 것은 가치를 느린 가중치 (actor·critic)에 굳혀 두기 때문이다.
- 에피소드 사이의 내용 전이.

## 2. 현재 위치 (README 6–7절, 이 세션에서 읽은 것)

- 1번 (기억)과 4번 (증거 망각)은 갈림길 과제에서 작게 확인 (ours, 증거 망각 + 경험적 베이즈 척도 + 온라인 위험률: 흐름 S 0.86–0.94).
- 2번은 놀라움 가중 (u = −log p(a))으로 풀렸지만 **손으로 넣은 편향**이다. 원리로 다시 세워야 하는 열린 문제.
- 3번은 아직 시험하지 않았다.
- Claude의 분석 (검토 대상): 흔적 위 RLS는 "결과 = 키 흔적의 선형 함수 + 가우시안 잡음" 모형 안에서 이미 F의 정확한 최소점이다 (RLS = 정확한 사후, RTRL로 읽기 가중치의 민감도를 구해도 시냅스전 상태 = 흔적). 복도가 공을 가져간 것은 근사 오차가 아니라 **모형 오지정** (상태 = 키들의 고정 지수 평균)이다.

## 3. 해 줄 것

1. **2번 (원인에 잇기)을 세션 안에서, 원리로.** 공 배정은 세션 안에서 빠르게 일어나야 한다 (흔적 같은 세션 안 장치를 빼지 않는다). 후보:
   - 생성 모델의 형식 자체: 능동적 추론에서 전이는 행동을 조건으로 하고 (p(s′ | s, a)), 행동은 에이전트가 아는 개입 (efference copy), 관측은 결과다. 이 형식에서 세션 안 공 배정을 유도하면 "선택이 원인"이 손으로 넣은 편향이 아니라 모형 구조에서 나오는가.
   - F의 기울기에서 학습 신호 (정밀도 가중 예측 오차)와 흔적 (믿음의 파라미터 민감도, RTRL의 국소 근사, e-prop류)을 유도해, 흔적의 입력과 감쇠가 모형에서 나오게.
   - 위 2절의 "모형 오지정" 분석이 맞는지 판단하고, 맞다면 세션 안에서 바뀌어야 하는 모형의 최소 형태.
   - 이력을 보는 예측자에서 "남은 문" 선택은 예측 가능하지만 원인이다 (놀라움 ≠ 원인). 이 반례를 통과해야 한다.
2. **3번 (새 목표에 바로 적응).** 가치를 느린 가중치에 캐시하지 않고, 결정하는 순간에 빠른 기억 + 지금의 선호로 계산하는 형태. 고정 계산이어야 한다 (매 스텝 긴 미래 시뮬레이션은 안 된다). 키 선행 창을 가진 TDP 시냅스가 "지금 상태에서 앞으로 무엇이 이어지는가"를 누적하면 무엇이 되는지, 그것이 새 선호로 바로 읽히는지.
3. **느린 학습과의 분업**: 느린 학습이 맡는 "일반 구조·표현·일반 사전 (정밀도, 위험률, 선택이 대개 원인이라는 것 등)"과 세션 안에서 해야 하는 "이번 과제의 구조·사실·공 배정"의 경계. 느린 쪽이 과제 전용 구조를 갖게 되는 설계는 받지 않는다.
4. **갈림길 과제에서의 시험 명세**: 2번 (원인에 잇기, 손 편향 없이)과 3번 (같은 세계에서 필요한 자원·목표를 바꿔 가며 물어봤을 때 재학습 없이 맞추는가; 너의 2판 설계의 A→B→A 전환 포함)을 각각. 비교군 (ours, ours_surp, tdpc = 가치 캐시, 정답 상한)과 사전 예측·실패 기준. Claude가 `gate.py`, `gate_memory.py` 위에 그대로 구현할 수 있는 수준.
5. `state_inference_design.md`와 `plasticity_design.md`에서 이 기준에 맞는 것과 버릴 것을 표로.
