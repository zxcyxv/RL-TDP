# 시냅스 층 기본형: 명세 (더하는 과정 잡음), 2026-11-17

짝 문서: 곱하는 망각판 [`synapse_layer_spec_mult.md`](synapse_layer_spec_mult.md). 배경: `../HANDOVER.md` 0절 (2026-11-17 방향).

## 0. 목적과 바뀌는 것

- **목적:** 바깥에 붙은 무작위 키 조회표를, 망의 표현에서 학습된 사영으로 키를 만드는 kv 외적 누적 시냅스로 바꾼다. 쓰기 규칙을 고친 뒤 (12.7–12.13)의 조건에서 학습된 키가 무엇을 하는지 잰다.
- **12.13에 비해 바뀌는 것:** 키 경로 하나. 무작위 키가 학습되는 키 사영과 학습되는 흔적 극으로 바뀐다.
- **그대로인 것:** 느린 월드 모델 μ⁰ (학습된 것, 고정), 칸별 칼만 쓰기 (σ_p, R_p, q_p), 값 = 잔차, 손 선호 판정, 시드 1.
- 초기값은 12.13의 무작위 키와 같다.

## 1. 구성

| 부품 | 식 | 상태 |
|---|---|---|
| 시야 표현 | w_t = feat(o_t)[0:9] (시야 9칸 × 8 = 72차원. HUD는 넣지 않음, 12.4) | 고정 임베딩 (12.13과 같음) |
| 표현 변환 | u_t = w_t + MLP(w_t), MLP 72 → 128 (SiLU) → 72, 마지막 층 0으로 초기화 | 학습. 초기에는 u = w |
| 키 (결정 시점의 상황 × 행동) | k̂_t = W_k[a_t] u_t, W_k[a] ∈ R^{128×72} (행동별), 초기값 = 12.13의 Wr[a] | 학습 |
| 키 크기 | k_t = exp(ℓ_t) · k̂_t / ‖k̂_t‖, ℓ_t = 선형([w_t; onehot(a_t)]), 초기값 0 | 학습. 초기에는 단위 크기 (= 12.13) |
| 인과적 시간 창 (흔적) | e_t = α e_{t−1} + k_t, α = sigmoid(θ_α), 초기 2^(−1/8) (반감기 8) | 학습 |
| 주소 = 질의 | x_t = [k_t; e_t] ∈ R²⁵⁶, 칸별 회귀 입력 z_p = σ_p x_t | |
| 값 (쓰기 목표) | r_p = feat(o_{t+1})_p − μ⁰_p(o_t, a_t) (느린 모델이 못 맞힌 몫) | |
| 시냅스 | 칸별 M_p ∈ R^{8×256}, P_p ∈ R^{256×256}, 세션 시작에 M = 0, P = I | 세션 안 쓰기만 (역전파 없음) |
| 칼만 매개변수 | σ_p, R_p, q_p (칸별, 36개), 초기값 = 12.13에서 맞춘 값 | 학습 (경험적 베이즈) |

질의를 주소와 묶는 이유: 칼만 회귀에서 다음 잔차의 사후 예측은 M z이고 분산은 R + zᵀPz다. 별도의 질의 사영을 두면 이 예측 의미가 깨지고, 학습 목적 (주변 우도)도 정의되지 않는다.

## 2. 한 스텝 (세션 안, 칸 p마다)

1. k_t, e_t, x_t, z_p를 위 식대로 계산한다.
2. 예측 (쓰기 전): 잔차 평균 M_p z_p, 분산 S_p = R_p + z_pᵀ P_p z_p. 다음 장면 예측은 μ⁰_p + M_p z_p.
3. 과정 잡음: P_p ← P_p + q_p I
4. 칼만 쓰기: g = P_p z_p / S_p, M_p ← M_p + (r_p − M_p z_p) gᵀ, P_p ← P_p − (P_p z_p)(P_p z_p)ᵀ / S_p
5. C 도착 뒤에는 쓰지 않는다 (stop_t, 12.13과 같음).

순서와 수치는 `scripts/world/diag_20261115/eb_scale.py`의 `write()` 그대로이고, 바뀌는 것은 1의 키 계산뿐이다. M은 시간에 걸친 (잔차 ⊗ 주소) 외적의 누적이고, 칼만 이득이 주소들 사이 상관을 풀어 준다 (델타 규칙과 Gated DeltaNet의 일반형).

## 3. 학습 (느린 가중치, 여러 세계, 역전파)

- **목적:** 학습 세계 교사 세션의 순차 예측 음의 로그우도.
  - Σ_t Σ_p ½ [ ‖r_p − M_p z_p‖² / S_p + H log S_p ]
  - 12.13 경험적 베이즈의 목적과 같은 식이다. 이 선형 가우시안 기억 모형의 음의 로그 증거, 즉 정확한 자유에너지다.
  - 기울기는 칼만 재귀 (M, P)를 거쳐 키 매개변수와 σ, R, q로 흐른다. 세션 전체를 역전파하고, 스텝마다 `jax.checkpoint` (12.13과 같음).
- **학습되는 것:** MLP, W_k, ℓ, θ_α, σ_p, R_p, q_p. μ⁰ (월드 모델)와 픽셀 임베딩은 고정.
- **자료:** 학습 세계 1,024개 (시드 50,000–51,023), 검증 세계 128개 (51,024–51,151), 판정 세계 256개 (1,000–1,255, 12.13과 같음). 모두 같은 교사 경로.
- **최적화:** Adam. 키 경로 lr 1e-3, 칼만 매개변수 lr 0.05 (12.13과 같음). 배치는 세션 8개.
  - 100반복마다 검증 NLL을 재고, 가장 낮은 시점을 쓴다.
  - 최대 2,000반복. 검증 NLL이 500반복 동안 나아지지 않으면 멈춘다.

## 4. 판정과 기록

- **판정:** 12.13과 같은 손 선호 판정. 끝 기억을 고정한 채 채집처마다 경로를 흉내 내고, 도착 칸에서 cos(M z, g_B)로 b1 / b0 / 다른 곳을 센다. 흉내 낸 경로에서도 키와 흔적을 같은 학습된 식으로 계산한다.
- **기록:**
  - 학습 전과 학습 뒤의 b1 / b0 / 다른 곳
  - 검증 NLL 곡선
  - 맞춘 α (반감기)와 σ_p, R_p, q_p
  - 도착 순간 쓰인 몫
  - 행동 종류별 키 크기 exp(ℓ) 평균: 상호작용 / 이동 / 대기 (12.2, 8절과 비교)
  - 이웃 스텝 주소 코사인 (12.6에서 0.97이 문제였음)

## 5. 비용

- 세션 안 계산은 12.13과 같다. 칸마다 P가 256 × 256이고, 키 경로는 스텝당 작은 MLP 하나가 더해진다.
- 학습 반복 하나는 12.13 경험적 베이즈 한 반복 (세션 8개 역전파)에 키 경로 기울기를 더한 것. 12.13은 200반복, 여기서는 최대 2,000반복.
- 순차 scan. 더하는 Q는 누적합 꼴이 아니라 시간 병렬이 안 된다 (명세 2에서 다룸).
