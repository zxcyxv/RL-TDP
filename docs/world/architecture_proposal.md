# 결합을 유지한 아키텍처 제안 — 2026-11-15, Codex

**권고는 결합을 유지하고, 느린 키 학습을 ‘기록한 기억의 재사용 F’까지 연결하는 것이다.** 사실 기억과 현재 선호로 가치를 읽는다. 경험의 흔적에 정밀도 가중 오차를 쓴다. 이 둘을 다른 본체로 교체하지 않는다.

DeltaNet 권고는 철회한다. 이번에 고칠 연결은 **C의 증거 → 흔적 위 쓰기 → b0을 다시 읽을 때의 예측**이다. 원인 주소가 어긋났다는 해석은 유력한 가설이다. 확정 사실로 쓰지 않는다. 구현·학습·새 성능 시험은 하지 않았다.

## 2. 유지하는 구조

| 구성 | 식·역할 | 느린 것 / 세션 안 빠른 것 | 빼면 무너지는 것 |
|---|---|---|---|
| 월드 모델 | 다음 관측의 칸별 평균 μ⁰와 분산 v를 예측한다. | 공통 표현·전이는 느리게 배운다. | 일반 예측과 이번 세계의 사실을 나눌 기준이 사라진다. |
| 학습된 키 | `k_t=kθ(o_t,a_t)` | θ는 세계 간 학습한다. | 서로 다른 원인·경로를 구분할 입력을 시냅스에 주기 어렵다. |
| 흔적 | `e_t=αe_{t−1}+k_t` | 순전파 상태다. | 늦게 온 결과가 과거 행동에 영향을 줄 통로가 사라진다. |
| 사실 시냅스 | 칸별 M·P에 정밀도 가중 오차를 쓴다. | 이번 세계의 사실·확신은 순전파로 바뀐다. | 새 세계의 생산 배정과 관측된 변경을 저장하지 못한다. |
| 현재 선호 u | 목표 단서 또는 실제 결과·보상으로 정한다. | 새 보상 관계는 세션 안에서 갱신한다. | 기억이 있어도 새 목표로 재평가하지 못한다. |
| 읽기 | `가치(a,g)=현재 선호 u_g × 사실 예측 Φ_M(a)` | 가치 자체를 느린 가중치나 TD 캐시에 굳히지 않는다. | 9절에서 확인한 목표 전환의 장점을 잃는다. |

Φ의 의미는 과제와 일치해야 한다. 11절의 후속 특징과 12.3절의 지연 관측 예측은 같은 대상이 아니다. 이번 판에서는 **기존 경로 probe의 도착 관측 예측**을 그대로 Φ로 쓴다. 새 계획기나 길 찾기를 추가하지 않는다.

공개 목표는 `u=u(g)`로 바로 바꾼다. 비공개 보상에서는 11절처럼 `u←u+β(r−uᵀy)y/(yᵀy+ε)`로 겪은 결과와 보상을 연결한다. 가치는 `Q(a)=uᵀΦ_M(a)`로 읽는다. 현재 의뢰를 구별할 증거가 없는데 목표를 알아낸다고 가정하지 않는다. 기존 B probe도 목표 추론 자체를 검사하지는 않는다.

느린 가중치는 표현과 쓰기·읽기의 공통 규칙을 배운다. 이번 세계의 생산 배정, 보상 관계, 축적한 확신은 빠른 상태에 둔다. 세션 중 역전파는 없다. 기억 차원과 매 스텝 연산은 지금처럼 고정이다.

## 3. 실제로 끊어졌을 수 있는 연결

현재 `errand_prec.py`의 핵심은 다음과 같다. 칸 p의 첨자는 일부 생략했다.

```text
z_t = s_t e_t,                 s_t² = v_t / v_max
δ_t = (y_{t+1} − μ⁰_t) − M z_t
K_t = P z_t / (R + z_tᵀ P z_t)
M⁺ = M + δ_t K_tᵀ
P⁺ = P − (P z_t)(P z_t)ᵀ / (R + z_tᵀ P z_t)
```

이 쓰기를 한 번 했을 때, 기존 probe의 장소 i를 읽는 주소 q_i의 변화는 정확히 다음과 같다. 분석할 때 q_i는 고정한다.

```text
Δŷ_i = (M⁺ − M) q_i = δ_t c_i
c_i = z_tᵀ P q_i / (R + z_tᵀ P z_t)
```

**C의 오차가 큰가보다, 그 오차가 b0 읽기에 얼마나 전달되는가가 먼저다.** c_b0가 작으면 C를 관측해도 b0 예측은 거의 바뀌지 않는다. 다른 주소의 계수가 크면 그곳을 바꾼다. 흔적의 단순 cosine이나 상호작용 키 크기만으로는 이 경로를 판정할 수 없다. P까지 포함해야 한다.

| 구분 | 확인된 것 | 검증할 해석 |
|---|---|---|
| 쓰기 주소 | C를 쓸 때의 주소는 현재 흔적 z_t다. 시작 행동의 주소를 별도로 쓰지 않는다. | 이동·대기의 성분이 C 수정의 목적지를 지배할 수 있다. |
| 읽기 주소 | probe는 후보 경로를 따라 새 흔적을 만들고 q_i로 읽는다. | 같은 채집처라도 실제 기록과 재사용의 주소가 어긋날 수 있다. |
| 증거 망각 | 12.3절에서 켜면 다른 곳 선택이 약 15–16% 생긴다. | 잘못된 흔적 방향에 확신 완화와 재쓰기가 적용됐을 수 있다. |
| 정적 회귀 | 망각 없는 RLS는 같은 주소의 관측을 누적한다. b0에는 과거 B 두 번과 C 한 번이 있다. | 주소가 맞아도 C의 영향이 작을 수 있다. |

c_b0가 충분히 크고 다른 주소와 잘 분리되는데도 b0를 고집한다면, 귀속 해석만으로는 설명할 수 없다. 그때는 기존 확신과 회귀 평균화, 읽기 점수를 봐야 한다. 이상적인 독립 주소에서는 b1의 순수 B가 b0의 B/C 혼합보다 B 점수가 높을 수도 있다. 따라서 평균화도 아직 단독 원인으로 확정하지 않는다.

## 4. 권고: 8절에서 성공한 재사용 학습을 결합 시험까지 잇는다

중요한 차이가 코드에 있다.

| | 8절의 키 학습 | 현재 지연 채집의 키 학습 |
|---|---|---|
| 학습 손실 | 재방문 결과를 기억으로 예측한 오차 | 모든 스텝의 다음 관측 NLL 평균 |
| 경사 | 세션 전체를 펼쳐 기록까지 연결 | 64스텝마다 기억·흔적 경사를 끊음 |
| 직접 요구하는 것 | 먼저 쓴 사실을 나중 질의에서 재사용 | 현재 흔적에서 당장 다음 관측을 예측 |
| 코드 | `gate_learned.py:156–166` | `errand_prec.py:148–164` |

이 차이는 학습된 키가 갈림길에서 성공하고 지연 채집에서 실패한 이유의 **후보**다. 인과 증명은 아니다. 8스텝 지연은 64보다 짧다. 단순히 ‘BPTT가 짧아 결과를 연결할 수 없다’는 주장은 하지 않는다. 문제는 기록·보존·변경·재사용의 전체 연결이 학습 목적에 들어갔는가다.

**바꾸는 것은 키를 학습시키는 F의 문맥이다. 키·흔적·시냅스·선호의 결합과 빠른 쓰기 식은 유지한다.**

```text
F_read(M,q,y) = 1/2 · Σ_p [ ‖y_p − μ⁰_p − M_p q_p‖² / S_p
                            + H log S_p ]
S_p = R + q_pᵀ P_p q_p

θ의 느린 학습:
경험으로 M·P·e를 순전파 갱신
→ 그 기억을 고정하고 같은 종류의 경로 질의로 결과 예측
→ 재사용 관측의 F_read를 기록·흔적·키까지 미분
```

현재 월드 모델의 칸별 NLL 학습은 유지한다. 키의 주된 학습 신호를 위 재사용 F로 연결한다. 세계별 보상 가치나 b1 정답 분류를 학습시키는 것이 아니다.

| 필요한 학습 연결 | 무엇을 요구하는가 |
|---|---|
| 관찰 뒤 재사용 | 보상이 없었던 경험도 사실로 읽혀야 한다. |
| 반복 경험·보존 뒤 재사용 | 자주 본 장소 때문에 다른 장소의 사실이 사라지면 안 된다. |
| 새 결과를 쓴 뒤 재사용 | C의 오차가 b0을 다시 읽을 때 나타나야 한다. b1의 B는 남아야 한다. |

훈련에는 다른 세계 512개의 기존 교사 경험을 쓴다. 재사용 경로는 이미 있는 probe와 같은 형식이다. 학습 세계에서 그 경로를 따라 얻은 일반 관측을 예측 대상으로 쓴다. 재질의 중에는 기억을 쓰지 않는다. 이는 느린 학습의 관측 예측 자료이며, 새 시험이나 행동 제거 대조가 아니다.

모든 채집처를 같은 방식으로 질의한다. b0·b1 역할, 산출물 정답표, 작업 시작·완료 신호를 모델 입력으로 주지 않는다. 특정 8스텝이나 도착 HUD에만 쓰는 gate도 없다. 일반화할 것은 **경험으로 쓴 기억이 다른 문맥의 질의에서도 같은 사실을 말하게 하는 표현**이다.

느린 학습에서는 해당 경험 prefix와 재질의 사이의 경사를 끊지 않는다. 원래 기록부터 나중 재사용까지 펼친다. 비용은 느린 학습에서 부담한다. 실행 중에는 기존 k, e, M, P의 고정 계산만 한다.

이 경로는 C 이후의 재질의 오차를 실제 C 쓰기의 주소·이득으로 돌려보낸다. 다른 사실의 재질의도 함께 맞춰야 하므로, 모든 기억을 C로 만드는 해는 불리하다. 별도 인과 라우터나 보호 슬롯 없이, 시냅스가 구분할 표현을 학습하는 8절의 분업을 유지한다.

## 5. 정밀도·증거 수정에서 버리지 않을 것

칸별 정밀도는 유지한다. 코드상 월드 모델 분산 v는 `s²=v/v_max`를 통해 입력·사전 예측분산을 조절한다. RLS의 오차 가중은 `R+zᵀPz`에서 나온다. 이를 단순히 ‘관측 오차에 1/v를 곱한다’고 부르지는 않는다. 이 구분은 현재 결합의 효과를 부정하는 말이 아니다.

증거 망각을 더 강하게 만드는 것을 첫 수정으로 삼지 않는다. 방향이 틀리면 강한 수정은 오염도 키운다. 같은 사실을 예측한 주소에 반증이 도달하는 연결부터 맞춘다. 현재 fixes와의 첫 비교에서는 **증거 망각 없음, 기존 RLS**를 그대로 쓴다.

이 설정에서 b1 선택이 좋아져도 일반적인 변경·망각까지 해결했다고 주장하지 않는다. 정적 RLS의 평균화는 남아 있다. 이미 흐름에서 효과를 본 증거 수정도 주소가 맞아야 작동한다. 이번 제안은 그 앞의 연결을 고치고 검증하는 것이다.

## 6. 같은 시험에서 가를 예측

**환경·경험 prefix·판정은 바꾸지 않는다.** 11×11, 지연 8, 보존 256, 시험 세계 256개와 시드 0이다. C 도착 뒤 쓰기 중지, HUD를 제외한 주소, 무작위 동점 처리도 fixes와 같다. DK=128과 키·월드 모델 크기도 유지한다.

기억을 복제하고 기존 경로 probe를 쓰기 없이 실행한다. 기존과 같은 도착 HUD의 B 점수로 최대가 b1인지 판정한다. 잔차 점수를 전체 예측 점수로 바꿔 개선을 만들지 않는다. 바꾸는 것은 느린 키 학습의 재사용 목적과 경사 연결이다. 늘어난 훈련 관측·계산량은 함께 보고한다.

39.45%는 기존 실행의 출발점이다. 통제 비교에서는 같은 학습 세계·재질의 자료·최적화 예산을 제공하고, 키 학습의 손실·경사 연결을 비교한다. 재사용 자료나 계산량 증가의 효과를 귀속 정렬의 효과라고 단정하지 않는다. 시험 세계는 느린 학습에 쓰지 않는다.

| 같은 실행에 붙일 기록 | 사전 예측·반증 기준 |
|---|---|
| C 쓰기 전후의 동일 q_i 예측과 c_i | 귀속 가설이 맞으면 c_b0를 통한 C 전달이 커지고, 다른 주소로의 전달은 줄어야 한다. 단순 키 노름 증가는 성공 기준이 아니다. |
| b1·b0·다른 곳 비율 | b1이 39.45%에서 오르고 b0가 60.55%에서 줄어야 한다. 다른 곳 오염으로 b0만 줄면 실패다. 난수 키 44.92%보다도 유용한 개선인지 본다. |
| b0의 B/C 예측, b1의 B 예측 | C 쓰기가 b0을 C 쪽으로 바꾸고 b1의 B를 보존해야 한다. |
| 학습 prefix에서 쓰고 재질의한 F와 시험 결과 | 재사용 F만 좋아지고 시험 b1이 오르지 않으면, 학습 문맥의 과적합이다. 연결을 고쳤다고 부르지 않는다. |

c_b0가 원래부터 충분하면 ‘C가 잘못된 흔적에 묶였다’는 설명의 우선순위를 낮춘다. c_b0가 개선돼도 b1이 그대로면 귀속만으로는 부족하다. 주소는 맞는데 이득이 작다면 정적 회귀·확신이 남은 병목이라는 해석이 강해진다. 이는 새로운 시험을 만드는 것이 아니라 같은 실행의 쓰기 경로를 읽는 진단이다.

비율의 작은 차이를 확정적 개선으로 부르지 않는다. 같은 세계별 승패·점수차를 남겨 짝지어 비교한다. 이번 문서는 결과를 예고하는 것이 아니라 반증 가능한 권고다.

## 7. Minecraft로 가져갈 결합

사실을 겪어서 쓰고, 흔적으로 늦은 결과를 잇고, 현재 선호와 읽을 때 가치를 계산하는 결합을 그대로 가져간다. 시작·완료 규칙이나 과제별 기억 구조를 더하지 않는다. 다중 원인·가림·긴 지연은 같은 표현·월드 모델·흔적의 학습 문제로 남는다. 이번 작은 시험이 그것들을 해결했다는 뜻은 아니다.

그 전에 필요한 것은 새 본체가 아니다. **지금의 결합 안에서, 경험을 쓴 주소와 나중에 그 사실을 읽는 주소가 실제로 연결되는지 같은 지연 채집 판정으로 확인하는 것**이다.
