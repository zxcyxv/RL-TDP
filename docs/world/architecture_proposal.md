# 새 아키텍처 제안 — 2026-11-15, Codex

**권고는 표준 DeltaNet을 본체로 쓰는 단일 순환 시퀀스 에이전트다.** 관측·행동·보상·주어진 목표를 같은 시퀀스로 넣는다. 여러 DeltaNet 블록과 일반 예측·행동 head만 둔다. 지연 귀속과 기억 사용은 전체 시퀀스 학습으로 배운다.

별도 인과 라우터, 원인 슬롯, 개입 대조 자료, 계획기, 보호된 기억 칸은 두지 않는다. 앞서 작성하던 설계는 폐기했다. 이번에는 문서만 작성했다. 구현·학습·새 시험은 하지 않았다.

지연 귀속과 정적 회귀는 아직 실패 후보다. 이들을 각각 위한 장치를 만들지 않는다. **일반적인 순환 시퀀스 모델이 표현과 쓰기 규칙을 함께 배우게 한다.** 다만 기존의 RLS는 정적 회귀라는 목적이 명확하므로 그대로 가져오지 않는다.

| 기존에서 가져오는 것 | 이유 |
|---|---|

| 예측 오차의 외적 쓰기 | 현재 연결을 순전파 안에서 수정한다. |
| 세계 간 느린 학습 | 표현과 경험을 사용하는 공통 규칙을 배운다. |

전 스텝 키의 단일 합, 칸별 P, Beta 위험률은 가져오지 않는다. HUD별 전용 기억이나 작업 시작·도착 규칙도 없다.

## 2. 구성과 느린·빠른 분업

요구 번호는 ① 기억, ② 늦은 결과의 귀속, ③ 새 보상·목표 적응, ④ 증거에 따른 망각이다.

| 구성 | 역할 | 느린 것 / 빠른 것 | 요구 | 빼면 무너지는 것 |
|---|---|---|---|---|
| 공통 입력 인코더 | 장면·행동·보상·목표를 토큰으로 만든다. | 인코더 가중치는 느리다. | ①②③ | 서로 다른 관측을 같은 경험 문맥에서 처리하기 어렵다. |
| 여러 DeltaNet 블록 | 과거 정보를 읽고 새 정보를 시냅스에 쓴다. | 투영·정규화·쓰기율은 느리게 배운다. 행렬 상태 S는 세션마다 빠르게 변한다. | ①②③④ | 처음 본 세계의 경험을 이후 예측·선택에 쓸 곳이 없다. |
| 일반 관측·보상 head | 다음 관측과 보상 분포를 예측한다. | 공통 decoder는 느리다. 이번 세계의 근거는 S에서 읽는다. | ①②③ | 무엇을 기억해야 예측이 좋아지는지 학습 신호가 사라진다. |
| 일반 행동 head | 현재 문맥에서 바로 행동 분포를 낸다. | 공통 행동 추론은 느리다. 현재 목표·경험은 입력과 S에 있다. | ③ | 기억이 행동 개선으로 이어지지 않는다. |

사실 기억과 목표 기억을 별도 기계로 분리하지 않는다. 둘 다 같은 S에 표현한다. 블록 안의 다중 head·잔차 연결·RMSNorm·SwiGLU·짧은 causal convolution은 표준 시퀀스 모델 구성으로 둔다. 어떤 head가 산출물이나 의뢰를 맡을지는 지정하지 않는다.

전체 과거 토큰을 저장하는 KV cache는 없다. 짧은 convolution cache도 길이를 고정한다. 첫 설정은 4블록, convolution 폭 4로 둔다. 층을 통한 국소 문맥 범위는 13토큰이다. Minecraft에서는 이미지·행동 인코더를 바꾸거나 키울 수 있다. 본체의 기억 규칙은 그대로다.

## 3. 빠른 시냅스의 식

한 head의 표준 delta 쓰기는 다음과 같다. 블록·head마다 독립적인 S가 있다.

```text
x_t = encode(o_t, a_{t−1}, r_t, 주어진 목표 단서)

k_t = normalize(W_k x_t)
q_t = normalize(W_q x_t)
v_t = W_v x_t
β_t = sigmoid(w_β x_t)

δ_t = v_t − S_{t−1} k_t
S_t = S_{t−1} + β_t δ_t k_tᵀ
h_t = S_t q_t
```

실제 블록은 이전 블록의 출력을 입력으로 받는다. 따라서 위 x는 맨 아래층에서만 원시 입력이다. 위층의 k·v·q는 아래층이 읽은 과거 문맥에도 의존한다. 이 경로가 늦은 결과와 이전 경험을 연결할 수 있게 한다. 별도 원인 주소를 보관하거나 정답 시점을 알려주지는 않는다.

S는 세션 시작에 초기화한다. 이후에는 위 순전파만 실행한다. optimizer·autograd·경사 스텝은 없다. 수학적으로 delta가 국소 경사와 같다는 사실과, 실행 중 역전파로 모델을 학습한다는 것은 구별한다.

**전역 감쇠는 넣지 않는다.** `S←αS`의 α는 항상 1이다. 이 때문에 Gated DeltaNet의 추가 망각 gate보다, 기본 DeltaNet을 출발점으로 택한다. 새 입력에 따른 delta 수정만 있다.

### F와 정밀도 가중 쓰기

단위 길이 k에서 이 delta는 다음 국소 목적의 해다.

```text
F_mem(S) = π_t/2 · ‖v_t − S k_t‖²
           + τ/2 · ‖S − S_{t−1}‖²_F

S_t = S_{t−1} + [π_t / (τ + π_t)] · δ_t k_tᵀ
β_t = π_t / (τ + π_t)
```

첫 항은 내부 KV 예측의 정확도다. 둘째 항은 이전 시냅스 주변의 가우시안 prior다. τ는 공통 양수다. β head는 이 정밀도 비율을 출력한다고 해석한다. 이는 표준 delta 식을 설명하는 목적함수이며 추가 필터가 아니다.

정밀도를 기억 입력의 크기에 섞지 않는다. 키는 정규화한다. β와 관측 decoder의 잡음 분산은 다른 양이다. 앞 식은 가우시안 점추정의 국소 자유에너지다. 이것만으로 완전한 변분 추론이나 올바른 인과 귀속을 했다고 주장하지 않는다.

## 4. 느린 학습과 행동

느린 학습은 **경험으로 바뀌는 S를 포함한 전체 시퀀스**를 펼쳐서 한다. 과거 기록이 훗날 예측·선택에 도움이 되는지까지 θ에 경사를 보낸다. 적어도 현재 교사 세션 전체를 덮는다. 64스텝마다 상태 경사를 끊는 학습을 그대로 유지하지 않는다. 학습의 시간·메모리 비용은 세션 실행의 고정 예산과 별개다.

관측·보상 예측은 일반적인 확률 decoder `pθ(o_{t+1}, r_{t+1} | h_t, a_t)`로 학습한다. 행동은 같은 문맥을 받는 분포 `πθ(a_t | h_t, 목표 단서)`에서 바로 낸다. 미래 경로를 검색하지 않는다.

F를 쓰려면 관측 모형과 선호를 구별해야 한다. 행동 학습에는 주어진 목표·외부 보상에 대한 선호 factor C를 둔다. 관측 likelihood, 행동 prior, 선호 factor를 포함한 생성모형의 F를 줄인다.

```text
F = E_q[log q − log pθ(관측·보상·행동, 선호 충족 | 목표 단서)]

정책 부분:
E[Σ_t log(πθ(a_t | h_t) / p₀(a_t)) − Σ_t log C(실제 결과_t)]
```

이는 느린 학습 때의 목적이다. 실제 훈련 궤적으로 평가한다. 모델이 예측한 보상을 스스로 높여 답을 만드는 목적이 아니다. 실행 중에는 학습된 행동 head 한 번으로 추론한다. 별도 Q·critic·계획기는 요구하지 않는다. 현재 관측의 예측 오차만 줄이면 목표 행동까지 저절로 나온다고도 주장하지 않는다.

| 느린 θ가 배울 것 | 이번 세션의 S가 담을 것 |
|---|---|
| 장면 표현, 일반 전이, 관측·보상 해석, 경험을 읽고 쓰는 공통 규칙 | 이번 세계의 생산 배정, 겪은 변화, 현재 보상·목표 문맥 |
| 다양한 목표에서 통하는 행동 추론 | 이번 세계에서 어느 결과를 얻어야 하는가에 대한 경험 |

세계 배정·보상 규칙·목표 순서를 학습 세계 사이에서 다양하게 한다. 특정 위치의 가치나 A×4→B 순서를 정답처럼 학습시키지 않는다. 이는 일반 세션 자료의 다양성이다. 별도의 행동 제거 쌍이나 인과 label을 요구하지 않는다.

표준 신경망이 느린 가중치에 과제 상관을 전혀 저장하지 않는다는 수학적 보장은 없다. 의도하는 분업은 새 세계의 임의 배정을 θ가 알 수 없게 하고, 그 정보가 S를 통해서만 제공되게 하는 것이다. 공통 행동 규칙과 현재 과제의 가치를 같은 것으로 취급하지 않는다.

## 5. 매 스텝 순서와 자원

| 순서 | 동작 |
|---|---|
| 1 | 현재 관측, 직전 행동, 새 보상, 제공된 목표 단서를 인코딩한다. |
| 2 | 각 블록이 k·v·q·β를 계산하고, 자기 S를 delta로 갱신한 뒤 읽는다. |
| 3 | 최상위 특징으로 관측·보상 예측과 행동 분포를 낸다. |
| 4 | 행동 하나를 실행한다. S와 고정 길이의 짧은 cache만 넘긴다. |

블록 수 L, head 수 H, key/value 차원이 고정이면 기억은 `O(LH d_k d_v)`다. fast 쓰기·읽기도 스텝당 같은 차수다. 세션 길이에 따라 늘지 않는다. 가중치 공분산이나 과거 관측 목록은 없다.

## 7. Minecraft로의 이전

구조는 바꾸지 않는다. 입력 인코더, 행동 표현, 모델 크기와 훈련 분포를 확장한다. 작업 시작·완료 detector나 별도 인과 기억은 추가하지 않는다.

| 규모 외에 어려워지는 점 | 이 구조에서의 처리 |
|---|---|
| 다시점·가림·대상 동일성 | 같은 시퀀스 표현과 기억 사용으로 배운다. |
| 동시 원인·가변 지연·행동 연쇄 | 같은 순환 상태에 표현한다. 단일 pending 규칙에 기대지 않는다. |
| 확률적 결과와 실제 변화의 구별 | 관측 분포와 문맥에 따른 쓰기를 배운다. |
| 긴 시간의 목표 유지 | 더 긴 느린 학습 문맥이 필요하다. 실행 기억은 고정이다. |
| 훨씬 많은 독립 사실 | 고정 행렬의 용량 한계가 있다. 모든 사실의 영구 보존은 불가능하다. |

학습·규모가 이 어려움을 해결할지는 실증 문제다. 구조 변경이 없다는 말은 성공 보장이나 계산량 불변이라는 뜻이 아니다. 선택한 모델 크기 안에서 세션 길이에 따른 비용 증가가 없다는 뜻이다.

## 8. 시험은 기존 것 하나

**지연 채집 과제와 판정을 그대로 쓴다.** 관찰 → A×4 → B의 첫 보상 → 256스텝 보존 중 b0 변경 → b0 재방문이다. 최종 기억을 복제한다. 쓰기 없는 기존 경로 probe에서, 도착 HUD의 B 점수가 최대인 곳이 바뀐 b0 대신 b1인가를 본다.

최신 fixes 판의 평가 규약을 공통으로 쓴다. 추가 distractor, 행동 제거, 새 분기, 새 시험 과제는 만들지 않는다. probe에서는 모든 S 쓰기를 멈춘다. 표준 고정 길이 convolution cache는 경로의 새 입력으로 진행한다. 기존 probe에서 흔적 e를 진행시키는 것과 같은 작업 문맥의 역할이다. 학습된 head의 예측을 기존 고정 관측 특징으로 디코딩해 같은 B cosine 점수를 낸다. 내부 특징을 임의로 B 점수로 삼지 않는다.

| 사전 예측 | 실패 기준 |
|---|---|
| 새 구조는 학습 키 RLS의 b1 39.45%보다 높고, b0 편향을 줄일 것으로 예상한다. | b1이 오르지 않거나 b0 편향이 유지되면 이번 권고는 검증되지 않은 것이다. |
| 유용한 권고로 인정할 기준은 기존 256세계에서 b1 ≥80%다. | 80% 미만이면 이 과제의 해결책이라고 부르지 않는다. |

80%는 이론적 예측값이 아닌 사전 효용 기준이다. 학습 예산·모델 크기는 실행 전에 정한다. 결과를 본 뒤 기준을 낮추지 않는다. 한 시드의 소폭 상승으로 학습·규모 가설이 입증됐다고 하지 않는다.

이 판정은 사실 보존과 변경 후 선택을 검사한다. 일반적 인과 추론, 비공개 목표 추론, Minecraft 능력까지 입증하지 않는다. 실패해도 별도 장치를 덧붙이지 않는다. 우선 이 표준 시퀀스 모델이라는 권고 자체를 실패로 기록한다.
