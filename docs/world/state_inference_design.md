# 학습된 상태 추론 위의 Hebb 사실 기억

작성: 2026-11-15, Codex. 이론·구현 명세다. 구현·학습·과제 실험은 하지 않았다.
사용자의 추가 제약을 반영했다. **문 정체성·장면·진행도를 설계자가 상태 인자로 나누지 않는다.**

표기: **[표준]** 알려진 결과, **[확인]** 원문·코드 대조,
**[기억]** 원문 미대조, **[유도]** 명시한 가정 아래의 계산, **[가설]** 실험으로 판정할 주장.

## 0. 판단과 하나의 권고

**권고는 ‘상태를 분해하지 않는 계층 상태공간 모형 + 상태 사후를 키로 하는 관측 모형의 빠른 베이즈 학습’이다.**
gate에서는 관측 복제본으로 초기화한 유한 HMM을 느리게 학습한다.
Craftax에서는 같은 역할을 학습된 RSSM 잠재가 맡는다.
어느 상태가 어느 문에 해당하는지 지정하지 않는다. 사건·자원·대기 상태도 지정하지 않는다.
같은 픽셀 뒤의 다른 예측을 구분해야 할 때 전이와 우도가 상태를 갈라야 한다.

빠른 기억은 관측 모형의 세계별 파라미터다.
지연된 결과가 오면 **그때 추론한 상태**에 관측을 한 번 결합한다.
원시 행동 키들을 지수 흔적으로 합쳐 결과를 회귀하지 않는다.
행동 빈도·관측 놀라움을 쓰기 계수에 곱하지 않는다. 별도 중요도 머리도 없다.
현재 과제에서 ET가 불필요해지면 삭제한다.

세 가지 제한을 먼저 고정한다.

1. **상태를 배울 자료가 필요하다.** 현재의 ‘문마다 한 번 노출 → 검사에서 종료’만으로는
   문에 따라 재사용할 상태와 노출 순서에 따른 상태를 식별하기 어렵다.
   두 설명의 관측 우도가 같아지는 모형도 만들 수 있다.
   같은 세계에서 같은 문을 다시 보는 사전학습 자료가 필요하다 (§6).
2. **불확실한 상태에 대한 외적 쓰기는 보통 변분 근사다.**
   알려진 상태의 디리클레 갱신과, 상태·파라미터의 정확한 공동 사후를 혼동하지 않는다 (§3).
3. **FEP가 상태 구조나 장기 일반화를 보장하지 않는다.**
   상태 수, 우도 계열, 근사 추론은 모형 선택이다.
   학습된 주소가 틀리면 베이즈 쓰기도 틀린 주소를 확신한다.

이 설계의 기본식은 새 알고리즘이 아니다.
능동적 추론의 디리클레 학습, HMM의 상태 추론, 베이즈 연상 기억의 결합이다.
기여를 주장하려면 같은 예산에서 **학습된 주소의 인과적 재사용·긴 보존·국소 수정**을 함께 보여야 한다.

\[
p(o_{t+1}\mid\mathcal H_t,a_t,A)

\tag{1}
\]

현재 복도 관측과 나중 자원 관측은 **다른 시점의 추론 상태**에 조건화한다.
그 상태들의 차이를 설계자가 부여하는 대신 느린 예측 학습으로 얻는다.

## 2. 생성 모형: 숨은 상태는 하나의 학습된 공간

### 2.1 이산판

행동 시점은 \(o_t\to a_t\to o_{t+1}\)다.
\(\mathcal H_t=(o_0,a_0,\ldots,o_t)\)다.
아래 j는 주어진 영상의 패치 번호다. 세계 좌표나 의미 상태 번호가 아니다.
\(s_t\in\{1,\ldots,S\}\)에는 이름 없는 상태 S개만 둔다.

\[
p_\theta(A,s_{0:T},o_{0:T}\mid a_{0:T-1})
 =p_\theta(A)p_\theta(s_0)
   \prod_{t=1}^{T}B^{a_{t-1}}_{s_t s_{t-1}}
   \prod_{t=0}^{T}\prod_{j=1}^{J} A_{j,o_{j,t},s_t},
\tag{2}
\]
\[
A_{j,:,s}\sim\operatorname{Dir}(\alpha^0_{j,:,s}),\qquad
\alpha^0_{j,:,s}=\kappa_{j,s}\pi^0_{j,:,s}.
\tag{3}
\]

B는 열 확률행렬이다. J=49, 관측 기호 수 K≤17인 첫 검사를 §8에 정한다.
모든 패치·상태에 같은 형태를 적용한다.
‘이 패치는 자원일 때만 빠르다’, ‘이 상태는 문 상태다’라는 마스크가 없다.

| 세계 간 공유하는 느린 θ | 세계 안의 빠른 상태 |
|---|---|
| 영상 부호화·정규화된 우도, B, 초기 상태 사전 | 현재 상태 믿음 b |
| 관측 사전 평균 \(\pi^0\), 세계 간 변이의 척도 \(\kappa\) | 관측 파라미터 사후의 계수 \(\alpha\) |
| 필요한 경우 변화 위험률의 사전 | 흐름판의 변화 사후·위험률 충분통계 |

‘왼쪽 문 뒤 복도’는 학습 뒤의 해석일 수 있다. 생성 모형의 인자 이름은 아니다.
같은 관측을 내는 여러 상태가 서로 다른 전이를 갖는 CSCG의 취지를 따른다.
다만 **고정된 전체 그림에 방출을 영구 고정하는 원래 CSCG를 그대로 쓰지 않는다.**
세계마다 결과 그림이 바뀌므로 방출 사전과 세계별 방출도 학습해야 한다.
관측 복제는 초기화다. 이후 방출의 이동·공유 여부는 자료가 정한다. [유도]

이 모형도 과제의 정확한 생성 과정은 아니다.
gate의 두 자원은 비복원 추출이지만 (3)은 상태별 독립 사전이다.
패치 간 조건부 독립도 근사다. 둘 다 학습·보정의 제한으로 보고한다.
정답 자원 쌍 12가설을 열거하는 모형은 과제 전용 정보 상한으로만 둔다.

### 2.2 연속판과 대응

범용 형태는 다음이다.

\[
p_\theta(M,s_{0:T},o_{0:T}\mid a)
 =p_\theta(M)p_\theta(s_0)
   \prod_{t=1}^{T}p_\theta(s_t\mid s_{t-1},a_{t-1},M)
   \prod_{t=0}^{T}p_\theta(o_t\mid s_t,M).
\tag{4}
\]

여기서도 위치·문·자원·inventory로 잠재를 손으로 나누지 않는다.
RSSM을 쓰면 \(s_t=(h_t,z_t)\)는 결정론/확률론 경로라는 계산상의 분해다.
특정 과제의 의미 상태 분해가 아니다.

\[
h_t=f_\theta(h_{t-1},z_{t-1},a_{t-1},\operatorname{Read}(M,h_{t-1})),
\quad z_t\sim p_\theta(z_t\mid h_t,M),
\]
\[
q_\theta(z_t\mid h_t,o_t,q(M)),\qquad
p_\theta(o_t\mid h_t,z_t,M).
\tag{5}
\]

읽기는 같은 생성 모형의 예측을 상태 추론에 전달하는 연산이다.
온라인에서 Read(q(M))를 쓰는 것은 생성 모형의 M 적분을
평균·공분산 등으로 대신하는 추론 근사다. q 자체를 생성 원인으로 둔 항등식은 아니다.
미리 정한 ‘문 비트’를 RSSM에 붙이지 않는다.
gate에서는 세계 간 B가 같지만 Craftax의 무작위 지형은 이동 결과도 바꾼다.
따라서 Craftax에서 세계별 변이를 관측 표에만 가둘 수는 없다.
공유 물리 전이가 추론한 세계 사실 M에 조건화하도록 (4)를 사용한다.
이는 새로운 전이 정답 표를 넣는다는 뜻이 아니다.

| 이산 HMM | 연속/RSSM |
|---|---|
| 같은 그림을 설명하는 다른 상태 복제본 | 같은 관측 뒤에도 다른 미래를 예측하는 잠재 사후 |
| \(B^a b\) | 학습된 순환 전이의 사전 |
| 관측 우도와 결합한 b | 인코더와 사전의 관측 사후 |
| 상태 지시자의 평균 b | 학습된 특징의 사후 모멘트 |
| 디리클레 \(\alpha\) | 조건부 가우시안이면 M의 평균·공분산/자연 파라미터 |

RSSM이 필요한 구별을 실제로 배운다는 보장은 없다.
범주형 잠재를 쓰는 Dreamer 계열에도 같은 원리가 적용된다.
일반 RSSM과 공액 빠른 시냅스가 자동으로 같은 모형이 되지는 않는다 (§5).

## 3. 상태 추론과 빠른 외적 쓰기

### 3.1 현재 자유에너지와 필터

새 관측 전 빠른 사전을 \(q^-(A)\), 상태 사전을 \(b^-\)라 하자.
온라인에서는 이전의 근사 사후를 다음 사전으로 쓴다.

\[
b_t^-=B^{a_{t-1}}b_{t-1},\qquad
F_t(q)=\operatorname{KL}(q(s,A)\|b_t^-(s)q^-(A))
             -\mathbb E_q\log p(o_t\mid s,A).
\tag{6}
\]

\(F_t=\operatorname{KL}(q\|p(s,A\mid o_t))-\log p(o_t\mid\mathcal H_{t-1},a_{t-1})\)다.
이는 주어진 근사 사전을 조건으로 한 항등식이다.
이전부터 버린 상태–파라미터 상관이 복원된다는 뜻은 아니다.

조건부 A가 알려졌을 때의 정확한 HMM 필터는

\[
b_t(s)=\frac{b_t^-(s)\prod_j A_{j,o_{j,t},s}}
                 {\sum_u b_t^-(u)\prod_j A_{j,o_{j,t},u}}.
\tag{7}
\]

변분 분해 \(q(s)q(A)\)에서 한 번의 좌표 갱신은 다음이다.

\[
\ell_t(s)=\sum_j
 \{\psi(\alpha^-_{j,o_{j,t},s})-\psi(n^-_{j,s})\},
\quad n_{j,s}=\sum_r\alpha_{j,r,s},
\]
\[
b_t=\operatorname{softmax}(\log b_t^-+\ell_t).
\tag{8}
\]

예측 확률의 \(\log(\alpha/n)\)와 변분 추론의 \(\psi(\alpha)-\psi(n)\)는 다르다.
사전 NLL은 관측 전에 정규화된 예측 분포로 기록한다.
방금 쓴 뒤의 재구성 점수로 대신하지 않는다.
모든 패치의 공동 예측 확률은
\(\sum_s b_t^-(s)\prod_j \alpha^-_{j,o_{j,t},s}/n^-_{j,s}\)다.

### 3.2 Hebb 쓰기의 유도

(6)을 q(A)에 대해 최소화하면

\[
\log q^+(A)=\log q^-(A)+
       \sum_{j,r,s}o_{j,r,t}b_t(s)\log A_{j,r,s}+\text{상수},
\]
\[
\boxed{\alpha^+_{j,r,s}
 =\alpha^-_{j,r,s}+o_{j,r,t}b_t(s).}
\tag{9}
\]

j마다 **관측 one-hot ⊗ 추론된 상태 믿음**이다.
키는 b다. 시간차는 이미 \(B^a\)와 상태 추론 안에 있다.
키에 미래 관측을 넣지 않는다는 원칙은 유지하되,
현재 관측으로 현재의 숨은 원인을 추론하는 것은 정당하다.
관측을 보고 주소를 추론하는 것과 미래 정답을 미리 주는 것을 구분한다.

알려진 상태에서는 (9)가 정확한 공액 사후다.
불확실한 상태에서는 q(s)q(A)라는 변분 가족 안의 좌표 해다.
그 경우 정확한 사후는 ‘어느 열에 썼는가’에 대한 디리클레 혼합이다.
한 디리클레의 소수 계수로 정확히 표현되지 않는다. [표준·유도]

기본 온라인 명세는 **(8) 한 번 → (9) 한 번**이다.
모든 프레임을 쓴다. 추가 게이트가 없다.
현재 관측으로 상태를 다시 추론하는 내부 반복을 시험한다면,
매번 \(\alpha^-+o\otimes b^{(i)}\)로 재계산해야 한다.
\(\alpha^{(i)}\)에 같은 관측을 계속 더하면 중복 증거다.
반복 횟수를 결과를 보고 늘리는 판은 기본 명세에 포함하지 않는다.

계수 하나의 쓰기는 두 끝 활동으로 표현된다.
그 앞의 b 계산은 전이 행렬·전체 관측 우도를 합치는 집단 계산이다.
시냅스 갱신의 국소성과 상태 추론 전체의 국소성을 구분한다.

관측이 불확실할 때도 주의가 필요하다.
감각 혼동 모형 L이 있으면 깨끗한 기호 r와 상태 s의 **공동** 책임도
\(\gamma_t(r,s)\)를 계산해 더한다.
일반적으로 \(q(r)q(s)\)를 곱하는 것과 다르다.
노이즈가 큰 프레임을 수제 신뢰도 계수로 한 번 더 깎지 않는다.

### 3.3 계수에서 나오는 새로움과 정밀도

한 열의 평균을 \(m_r=\alpha_r/n\)라 하자.
그 상태가 확실하고 관측이 e_y이면

\[
m^+=m+\frac{e_y-m}{n+1},\qquad
\operatorname{Cov}(A)=
       \frac{\operatorname{diag}(m)-mm^\top}{n+1}.
\tag{10}
\]

소수 책임도 b를 쓰는 변분 판에서는 평균 이득이 \(b/(n+b)\)다.
**원시 계수에는 매번 증거를 더한다. 작아지는 것은 평균의 변화와 정보 이득이다.**
‘아는 것은 원시 메모리에 아예 안 쓴다’는 규칙은 디리클레 학습에서 나오지 않는다.

패치·상태가 알려진 경우의 관측 전 파라미터 정보 이득은 정확히

\[
\mathcal I_A(\alpha)=I(A;Y)
 =H(m)+\sum_r m_r\{\psi(\alpha_r+1)-\psi(n+1)\}.
\tag{11}
\]

같은 평균에서 n이 커지면 이 값은 작아진다.
작은 확률의 결과가 나왔다는 관측 놀라움 \(-\log p(y)\)와 다르다.
확률적 우도를 충분히 배운 뒤에도 관측 놀라움은 남을 수 있다.
그 경우 파라미터 정보 이득은 거의 0이다.

디리클레 n은 파라미터 불확실성이다. 감각 잡음 정밀도와 같은 양이 아니다.
gate의 첫 기호화는 잡음 없는 고정 무늬라는 가정이다.
연속·잡음 판에서는 관측 우도와 상태 사후가 신뢰도를 담당한다.

또한 (11)을 (9)에 곱하지 않는다.
그 곱은 원래 사후를 다른 가중 자료의 사후로 바꾼다.
EFE의 정보항은 무엇을 관측할 행동을 택할지에 들어간다.
안정된 무관 새 무늬도 파라미터 정보를 줄 수 있으므로,
계수만으로 과제 관련성·용량 경쟁이 모두 해결됐다고 주장하지 않는다.

## 4. 흔적, 시간차 창, 원인의 자리

### 4.1 이제 사실 학습에는 별도의 ET가 필수가 아니다

배운 상태가 충분통계라면
\(p(o_{t+1}\mid\mathcal H_t,a_t,A)=p(o_{t+1}\mid b_t,a_t,A)\)다.
지연된 자원을 볼 때의 b에는 실제 과거 행동의 영향이 전이로 전달되어 있다.
사실 갱신 (9)은 현재의 한 스텝 관측 모형 학습이다.

| 세 종류의 시간 연결 | 담당하는 것 |
|---|---|
| 순방향 상태 메시지 | 과거 행동·관측이 현재 숨은 원인에 주는 정보 |
| 역방향 평활 메시지 | 나중 증거가 과거 상태·전이 배정을 바꾸는 정보 |
| 정책/가치의 적격 흔적 | 뒤늦은 효용이 과거 정책 파라미터에 주는 공 |

이 세 가지를 하나의 ET라고 부르지 않는다.
특히 (9)는 정책 기울기의 score 흔적이 아니다.

고정 A에서 전방 필터의 과거 영향은 야코비안의 곱이다.
\(D_t=\operatorname{diag}(p(o_t\mid s))\),
\(Z_t=\mathbf1^\top D_tB^{a_{t-1}}b_{t-1}\)라 두면

\[
\frac{\partial b_t}{\partial b_{t-1}}
  =\frac{(I-b_t\mathbf1^\top)D_tB^{a_{t-1}}}{Z_t},
\quad
\frac{\partial b_t}{\partial b_\tau}=\prod_{\ell=\tau+1}^t J_\ell.
\tag{12}
\]

이는 행동·관측에 따라 달라지는 행렬 전달이다.
\(e_t=\alpha e_{t-1}+k_t\)는 이 역할을 고정 선형 동역학으로 근사하는 한 방법이다.
정확한 상태 추론과 일반적으로 같지 않다.
반복 입력을 무조건 더하는 ET와 달리 b는 항상 확률질량 1이다.

HMM 평활의 역방향 메시지는

\[
\beta_t(s)=\sum_{s'} B^{a_t}_{s's}
                      p(o_{t+1}\mid s')\beta_{t+1}(s'),\quad
\gamma_t\propto b_t\odot\beta_t.
\tag{13}
\]

TDP의 시간차 창을 메시지의 압축된 근사로 시험할 수는 있다.
그러나 고정 시차 이중합이 자동으로 (12)나 (13)이 되지는 않는다.
원문 창은 음수·복소 성분도 허용한다. 확률 메시지는 정규화·비음수 조건을 갖는다.
양방향 창을 쓴다고 세계 결과의 올바른 원인이 식별되는 것도 아니다.

TDP 가소성 문서 §2.5의 ‘빠른 기억=정책 ET’는
행동 표본 편차를 값으로, 키 선행 반창만, 행동 토큰만 모으는 조건에서의 별도 대응이다.
그 정책 학습의 대응을 사실 관측 표의 학습으로 옮기지 않는다. [확인·유도]

### 4.2 측정된 두 실패는 어떤 조건에서 사라지는가

자원 관측 시각을 \(\tau\)라 하자. 학습된 두 주소 믿음을 \(b^{(1)},b^{(2)}\)라 쓴다.
이는 설계자가 정한 두 문 변수가 아니라 사후의 진단 표기다.

\[
\Delta\alpha_\tau=o_{\rm res}\otimes b_\tau,\qquad
\Delta\alpha_{\rm room}=\sum_{t\in{\rm room}}o_t\otimes b_t.
\tag{14}
\]

| 기존 현상 | 새 모형에서 없어지는 조건 | 남는 실패 |
|---|---|---|
| 자원 시점 ET의 70%를 직전 복도 키가 차지 | 자원 시점의 상태 사후가 경로별로 구분됨. 최근성 비율을 배분할 ET가 없음 | 상태를 합쳐 배웠다면 두 경로가 같은 열을 씀 |
| 둘째 결과를 ‘둘째−첫째’로 저장 | 두 사후의 지지 상태가 분리되면 첫째 관측은 둘째 열을 바꾸지 않음 | 주소가 겹치면 explaining-away와 오배정이 여전히 가능 |
| 방 반복으로 \(\|e\|^2\)가 수십까지 증가 | \(\|b_t\|_1=1,\ \|b_t\|_2^2\le1\). 방 횟수가 현재 키의 노름을 키우지 않음 | 작은 오배정이 긴 대기 동안 누적될 수 있음 |
| 중간의 잔차 0이 과거 문 연합을 지움 | 중간 관측은 중간 상태 열에 대한 증거. 지연 결과와 같은 입력 회귀가 아님 | 잘못 학습한 상태 공유는 여전히 두 표적을 충돌시킴 |

엄밀한 긴 대기 불변성은 공짜가 아니다.
보호할 상태 s*에 방 사후가 매번 \(\epsilon_t\)씩 새면 그 열에 쌓이는 오증거는
\(\sum_{t=1}^D\epsilon_t\)다.
그 지지가 정확히 0일 때만 해당 열이 엄밀히 보존된다.
학습한 양의 확률 HMM에서는 유한 D=2048/36,000에서 누수를 측정해야 한다.
q의 문턱을 잘라 0으로 만드는 수선은 권하지 않는다.

### 4.3 예측 가능한 ‘남은 문’도 원인이다

이력이 둘째 행동을 완전히 정하면 \(-\log p(a_t\mid\mathcal H_t)=0\)이다.
그러나 상태 사전은 여전히

\[
b_{t+1}^-=B^{a_t}b_t
\tag{15}
\]

로 바뀐다. 행동의 확률로 B를 곱하거나 차분하지 않는다.
다른 행동을 개입했을 때의 예측은 \(B^{a'}b_t\)다.
두 예측이 다르면 그 모형은 행동의 효과를 표현한다.
행동이 놀라운지 여부는 이 식에 없다.

반대로 정책 기울기의 \(e_a-\pi\)가 0인 것은
이미 확실하게 고르는 행동의 확률을 더 올릴 직접 score가 없다는 뜻이다.
물리적 효과가 없다는 뜻이 아니다.

관측 자료만으로 임의의 반사실적 효과가 식별되지는 않는다.
이번 사전학습은 문 선택을 외생적으로 바꿔 같은 이력 부근의 두 행동을 관측해야 한다.
항상 ‘남은 문’만 실행한 자료의 지원 밖 행동까지 FEP가 알아낸다고 하지 않는다.

## 5. 연속 잠재에서 같은 학습은 무엇인가

### 5.1 조건부 선형 가우시안에서 닫히는 식

학습된 상태 특징 \(f_\theta(s)\in\mathbb R^d\)를 쓴다.
‘문 좌표’를 특징의 특정 칸에 배정하지 않는다.
정규화된 관측 인자가 실제로 다음 형태일 때를 먼저 보자.

\[
y_i=\mu^0_{i,\theta}(s)+w_i^\top f_\theta(s)+\varepsilon_i,\quad
\varepsilon_i\sim N(0,R_i(s)),\quad q(w_i)=N(m_i,P_i).
\tag{16}
\]

상태가 알려져 k=f(s)일 때

\[
g_i=\frac{P_i^-k}{R_i+k^\top P_i^-k},\quad
m_i^+=m_i^-+g_i(y_i-\mu_i^0-(m_i^-)^\top k),
\]
\[
P_i^+=P_i^--\frac{P_i^-kk^\top P_i^-}{R_i+k^\top P_i^-k}.
\tag{17}
\]

이전 설계 식 (1)에서 **ET e를 현재 추론 상태의 특징 k로 바꾼 조건부 공액식**이다.
새 규칙이라는 주장은 없다.
관측 정밀도 R, 세계 간 사전 P₀는 느린 우도·계층 사전에서 배운다.
정보 이득은 조건부로
\(\frac12\log(1+k^\top P_i^-k/R_i)\)다.

불확실한 상태에서는 \(k=\mathbb E[f(s)]\)만 넣고 정확하다고 할 수 없다.
변분 좌표 해의 자연 파라미터는

\[
\Lambda_i^+=\Lambda_i^-+
       \mathbb E_q[f(s)f(s)^\top/R_i(s)],
\]
\[
\eta_i^+=\eta_i^-+
       \mathbb E_q[f(s)(y_i-\mu_i^0(s))/R_i(s)],
\quad P_i^+=(\Lambda_i^+)^{-1},\ m_i^+=P_i^+\eta_i^+.
\tag{18}
\]

\(\mathbb E[ff^\top]\neq\mathbb E[f]\mathbb E[f]^\top\)다.
자료가 두 숨은 원인을 구분하지 못할 때 평균 특징만으로 갱신하면 섞인 주소를 확신할 수 있다.
식 (18)도 상태–가중치의 독립 근사를 둔다. 다중 모드를 완전히 보존하는 식이 아니다.

### 5.2 RSSM에 연결할 때의 금지와 미해결점

RSSM의 사후 잠재를 그대로 독립적인 새 관측 y로 쓰지 않는다.
관측이 없는 방향의 자기 예측을 다시 증거로 넣으면 기억만으로 정밀도가 증가한다.
필요한 것은 실제 픽셀 우도가 더한 인자다.

정확한 가우시안 인자라면 사전/사후의 자연 파라미터 차
\(\Lambda_{\rm obs}=V_q^{-1}-V_p^{-1}\),
\(\nu_{\rm obs}=V_q^{-1}m_q-V_p^{-1}m_p\)
에서 관측 인자를 복원할 수 있다.
관측이 아무것도 제약하지 않으면 이 차는 0이다.
비선형·범주형 RSSM에서 이 차가 늘 양의 우도 인자가 된다는 보장은 없다.

Craftax의 최소 연결은 기존의 정규화된 디코더/잠재 생성 인자 일부를
조건부 선형의 빠른 파라미터 M으로 만드는 것이다.
비선형 디코더를 거치면 국소 선형화나 변분 근사를 명시한다.
새로운 ‘자원 정답 잠재’나 정밀도 정답 머리는 만들지 않는다.
보이지 않는 사실에 대한 우도가 M에 의존하지 않으면 그 인자의 M 정보는 0이다.
이는 사건 마스크를 전달하는 조작과 다르다.

이는 수학적 연결 명세다. 임의의 기존 RSSM에 (17)을 끼우면
올바른 픽셀 자유에너지가 된다는 증명이 아니다.
이 연결과 주소 학습을 검증하지 않은 채 Craftax 학습으로 넘어가지 않는다.

### 5.3 의미 상태를 추가하지 않는 연속판의 구체 기준형

연결을 단순한 ‘RSSM 위의 임의 메모리’로 남기지 않기 위해,
기존 영상 디코더의 마지막 관측 사상을 다음 조건부 가우시안으로 두는 기준형을 정한다.
입력은 실제 관측 픽셀이다. 인코더의 자기 예측이 아니다.

\[
o_{j,i,t}=\mu^0_{\theta,j,i}(s_t)
              +m_i^\top f_{\theta,j}(s_t)+\varepsilon_{j,i,t},
\quad
\varepsilon_{j,i,t}\sim N(0,R_{\theta,j,i}(s_t)).
\tag{18a}
\]

j는 영상 패치, i는 패치 안 픽셀·색 채널이다.
147차원 패치를 유지하면 i=1,…,147, \(f_{\theta,j}(s)\in\mathbb R^{32}\)다.
M은 147×32이고 모든 패치에 공유한다.
패치 j는 영상 출력의 인덱스다. 세계 좌표나 물체 정답이 아니다.
기존 디코더의 특징이 f를 만들고 μ⁰가 공유된 관측 구조를 낸다.
별도의 자원 분류·중요도·쓰기 머리를 추가하지 않는다.
‘각 패치가 어떤 세계 사실을 조회하는가’도 f와 상태 추론의 학습 결과다.

현재 q(s,M)로 (18a)의 예측을 RSSM의 기존 관측 추론에 사용한다.
관측 후 각 실제 패치 인자로 (18)의 충분통계를 더한다.
같은 프레임의 여러 패치는 같은 s에 의존하므로,
상태 사후를 한 번 구하고 그 사후 아래의 기대 통계를 합산한다.
어떤 패치가 자원인지·언제 보이는지에 따른 선택은 없다.
f가 서로 다른 맥락을 구분하지 못하면 연속판도 실패한다.

느린 가우시안 사전 \(p(m_i)=N(m_i^0,P_i^0)\)의 공통 좌표가 고정되어 있다면,
세계별 사후 \(N(m_i^w,P_i^w)\)에서 경험적 베이즈의 모멘트는

\[
m_i^0=\mathbb E_w m_i^w,\qquad
P_i^0=\mathbb E_w[P_i^w+(m_i^w-m_i^0)(m_i^w-m_i^0)^\top].
\tag{18b}
\]

R은 같은 생성 우도의 기대 잔차 제곱에서 배운다.
그 기대에는 상태와 M의 사후 분산도 포함한다.
원시 예측 오차의 세계 간 분산을 모두 R로 넣으면 세계 사실을 잡음으로 버리게 된다.
상태·관측이 반복되는 같은 세계 자료가 이 구분에도 필요하다.

이 기준형은 정규화된 전체 관측 우도를 갖는다.
실제 채택하는 RSSM 디코더가 다른 우도라면 공액식도 그에 맞춰 다시 유도해야 한다.
RSSM이 (18a)를 그대로 쓴다는 주장이 아니다.
지금의 원리 검사를 위해 마지막 관측 사상을 선택한 것이다.
기존 표준 RSSM 대조에도 같은 관측 우도를 적용해 우도 변경의 이득을 분리한다.

출력별 full P를 쓰면 M 4,704 + P 150,528 = 155,232 float32,
**620,928바이트**에 RSSM carry가 더해진다.
패치 수 J는 관측 갱신 비용에 곱한다.
등방 출력 잡음·행렬 정규 사전이 정당화될 때만 P를 공유할 수 있다.
비용을 줄이려고 이를 몰래 가정하지 않는다.

변분 EM에서는 q를 고정한 M-step으로 θ를 학습할 수 있다.
빠른 쓰기 연산 전체를 D스텝 역전파해야만 하는 것은 아니다.
그러나 q를 제대로 얻거나 f와 순환 전이를 학습하는 시간 의존성은 여전히 남는다.
훈련 중 θ가 바뀌면 이전 좌표로 쓴 M을 새 좌표의 replay에 붙이지 않는다.
훈련 세션을 새 θ로 다시 추론하거나, 일치하는 carry/표현 버전을 사용해야 한다.
이 훈련 비용을 온라인의 고정 계산 보장에 포함시켜 숨기지 않는다.

## 6. 느린 학습: 무엇을 배우며, 신호는 얼마나 멀리 가야 하는가

### 6.1 현재 자료로 식별하지 못하는 두 가지

첫째, 세계별로 각 주소의 관측이 한 번뿐이면 디리클레 사전의 총계수는 식별되지 않는다.
한 관측 y의 주변 우도는

\[
\frac{\mathcal B(\kappa\pi^0+e_y)}
     {\mathcal B(\kappa\pi^0)}
 =\pi^0_y.
\tag{19}
\]

\(\kappa\)가 사라진다.
관측 가능한 세계 간 결과 분산을 추정하는 것과,
세계별 파라미터의 분산·세계 안 측정 잡음을 분리하는 것은 다른 문제다.
원래 이상적 v를 없앴다면서, 한 번 노출만으로 그 둘을 모두 배웠다고 하지 않는다.
같은 세계의 같은 결과에 대한 반복 관측이 필요하다.
자료가 없으면 \(\kappa=1\) 같은 사전 가정을 명시할 수 있을 뿐이다.

둘째, ‘각 문을 한 번씩, 이후 결과 없이 종료’는 재사용 구조를 충분히 제약하지 않는다.
문에 따라 상태를 가르는 모형과 첫째/둘째 노출에 따라 가르는 모형은
교환 가능한 세계별 방출 사전 아래 같은 자료를 설명할 수 있다.
비복원 추출에 따른 두 결과의 차이도 ‘두 노출을 다르게 취급하라’는 증거는 되지만,
‘같은 문이면 재사용하라’까지 고유하게 정하지 않는다.
이후 검사 선택의 정답을 학습 손실로 주지 않으면 그 차이는 평가에서 처음 드러날 수 있다.

따라서 원래 자료만 쓰는 학습판을 **식별성 음성 대조**로 남긴다.
성공할 수 없다는 일반 정리가 아니라, 성공을 보장할 식별 근거가 부족하다는 판단이다. [유도]

### 6.2 최소 공통 사전학습 자료

환경의 의미 라벨을 추가하지 않고 같은 세계를 재방문한다.
기존 make_world가 만든 두 경로의 관측·행동 블록을 같은 세계 안에서 재사용하면 된다.
이는 Claude가 만들 훈련 자료 생성 절차다. 이번에는 구현하지 않았다.

1. 세계별 자원 추첨은 기존과 같다. 선택을 자원에서 역산하지 않는다.
2. 같은 세계에서 두 경로를 각각 두 번 통과한다.
   네 선택은 L,L,R,R의 무작위 순열이다. 관측하는 실제 행동만 학습기에 준다.
3. 세 노출 간 간격은 각각 {0,8,16,32}에서 뽑는다.
   마지막 대기는 {8,16,32}에서 뽑는다.
4. 기존과 같은 HUD 검사 관측을 보여 준다.
   훈련에서는 그 뒤에도 무작위 문 하나로 실제 같은 세계의 결과를 한 번 더 관측한다.
   정답 행동·정답 주소는 주지 않는다. 이 마지막 탐침은 느린 재사용 학습의 자료다.
5. 최종 평가는 기존 gate.py 그대로다.
   각 문 한 번 노출, gap=0/32, D=32/256/2048, 첫 선택에서 점수를 낸다.
   검사 뒤 결과는 평가 학습기에 주지 않는다.

자료 생성기 안에서 블록을 조합하려고 환경 배열을 읽는 것과,
학습기에 숨은 상태·자원 배정을 전달하는 것은 다르다.
학습 입력은 렌더링된 패치, 실제 행동뿐이다.
world.answer와 내부 타일 ID는 평가기/자료 생성기 밖으로 넘기지 않는다.
모든 학습 비교군에 같은 자료를 준다. 새 자료의 이득을 새 기억의 이득으로 세지 않는다.

이 조작은 보편적인 ‘재방문 경험’이다.
문 상태를 알려 주거나 특정 시점의 쓰기를 강화하는 표지가 아니다.
Craftax에서도 재관측·이동·같은 물체에 대한 반복 경험이 이 역할을 해야 한다.

### 6.3 느린 목적과 충분통계

훈련 세계 w마다 빠른 A가 있고 θ는 공유한다.
학습 목적은 이 생성 모형의 계층 ELBO다.

\[
\mathcal L_{\rm slow}
 =\sum_w\left[
 \mathbb E_{q_w}\log p_\theta(o^w,s^w\mid a^w,A^w)
 -\operatorname{KL}(q_w(A^w)\|p_\theta(A^w))
 +H(q_w(s^w))\right]+\log p(\theta).
\tag{20}
\]

단일 목표다. ‘좋은 기억’·문 정체성·중요도 정답의 보조 손실은 없다.
고정 θ에서 q(A)와 q(s₀:T)를 교대한다.
q(s₀:T)는 기대 로그 방출을 쓰는 HMM 전방–후방으로 구한다.
훈련에만 평활을 허용한다. 평가 주소는 미래 관측 없는 필터로 계산한다.

두 시점의 공동 사후를
\(\xi_t(s',s)=q(s_t=s',s_{t-1}=s\mid o_{0:T},a)\)라 하면

\[
C^u_{s's}=\frac1S
  +\sum_{w,t:a^w_{t-1}=u}\xi^w_t(s',s),\qquad
B^u_{s's}=\frac{C^u_{s's}}{\sum_v C^u_{vs}}.
\tag{21}
\]

총 가산 횟수 1의 MAP 전이 추정이다. 대응하는 사전은 열마다 Dirichlet(1+1/S)다.
매 EM 순회에서 현재 자료의 소수 횟수를 다시 계산한다.
\(\xi_t\)를 \(\gamma_t\gamma_{t-1}^\top\)로 대신하지 않는다.
‘동일한 화면인데 다른 미래를 설명해야 한다’는 증거가 복제본 배정을 바꾼다.
대칭은 임의 초기 전이로 깨고, 어떤 의미를 갖는 복제본인지 지정하지 않는다.

관측 사전의 평균·척도는 세계별 기대 횟수 \(N^w_{j,:,s}\)로 학습한다.
고정 책임도에서의 경험적 베이즈 항은

\[
\sum_w\{\log\mathcal B(\kappa_{j,s}\pi^0_{j,:,s}+N^w_{j,:,s})
              -\log\mathcal B(\kappa_{j,s}\pi^0_{j,:,s})\}.
\tag{22}
\]

여기에 §8의 고정된 proper hyperprior를 더해 최대화한다.
소수 N에서는 공동 변분 목적의 좌표 근사임을 표시한다.
세계별 평균 차이의 척도는

\[
\operatorname{Cov}(A_{j,:,s})=
 \frac{\operatorname{diag}(\pi^0)-\pi^0\pi^{0\top}}{\kappa_{j,s}+1}
\tag{23}
\]

로 나타난다. 스텝 번호별 v 표를 쓰지 않는다.
안정된 방출의 평균이 한 기호에 집중하면 이 분산도 작아진다.
어떤 패치·상태가 그런지는 학습 결과다.

### 6.4 ‘국소 학습’의 정확한 뜻

| 학습/추론 | 끝점의 갱신 신호 | 시간상 필요한 정보 |
|---|---|---|
| 빠른 A | \(o_t\otimes b_t\) | 현재까지의 필터에 과거가 이미 들어 있어야 함 |
| 느린 B | 두 끝 상태의 공동 책임도 ξ | 그 책임도를 구하는 메시지는 미래 결과까지 거슬러 갈 수 있음 |
| 느린 \(\pi^0,\kappa\) | 세계별 방출 횟수·사후 모멘트 | 같은 세계의 반복을 같은 파라미터의 증거로 묶어야 함 |
| RSSM의 상태·전이 | 생성 ELBO의 재구성/KL 신호 | 표준 BPTT에서는 별칭을 해소할 결과까지의 경사가 필요할 수 있음 |
| 변화 위험률 | 변화의 사후 책임도 | 변화가 언제 일어났는지 추정하려면 반증 이전 구간도 필요할 수 있음 |

(21)의 M-step은 두 끝 상태의 통계로 쓸 수 있다.
**그 통계가 감각적으로 국소적인 것은 아니다.**
평활을 만드는 역방향 메시지가 d스텝을 건너면 시간 공 배정을 한 것이다.
EM으로 썼다고 긴 의존성 문제가 사라지지 않는다.

이번 훈련에는 최대 32스텝짜리 대기가 있다.
여러 gap과 복도를 합친 같은 문 재방문의 의존 경로는 32보다 길 수 있다.
전체 훈련 세션을 평활하면 그 길이의 정보가 통계에 반영된다.
RSSM은 같은 자료를 쓰고 길이 32로 BPTT를 자르면, 필요한 경로가 잘릴 수 있다.
상태 carry만 유지하는 것과 그 의존성을 배우는 것을 구별해 보고한다.
강한 대조는 전체 훈련 세션의 경사를 허용한다.

평가에서 D=2048을 반드시 경사가 건너야 하는 것은 아니다.
조건은 (i) 사건 때의 주소가 이미 구분되고, (ii) 그 사후가 A에 저장되며,
(iii) 재방문 때 학습된 전이가 같은 주소를 다시 찾는 것이다.
이때 내용은 순환 활성에 D스텝 유지될 필요가 없다.
그러나 대기 뒤 상태 재인식이 실패하거나, 복제본이 훈련의 노출 순번을 세면 일반화도 실패한다.
훈련 d보다 긴 별칭 구간에 대한 일반화는 별도다. 전이 오차의 반복 누적을 피하지 못한다.

원리상 HMM의 재귀 평활 충분통계로 고정 크기 온라인 EM도 가능하다.
하지만 파라미터 통계별 추가 상태와 연산이 든다.
이를 무료의 한 스텝 Hebb라고 부르지 않는다.
첫 느린 학습은 오프라인 전방–후방으로 고정한다.

## 7. 초기화 없는 흐름과 위험률

### 7.1 먼저 구별할 세 확률

| 양 | 의미 |
|---|---|
| 세계 재추첨 확률 | 같은 주소의 내용이 새 사전에서 다시 뽑혔을 확률 |
| 관측값이 달라질 확률 | 재추첨해도 같은 자원이 나올 수 있어 위와 다름 |
| 스텝당 물리적 변화 위험률 | 관측하지 않는 동안에도 누적되는 확률 |

4종 균등 자원을 매 세계 새로 뽑으면, 주소의 재추첨 확률은 1이고 값 변경률은 3/4이다.
현재 기록의 약 .75를 자동으로 재추첨 위험률 정답으로 쓰지 않는다.
또 한 번 방문할 때의 위험률을 스텝당 위험률로 해석하지 않는다.

### 7.2 구현할 첫 흐름 대조: 관측 시점의 두 가설 투영 필터

이는 기존 evidence_h를 확률적으로 더 분명하게 만든 **추적 근사**다.
정적 세계의 (9)와 정확히 같은 사후 가족이 아니다.
외부 경계 표지·s>0 같은 관측 기회 표지를 받지 않는다.
각 학습된 방출 열 (j,s)에 Beta(a,b)를 둔다. 모든 실제 관측에 책임도만큼 증거를 준다.

한 열의 ‘유지’ 사전은 Dir(α), ‘재추첨’ 사전은 Dir(α⁰)다.
기호 y를 실제 관측한 경우

\[
L_0=m_y,\quad L_1=\pi^0_y,\quad
\chi=\frac{hL_1}{(1-h)L_0+hL_1},\quad h=\frac{a}{a+b}.
\tag{24}
\]

상태 추론도 이 혼합 우도를 사용한다.
\[
\widetilde L_t(s)=\prod_j[(1-h_{j,s})L_{0,j,s}
                                    +h_{j,s}L_{1,j,s}],
\quad b_t\propto b_t^-\widetilde L_t.
\tag{25}
\]

각 열의 관측 뒤 분포는

\[
\widetilde q_{j,s}
 =(1-b_t(s))q^-_{j,s}
 +b_t(s)\big[(1-\chi_{j,s})\operatorname{Dir}(\alpha_{j,:,s}+e_y)
             +\chi_{j,s}\operatorname{Dir}(\alpha^0_{j,:,s}+e_y)\big].
\tag{26}
\]

처음 항은 그 상태를 방문하지 않았을 가능성이다.
각 가지에서 관측은 한 번만 쓴다.
현재 관측으로 χ를 구한 뒤 분산만 키우고 같은 우도를 또 곱하지 않는다.

혼합의 평균 m과 전체 공분산 V를 계산한다.
평균 차이에 의한 공분산도 포함한다.
다음 디리클레는 평균과 공분산의 trace를 맞춘다.

\[
\widehat n=\frac{1-\|m\|^2}{\operatorname{tr}V}-1,\qquad
\alpha^+=\widehat n m.
\tag{27}
\]

모든 공분산 성분을 맞추지는 못한다. §12에 오차 예가 있다.
실제로는 V 전체 대신 각 혼합 가지의 평균 m_l, trace v_l, 가중치 ω_l로
\(\operatorname{tr}V=\sum_l\omega_l[v_l+\|m_l-m\|^2]\)만 계산해도 된다.
1−Σm²의 상쇄 오차는 동치인 \(2\sum_{r<r'}m_rm_{r'}\)로 줄인다.
투영 모멘트 계산의 임시 float64는 허용하되 carry는 float32다.
정확한 산술에서 부적절한 n이 나오면 구현/수치 오류다. 성능용 clipping으로 감추지 않는다.
이는 정확한 무한 run-length 변화점 사후가 아니다.
확실한 상태·변화 없음에서는 (9)의 알려진 상태 갱신으로 돌아간다.
불확실한 상태에서는 분수 횟수를 바로 더하는 (9)와도 다른 투영이다.

\[
a_{j,s}\leftarrow a_{j,s}+b_t(s)\chi_{j,s},\quad
b_{j,s}\leftarrow b_{j,s}+b_t(s)(1-\chi_{j,s}).
\tag{28}
\]

여기서 b와 상태 믿음 b_t의 기호 혼동에 주의한다.
구현 변수는 hazard_yes/hazard_no로 쓴다.
(28)은 잠재 변화 사건의 소수 횟수를 쓰는 베이즈/EM 근사다.
정확한 hazard 사후도 혼합이며 Beta 하나는 아니다.
변화 증거가 없는 열에서 평균은 그대로여도 허위 정밀도가 증가할 수 있으므로 보정도를 잰다.
재관측이 너무 드물거나 과거 변화가 계속 누락되면 위험률도 낮게 추정할 수 있다.

### 7.3 이 추적기를 완전한 동적 FEP 모형이라 부르지 않는다

중요한 제한이다.
관측 시점마다 일정 h로 재추첨한다고 가정한 모형을 미래 행동 예측에도 쓰면,
가상의 재방문에도 \((1-h)m+h\pi^0\)를 예측해야 한다.
흐름에서 h가 1에 가깝다면 기억을 이용하는 행동의 예측 이득도 사라진다.
**관측이 올 때만 h를 쓰고, 계획할 때는 항상 h=0으로 읽는 것은 같은 생성 모형이 아니다.**

따라서 §7.2의 MAP 현재 사실 회상은 기존 흐름 대조와 비교하는 진단이다.
이를 그대로 ‘동적 능동적 추론까지 해결’한 점수로 내세우지 않는다.
새 세계의 독립 내용과 같은 세계의 재사용을 구별하려면,
변화 위험이 이력/학습된 맥락에 의존해야 한다.

일관된 확장은 이미 학습한 상태 전이에 변화 잠재 c를 붙이는 것이다.
예를 들어 \(p(c_t=1\mid s_{t-1},a_{t-1},s_t)=H^a_{s_t s_{t-1}}\)로 두고,
변화 시 M의 해당 사전을 재추첨한다.
H의 Beta 통계는 \(\mathbb E[1_{s',s,a}c_t]\)와
\(\mathbb E[1_{s',s,a}(1-c_t)]\)다.
어떤 전이가 세계 경계인지는 지정하지 않는다.
이 경우 **변화가 관측되기 전의 전이에 공을 돌리는 평활**이 필요할 수 있다.
그 거리가 D라면 그 학습 신호도 D를 건너야 한다.
고정 두 모형 투영만으로 정확한 공동 추론을 했다고 할 수 없다.

이 확장은 첫 정적 gate의 필수 부품으로 권하지 않는다.
관측 시점 추적과 일관된 동적 예측을 혼동하지 않는 것이 이번 판단이다.
학습된 상태+정적 빠른 쓰기가 먼저 통과해야 한다.
그 뒤 동일 생성 목적의 동적 사전이 필요하다는 흐름 실패가 남으면 그 모형을 검증한다.
새 경계 분류기나 위험률 정답 손실을 덧붙이지 않는다.

‘경계 신호 없음’도 기록을 정확히 한다.
gate의 마지막 HUD와 다음 세계의 빈 HUD 등으로 경계가 통계적으로 추론될 수 있다.
이를 쓰는 학습은 허용하지만, 관측상 완전히 숨겨진 경계라고 주장하지 않는다.
경계까지 관측 이력이 같은데 지도가 바뀐 두 흐름은 첫 새 증거 전에 구별할 수 없다.

이 표는 과제 실행 전에 고정한다.
성능을 보고 상태 수·문턱·쓰기 머리를 늘리지 않는다.

기호 축의 미사용 칸은 디리클레의 차원에 포함하지 않는다.
그 padding은 0으로 두고 합·entropy·digamma 계산에서 제외한다.
활성 기호의 모든 사전 계수는 양수다.
서로 다른 그림이 16개보다 적으면 중복 prototype을 허용한다.
k-means의 빈 군집은 seed 난수로 훈련 그림에 다시 놓는다.
최종 거리 동률은 균등 책임도로 나눠 패치 빈도를 계산한다.
이는 상태의 의미를 지정하는 조작이 아니라 유한 군집 초기화의 규약이다.
prototype은 의미 상태의 정답이 아니다.
관측이 비슷한 곳에서 시작하도록 하는 보편적 시각 초기화다.
계층 모형을 학습하는 동안 전이와 방출은 자유롭게 바뀐다.
전체 관측의 특정 패치를 가리고 ‘장면’을 만든 뒤 복제하지 않는다.
S=64라는 용량 가정 자체는 귀납 편향이며 공개한다.
초기 prototype이 자원 종류를 잘못 분리한 채 굳는 것도 가능한 실패다.

원래 CSCG의 결정적 방출을 고정한 판은 별도 비교군으로 둔다.
그 판은 새 세계의 방출 변이를 같은 주소에 쓸 수 있는지부터 검사해야 한다.

### 8.2 느린 학습 일정

- 기본 d=4/8 각각 별도 학습. 대기·gap은 §6.2처럼 혼합한다.
  d별 모형을 따로 학습했다는 사실을 숨기지 않는다.
  d=16은 해당 시각 무늬까지 포함한 학습판에서 별도 확장 검사다.
  보지 못한 무늬를 아는 것처럼 부호화하지 않는다.
- 훈련 세계 4,096개, 검증 세계 1,024개. 기존 평가 세계와 seed를 분리한다.
  예: 훈련 40,000+seed, 검증 50,000+seed, 최종 평가 60,000+seed.
  최종 평가 세계 1,024개/조건, 학습·인코더 seed 0–4다.
- 느린 학습 20회 자료 순회. 세계 안의 국소 변분 반복은 4회로 고정한다.
  매 세계·순회 시작에 α=α⁰로 둔 뒤, 전방–후방과 관측 횟수 갱신을 교대한다.
  매 반복에서 α=α⁰+Σo⊗γ로 재구성한다. 같은 관측을 4번 누적하지 않는다.
  전방–후방의 마지막 γ,ξ로 느린 통계를 계산한다.
- B는 (21)의 사전+현재 자료 기대 횟수로 재추정한다.
  같은 훈련 자료를 다음 EM 순회에서 새 독립 자료처럼 계속 더하지 않는다.
- 방출 사전은 (22)+hyperprior로 갱신한다.
  π는 softmax, κ는 exp 좌표에서 최적화한다.
  M-step은 L-BFGS 최대 50 반복, 상대 목적 변화 10⁻⁶이면 종료한다.
  이 문턱은 수치 최적화 종료 기준이며 기억 선택 기준이 아니다.
- 초기 상태 사전은 첫 검사의 단순성을 위해 균등에 고정한다.
  최종 20회차를 평가한다. 최고 검사 정확도 checkpoint를 고르지 않는다.
- θ는 평가 전체에서 고정한다. 시험 시간 optimizer·autograd는 없다.
  학습 반복·평활 비용은 환경 자료 수와 따로 보고한다.

이 학습 절차가 의미 있는 복제본을 찾을지는 [가설]이다.
변분 국소해·상태 붕괴·세계별 A가 모든 것을 대신 설명하는 해가 가능하다.
실패하면 문 비트를 넣지 말고 자료의 식별성·우도·변분 가족을 재검토한다.

### 8.3 매 관측의 갱신 순서

~~~text
입력: 이전 b, α, n, 실제 이전 행동 a, 고정 θ
1. B[a] b로 새 상태 사전 계산
2. 실제 픽셀을 기호화; 쓰기 전 예측 NLL 기록
3. 현재 실제 관측과 (8)로 b 계산
4. 모든 패치에 α[j,:,s] += onehot(o[j]) * b[s]
5. n[j,s] += b[s]; 같은 관측을 다시 증거로 쓰지 않음
6. 현재 행동이 주어진 노출이면 그대로 실행
7. 검사면 같은 사후로 읽고 첫 선택 기록
8. 선택/실행한 행동을 다음 전이에 전달
~~~

첫 o₀에서는 행동 전이 없이 균등 상태 사전으로 2–5를 실행한다.
마지막 검사 관측도 한 번만 처리한다.
행동을 고른 뒤 아직 오지 않은 자원 결과를 현재 α에 넣지 않는다.
관측한 실행 행동과 정책이 예상한 행동은 구분한다.

흐름에서는 3–5를 (25)–(28)의 상태 추론·혼합·투영으로 바꾼다.
투영 뒤 n은 증가식이 아니라 \(\sum_r\alpha^+_{j,r,s}\)로 다시 맞춘다.
최종 검사 프레임 뒤 다음 세계 첫 프레임까지도 연속 입력 규약을 명시한다.
현재 gate_stream은 세계별 스캔이라 그 사이의 환경 전이를 명시하지 않았다.
새 상태 모형에는 이 누락을 그대로 가져오면 안 된다.
공통 wrapper에서 검사 때 고른 실제 행동 뒤 다음 첫 관측이 오는 전이로 기록한다.
같은 외생 재시작 전이를 훈련 흐름에도 포함한다.
별도 RESET 행동·세계 번호·carry 초기화는 주지 않는다.
자료를 붙일 때 그림을 중복하거나 이전 행동을 몰래 버리지 않는다.

### 8.4 읽기와 행동

첫 gate 평가는 기존과 같은 질문이다.
현재 갈림길에서 후보 a를 실행하고, 이후 주어진 FWD를 따라 d스텝 뒤
가운데 칸이 HUD의 요구 기호 g일 확률을 묻는다.
이것은 **평가 과제의 질의 지평/행동열**이다. 상태 분해나 정답 주소가 아니다.
모든 모형에 같은 질의를 준다.
온라인 필터·쓰기에는 d를 입력하지 않는다.

\[
q^a=B_{\rm FWD}^{\,d-1}B^a b_t,\quad
p_a(r)=\sum_s q^a(s)\frac{\alpha_{{\rm CENTER},r,s}}
                                  {n_{{\rm CENTER},s}},
\quad a_{\rm MAP}=\arg\max_{a\in\{L,R\}}p_a(g).
\tag{29}
\]

같으면 균등 무작위로 고른다.
원래의 잔차 cosine은 쓰지 않는다. 정규화된 같은 관측 모형의 예측 확률을 읽는다.
두 고정 행렬 \(B_{\rm FWD}^{d-1}B^a\)는 θ 고정 뒤 미리 계산할 수 있다.
이는 과거 기억 항목 검색이나 온라인 후보 궤적 탐색이 아니다.

query horizon을 알고 성능이 좋다는 것은 일반적인 목표 도달 제어의 성공과 다르다.
추가 검사로 θ는 같은 채 질의 지평을 바꾼 예측 NLL을 보고한다.
Craftax에서는 이 고정 행동열 대신 기존 RSSM의 정책/가치가
같은 세계 모형을 사용해야 한다. 관측–기억 API는 바꾸지 않는다.
문 전용 읽기 머리를 이전하지 않는다.

**능동적 추론의 행동도 별도 기록한다.**
선호는 \(C_g(r)\propto\exp(1_{r=g})\)로 고정한다.
목표 결과 1점이라는 효용 단위다. 정확도를 맞추려고 온도를 조절하지 않는다.
한 미래 가운데 관측에 대한 EFE 근사는

\[
G_a=\mathbb E_{p_a}[-\log C_g(Y)]
       -I_q((S,A);Y\mid a),\qquad
q(a)\propto e^{-G_a}.
\tag{30}
\]

현재 근사 q에서 미래 상태와 A를 독립으로 예측한 한 관측의 정보항은

\[
I_q((S,A);Y\mid a)
 =H(p_a)+\sum_s q^a(s)\sum_r m_{r,s}
                      [\psi(\alpha_{r,s}+1)-\psi(n_s+1)].
\tag{31}
\]

중간 관측 전체·미래 적응 정책의 정보 가치는 생략한 endpoint 근사다.
알려진 상태에서는 (11)로 줄어든다.
이 수치를 쓰기 계수로 다시 곱하지 않는다.

첫 주 지표 S_mem은 (29)의 MAP 사실 회상이다.
\(S_{\rm mem}=2\,\Pr(a_{\rm MAP}=\text{정답})-1\)이며 우연은 0이다.
(30)의 MAP 선택과 표본 정책 정확도도 따로 보고한다.
탐색의 정보 가치를 선호하는 정책이 최종 회상 정확도와 언제나 같지는 않다.
알려진 상태·대칭 사전·문마다 한 번 관측한 깨끗한 경우에는 정보항이 같아 MAP이 일치한다.
정보항이 같아도 softmax 표본 정책의 정확도는 1이 아니다.
예컨대 예측 목표 확률 차이가 .5이면 정답 표본 확률은 sigmoid(.5)≈.622다.
이를 기억 실패나 온도 조절의 이유로 읽지 않는다.

동적 흐름에서 미래 예측을 (30)에 넣는다면 §7.3의 변화 사전도 일관되게 전파해야 한다.
§7.2의 현재 사실 추적 점수와 구분한다.

### 8.5 고정 계산·고정 크기

정적 이산 평가 carry는 α[J,K,S], n[J,S], b[S], 직전 행동 하나다.
J=49,K=17,S=64이면 56,512 float32, **226,048바이트**와 행동 정수다.
흐름 대조의 Beta 두 개/열은 6,272 float32를 더해 **251,136바이트**와 행동 정수다.
α⁰·B·감각 사전은 느린 모델 바이트에 따로 센다.
느린 B만도 4×64²=16,384 float32다.
prototype·관측 사전과 임시 작업 공간도 총 예산에서 누락하지 않는다.

상태 필터는 O(S²+JS), sparse one-hot 쓰기는 O(JS)다.
소유한 모든 기호 계수를 저장하는 공간은 O(JKS)다.
전체 예측/정보항을 계산하면 O(JKS)가 든다.
디리클레 혼합의 평균·trace는 한 열씩 처리해 O(K) 임시 공간을 재사용한다.
어느 값도 t,D,세계 수와 함께 커지지 않는다.
수치 계수는 float32 근사이므로 무한한 정확한 횟수 저장을 주장하지 않는다.

정확한 상태–파라미터 공동 사후는 이 고정 크기에 들어가지 않는다.
변분 분해와 두 가설 투영이 그 대가다.
온라인 전체 평활·과거 재스캔·증가하는 KV 목록을 몰래 쓰지 않는다.

연속판도 d와 출력 수 m이 고정이면 공분산 포함 O(md²) carry와 갱신이다.
상태 모멘트를 고정 개수 표본으로 근사하면 그 표본 수까지 비용에 센다.
전 관측에 대한 비선형 선형화가 출력 간 공분산을 만들면
출력별 독립 P의 비용식으로 축소 보고하지 않는다.
고정 형상은 낮은 지연의 증명이 아니다. 실제 batch 1 p50/p95를 별도 측정한다.

## 9. 비교군과 인과 개입

| 비교군 | 맞추는 것 / 판별할 질문 |
|---|---|
| 현재 ours, ours_noet, ours_surp | 기존 코드를 역사적 기준으로 재사용. 이상적 스텝별 느린 모형을 쓰므로 ‘oracle slow’로 표시 |
| 새 학습 느린 모형 + 기존 ET/RLS | 같은 관측·자료에서 배운 다음 관측 평균/불확실성을 사용. 이상적인 시간 표의 이득을 분리 |
| 상태 추론 + 모두 쓰는 단순 Hebb/고정 β 델타 | 같은 상태 공간·B에서 각자 관측 모형으로 추론. 정밀도 학습이 없어도 충분한지 확인 |
| 상태 추론 + (9) | 권고한 기본형. c=1, ET 없음 |
| 같은 HMM의 느린 관측 모형만 | 빠른 A 없이 b를 계속 유지. 학습부터 따로 수행한 강한 비교군도 포함 |
| 고정 무작위 B + 같은 빠른 A | 상태를 배운 이득인지, 시각 prototype만의 이득인지 |
| 원래 CSCG의 고정 기호 방출 | 상태 추론만으로 세계별 내용을 같은 주소에 남길 수 있는지 |
| GRU 128 / RSSM | 같은 전체 관측 예측 자료·우도. 세션 carry 유지. 기존 A2C 붕괴 실행을 대표로 삼지 않음 |
| 학습된 강한 쓰기 gate | 같은 b·innovation·불확실성에 접근. 기존 생성 목적/동일 제어 목적에서 학습. 중요도 정답 손실 없음 |
| 정답 주소/정답 쓰기 상한 | 평가 진단에서만 실제 문–결과 대응을 사용. 학습판에는 주지 않음 |
| 정확한 과제 전용 지도 사후 | 12개 자원 배정의 정보 상한. 범용 상태 학습의 성공으로 세지 않음 |

핵심은 주소 학습과 쓰기 규칙의 효과를 나누는 것이다.
두 사실에서 단순 외적이 같으면 정밀도 학습의 성능 기여는 주장하지 않는다.
상태를 바꾼 효과와 쓰기 규칙을 바꾼 효과를 섞지 않는다.

전체 에이전트 비교에서 각 방법은 자신의 관측 파라미터로 상태를 추론한다.
다른 방법의 빠른 A로 만든 b를 무료로 제공하지 않는다.
같은 b를 고정해 쓰기만 바꾸는 검사는 별도의 조건부 표현 진단이다.
그것을 독립 에이전트의 성능/비용으로 내지 않는다.

새 상태 기반 단순 비교의 구체 규칙은 다음으로 고정한다.

- Hebb는 \(H_{j,:,s}=\log\pi^0_{j,:,s}\)에서 시작해
  \(H\leftarrow H+o\otimes b\)로 누적한다.
  방출은 softmax(H)로 정규화한다. 계수 불확실성을 쓰지 않는 점 모형이다.
- 고정 델타는 \(\widehat A=\pi^0\)에서 시작해
  \(\widehat A_{j,:,s}\leftarrow\widehat A_{j,:,s}
       +.5\,b(s)(o_j-\widehat A_{j,:,s})\)로 갱신한다.
  simplex를 보존하며 β=.5를 성능으로 고르지 않는다.
- 둘 다 상태 필터에는 자신의 점 방출의 로그 우도를 쓴다.
  읽기는 (29)의 α/n을 각자의 정규화된 방출로 바꾼다.

기존 ET/RLS의 학습 느린 모형 대조에는 별도 시간 표가 필요하지 않다.
빠른 쓰기 없이 α⁰만 쓰는 HMM 필터 \(b^0_t\)에서
\(\widetilde b=B^{a_t}b^0_t\)를 만든다.
감각 사전 기호 r의 기존 8차원 임베딩을 φ_r라 하면
\(\mu_s=\sum_r\pi^0_{{\rm CENTER},r,s}\phi_r\),
\(\mu_t^0=\sum_s\widetilde b(s)\mu_s\)다.
세계별 관측 평균의 공분산은

\[
V_t^{\rm world}=\sum_s\widetilde b(s)
 \frac{\sum_r\pi^0_{{\rm CENTER},r,s}\phi_r\phi_r^\top-\mu_s\mu_s^\top}
      {\kappa_{{\rm CENTER},s}+1}.
\]

기존 s는 \(\sqrt{v_t/v_{\max}}\), \(v_t=\operatorname{tr}V_t^{\rm world}/8\)로 한다.
v_max는 훈련 경험에서 계산해 고정한다. 양의 세계 변이가 없으면 빠른 잔차 대조는 무효다.
읽기 기준 평균도 훈련에서 같은 s로 가중한 μ⁰의 평균으로 고정한다.
이 대조의 상태 필터가 정답 세계의 빠른 기억을 참조해서는 안 된다.
이는 비교용 일반화다. 생성 우도가 다른 기존 RLS를 정확한 계층 HMM 사후라고 부르지 않는다.
ours_surp의 행동 빈도도 원래 oracle 표 판과 학습된 행동 예측 판을 구별한다.

GRU/RSSM의 생성 출력은 같은 패치 관측 분포다.
정답 행동 분류기를 추가하지 않고, 같은 행동열의 예측으로 (29)를 평가한다.
GRU의 첫 BPTT 길이는 32, 강한 대조는 전체 훈련 세션이다.
느린 신경망 optimizer는 Adam lr=10⁻³, 전역 gradient norm 상한 1로 사전 고정한다.
모든 방법에 같은 원자료·세계 수·재방문 기회를 주고,
자료 순회 횟수와 실제 추론/optimizer 비용을 각각 보고한다.
EM의 네 내부 반복을 공짜인 같은 compute로 세지 않는다.

주 비교는 같은 원자료·느린 모델 규모다.
그 뒤 같은 총 carry 바이트 비교도 한다.
기본 이산 모형의 약 226KB와 기존 gate RLS의 약 5KB는 크게 다르다.
이 차이를 숨기고 점수 우월성을 주장하지 않는다.
바이트를 맞추려고 GRU의 느린 파라미터 수까지 바뀌면 둘 다 공개한다.

다음 개입은 평가 때만 한다.

| 개입 | 기대 / 잘못된 해석 방지 |
|---|---|
| 관측 전 이력의 실제 문 선택만 바꾼 짝 경험 | 자원 보기 전 복도에서 b가 달라지는지. 자원을 본 뒤만 갈라지면 인과 주소 증거가 약함 |
| 결과가 같아도 문 선택 이력을 바꿈 | 자원 종류가 주소를 대신 정하고 있는지 검사 |
| 서로 다른 세계의 α,n만 교환. θ와 현재 b·HUD 고정 | 우연 초과 사실 회상 이득의 큰 부분이 빠른 파라미터에서 나오는지 |
| 대기 뒤 α=α⁰, n=n⁰로 복원 | 느린 상태 carry만으로 두 사실을 대신 기억하는지. 모든 상태를 동시에 초기화하지 않음 |
| 사실은 고정하고 HUD 필요만 바꿈 | 물리적 사실이 선호에 따라 부호/주소를 바꾸지 않는지 |
| 행동 빈도 추정기를 스텝별에서 전체 이력으로 바꿈 | ours_surp의 마지막 필연 선택은 약해져도 새 모형의 입력·갱신은 변하지 않아야 함 |
| 훈련 순서와 다른 재방문 순서, 같은 총 사건 수 | 노출 순번 복제본을 외운 해를 드러냄 |

HMM 상태 번호는 seed마다 순열 대칭이다.
정답 상태 이름과의 분류 정확도로 훈련하지 않는다.
학습 뒤 진단은 사후 간 TV/겹침, 조건부 예측 NLL, 교환 개입으로 한다.
원시 상태 번호가 다르다는 이유만으로 의미 구별이 생겼다고 하지 않는다.

## 10. 사전 예측과 실패 기준

### 10.1 정확한 조건부 계산과 실험 가설을 구분

상태가 올바르게 구분되고 방출 사전이 두 주소에서 같은 경우,
두 다른 자원을 한 번씩 관측한 뒤 목표 확률은 맞는 열에서 더 크다.
균등 4종·총계수 1이면 .625 대 .125다.
따라서 그 조건에서 MAP 회상은 1이다. 이는 **주소가 학습된다는 증명은 아니다.** [유도]

아래는 실제 학습을 포함한 [가설]이다.
모든 수치는 훈련/추론 프로그램을 바꾸기 전에 고정한다.
조건별 1,024개 세계와 5개 학습 seed를 사용한다.
세계 1,024개를 1,024개의 독립 학습 seed로 취급하지 않는다.
시드별 값과 시드 단위 paired 차이를 함께 낸다.

| 검사 | 사전 예측 [가설] | 실패 기준 / 판정 |
|---|---|---|
| 기본 회상, d=4/8, gap=0/32, D=32 | S_mem 평균≥.90, 각 seed≥.80 | 미달이면 상태 학습+빠른 학습의 결합을 입증하지 못함 |
| 대기 D=32→256→2048 | 같은 seed의 S_mem 감소≤.05 | 초과하면 보존 또는 상태 재인식 실패. ET 길이를 늘려 수선하지 않음 |
| gap 0→32 | S_mem 차이 절댓값≤.05 | 초과하면 반복 관측의 주소 누수/상태 순번 의존을 확인 |
| 문별 같은 그림의 짝 이력 | 자원 관측 전 사후가 구별되고 그 구별이 재사용 예측을 개선 | 본 뒤에만 갈라지거나 순서 교환에서 반전하면 인과 주소 주장 실패 |
| α 교환/삭제 | 우연 초과 회상 이득의 ≥80% 제거 | 효과가 작으면 빠른 사실 시냅스의 필요성 미입증. b만으로 되는 단순 모형 채택 |
| ET 완전 제거 | 기본 구현에 ET가 없으므로 성능 변화 없음 | ET를 추가해야만 통과하면 충분한 상태 추론이라는 요구가 아직 실패한 것 |
| ‘남은 문’이 확률 1인 경험 | 전체 이력 행동 예측기의 정확도와 무관하게 동일한 (8)–(9) | 모형이 행동 놀라움 값에 의존하면 구현이 명세와 다름 |
| 원래 두 노출만으로 느린 학습 | 재방문 자료보다 해의 순서 의존·seed 변동이 클 것으로 예측 | 잘되면 불가능성을 주장하지 말고 어떤 공유 구조/사전이 식별을 도왔는지 분석 |
| 단순 Hebb 대 정밀도 | 깨끗한 두 사실만이면 같은 점수일 수 있음 | 동률은 정밀도 규칙의 성능 우월성 근거가 아님 |
| 파라미터 정보 보정 | 같은 평균·독립 반복에서 n 증가와 함께 (11) 감소 | 아는 결과를 새로 관측할수록 정보 보너스가 커지면 구현/모형 오류 |
| 현재 사실 흐름 추적 §7.2 | 정적 기본형을 통과했다면 세계 101–200의 평균 S_mem≥.80, 21–50 대비 하락≤.05 | 미달이면 흐름 관문 미통과. 이를 동적 EFE 성공으로 대체 해석하지 않음 |

새 구조의 주요 사전 예측은 상태 학습까지 포함한다.
정답 상태 상한에서만 잘되면 구조 학습의 실패다.
같은 관측 데이터에서 고정/학습 B의 차이가 없으면 ‘배운 전이가 공 배정했다’는 설명도 약해진다.
GRU/RSSM이 같은 바이트·자료·비용에서 같으면 더 단순한 쪽을 선택한다.

### 10.2 실패를 위치별로 나누는 기록

- **쓰기 전 상태**: 각 프레임 b의 entropy, 짝 이력 간 TV,
  쓰기 때 사후와 검사 때 미래 질의 사후의 겹침을 저장한다.
  진단용 실제 경로 라벨은 학습 입력과 분리한다.
- **쓰기 전 예측**: 전체 패치와 가운데 결과의 NLL, calibration,
  첫 노출/둘째 노출/재방문을 구분한다.
- **보존 누수**: 대기 프레임이 보호된 결과 상태 열에 더한 총 책임도,
  그 전후 목표 확률 변화를 기록한다.
  ‘키 노름≤1’만 확인하고 누수 0이라고 하지 않는다.
- **불확실성**: α의 총계수, 방출 평균 변화, 정보 이득,
  변화 χ와 hazard의 보정도를 기록한다.
- **구조**: 복제본 사용량·전이 entropy·세계 간 상태 재사용을 기록한다.
  상태 수를 많이 썼다는 사실 자체는 성공 지표가 아니다.
- **비용**: 온라인 carry, 느린 가중치, 최대 임시 메모리,
  관측당 함수 호출 수와 batch 1 지연을 보고한다.

빈 방에 같은 그림을 반복하는 이번 과제만으로 잡음 상관 처리의 성공을 주장하지 않는다.
(2)는 상태가 주어지면 프레임이 조건부 독립이라는 우도다.
완전 복사된 센서 잡음은 독립 재측정이 아니다.
연속 판에서는 상관된 감각 잔차를 상태/우도에 포함해야 하며,
그렇지 않으면 계수만 계속 증가하는 과신이 남는다.
이를 막을 목적으로 임의 novelty 문턱을 추가하지 않는다.

## 12. 작은 수치 확인과 최종 결정

저장소 구현을 실행하지 않고 CPU의 작은 NumPy/표준 수학 연산만 사용했다.
SciPy는 기본 Python에 없어 설치하지 않았다.
digamma는 양수 인자에서 점화·점근식으로 계산했다.
상태 학습이나 gate 성능을 확인한 실험이 아니다.

.4375와 .5000의 차이는 불확실한 상태를 평균 키로 쓴다고

소수 디리클레 쓰기를 사용할 수 없다는 뜻은 아니다. 근사의 위치를 드러내는 계산이다.

**실행 순서는 하나다.**
의미 인자 없는 계층 HMM을 재방문 자료로 학습하고,
미래 정보 없는 상태 필터 + 모든 관측의 (9) + 확률 읽기 (29)를 먼저 검사한다.
성공하면 ET를 삭제한다.
실패하면 상태의 식별성·주소 재사용·우도·사후 근사 중 무엇이 실패했는지 위 개입으로 나눈다.
행동 놀라움, 문 상태 정답, 쓰기 문턱으로 점수를 복구하지 않는다.

Craftax로 넘길 것은 관측–행동에서 학습한 상태공간과
그 상태 믿음에 결합하는 빠른 관측 파라미터의 API다.
gate에서 해석한 상태 번호나 경로 분해는 넘기지 않는다.
동적 흐름의 위험률까지 일관된 EFE로 닫는 문제와,
RSSM의 실제 관측 인자를 공액 쓰기에 연결하는 문제는 아직 검증되지 않았다.
두 한계를 숨긴 채 보편적인 장기 기억을 완성했다고 판단하지 않는다.
