# 후속 특징 시냅스: 다음 아키텍처 제안 (2026-11-15)

작성: Claude, 사용자와 논의. **제안이다. 구현·실행 전.**
출발점: errand 12.13 구성 (b1 84%, 손 선호 판정). 근거 기록은 [`README.md`](README.md) 12절.

## 0. 왜

- 시냅스에 기대하는 성질은 **시간적 신용할당**과 **그것을 기억해 행동에 쓰기**다. 그 가장 직접적인 형태는 빠른 선형 Q-net (11절 value: Q = w·k, 흔적 위 TD(λ))이지만,
  가치를 담으면 목표가 바뀔 때 굳은 가치를 따라가고 (9절: −1), 본 적만 있고 보상받은 적 없는 곳 (errand의 b1)을 고르지 못한다.
- 지금 errand 시냅스는 다음 관측을 예측하는 빠른 선형 모델 (= 할인율 γ = 0인 후속 특징)이다. 사실을 담아 b1을 고를 수 있지만,
  (1) 정확한 도착 시점까지 맞혀야 하고 (12.6, 12.10), (2) 행동으로 잇는 경로가 에이전트 안에 없다 (판정은 바깥에서 기억 내용만 본다).
- 후속 특징 (successor features)은 둘을 묶는다: 시냅스가 Ψ(s, a) = "여기서 이걸 하면 앞으로 어떤 관측이 할인돼 오나"를 담고, 가치는 Q = u·Ψ (u = 선호).
  신용할당은 TD와 흔적이, 무엇이 좋은가는 u가 맡는다. 해마를 예측 지도 (후속 표현)로 보는 가설 (Stachenfeld, Botvinick & Gershman 2017)과 같은 줄기.

## 1. 구성

느린 쪽 (여러 세계, 경사, 평가 중 고정):

| 부품 | 역할 |
|---|---|
| 특징 φ(o) | 장면 칸별 특징 (지금 고정 임베딩) |
| 키 k(o, a) | 시냅스 주소 (지금 난수 키) |
| 기본 후속 특징 Ψ⁰(o, a) | 모든 세계에 공통인 "앞으로 무엇이 오나". 빠른 기억은 편차만 맡는다 (6.2의 잔차 교훈, 지금의 μ⁰ 자리) |
| 칸별 σ², R, Q | 칼만 쓰기의 사전 분산, 관측 잡음, 과정 잡음. 경험적 베이즈 (12.13 그대로) |

빠른 쪽 (세션 안 가소성, 경사 없음):

| 부품 | 역할 |
|---|---|
| 흔적 e, 주소 z = [k; e] | 12.13 그대로 |
| 시냅스 M (칸별) | 이 세계의 후속 특징 편차. Ψ(o, a) = Ψ⁰(o, a) + M z |
| 선호 u | 무엇이 좋은가. r ≈ u·φ(o′) |

## 2. 한 스텝

1. 주소 z_t = [k(o_t, a_t); e_t].
2. TD 목표 (벡터): y_t = φ(o_{t+1}) + γ Ψ(o_{t+1}, a_{t+1}) − Ψ⁰(o_t, a_t).
3. 쓰기: y_t를 M z_t의 관측으로 보고 칼만 갱신. P ← P + Q, 이득 P z / (R + zᵀ P z). 칼만 시간차 학습 (KTD, Geist & Pietquin 2010). Q = 0이면 최소제곱 TD (LSTD).
4. 선호: r_t를 u·φ(o_{t+1})의 관측으로 보고 같은 칼만 갱신. 과정 잡음 Q_u가 있으면 의뢰가 바뀔 때 덮어쓴다 (요구 3).
5. 행동: 점수 = u·Ψ(o, a) + ½ log(1 + zᵀ P z / R), softmax. 둘째 항은 그 행동으로 M에 대해 얻는 정보량 (기대 자유에너지의 정보 항, 손 계수 없음). 탐색을 맡는다.

γ = 0이고 행동 선택이 없으면 지금 errand 시냅스 (12.13)와 같다.

정밀도는 칼만 모델의 P, R, Q와 그로 정해지는 이득만 뜻한다 (12.13 끝). 입력 척도 같은 것을 새로 만들지 않는다.

## 3. 요구별 담당

| 요구 | 담당 |
|---|---|
| 1. 기억 | M (지도와 "b1에서 하면 B가 온다"를 후속 특징으로) |
| 2. 원인 잇기 | TD(γ)와 흔적. 지연된 산출물이 할인돼 상호작용 주소에 붙는다. 정확한 도착 시점을 맞힐 필요가 없다 |
| 3. 새 보상 적응 | u (세션 안 칼만 + Q_u). Q = u·Ψ가 즉시 바뀐다 |
| 4. 증거로만 고치기 | 칼만 + Q (12.13에서 효과 확인) |
| 자율 행동 | u·Ψ + 정보 획득으로 고름. 바깥 판정과 교사 경로가 필요 없다 |

## 4. 열린 문제 (실험 전에 따질 것)

1. **정책 의존성**: Ψ는 그것을 만든 정책 (교사 또는 자기 행동) 기준이다. 표준 해법은 여러 정책의 Ψ 중 최대 (일반화 정책 개선, GPI, Barreto 외 2017). 기억 크기가 는다.
2. **부트스트래핑과 칼만**: TD 목표에 M 자신이 들어가 관측이 정상적이지 않다. KTD가 다루는 경우지만 Q가 그 몫을 얼마나 흡수할지는 재야 안다.
3. **길 찾기**: 한 스텝 Q 최대로 먼 목표에 가려면 Ψ가 지도 전체에서 맞아야 한다. 11절 fact (고정 난수 키 위의 후속 특징, 정규화 델타 규칙 β = 0.5)가 value보다 느렸던 이유 ("걸어 본 길에서만 맞음")가 여기 걸린다. 칼만 쓰기로 후속 특징을 해 본 적은 없다.
4. **γ**: 지연 8스텝과 귀환 거리를 덮어야 한다 (γ = 0.9면 8스텝 뒤 무게 0.43). 경험적 베이즈로 맞출 수 있는지 확인 전.
5. **병렬화** (모방학습 등 긴 궤적 학습): LSTD와 망각 계수판 (Λ_t = λΛ_{t−1} + zzᵀ/R)은 병렬 스캔이 된다. 등방 Q의 KTD는 시간 병렬 칼만 (Särkkä & García-Fernández 2021)이 필요해 비싸다. 쓰기 크기나 주소가 기억 읽기에 의존하면 병렬화가 근본적으로 안 된다 (R1 기록).

## 5. 시험 순서 (한 번에 하나씩)

1. **γ만 바꿈**: 쓰기 목표를 γ > 0으로. 같은 판정 (교사 경로, 손 선호). 84% 유지와 도착 시점 문제 감소를 본다. 지금 코드에서 쓰기 목표 한 줄 변경.
2. **선호를 세션 안 칼만으로**: 요구 3 (비공개 의뢰).
3. **행동 선택**: 관찰 단계는 교사, 판정 구간만 자율.
4. **관찰도 자율**: 정보 획득 항이 탐색을 맡는가.
