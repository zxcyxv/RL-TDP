# 시냅스 층, 곱하는 망각판: 명세 (명세 2), 2026-11-17

짝 문서: 기본형 [`synapse_layer_spec_basic.md`](synapse_layer_spec_basic.md) (명세 1). 여기에는 명세 1과 다른 곳만 적는다. 진행 순서는 명세 1 → 명세 2 (읽기 기준 일부가 명세 1 결과에 기댄다).

## 0. 목적과 바뀌는 것

- **목적:** 시냅스 층을 시간 축으로 병렬 학습할 수 있는 꼴 (누적합)로 만든다. 모방·오프라인 사전학습으로 긴 궤적을 대량 학습하려면 필요하다 (`../HANDOVER.md` 0.2절).
  12.15에서 무작위 키로는 곱하는 망각 단독이 65.6% (더하는 Q 84.4%)였다. 학습된 키 위에서 다시 잰다.
- **명세 1에 비해 바뀌는 것:** 쓰기 하나. 더하는 과정 잡음 (P ← P + qI)이 곱하는 망각으로 바뀐다.
- **그대로인 것:** 키 경로 (시야 표현, 표현 변환, 행동별 W_k, 키 크기 ℓ, 학습되는 흔적 극 α), 주소 = 질의, 값 = 잔차, 학습 목적·자료·최적화, 판정.
- **초기값에서 12.15와 정확히 같아지도록** 둔다. 키 경로는 12.13의 무작위 키, 칼만 매개변수는 12.15에서 맞춘 값.

## 1. 구성 (명세 1과 다른 줄만)

| 부품 | 식 | 상태 |
|---|---|---|
| 시냅스 상태 (칸별, 정보형) | H_p ∈ R^{256×256}, G_p ∈ R^{8×256}. 세션 시작에 H = 0, G = 0. 사전 M ~ N(0, I)는 감쇠하지 않음 | 세션 안 쓰기만 |
| 읽기 | M_p = G_p (H_p + I)⁻¹, 잔차 예측 M_p z_p | |
| 칼만 매개변수 | λ_p = sigmoid(θ_p), σ_p, R_p (칸별, 36개). 초기값 = 12.15에서 맞춘 값 (`results/errand_diag_20261116/mult_forget.log` 마지막 줄). q_p는 없음 | 학습 (경험적 베이즈) |

## 2. 한 스텝 (세션 안, 칸 p마다)

1. k_t, e_t, x_t, z_p = σ_p x_t (명세 1과 같음)
2. 감쇠: H_p ← λ_p H_p, G_p ← λ_p G_p
3. 예측 (감쇠 뒤, 쓰기 전): 잔차 평균 M_p z_p, 분산 S_p = R_p + z_pᵀ (H_p + I)⁻¹ z_p
4. 쓰기: H_p ← H_p + z_p z_pᵀ / R_p, G_p ← G_p + r_p z_pᵀ / R_p
5. C 도착 뒤에는 쓰지 않음 (stop_t)

**누적합 꼴:** H_t = Σ_j λ^{t−j} z_j z_jᵀ / R, G_t = Σ_j λ^{t−j} r_j z_jᵀ / R. 주소 z_j는 기억 내용과 무관하다 (키 경로만의 함수). 그래서 학습 때 조각 안을 시간 병렬로 계산할 수 있다 (MesaNet과 같은 꼴). 읽을 때는 스텝마다 (H_t + I)를 풀어야 한다.

## 3. 수치 구현 (12.15 그대로, 필수)

- 곱하는 망각은 P에 바닥이 없다. 같은 방향에 계속 쓰면 분산이 약 (1 − λ)R / |z|²로 내려가 float32에서 P가 양정치를 잃는다. 12.15에서 정보형·공분산형 모두 반복 100에서 NaN.
- 제곱근 공분산형 (`scripts/world/diag_20261115/eb_scale.py`의 `mult_step`). P = (H + I)⁻¹ = S Sᵀ로 두고 M과 S를 들고 간다.
  - **감쇠:** C = λI + (1 − λ) SᵀS를 촐레스키 분해 (C = LLᵀ). M ← M − (1 − λ) M S C⁻¹ Sᵀ, S ← S L⁻ᵀ.
  - **쓰기 (Potter):** f = Sᵀz, α = 1 / (R + |f|²), γ = 1 / (1 + √(αR)), K = α S f. M ← M + (r − M z) Kᵀ, S ← S − γ K fᵀ.
  - **예측 분산:** R + |Sᵀz|² (구조상 양수).
- 행렬곱 정밀도 `highest`를 쓰기와 **판정 경로 모두**에 둔다. 12.17에서 판정 경로 정밀도가 달라 12.15와 3세계 (65.6% 대 64.5%) 어긋났다.
- 병렬 꼴 (누적합 + 스텝별 풀이)은 이번 시험에서 구현하지 않는다. 이 시험은 형태가 되는지 보는 것이고 속도가 아니다.
  - 선택 확인: 세션 하나에서 float64 누적합 꼴과 순차 구현의 예측이 같은지 (상대오차 1e-5 이하).

## 4. 학습 (명세 1과 같음, 다른 점만)

- **목적:** 순차 예측 음의 로그우도. S_p는 2의 3 (감쇠 뒤 분산).
- **학습되는 것:** 키 경로 전부 + θ_p, σ_p, R_p.
- 자료, 배치, lr (키 경로 1e-3, 칼만 매개변수 0.05), 검증 기반 조기 종료는 명세 1과 같다.
- **비용:** 칸마다 스텝당 256 × 256 촐레스키 하나와 삼각 풀이. 12.15에서 세션 8개 배치에 반복당 2.7초. 최대 2,000반복이면 약 1.5시간.

## 5. 판정과 기록

명세 1과 같다. 더 기록할 것:
- 맞춘 λ_p와 창 1/(1 − λ_p). 12.15와 비교 (세계 칸 23–74스텝, 도착 칸 190스텝).
- 키 크기와 창의 관계.

## 6. 사전 예측과 읽기 기준 (실행 전에 고정)

| | 예측 / 기준 |
|---|---|
| 학습 전 | b1 = 12.15 값 (`highest` 정밀도로 다시 잰 값, 64.5–65.6%). 검증 NLL = 12.15 매개변수의 값. 다르면 멈추고 고침 |
| 학습 뒤, 증거 | 검증 NLL이 학습 전보다 낮다 |
| 학습 뒤, 학습 이득의 크기 (방향만) | 명세 1보다 크다 |
| 채택 기준 (사용자, 2026-11-16) | b1 80%대면 병렬형으로 충분히 고려 |

"학습 이득이 명세 1보다 크다"의 근거: 곱하는 망각에서 한 번 쓸 때 들어가는 정보는 |k|² / R에 비례하고, 정상 상태 정밀도는 |k|² / (R(1 − λ))에 비례한다. 그래서 학습된 키 크기가 드물지만 중요한 스텝 (상호작용)에서 망각을 보상할 수 있다. 더하는 Q에는 이 경로가 약하다.

읽기:
- **80% 이상:** 시냅스 층을 병렬형으로 둘 수 있다. 이후 단계 (공고화, 후속 특징)를 이 꼴로 진행.
- **명세 1과 ±3점 안 (명세 1이 80% 미만이어도):** 망각 형태는 병목이 아니다. 병렬형을 택한다.
- **명세 1보다 3점 넘게 낮고 80% 미만:** 곱하는 망각이 잘 정해진 방향까지 같은 비율로 잊는 손해 (12.15)를 키 학습이 메우지 못한 것. 병렬화는 다른 길 (더하는 Q의 결합 스캔 d³, 또는 청크 지연)로 남긴다.
- **증거는 좋아졌는데 b1이 학습 전보다 3점 넘게 떨어짐:** 명세 1과 같이 읽는다 (증거 목적과 판정의 어긋남).

## 7. 범위 밖과 단서

- 범위 밖은 명세 1과 같다.
- 곱하는 망각은 고정된 선형 가우시안 동역학이 없다 (암묵적 과정 잡음이 믿음 P에 의존). 학습 목적은 생성모형의 증거가 아니라 이 순차 예측 절차의 예측 우도다 (12.15의 자유에너지 관점 단서). 명세 1의 목적은 정확한 증거다.
