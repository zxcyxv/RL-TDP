## 1. 구현에서 나온 것 (README 6–7절 요약)

과제 (gate.py): 두 출입구를 정해진 경로로 한 번씩 (무작위 순서). 출입구 행동 d스텝 뒤에 자원이 보인다. 복도는 두 출입구가 같다 (깊이마다 장면은 다름). D스텝 대기 뒤, HUD에 필요한 자원이 보이는 갈림길에서 첫 선택. 세계마다 자원 배정이 바뀐다. S_mem = 2·정확도 − 1.

1단계 설정: 패치 임베딩·주소 사영은 고정 난수, 결과 y = 다음 관측 가운데 칸의 임베딩. 느린 모델은 이상적인 것 (스텝별 세계 간 평균 μ⁰, 분산 v, 행동 빈도).

1. **명세 기본형 (c = 1, μ⁰ = 0)은 구조적으로 실패** (모든 기억 S ≈ 0). 결정적 스텝 (복도 다음 복도)의 잔차 0 관측이 흔적 위 회귀의 제약이 되어 갈림길 연합을 지운다. 느린 모델 잔차 r = y − μ⁰와 세계 분산 크기 s = √(v / max v)를 넣어 풀었다 (너의 일반형 y = μ⁰ + s wᵀe).
2. **읽기는 편차끼리**: cos(M k(a), φ − μ̄).
3. 그 뒤 ours (ET α = 2^(−1/8) + RLS) S = 0.90–1.00. ET 끔 ≈ 0, 기억 교환 ≈ 0. 대기 D와 무관한 것은 이상적 느린 모델이 대기 스텝의 s를 0으로 알기 때문 (공짜).
4. **오답의 원인 (측정)**: 첫째 자원이 보일 때 흔적의 70%가 직전 복도 키라 공이 복도에 갔다. 둘째 노출의 같은 모양 복도에서 기억이 첫째 자원을 예측하고, 오차 "둘째 − 첫째"가 둘째 갈림길 키에 쓰였다. 노출 사이에 방 대기를 넣으면 방 키가 흔적을 부풀려 (|x|² 수십) 더 나빠진다.
5. **임시방편 (Claude)**: 흔적 입력을 행동의 놀라움으로 가중 e ← α e + u_t k_t, u_t = −log p(a_t) (스텝별 행동 빈도). 모든 조건 S = 1.00. 그러나 **이것은 손으로 넣은 편향이다**: 자유에너지원리의 놀라움은 관측의 −log p(o)이지 행동의 빈도가 아니다. 또 이력을 보는 예측자라면 둘째 갈림길 선택 ("남은 문")은 u = 0인데도 원인이다. 이번 성공은 느린 모델이 이력을 몰랐기 때문이다.
6. **초기화 없는 흐름 (세계 200개, 경계 신호 없음)**: 증거 망각 (두 가설 우도비, 관측한 주소 방향만 P 증가) + 경험적 베이즈 척도 (P₀ = q₀ I, q₀ = v̄ / E|x|²) + 사건 위험률의 온라인 Beta 추정 → S = 0.86–0.94 평평 (초기화 1.00). 세계 간 내용은 독립이라 넘어가는 것은 잡음뿐이고, 쓸모 있게 넘어간 것은 h 같은 구조뿐이었다.

## 2. 사용자의 판단과 요청

- 놀라움 가중은 손으로 넣은 편향이다. 자유에너지원리 안에서 이 과제를 풀면, 지연된 결과를 잇는 것은 흔적의 무게가 아니라 **숨은 상태의 추론**이어야 한다: 생성 모델에 숨은 상태 (예: 어느 출입구 쪽에 있나)가 있고, 갈림길 행동으로 정해져 전이 모형에 따라 복도 동안 유지된다. 자원이 보일 때의 학습은 관측 모형에 대한 1스텝 Hebb 누적 (디리클레 계수, 관측 ⊗ 상태 믿음 = KV 외적, 키 = 추론된 상태 믿음)이 된다. 새로움 (무엇을 얼마나 크게 쓰나)은 계수에서 나온다 (기대 자유에너지의 파라미터 정보 이득).
- 이 방향으로 갈림길 과제의 자유에너지원리판을 **유도·설계**해 달라.

## 3. 해 줄 것

1. **생성 모델**: 숨은 상태, 전이, 관측 모형을 이 과제와 이후 Craftax (연속 잠재, RSSM)에 모두 맞는 형태로. 무엇이 세계마다 같고 (느린 학습) 무엇이 세계마다 다른지 (빠른 Hebb). 이산 상태 판과 연속 잠재 판이 어떻게 대응하는지.
2. **상태 추론과 빠른 쓰기의 식**: 필터링 (또는 평활)으로 상태 믿음을 얻고, 그 믿음을 키로 관측 모형의 빠른 파라미터를 쓰는 갱신. 정밀도·새로움이 계수 (또는 공분산)에서 어떻게 나오는지. 고정 계산·고정 크기를 지키는지.
3. **흔적의 자리**: 적격 흔적 (그리고 TDP의 시간차 창)이 이 구조에서 무엇에 해당하는가 (상태 믿음의 근사? 평활의 역방향 메시지? 불필요?). 1절 4·5의 실패가 이 구조에서 어떻게 사라지거나 남는지 식으로.
4. **원인과 예측 가능성**: 1절 5의 반례 ("남은 문" 선택은 예측 가능하지만 원인)를 이 구조가 어떻게 다루는지.
5. **느린 학습**: 전이 구조 (문은 복도에서 유지된다), 관측 모형의 세계 간 평균·분산, 사건 위험률을 무엇으로 배우는지 (국소 신호인지, 경사가 대기를 건너야 하는지). 1단계의 이상적 느린 모델을 대체하는 최소 형태.
6. **구현 명세**: Claude가 gate.py 위에 그대로 구현할 수 있는 수준 (차원, 초기값, 갱신 순서, 읽기와 행동 선택, 고정할 값). 비교군 (현재 ours, ours_surp, GRU 등)과 **사전 예측·실패 기준**.
7. 선행 연구 (능동적 추론의 디리클레 학습, 후속 표상, 숨은 상태 추론 기반 기억 등) 대조, [확인]/[기억] 표기.
