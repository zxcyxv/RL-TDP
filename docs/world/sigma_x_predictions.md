# 기억 몫의 사전 분산을 주소의 함수로: σ_p(x) (2026-11-16, 실행 전 고정)

영감: BTSP의 고원 전위는 드물고 (새 맥락, 보상 근처), 한 번에 크게 쓴다. 칼만 시냅스에서 "드물게 쓴다"를 정하는 정보는
"이 순간의 결과가 세계마다 얼마나 다른가" = 생성모형 y − μ⁰ = M z + ε, z = σ(x) x에서 기억 몫의 사전 분산 σ²(x)|x|²이다.
세계 공통으로 정해진 관측 (보급소로 걸어가는 중 HUD 빈칸)은 σ ≈ 0 → z ≈ 0 → 평균도 확신 (P)도 거의 쓰지 않는다.
결과가 세계마다 다른 순간 (8스텝 전 상호작용한 산출물이 도착)은 σ가 크다.

동기 (A → B → A, `aba_predictions.md`): 시냅스는 세션 약 6,300스텝을 매 스텝 써서 넘쳤다. 실제 사건 (도착)은 약 330번이고 나머지는 "아무것도 안 옴"인데,
칸별 상수 σ에서는 그 쓰기도 쓴 방향의 P를 줄여 용량을 쓴다.

예전 시도와 다른 점: 12.6 / 12.9 (wm)는 σ = c √v(o, a) (월드 모델 예측 분산). 월드 모델 입력이 지금 (o, a)뿐이라 "8스텝 전 상호작용"을 모르고,
세계 안 잡음과 세계 간 차이를 가르지 않은 전체 분산이었다 (도착 칸 0.0003–0.002로 뭉개짐, b1 44%). 여기서는 이력 (흔적)을 담은 주소 x를 입력으로,
값은 월드 모델 분산이 아니라 주변 우도로 맞춘다.

## 바꾸는 것 하나

12.13 구성 (`eb_scale.py`, `QN=1`: 더하는 Q, 난수 키, 주소 [k; e] 극 {0, 8}, 키 128, 손 선호 판정, 시드 1, 세계 256개)에서
칸별 상수 σ_p를 **σ_p(x) = exp(½ f_p(x))**로. f: R²⁵⁶ → R¹², 은닉 64 (SiLU) 한 층. `MODE=net`.
- 입력 x = e.reshape(−1) (시냅스 주소 그 자체): 기억 상태가 아니라 입력 흐름에만 의존 → 쓰기는 여전히 누적합 꼴 (병렬화 유지).
  흔적에 8스텝 전 상호작용 키가 반쯤 (2^(−8/8)) 남아 "지금 도착이 오는가"를 담는다. 키는 행동별 사영이라 상호작용 키가 구별된다.
- 은닉층이 있는 이유: "흔적 속 상호작용 성분의 크기가 8스텝 전 크기"와 "지금 행동" 같은 결합을 가리려면 비선형이 필요하다. 가장 작은 비선형 족으로 한 층.
- 초기값: 출력층 0 → 처음에는 모든 칸 σ² = 1 (12.13의 ls = 0 초기값과 같음). 첫 층은 N(0, 1/256).
- R_p, q_p는 12.13처럼 함께 맞춘다. 맞추는 절차도 같다 (학습 세계 50,000–50,255의 교사 세션, 순차 예측 NLL, 반복 200, 배치 8, Adam 0.05).
- 맞춘 매개변수는 `results/errand_diag_20261116/sigma_x_params.npz`로 저장해 A → B → A에서 그대로 쓴다 (다시 맞추지 않음).

| P2 희소성 | 판정 세계의 도착 칸에서, 도착 스텝의 σ² 평균이 도착 아닌 스텝 평균의 10배 이상 |

읽기 (실행 전에 정함):
- P2가 틀리면: 경험적 베이즈가 x 안에서 "세계 고유한 순간"을 찾지 못했다 (정보가 x에 없거나 함수족이 작음). 그 뒤 예측은 해석하지 않는다.
- P2는 맞고 P3이 틀리면: 시냅스 넘침의 원인이 빈 쓰기가 아니라 주소 겹침이다 → 다음은 구조 기반 주소 (TEM).
- P1이 틀리면: σ(x)가 errand의 변경 (b0 B → C) 쓰기를 해친다. 원인을 따로 본다.
- A → B → A는 `aba.py`의 기억에서 σ만 바꾼다 (R, q도 σ(x) 적합에서 나온 값). m은 32 그대로 (다시 정하지 않음).

## 절차 정정 (2차 실행 전)

- 초기값: 출력층 편향 = 12.13의 log σ²_p, R·q = 12.13 값, 출력층 가중치 0 → 출발점이 정확히 12.13 (`INIT1213=1`).
- 최적화: 모든 매개변수 학습률 0.005, 반복 600 (`LR`, `ITERS`). 배치·순서는 같은 난수.
- 성립 기준: 학습 세계 64개 고정 집합의 전체 NLL이 σ(x) < 12.13 상수. 성립하지 않으면 그 자체를 기록하고 판정 결과는 해석하지 않는다.
- 2차에서도 q가 크게 오르고 σ(x)가 반대 방향이면, 최적화가 아니라 이 생성모형에서 σ(x)와 q가 잘 구별되지 않는 것으로 읽는다.
- 생성모형, 판정, 사전 예측 P1–P5는 바꾸지 않는다.

## 2차 결과 (2026-11-16): 증거는 크게 좋아졌고 쓰기도 희소해졌지만, 과제는 무너짐

기록 `results/errand_diag_20261116/sigma_x2.log`, 매개변수 `sigma_x2_params.npz`.

| | σ(x) 2차 | 12.13 (상수 σ) |
|---|---|---|
| 학습 세계 64개 전체 NLL | **−13,755,513** | −12,707,512 |
| errand b1 / b0 / 다른 곳 | **30.1** / 42.6 / 27.3% | 84.4 / 15.6 / 0% |
| 도착 순간 쓰인 몫 | 0.98 | 0.49 |
| 도착 칸 σ²: 도착 스텝 / 아닌 스텝 | **93.7 / 2.85 (33배)** | 0.0039 (상수) |
| 도착 칸 q / R | 0.00082 / 0.000053 | 0.000018 / 0.00089 |

- 성립 기준 충족 (전체 NLL이 12.13보다 약 105만 낮음). 배치 NLL은 600반복에서도 아직 내려가는 중 (−214,521), 카드 칸 R은 0으로 가는 중.
- **P2 맞음** (도착 순간 σ²가 33배). **P1 틀림** (b1 30%). 정한 읽기: "σ(x)가 errand 쓰기를 해친다, 원인을 따로 본다". A → B → A (P3–P5)는 아직 돌리지 않음.
- 맞춘 기억의 모양: 도착 순간 한 번에 거의 전부 쓰고 (0.98), 과정 잡음이 커서 (q 45배) 쓴 방향의 확신이 곧 사라진다. 사실상 "주소마다 마지막 쓰기가 이김". b1의 B (관찰 단계, 오래전, 한 번)는 그 뒤 비슷한 주소의 도착들에 덮인다.
- **원인 가설 (확인 안 함): 경험적 베이즈의 학습 자료가 "오래된 사실은 틀린다"를 가르친다.** errand 교사 세션에서 오래 지나 다시 확인되는 사실은 b0 하나뿐이고, 그것은 언제나 바뀐다 (B → C). 오래전에 한 번 보고 그대로인 사실 (b1)이 다시 확인되는 경우는 학습 자료에 없다. 그러니 주변 우도는 "최근 것만 믿기"를 고르고, 함수족이 넓어질수록 (σ(x)) 더 그렇게 간다. 판정은 바로 그 반대 (오래전 한 번 본 b1의 B)를 묻는다.
  - 12.13의 상수 σ도 같은 자료로 맞췄지만 자유도가 작아 이 방향으로 덜 갔을 수 있다.
  - 이 가설은 학습 세계의 교사 일정에 "오래전 사실이 그대로인 재방문"을 넣고 다시 맞추면 시험할 수 있다 (시험 과제는 그대로, 경험적 베이즈 자료만 바뀜).
