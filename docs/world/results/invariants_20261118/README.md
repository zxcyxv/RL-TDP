## 읽기

- **키만 학습한 하락·회복은 망각의 양으로 설명된다.** 판정 읽기 방향의 누적 망각 ρ_q·gap이 0.003 → 0.39 → 0.18로 움직이고, 마지막 도착 쓰기 (b0 C)의 가중치가 0 → 0.091 → 0.046으로 같이 움직인다. b1 쓰기 가중치는 내내 0.14.
  `learned_dip_20261118`에서 "b0 C 섞임 = 귀환 경로 키로 주소가 겹침"이라고 한 해석은 주소 코사인과 키 크기 (게이지 값)에 기댄 것이라 근거가 약하다. 불변량으로는 **망각이 늘어 가장 최근 쓰기가 섞인 것**이다 (b0 C는 세션의 마지막 도착).
- **A의 붕괴 (본판·대조판 모두)는 기억이 "마지막 값 레지스터"가 된 것이다.** 모든 쓰기의 덮어쓰기 비율이 0.999, 스텝당 망각이 관측 잡음의 약 1,000배. 쓸 때마다 그 주소 방향을 통째로 갈아치우고 쓰지 않는 방향도 매 스텝 거의 처음 상태로 돌아가므로, 판정 읽기는 마지막 쓰기 (0.78)로 채워지고 400스텝 전의 b1 (0.007)은 남지 않는다. 주소 (키)가 무엇이든 이 상태에서는 같은 결과가 난다.
- R은 바닥 R₀ 아래로 내려갔다 (R + R₀ ≈ R₀). 따라서 위 비율이 커진 것은 q|z|²가 R₀ 대비 커진 것이다. 예측 분산 S 자체의 크기는 기준선과 같은 자릿수일 수 있다 (분산이 R 쪽에서 기억 사전 쪽으로 옮겨 감): 확인 안 함.
- 왜 f를 함께 학습하면 이렇게 되는지는 아직 확인 안 함. 가설: f↔M 게이지로 f가 도착 칸 (HUD) 예측을 기억에 넘기고, 남은 잔차 r = y − f가 시간적으로 지속 (빈칸·도장은 그대로 유지)되면 "직전 값 복사"가 NLL 최적이 된다. f 고정 (wm_q8)에서는 잔차가 덜 지속적이라 그렇지 않다.
