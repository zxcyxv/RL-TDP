## b1 증거 (d)

- b1은 세션에서 **한 번만** 방문된다 (256세계 모두, 관찰 단계). 작업 뒤 D = 8스텝에 HUD 도착 칸 (SLOT = 10)에 B 그림이 **직접** 보인다 (256세계 모두 B). 출처 표시는 없어서 채집처와의 연결은 흔적 주소로만 이어진다 (간접).
- 도착 스텝 중앙값 43, 쓰기 종료 (stop_t = C 도착) 중앙값 441: b1 쓰기에서 판정까지 약 400스텝. 쓰기는 그 스텝의 예측 읽기 뒤에 하고, 판정 읽기는 쓰기 종료 뒤라 정답 특징을 보지 않는다.
- 쓰기 잔차와 g_B의 코사인 중앙값 0.70 (시작점) / 0.69 (900반복). b1 도착의 SLOT 쓰기 크기는 세션 중앙값의 140배 (시작점) / 46배 (900반복).
- **주소 일치** (판정 때 후보 경로의 도착 주소와 교사 때 b1 도착 주소의 코사인):

| | b1 후보 | 다른 후보 최대 | b1이 가장 가까움 |
|---|---|---|---|
| 시작점 (고정 난수 키) | 0.89 | 0.63 | 99.6% |
| 900반복 (동시 학습) | 0.998 | 0.9985 | 39.8% |

**읽기**: 900반복의 판정 하락은 b1을 안 쓴 것이 아니라 **주소가 채집처를 구별하지 못하게 무너진 것**이다. 쓰기는 크게 했지만 다섯 후보가 거의 같은 주소를 읽는다.
A 단계 (키·흔적을 쓰기 재귀를 통해 함께 학습)에서도 같은 일이 생길 수 있으므로, 학습 중에 이 주소 일치를 함께 기록한다.
