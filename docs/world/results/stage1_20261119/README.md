## 읽기

- 결과 기억을 켜면 b1 선택이 무작위 수준(21%)에서 45%로 오릅니다. 같은 경험을 스칼라 가치로 쓰면 무작위 수준에 머뭅니다(23%).
- 그러나 절대 수준은 45%입니다. 실행 전에 "거의 확실히 통과"로 본 예측은 틀렸습니다.
- 확인된 원인은 보상 믿음입니다. 판정 시점에 A와 B의 예측 보상이 거의 같습니다.
  - 교사 구간에서 B 의뢰 중에 A가 도착하는 경험이 한 번도 없습니다.
  - 그래서 "지금 의뢰에서는 A가 보상이 아니다"라는 증거가 학습 세계에도 세션 안에도 없습니다.
  - 명세 11절의 "확인 전 가정"(관측 이력이 현재 비공개 의뢰를 구별하기에 충분한가)이 여기서 성립하지 않습니다.
- 그러면 A 채집처(a0와 다른 A)가 b1과 같은 선호를 받고, 선택은 거리 할인 γ^L로 갈립니다. "다른 곳" 37.5%가 A 채집처인지는 채집처별 내역으로 아직 확인하지 않았습니다.
- 결과 믿음에서 b1의 B 무게가 b0보다 큰 세계가 75%에 그치는 것, 그리고 두 경로에 공통으로 있는 C 무게도 아직 분해하지 않았습니다(ψ_θ 몫과 M_Ψ k 몫).
- Q = 0과 차이가 없습니다. b0 선택도 18.0%와 19.9%로 비슷합니다. 이유는 확인하지 않았습니다. 지금 b1의 주된 경쟁 상대가 b0가 아니라 A 채집처라면 Q의 효과는 드러나지 않을 수 있습니다.
