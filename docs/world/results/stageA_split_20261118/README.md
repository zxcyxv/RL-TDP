## g판 (GNET=1): 분할판 위에 기억 입력 망 g (`A_split_g.*`, 분석 `g_invariants.*`, `g_persistence.*`, `g_decomp.*`)

ŷ = μ₀(x, a) + m + g(x, a, m), g (SiLU 256, 마지막 층 0)는 L_mem (v = y − sg(μ₀) − m − g)으로 학습. 1,300반복에서 사용자 요청으로 중단 (NaN 없음).

**읽기**: g가 A 본판의 f와 같은 레지스터 해를 다시 연다. 500반복에 이미 모든 쓰기 κ 0.999, 모든 후보가 마지막 쓰기를 약 1.0 읽고 b1 0.02. 기억이 받은 도착 칸 잔차 (y − μ₀ − g)가 분할판의 35배이고 지속적이다 (지속성 0.33–0.60). Δg는 m과 반대 방향으로 m의 약 2/3를 지운다 (A 본판과 같음).
손실 분할은 f₀의 경로만 닫았고, 기억 손실로 학습되는 g는 기억과 몫을 주고받을 수 있어 같은 게이지가 열린다. g는 μ₀가 이미 맞추는 HUD 상태를 기억으로 옮기고 (r = y − μ₀ − g에서 g가 μ₀ 몫을 되돌려 잔차를 키움), 기억이 그것을 마지막 값 복사로 맞춘다.
