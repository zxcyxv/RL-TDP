## 확인된 것

- **실행마다 μ⁰를 다시 학습하면 같은 설정의 출발점 판정이 54–85%로 흔들린다.** μ⁰를 저장해 고정해야 비교가 된다 (`wm_q8.npz`).
- 같은 μ⁰에서 12.13 절차 (키 고정, 경험적 베이즈)는 70.7%. 이전의 "12.13 = 84%"는 특정 μ⁰와 그에 맞춘 값의 조합이었다.
- 학습된 키는 증거를 크게 올리고 (−199k → −246k) 판정은 기준선과 구별되지 않는다 (74.6 대 70.7, p = 0.25).
- R₀ 없이 키를 학습하면 결정적 관측에서 R → 0 (우도 특이점)으로 NaN. R₀로 막힌다.
- 월드 모델을 동시 학습하면 시야 칸 q가 1e-10까지 내려가 P의 동적 범위가 약 1e8이 되고, float32 공분산형 갱신이 양정치를 잃는다. FP32 계산으로도 막히지 않는다.
- 동시 학습판은 쓰기 (y − F₀ − m)와 정밀도 학습 목적 (y − F₀ − m − G)이 다른 관측 모형이다 (Codex 지적, 반례 G = −m).
