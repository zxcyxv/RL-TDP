## 읽기 분해 (`decomp.*`, `scripts/world/diag_20261118/stageA_decomp.py`)

판정 읽기 = m + Δf (m = M z, Δf = f(x, a, m) − f(x, a, 0)). m은 쓰기별로 정확히 나뉜다 (m = Σ_t w_t r_t, r_t = y_t − f(x_t, a_t, m_t), 재구성 오차 ≤ 1.4e-3). Δf는 m에 비선형이라 나누지 않고 크기·방향만 본다.

**읽기**
- 판정은 m이 정한다 (m만으로 매긴 판정이 전체와 ±2점). Δf는 m과 반대 방향 (cos −0.94 ~ −0.97)으로 m의 약 2/3를 지운다: f가 기억 읽기를 상쇄하도록 학습됐다.
- 500반복: q8_learned의 하락과 같은 꼴. 자기 기록은 그대로 (b1 0.15, 다른 곳 0.22)이고, 모든 후보 읽기에 b0의 C 쓰기가 약 0.11씩 섞인다.
- 1000반복 이후: **모든 후보가 마지막 쓰기 (b0의 C 도착, stop_t)를 0.7–0.8만큼 읽고 자기 기록은 0.01–0.02로 사라진다.** 보존 실패와 간섭이 함께 일어난 "마지막 쓰기가 모든 주소에서 이김".
- 순전파로 본 원인: 도착 칸 칼만 값이 q 8.2e-7 → 3.7e-3 (4,500배, 망각 창 1/q ≈ 270스텝), R 9.5e-4 → 1.3e-7 (7,000분의 1)로 움직였다. 관측을 전부 믿고 (이득 ≈ 1) 빨리 잊는 칼만이라, 약 400스텝 전에 쓴 b1은 지워지고 판정 때 읽기는 마지막 쓰기로 채워진다. 11-16 σ(x) 실험의 "주소마다 마지막 쓰기가 이김"과 같은 꼴이다.
  왜 학습이 도착 칸 q를 키우고 R을 줄였는지는 확인하지 않았다 (키만 학습한 q8_learned에서는 q가 7.5e-7로 돌아갔다).
