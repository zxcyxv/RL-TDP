## 읽기

- **b1 자기 기록은 내내 그대로다** (b1 후보 읽기의 b1 쓰기 가중치 0.13–0.14). 하락은 b1 기억을 잃어서가 아니다.
- **하락 = b0 쓰기의 섞임.** 500반복에서 b1 후보 읽기가 b0의 C 쓰기를 0.09만큼 끌어온다 (0반복 0). b1 주소와 교사 때 b0 C 주소의 코사인이 0.61 → 0.95. B가 아닌 성분이 섞여 b1 읽기의 B 코사인이 떨어지고 b0이 이긴다. 오답이 b0뿐이고 "다른 곳"이 0인 것과 맞는다.
  이때 키 크기는 이동 1.5, 상호작용 2.1, 대기 0.33: 흔적에 보급소 근처 이동 경로의 키가 크게 들어가 서로 다른 채집처의 귀환 경로 주소가 겹친다.
- **회복 = 상호작용 키가 흔적을 지배.** 상호작용 키 크기 2.1 → 24.6, 대기 0.33 → 0.08, 이동 0.95. 도착 순간의 흔적이 "어디서 작업했나"로 정해져 b1 읽기의 b0 C 섞임이 0.046으로 줄고, b1 주소가 가장 가까운 비율이 100%로 돌아온다.
- **도착 칸 NLL은 학습 내내 나빠진다** (b1 146 → 174, b0 B 315 → 358, 다른 곳 605 → 708). 이득은 도착 없는 스텝 (세션당 약 499스텝)에서 난다 (−11,261 → −11,436). 판정이 보는 도착 사건은 학습 목적이 직접 좋게 만드는 대상이 아니며, 회복은 키 모양 변화의 부산물이다. 상호작용 키가 커지는 이유는 확인하지 않았다 (가설: 작업 뒤 경과 시간을 흔적으로 실어 도착 시점과 빈 칸을 예측).
- **코사인은 주소 구별의 좋은 척도가 아니다.** 3000반복에서 모든 후보의 코사인이 0.997–1.0인데도 b1 주소가 100% 가장 가깝고 판정도 71.5%다. 칼만 이득은 이미 많이 쓴 공통 방향을 P로 줄이고 남은 작은 차이로 쓰고 읽는다. stage0·A의 "코사인 0.999 = 붕괴" 판단은 이것만으로는 근거가 약하다 (A에서는 "다른 곳" 52%라는 판정 근거가 따로 있다).


## 정정 (2026-11-18, `../invariants_20261118/`)

위 "하락 = 귀환 경로 키로 주소가 겹침" 해석은 주소 코사인과 키 크기 exp(ℓ)에 기댔다. 둘 다 게이지 값 (z의 크기는 σ, P, q와 맞바꿀 수 있음)이라 근거가 되지 않는다.
게이지 불변량으로는 판정 읽기 방향의 누적 망각 q|z|²·gap/(R + R₀)이 0.003 → 0.39 → 0.18로 움직이고, 마지막 도착 쓰기 (= b0 C)의 가중치가 0 → 0.091 → 0.046으로 같이 움직인다. **하락은 망각이 늘어 가장 최근 쓰기가 섞인 것**으로 본다.
