# forage 월드 (R3, 현재 작업)

왜 R1에서 바로 여기로 왔는지: [`../HANDOVER.md`](../HANDOVER.md) 0.1절. 요약하면 MQAR에서 성공한 형태가 Craftax 형태로 그대로 옮겨지지 않았고,
Craftax와 같은 꼴의 입력에서 설계가 성공하면 R4에서 바뀌는 것은 난이도와 학습 규모뿐이다.

## 1. 과제 (`rltdp/world/env.py`)

- 7×7 격자, 칸마다 무늬 타일 (16종, 에피소드마다 무작위 배치). 관측은 에이전트 중심 7×7 타일, 타일 하나가 7×7×3 픽셀 패치 → 패치 49개 (Craftax와 같은 꼴).
- 행동 4개 (이동). 보상 칸 하나, 겉보기로 구별되지 않음. 들어가면 +1을 받고 출발 칸으로 돌아간다. 출발·보상 칸은 에피소드마다 무작위. T = 256.
- 평가: 학습에서 나온 적 없는 배치 1,024개 (고정 키 10,000), 가중치 고정.

## 2. 지표 (`summarize`)

n = 한 에피소드에서 받은 보상 횟수.

| 지표 | 뜻 |
|---|---|
| `rewards` | n의 평균 |
| `found` | n ≥ 1인 에피소드 비율 |
| `first` | 찾은 에피소드에서 첫 보상까지 스텝 |
| `lap`, `shortest` | n ≥ 2인 에피소드에서 보상 사이 평균 스텝, 그리고 출발→보상 최단 거리 (lap이 shortest에 가까울수록 기억해서 바로 돌아감) |
| `h0_0` … `h40+`, `n_median` | n의 분포 (2026-11-14 추가). **평균만 보면 안 된다**: "적은 에피소드에서 아주 많이"와 "많은 에피소드에서 조금"이 같은 평균을 낸다 |

무작위로 걸어도 256스텝 안에 보상 칸을 못 밟는 에피소드가 약 12.5% (random의 h0_0 = 0.126). 첫 보상 전 탐색이 무작위만큼이면 found ≈ 0.875다.

## 3. 에이전트

| 이름 | 파일 | 기억 | 행동 | 학습 |
|---|---|---|---|---|
| random / oracle | `agents.py` | 없음 / 정답 위치 | 무작위 / 첫 보상 뒤 최단 경로 | 없음 (하한·상한) |
| synapse | `agents.py` | 시냅스 M 하나, TD 오차 × 키 흔적으로 매 스텝 씀 (선형 TD(λ) 꼴). 설계 `model_design.md` | M을 읽은 "앞으로의 보상" softmax | MLP 인코더·키 사영만 BPTT (장면 예측) |
| gru | `agents.py` | GRU 상태 (RL²) | 정책 머리 | A2C + GAE |
| tdp | `tdp_agent.py` | 토큰 51개 (패치 49 + 행동 + 보상), 복소 키·값 흔적 + RPE로 옮기는 장기 W | 후보 행동 4개를 읽어 보고 고름 | BPTT (다음 장면·보상·앞으로의 보상 예측). 스케일 변경 내역 `tdp_scale_stability.md` |

`model_design.md`는 synapse 설계 문서다. tdp 에이전트의 설계는 `tdp_agent.py` 머리 주석과 `tdp_scale_stability.md`에만 있다.

### 읽기

- **synapse**: 학습 전에 이미 30.4 (random 2.6, oracle 53.4). 시야가 위치마다 거의 유일해서 무작위 인코더 + TD(λ) 쓰기만으로 (위치, 행동)이 구별된다. 학습은 lap을 22 → 7로 줄인다.
  첫 보상 전에는 Mr = 0이라 행동이 균등 → found가 random과 같다 (0.876). 이 환경에서 synapse 점수는 표현 학습의 증거가 되기 어렵다 (Craftax처럼 시야가 겹치는 경우는 R4의 난이도 몫).
- **gru (A2C)**: 이봉으로 갈린다. iter 800 이후 found 0.13, 찾은 에피소드는 lap = shortest (3.77). 탐색이 결정적 정책으로 무너지고, 그 정책에 걸리는 배치에서만 최단 경로로 반복.
- **tdp**: 탐색은 무너지지 않는다 (found 0.80~0.88). 대신 **기억 활용이 생겼다 사라지기를 반복**한다: 320, 640~800에서 h20+ ≈ 0.08~0.19, 나머지 구간 (240, 560, 880~960)은 random과 같은 분포. 최종 가중치는 random 수준.
  - 첫 보상 전 정책 엔트로피 (`scripts/world/diag_prefound_policy.py`): 초기 1.386, 최고 (iter 320) 1.37~1.38, 최종 1.38. "느린 가중치가 기억이 빈 상태의 행동을 몰아 탐색을 무너뜨린다"는 가설은 이 실행에서 틀렸다.
  - 기억 크기는 안정 (tr_Wn 0.03~0.06, Wclip 0). 상태 폭주로 무너진 것이 아니다.
  - **실행 간 변동이 크다**: `tdp_scale_stability.md`의 같은 설정 (시드 0) 실행은 iter 400에서 found 0.242, 이번은 0.818. 평가 지표 추가는 학습에 영향이 없으므로 GPU 비결정성 등 실행 간 변동으로 본다. 시드 하나로는 tdp의 어느 패턴도 성질로 말할 수 없다.
