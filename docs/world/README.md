# forage 월드 (R3, 현재 작업)

왜 R1에서 바로 여기로 왔는지: [`../HANDOVER.md`](../HANDOVER.md) 0.1절. 요약하면 MQAR에서 성공한 형태가 Craftax 형태로 그대로 옮겨지지 않았고,
Craftax와 같은 꼴의 입력에서 설계가 성공하면 R4에서 바뀌는 것은 난이도와 학습 규모뿐이다.

## 1. 과제 (`rltdp/world/env.py`)

- 7×7 격자, 칸마다 무늬 타일 (16종, 에피소드마다 무작위 배치). 관측은 에이전트 중심 7×7 타일, 타일 하나가 7×7×3 픽셀 패치 → 패치 49개 (Craftax와 같은 꼴).
- 행동 4개 (이동). 보상 칸 하나, 겉보기로 구별되지 않음. 들어가면 +1을 받고 출발 칸으로 돌아간다. 출발·보상 칸은 에피소드마다 무작위. T = 256.
- 평가: 학습에서 나온 적 없는 배치 1,024개 (고정 키 10,000), 가중치 고정.

## 2. 지표 (`summarize`)

n = 한 에피소드에서 받은 보상 횟수.

| 지표 | 뜻 |
|---|---|
| `rewards` | n의 평균 |
| `found` | n ≥ 1인 에피소드 비율 |
| `first` | 찾은 에피소드에서 첫 보상까지 스텝 |
| `lap`, `shortest` | n ≥ 2인 에피소드에서 보상 사이 평균 스텝, 그리고 출발→보상 최단 거리 (lap이 shortest에 가까울수록 기억해서 바로 돌아감) |
| `h0_0` … `h40+`, `n_median` | n의 분포 (2026-11-14 추가). **평균만 보면 안 된다**: "적은 에피소드에서 아주 많이"와 "많은 에피소드에서 조금"이 같은 평균을 낸다 |

무작위로 걸어도 256스텝 안에 보상 칸을 못 밟는 에피소드가 약 12.5% (random의 h0_0 = 0.126). 첫 보상 전 탐색이 무작위만큼이면 found ≈ 0.875다.

## 5. 수정: tdpc (`rltdp/world/tdp_credit.py`), 2026-11-15

### 5.1 tdp의 설계 문제 (추상화)

이 과제의 기억은 "보상 시점에 '이 상황에서 이 행동 → 곧 보상'을 쓰고, 같은 상황에서 행동 후보별로 꺼내는" 일을 해야 한다. 반드시 필요한 성질 셋:

| 성질 | synapse | tdp |
|---|---|---|
| 1. 키 = 결정 시점의 (상황 × 행동), 결과는 값에만 | `K[a] = Wk[a] h`, 보상은 Mr에만 | 행동은 51개 토큰 중 하나로 덧셈 꼴로 섞이고, 쓸 때는 실제 보상이 키 쪽에 섞임 (읽을 때와 키가 다름) |
| 2. 공은 결과보다 먼저 온 것에만, 짧은 창으로 | TD 오차 × 키 흔적 (과거 키만) | band_product는 값 선행 반창을 끌 수 없고 (`docs/btsp/tdp_plasticity_rl.md` 2.5절), `5ada02e` 뒤로 창이 대칭 |
| 3. 공 배정 창과 보존을 나누고, 공 받은 것만 놀라움으로 게이트해 남김 | 흔적 γλ, Mr은 에피소드 동안 감쇠 없음 | band_product는 두 시간척도가 한 극점에 묶임. 장기 W는 단기 기억 전체 (대부분 패치 칸 자기 연합)를 복사하고, \|RPE\| > 0이면 매 스텝 지워짐 |

2.5절의 "TDP 빠른 기억 = 적격 흔적" 조건 (값 = 행동 표본 편차, b = 0, 행동 토큰에서만 모음)을 tdp의 장기 W는 하나도 만족하지 않는다.
첫 보상 전 탐색은 부족하지 않다 (4절, 엔트로피 ≈ 균등).

### 5.2 수정

TDP 블록은 장면 표현과 작업 기억 (단기 STDP)으로 그대로 두고, 장기 기억 경로만 세 성질대로 바꾼다. 자세한 식은 파일 머리 주석.
- 키: 행동 "아직 안 고름" · 보상 "아직 모름"으로 블록을 한 번 돌아 h(s), k(s, a) = unit(Wk[a] h(s) + bk[a]). Craftax (17개), MineRL (25개)의 범주형 행동에 그대로 쓴다.
- 흔적: e ← γλ(1 − r_prev) e + k(s_t, a_t). 키만, 보상 뒤 끊음.
- 장기 기억: w ← w + β δ e, δ = TD 오차. 에피소드 안 감쇠 없음, 에피소드마다 비움. 행동 = softmax(w · k(s, a) / temp).
- 뺀 것: RPE 복사 W, 느린 가중치에서 바로 나오는 가치 머리 (행동에 쓰지 않음).
- 손실은 tdp와 같다 (그림 + 즉시 보상 + λ-수익). λ-수익의 예측값이 기억에서 읽은 Q라서 경사가 쓰기를 거쳐 키 사영으로 흐른다.
- 자유 파라미터는 tdp·synapse와 같게 고정: γ = 0.9, λ = 0.8, temp = 0.05. β는 학습 (초기 0.5).

블록 통과는 스텝당 5번 → 3번 (장면 읽기, 고른 행동의 예측, 쓰기).

## 6. 갈림길 과제 1단계 (`rltdp/world/gate.py`, `gate_memory.py`), 2026-11-15

`plasticity_design.md` 7.2절 과제의 첫 구현. Codex는 이론, 구현·실행은 Claude.

### 6.1 과제와 1단계 단순화
- 두 출입구를 정해진 경로로 한 번씩 (무작위 순서, 노출 사이 간격 gap). 출입구 행동 d스텝 뒤에 자원 (4종 중 2종, 세계마다 배정). 복도는 두 출입구가 같다 (깊이마다 장면은 다름). 대기 D스텝 (방). 검사: HUD에 필요한 자원, 첫 선택. S_mem = 2·정확도 − 1 (우연 0, 정답 1).
- **학습 없음**: 패치 임베딩 (147 → 8)과 행동별 주소 사영 (dk = 32)은 고정 난수 (시드 0, 1, 2). 결과 y = 다음 관측의 가운데 칸 임베딩 (Codex 명세의 "생성 모델의 작은 잠재"를 대신한 단순화).
- **이상적인 느린 모델**: 스텝별 세계 간 평균 μ⁰와 분산 v (세션 구조를 안다). 빠른 기억은 세계별 편차 r = y − μ⁰만, 크기 s = √(v / max v)로 맡는다 (`plasticity_design.md`의 일반형 y = μ⁰ + wᵀe).
- 기억: ours = 키 선행 ET (α = 2^(−1/8)) + 정밀도 가중 쓰기 (RLS, R = 0.01, P₀ = I, c = 1). 비교: ET 없음, 모두 쓰는 Hebb + ET, band_product (토큰 하나, 극점 짧음·긴 것). 읽기 = cos(M k(a), φ − μ̄).
- GRU·학습된 느린 모델·tdpc는 아직 안 돌렸다.

### 6.2 구현 중 드러난 것 (명세 수정 두 가지)
1. **명세 기본형 (c = 1, μ⁰ = 0)은 구조적으로 실패한다** (모든 기억 S ≈ 0). 결정적 스텝 (복도 다음 복도)의 잔차 0 관측도 흔적 위 회귀의 제약이 되어, 갈림길 키 방향의 연합을 지운다 (즉시 결과와 d스텝 뒤 결과를 한 선형 사상으로 맞추라는 모순). 느린 모델 잔차 + 세계 분산 크기 s를 넣자 풀렸다. 이 항은 문턱이 아니라 생성 모델의 일부다.
2. **읽기는 편차끼리 비교해야 한다.** 원래 φ와의 내적은 자원 임베딩끼리의 상관 때문에 노름이 판정을 좌우했다 (오답 쪽으로).

### 6.4 읽기
- **ET는 필요하다**: α = 0이면 우연 수준 (사전 예측: ≥ 0.20 하락 → 맞음). 기억 교환이 이득을 전부 없앤다 (예측: ≥ 80% → 맞음).
- **정밀도 가중 쓰기가 모두 쓰는 Hebb보다 안정적이다** (시드 간 0.90~1.00 대 0.15~1.00).
- **D 불변은 이 설정에서 당연하다**: 이상적 느린 모델이 대기 스텝의 세계 분산을 0으로 알아서 s = 0, 쓰기가 없다. "무엇이 세계마다 다른가"를 느린 모델이 정답으로 아는 셈이다. 학습된 느린 모델에서 다시 재야 의미가 있다 (Codex 1차 설계의 "미래 필요 분포" 빈칸이 여기로 옮겨 왔다).
- **gap = 0의 오답 (시드 1, 2) — 정정**: 처음에 "둘째 결과가 첫째 갈림길 키에도 공을 받는다"고 썼으나 측정 결과 틀렸다.
  첫째 문 키로 읽은 값 ≈ 1.0·r1 − 0.56·r2 (철 그대로), 둘째 문 키 ≈ −0.9·r1 + 0.45·r2 (**"금 − 철"**).
  첫째 자원이 보일 때 흔적의 70%가 직전 복도 키라서 공이 주로 **복도**에 갔다 (기록 뒤 P: 흔적 방향 0.001, 갈림길 키 방향 0.96).
  둘째 노출의 복도 (모양이 같다)에서 기억이 철을 예측하고, 오차 "금 − 철"이 아직 불확실한 둘째 갈림길 키에 쓰였다. 덮어쓰기가 아니라 explaining-away가 잘못된 원인 지목 위에서 작동한 것이다.
  오답은 전부 둘째 문 자원이 필요할 때 (시드 1: 0.914, 시드 2: 0.897; 첫째 문 자원이 필요할 때는 1.000)이고, 철·금 임베딩이 닮은 세계에서 난다.
- **gap = 32가 더 나쁜 이유**: 같은 방 장면이 반복되면 흔적에 방 키가 쌓여 (노름 약 1/(1 − α) ≈ 12) 둘째 결과의 회귀 입력을 방 키가 지배한다.
- product의 실패는 토큰 하나라 계수 1인 탓도 있어 "창과 보존이 묶여서"로만 읽을 수 없다.

### 6.6 행동의 놀라움으로 흔적 입력을 가중 (ours_surp)

원리: 공은 오래된 정도가 아니라 **미래를 가른 지점**에 간다. 복도는 갈림길 선택으로 이미 정해진 결과다. 흔적 입력을 e ← α e + u_t k_t, u_t = −log p(a_t)로 바꾼다 (p = 느린 모델의 스텝별 행동 빈도. 갈림길 ln 2, 복도·방 0). 관측의 놀라움은 넣지 않는다 (관측은 결과, 행동은 원인). 3요소 규칙의 "행동 표본 편차"와 같은 뜻.

사전 예측 (실행 전): gap 0·32 모두 S_mem ≥ 0.95, 시드 차이 소멸, 둘째 문 키 ≈ r2.

진단 (χ와 크기를 관측 기회마다 출력):
- **ours의 evidence는 한 번도 켜지지 않는다 (χ ≈ 0).** 흐름에서는 방 키가 세계를 넘어 흔적에 쌓여 |x|² ≈ 60–86이 된다. "바뀜" 가설의 예측 분산 R + q₀|x|²가 너무 커져 어떤 오차도 설명하지 못한다. 6.4의 "반복 상태가 흔적을 부풀림"이 변화 감지까지 막는다.
- **ours_surp의 evidence는 켜지다 말다 한다 (χ = 0.98, 1.0, 0.32, 0.00, …).** 놓치는 경우: 오차 |ε₀| ≈ 0.3–0.5가 "그대로" 가설의 예측 분산 (S₀ ≈ 0.017)에 비해 분명히 큰데도, "바뀜" 가설이 q₀ = 1 때문에 훨씬 큰 오차 (분산 약 0.3)를 예측해서 둘 다 설명이 나쁘고 "그대로"가 이긴다. **q₀ = 1은 실제 내용의 크기 (자원 편차의 세계 간 분산, 성분당 약 0.03)와 맞지 않는다.** P₀ = I도 같은 문제다.
- const는 h q₀ = 0.001씩만 P를 키워, 세계가 바뀌어도 새 내용이 작은 이득으로만 쓰인다.

정리: 실패는 증거 망각의 원리가 아니라 **척도 두 가지**에서 왔다. (1) 흔적 부풀림 (놀라움 가중이 해결), (2) 사전 분산 q₀, P₀가 내용의 실제 분산과 다름. 원리대로라면 q₀·P₀는 손으로 고르는 값이 아니라 느린 모델이 아는 세계 간 분산 (v)에서 와야 한다 (경험적 베이즈). 아직 돌리지 않았다.

## 8. 학습된 인코더가 시냅스 입력을 만든다 (`rltdp/world/gate_learned.py`), 2026-11-15

틀 (사용자): DreamerV3는 F를 목적함수로 잘 학습하지만, 놀라움·정밀도는 학습 때 경사로만 쓰이고 추론 중에는 버려져 실시간 적응이 없다. 구조는 그대로 두고 기억을 시냅스로 다시 정의하면, 추론 시점에 놀라움 (쓰기 세기)·정밀도·실시간 적응을 정의할 수 있다. 원인 구별은 시냅스가 하고, 시냅스가 구별할 수 있는 입력은 규모로 학습된 인코더가 만든다.
6.6의 놀라움 가중 (u = −log p(a))은 이 틀에서 보면 정의 (관측이 아니라 행동의 놀라움)도 자리 (쓰기 세기가 아니라 흔적 입력)도 틀린 손 편향이었다.

설정: 시냅스는 1단계 ours 그대로 (흔적 α = 2^(−1/8), RLS, 흔적 입력에 손 무게 없음). 쓰기 세기 s = 이상적 느린 모델의 세계 간 분산 크기 (월드 모델 놀라움의 대리, 다음 단계에서 학습된 것으로). 바꾼 것은 키 하나:
random (고정 난수, 정규화) / surp (random + 손 편향, 비교) / learned (MLP([장면, 행동]) → 키, 크기 정규화 없음).
learned 학습: 같은 세계에서 대기 (8, 16, 32) 뒤 무작위 문을 다시 방문하는 세션, 재방문 갈림길 HUD는 무작위, 손실 = 재방문 결과를 시냅스로 예측한 오차, 2,000회 × 64세션.
평가: 원래 과제, 후보 문으로 걸어 들어갈 때 생길 흔적으로 읽음 (1단계는 갈림길 키만으로 읽었다), d = 4, 세계 1,024개. 기록 `results/gate_20261115/learned.json`.

### 8.1 쓰기 세기도 학습된 월드 모델에서 (learned_wm)

이상적 느린 모델 (스텝별 세계 간 평균·분산) 대신, (장면, 행동) → 다음 결과의 평균 μ⁰와 분산 v를 내는 작은 신경망을 여러 세계에 걸친 가우시안 음의 로그우도 (F의 정확도 항, DreamerV3의 월드 모델 학습과 같은 꼴)로 먼저 학습하고 고정. 쓰기 = 정밀도 가중 예측 오차 (내용 r = y − μ⁰, 크기 s = √(v / v̄)). 그 위에서 키를 학습. 스텝 번호는 주지 않는다. 기록 `results/gate_20261115/learned_wm.json`.

학습된 s (시드 0의 한 세션): 자원이 나오는 스텝 1.0, 결정적 복도 0.13–0.15, 자원 다음 스텝 0.69 ("갈림길인가 방인가"를 장면만으로 모름), 대기 방 0.4 (마지막 방 스텝만 다음이 갈림길이라 구별 불가). **대기 중에도 쓰기가 일어나므로 대기 길이 불변은 더 이상 공짜가 아니다.**

|---|---|---|---|
| learned_wm, D = 32 / 256 / 2048 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

학습된 키 크기: 갈림길 4.2–9.1, 복도 3.8–8.0, 방 2.9–7.5. 8절과 달리 방 키를 작게 만들지 않았다. 크기가 아니라 방향으로 구별하는 것으로 보이며, 어떻게 구별하는지는 아직 분석하지 않았다.

정리: 이 과제에서 시냅스 (흔적 + 정밀도 가중 쓰기)는 손 편향도 이상적 느린 모델도 없이, 학습된 인코더와 학습된 월드 모델의 놀라움만으로 학습 길이의 64배 대기를 견딘다. 요구 1 (기억)·2 (원인에 잇기)를 이 규모에서 만족. 요구 3 (새 목표에 바로 적응)은 아직 시험 전.

## 9. 새 목표에 바로 적응: 같은 기억에 A → B → A (`rltdp/world/gate_goal.py`), 2026-11-15

`insession_design.md` 10.2절 명세. 두 문을 한 번씩 노출 → 자원 A를 목표로 (HUD = A) A의 문을 8번 실행, A를 볼 때마다 보상 +1 → 검사 위치로 돌아와, **쓰기·갱신 없이 순수 읽기로** 목표 g = A, B, A를 차례로 묻는다 (B = 같은 세계에서 본 다른 자원). 시드 0, d = 4, 세계 1,024개. 기록 `results/gate_20261115/goal_ABA.json`.

| 기억 | g = A | g = B | g = A |
|---|---|---|---|
| **사실 기억** (8.1의 learned_wm: 학습된 키 + 학습된 월드 모델의 정밀도 가중 쓰기, 선호로 읽기) | 1.00 | **1.00** | 1.00 |
| 가치 캐시 (TD(λ), tdpc와 같은 규칙, 정규화된 난수 키) | 1.00 | **−1.00** | 1.00 |

사전 예측 (실행 전): 사실 기억은 셋 다 맞음, 가치 캐시는 B에서 반대 (S ≈ −1). 둘 다 맞았다.
가치 캐시는 보상받은 A의 문을 목표와 무관하게 고른다 (목표는 HUD로만 들어가고, 키의 작은 차이로는 굳은 가치를 뒤집지 못한다). 사실 기억은 무엇이 어디 있는지를 담고 가치를 읽을 때 지금의 선호로 계산하므로, 재학습 없이 목표가 바뀌는 즉시 맞춘다. 요구 3 (새 목표에 바로 적응)을 이 규모에서 만족.

비고: 가치 캐시에 학습된 키를 쓰면 (정규화해도) 스텝끼리 방향이 닮아 흔적이 커지고 TD 걸음 (β = 0.5)이 진동해 부호가 뒤집혔다 (A에서 −1). 정규화하지 않으면 키 크기 (약 9) 때문에 발산 (≈ 0). 비교는 tdpc 1단계와 같은 정규화된 난수 키로 했다.

## 10. 스스로 움직이는 에이전트 + 세션 안 목표 전환 (`rltdp/world/goal_forage.py`), 2026-11-15

| 무작위 정책 (학습 전) | 1.3 | 47 | 97 |

차이 없음. 진단: **시냅스 읽기만 따르는 정책 (학습 없이 argmax feat)은 보상 0.2** — 맴돈다. 이 시냅스는 "흔적 다음에 어떤 칸이 나왔나"의 회귀라, 경로를 모르는 열린 격자에서 한 스텝 키로 읽으면 "목표가 그 방향 앞에 있다"를 말하지 못한다 (흔적 창에 목표를 지나친 뒤의 스텝도 섞인다). 읽기 설계를 즉석에서 정한 것이 문제.

## 11. 세션 안 신용할당으로 새 보상에 곧바로 적응 (`rltdp/world/credit.py`), 2026-11-15

goal_forage 격자 (9×9, 시야 3×3), 목표 입력 없음. 자원 3종 중 한 종류만 보상 (밟을 때마다 +1, 자원은 남음). 무엇이 보상인지는 겪어서만 안다. T = 512, 에피소드 512개, 시드 0.
학습 분포: 보상 자원 0. 시험 "new": 자원 2 (학습 중 한 번도 보상이 아니었음). "switch": 앞 절반 자원 2, t = 256에서 알리지 않고 자원 1로.
- **frozen** (DreamerV3식): 시야 → MLP 정책·가치, A2C로 학습 분포에서 1,500회 × 64 에피소드 학습 뒤 고정. 새 보상에는 경사 갱신으로만 따라간다.
- **value** (시냅스 가치 캐시, tdpc 규칙)와 **fact** (시냅스 후속 특징 + 세션 안 보상 가중치): 학습 없음, 고정 난수 키. 모든 적응이 세션 안 시냅스. γ = 0.9, λ = 0.8, β = 0.5.

64스텝 구간별 보상 (에피소드 평균):

| | 조건 | 0–63 | 64–127 | 128–191 | 192–255 | 256–319 | 320–383 | 384–447 | 448–511 |
|---|---|---|---|---|---|---|---|---|---|
| frozen | train (자원 0) | 10.2 | 12.1 | 12.6 | 13.0 | 13.3 | 13.3 | 13.4 | 13.1 |
| frozen | **new** (자원 2) | 0.8 | 0.9 | 0.8 | 0.8 | 0.8 | 0.8 | 0.8 | 0.9 |
| value | **new** | 1.7 | 5.0 | 8.5 | 12.1 | 15.4 | 18.2 | 20.6 | 22.4 |

| fact | switch | 1.4 | 3.9 | 6.2 | 9.1 | 3.4 | 6.6 | 9.6 | 12.0 |

frozen을 새 보상 (자원 2)으로 A2C를 이어 학습한 경우, 512스텝당 보상: 50회 갱신 (82만 환경 스텝) 7.4, 200회 (330만) 8.5, 400회 (660만) 9.3.

사전 예측 (실행 전) 대조:
- frozen은 처음 보는 보상에서 우연 수준, 회복에 경사 갱신이 많이 든다 → **맞음** (660만 스텝 뒤에도 512스텝당 9.3).
- 두 시냅스는 첫 보상 뒤 경사 없이 따라간다 → **맞음**. value는 한 에피소드 안에서 64스텝당 1.7 → 22.4 (512스텝 합 약 104). 학습된 frozen이 자기 학습 보상에서 내는 수준 (약 104)과 같다.
- 전환 뒤 fact가 value보다 빨리 회복 → **틀림**. 둘 다 약 3.3에서 다시 오르고 value가 조금 빠르다 (13.5 대 12.0). fact는 처음 적응도 더 느리다.

읽기: 세션 안 시냅스 신용할당 (흔적 × 보상 오차)은 학습 없이 처음 보는 보상에 한 에피소드 안에서 적응하고, 경사로만 적응하는 고정 정책은 수백만 스텝이 지나도 거의 회복하지 못한다. 이 대비가 이 연구의 주장 그대로다. 사실 기억 + 보상 가중치 (후속 특징식)의 이점 (보상이 바뀌어도 지도를 재사용)은 이 설정에서 나타나지 않았다. 고정 난수 키 위의 후속 특징이 걸어 본 길에 대해서만 맞아서 지도로서 약한 것으로 보인다 (10절과 같은 원인).

## 12. 통합 시험 축소 1판: 지연 채집과 바뀌는 의뢰 (`rltdp/world/errand.py`), 2026-11-15

`integrated_experiment_design.md` (Codex)의 과제를 줄여 핵심 선택만. 11×11 격자, 시야 3×3 + HUD 3칸 (의뢰 카드, 도착한 산출물, 완료 도장), 행동 6개, 채집처 5곳 (겉모습 같음, 산출물 {A, A, B, B, C}), 상호작용 8스텝 뒤 산출물이 HUD에 도착 (출발지 표시 없음), 비공개 의뢰 (카드 뒷면, 맞는 산출물 도착에 +1).
교사 경로: 관찰 (5곳 1회씩, 보상 없음) → A 의뢰 ×4 → B 의뢰: b0에서 첫 +1 → 보존 256스텝 중 b0을 B → C로 → b0 재방문 (C, 보상 0) → **자율 64스텝: 첫 상호작용 채집처가 b1인가** (관찰 때 B를 봤지만 보상받은 적 없음). 세계 256개, 시드 0, 학습 없음, 고정 난수 키 128차원.
뺀 것: 고정 정책 비교군, 내부 벽, 조작판, 공개 의뢰 A → B → A, 긴 세션. 기록 `results/errand_20261115.json`.

| | b1 (정답) | b0 (옛 자리) | 다른 곳 | 안 감 |
|---|---|---|---|---|
| random | 2.7% | 7.0% | 15.2% | 75% |
| value (TD, 흔적 크기 정규화) | 0.8% | 2.7% | 3.5% | 93% |
| fact (후속 특징 + 보상 가중치) | 3.1% | 1.2% | 7.8% | 88% |

교사 구간 보상은 모두 5 (A 4 + B 1, 변경 증거 0) = 환경 정상.
진단 (기억 내용과 길 찾기를 분리, 각 채집처 자리에서 상호작용의 Q를 기억에서 직접 읽음): **b1이 최대인 비율 value 15.6%, fact 15.2% (우연 20%)**. 기억에 "b1에서 하면 B가 온다"가 들어 있지 않다. 길 찾기 이전에 기억 내용이 없다.

읽기: 고정 난수 키, 학습 없는 시냅스로는 이 과제의 신용할당 (상호작용 8스텝 뒤, 걸어가는 도중 도착하는 결과를 출발 행동에 잇기)이 되지 않는다. 결과가 올 때 흔적의 대부분은 돌아오는 길의 키이고 (γλ = 0.72, 8스텝 전 상호작용의 몫 약 0.07), HUD 칸이 모든 키에 공통으로 들어가 키끼리 겹친다. 갈림길 과제에서 원인 구별을 푼 것은 학습된 키였다 (8절). 이 과제도 학습된 키 (+ 시야 이동처럼 예측 가능한 것을 맡는 월드 모델)가 필요하다.

### 12.1 학습된 월드 모델·키 위의 예측 쓰기, 기억 내용 판정 (`rltdp/world/errand_learned.py`)

판정을 나눴다: 교사 구간 끝의 기억을 복제해 채집처마다 "가서 하고 돌아오기"를 시뮬레이션 (쓰지 않음), 산출물 도착을 예측하는 순간 HUD 도착 칸의 B 점수가 최대인 곳이 b1인가. 자율 길 찾기는 이번 판정에서 뺐다.
쓰기 = 흔적 위의 정밀도 가중 예측 쓰기 (12절의 후속 특징이 아님). 느린 학습: 월드 모델 (다음 관측 특징의 평균·분산, 음의 로그우도), 키 (SwiGLU, 시냅스가 월드 모델 잔차를 예측한 오차, 64스텝 조각). 자료는 다른 세계 512개의 교사 세션. 세계 256개, 시드 0. 기록 `results/errand_learned_20261115.json`.

| | b1 (정답) | b0 (바뀐 옛 자리) | 다른 곳 |
|---|---|---|---|
| 고정 난수 키, 월드 모델 없음 | 36% | 53% | 11% |
| 고정 난수 키 + 월드 모델 | 41% | 39% | 19% |
| 학습된 키 + 월드 모델 | 44% | 38% | 18% |
| (위 셋 + 증거 망각) | 같음 | 같음 | 같음 |

- 예측 쓰기는 "b0과 b1에서 B가 나온다"를 담는다 (다른 곳 11–19%). 12절의 실패 (우연 수준)는 쓰기 규칙 탓이 컸다.
- 남은 실패는 거의 b0을 아직 B로 기억하는 것 (b1과 b0이 거의 반반). 요구 4 (증거로만 고치기)가 걸리는 지점.
- 7절의 증거 망각 (두 가설 우도비, 온라인 위험률, q₀ = 1)을 붙여도 결과가 같다: 변화 감지가 켜지지 않는다. 의심되는 원인: 도착 순간의 흔적이 돌아오는 길의 키로 채워져 있어 "그대로" 가설의 예측이 애초에 B를 강하게 말하지 않는다 (그래서 C 도착이 놀랍지 않다). q₀ = 1과 내용 분산의 척도 불일치 (7절)도 겹칠 수 있다. 확인 전.
- 학습된 월드 모델·키의 이득은 작다 (b1 36 → 44%).

### 12.2 키 정규화 해제와 손실의 머리별 척도

- 12.1의 학습된 키는 단위 크기로 정규화되어 있어 인코더가 키 크기로 흔적을 조절할 수 없었다 (8절에서 문제를 푼 장치를 막아 둔 구현 실수). 정규화를 풀어도 결과는 거의 같다 (b1 44%, b0 41%). 학습된 키 크기: **상호작용 0.39, 이동 1.60, 대기 0.65** — 필요한 것과 반대.
- 원인 (추정): 키 학습 손실 (다음 관측 예측 오차, 96성분 합)의 대부분이 이동 때 새로 보이는 칸 (지도)이다. 지도를 맞히려면 흔적이 지금 이동 키를 크게 담아야 하고, 상호작용 키를 키우면 그 뒤 8스텝 동안 흔적을 차지해 지도 예측이 나빠진다.

### 12.6 진단: b0 고집의 원인은 지연 귀속이 아니라 쓰기 크기와 이웃 주소 (`scripts/world/diag_20261115/`)

**왜 읽기가 작은가** (첫 B 도착 스텝의 주소로, 그 뒤 k스텝 쓰기를 더 한 기억에서 다시 읽은 B 오차 몫, 세계 32개):

| k | 0 | 1 | 2 | 5 | 11 |
|---|---|---|---|---|---|
| 남은 몫 | 0.33 | 0.12 | 0.11 | 0.10 | 0.09 |

- 쓰는 순간에도 1/3만 들어간다: 도착 칸의 회귀 입력 z = s e에서 s = √(v_HUD / v̄)가 작다 (HUD 칸 월드 모델 분산 0.0003–0.002, v̄ ≈ 0.03). 도착은 드물어 평균 분산이 작지만, 도착 순간의 오차는 크다.
- 바로 다음 스텝 쓰기가 2/3를 지운다: 이웃 스텝 흔적 코사인 0.971. 다음 스텝은 빈칸 (r ≈ 0)인데 주소가 거의 같아, 회귀가 "여기서는 B가 아니었다"로 고친다.

**세션 안 선호 (델타 규칙 u ← u + β(r − u·y) y/|y|²)**, 판정의 손 선호 (B 방향) 대신:

| | b1 | b0 | 다른 곳 | 배운 선호 A / B / C |
|---|---|---|---|---|
| 손 선호 (12.4) | 45% | 53% | 2% | — |

비공개 의뢰에서는 "B 의뢰 중 A는 보상 0"을 겪을 기회가 교사 경로에 없어 A 선호가 남는다 (규칙이 아니라 경험에 정보가 없음). 공개 의뢰면 같은 규칙이 B로 옮겨 간다. C 선호가 남는 것은 고정 8차원 임베딩에서 B·C 코사인 0.79.

### 12.9 쓰기 스케일을 표준형으로 (경험적 베이즈) (`scripts/world/diag_20261115/eb_scale.py`)

### 12.15 곱하는 망각: b1 66%, 더하는 Q를 대신하지 못함 (`eb_scale.py`, `FORGET=mult`), 2026-11-16

명세 `../HANDOVER.md` 0.2절. 12.13 구성에서 `write()`의 칸별 갱신 하나만 정보형 곱하는 망각으로: H ← λ_p H + zzᵀ/R_p, G ← λ_p G + r zᵀ/R_p, M = G (H + I)⁻¹, 사전 N(0, I)는 감쇠 안 함, 예측은 감쇠 뒤·쓰기 전. λ_p를 q_p 자리에 σ_p², R_p와 함께 같은 경험적 베이즈로 맞춤 (초기 1 − λ = 1e-3, λ = sigmoid). 시드 1, 세계 256개. 기록 `results/errand_diag_20261116/`.

| 쓰기 | b1 | b0 | 다른 곳 | 도착 순간 쓰인 몫 | 기록 |
|---|---|---|---|---|---|
| RLS (Q = 0, σ², R 맞춤, 12.9) | 73.4% | 26.6% | 0% | 0.34 | `eb_scale.log` (12.9) |
| **12.13 분해**: 12.13의 σ², R 그대로, q = 0 | **77.3%** | 22.7% | 0% | 0.48 | `decomp_1213_q0.log` |
| 더하는 Q (12.13) | 84.4% | 15.6% | 0% | 0.49 | `eb_process_noise.log` |

- **12.13 분해**: 73.4 → 84.4%의 11점 중 σ² 재적합이 약 4점 (→ 77.3%), 과정 잡음 자체가 약 7점. 도착 순간 쓰인 몫 (0.34 → 0.48)은 σ² 몫이고 Q는 거의 바꾸지 않음 (0.48 → 0.49). Q의 효과는 쓰는 크기가 아닌 다른 데서 옴 (어디인지는 재지 않음).
- **곱하는 망각은 RLS보다도 낮음**: 명세의 읽기 ("84% 근처면 대체, RLS 쪽이면 더하는 Q의 무엇이 필요했는지 본다")에 따라 대체하지 않는다.
- 맞춘 값 (칸 0–8 세계, 9 카드, 10 도착, 11 도장):

  | 칸 | 1 − λ | 창 1/(1 − λ) | σ² (12.13) |
  |---|---|---|---|
  | 세계 0–8 | 0.014–0.044 | 23–74스텝 | 0.029–0.056 (0.020–0.031) |
  | 카드 9 | 0.10 | 10 | 0.00013 (0.0023) |
  | 도착 10 | 0.0053 | 190 | 0.00056 (0.0039) |
  | 도장 11 | 0.065 | 15 | 0.0016 (0.0092) |

  - 세계 칸이 수십 스텝 창으로 맞춰짐 (더하는 Q에서는 q ≈ 2e-6, 사실상 안 잊음). 곱하는 망각은 데이터가 잘 정한 방향까지 같은 비율로 잊어서, 바뀌는 것을 따라가려면 안정된 내용도 버려야 한다 (0.2절에 적은 차이와 같은 방향). 판정은 도착 칸만 읽으므로 세계 칸의 창이 b1에 직접 들어가지는 않는다.

  - 맞춘 학습 세계 NLL은 곱하는 망각이 더 낮음 (마지막 반복 −203186 대 12.13 −197143, 배치 같음, 반복마다 흔들림 ±수천). 주변 우도가 더 좋아도 b1은 낮다: 도착 칸 NLL은 대부분 아무 일 없는 스텝이고 b1은 드문 도착 사건이 정한다.
- **자유에너지 관점의 단서**: 더하는 Q는 "기억 내용이 무작위 보행"이라는 생성모형의 정확한 추론이다. 곱하는 망각 (자연 매개변수에서 사후와 사전의 λ : 1 − λ 기하 혼합, Kulhavý의 안정화된 망각)은 고정된 선형 가우스 동역학이 없고 (암묵적 과정 잡음 P′ − P가 믿음 P에 의존), 맞춘 것은 생성모형의 증거가 아니라 이 순차 예측 절차의 예측 우도다.

**수치 (구현 기록)**: 곱하는 망각은 P에 바닥이 없다. 같은 방향에 계속 쓰면 그 방향 사후 분산이 (1 − λ)R/|z|²로 가고 (지도 칸 ~1e-8), 쓰지 않은 방향은 1이라 조건수가 float32 정밀도 (1.2e-7)를 넘는다. 더하는 Q는 √(qR)/|z| 근처에서 바닥이 생겨 버텼다.
- 정보형 (H를 그대로 쌓음)과 공분산형 (P, 감쇠는 A = λI + (1 − λ)P) 모두 EB 반복 100에서 NaN (`mult_forget_nan_infoform.log`, `mult_forget_nan_covform.log`). 진단: 학습 세계 50/256에서 P 최소 고유값이 음수가 되고 (세션 5 칸 5: 스텝 281부터, −0.0035까지) 예측 분산 S = R + zᵀPz < 0 → log S NaN (기울기는 유한).
- QR 기반 제곱근 정보형 (SRIF)은 정확하지만 GPU에서 너무 느림 (스텝마다 QR 두 번, 열 단위 직렬).
- 최종: 제곱근 공분산형 (`mult_step`). P = SSᵀ, 쓰기는 Potter (행렬-벡터 곱과 외적, P가 구조상 양정치), 감쇠는 C = λI + (1 − λ)SᵀS (고유값 ∈ [λ, 1])의 촐레스키와 Woodbury로 S ← S L⁻ᵀ, M ← M − (1 − λ) M S C⁻¹ Sᵀ. 행렬곱 정밀도 `highest`. float64 정보형 기준과 예측 상대오차 9.4e-6, iter당 2.7초.
