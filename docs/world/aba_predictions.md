# A → B → A 복귀: 설계와 사전 예측 (2026-11-16, 실행 전 고정)

질문 (사용자): A를 하고 증류되고, B를 하고 증류된 뒤 단서 없이 A에 다시 놓으면, A를 처음 볼 때보다 훨씬 빨리 보상에 닿는가.
세션 저장소는 세션마다 초기화되므로 A → B → A는 **한 세션 안의 두 맥락**이다 (겉날개 → 드래곤 → 겉날개를 한 세계에서).
사용자 결정: 두 구역 (공간이 다름, 같은 종류의 목표), 손 선호 판정.

## 과제 (`scripts/world/diag_20261116/aba.py`)

- 구역 = errand 세계 하나 (11×11, 채집처 5곳, 산출물 {A, A, B, B, C} 무작위 배정, 바닥 무늬 무작위). 변경 (b0 → C) 없음, 의뢰 없음.
- 한 세션: 구역 A → 구역 B₁ … B_m (서로 다른 세계) → 구역 A로 복귀. 구역 사이는 순간이동. 기억 (시냅스, 저장소, 흔적)은 이어지고, 구역 경계를 넘는 전이는 쓰지 않는다.
- 각 구역에서 교사가 관찰 2바퀴: 바퀴마다 채집처 5곳을 무작위 순서로 "가서 상호작용 → 보급소로 돌아오며 도착까지 대기" (errand의 관찰 단계와 같은 동작).
- 복귀 판정: A의 보급소에서, 채집처마다 "가서 하고 돌아오기"를 끝 기억으로 흉내 내 도착 칸 예측 ŷ와 손 선호 g_C (C − 산출물 평균)의 코사인으로 점수를 매긴다 (12.1의 판정과 같은 방식, 목표만 C).
  **첫 보상까지 시도 수** = 점수 내림차순 (동점 무작위)에서 C 채집처의 순위 (C는 세계마다 한 곳). 방문한 곳은 다시 가지 않는다고 보고, 틀린 시도에서 쓰이는 내용이 남은 순서를 바꾸는 효과는 무시한다.
  기억 없음 (처음 A) = 무작위 순서, 기댓값 3.0. 함께: 첫 시도에 맞힐 확률 (우연 0.2).
- 기억: 12.16 그대로 (더하는 Q 시냅스, σ², R, q는 12.13 도착 칸 값, 다시 맞추지 않음; 저장소 φ 1024, η_a = η_s = 0.05, 잠 K = 64, n = 5, 버퍼는 세션 전체, 복귀 판정 직전 잠 한 번). 도착 칸만 계산.
- 읽기 (한 실행에서): **시냅스만** = M_r z (S의 영향을 받지 않으므로 저장소 없는 실행과 같음), **합친 기억** = M_r z + S (φ − M_φ z), **저장소만** = S φ.
- 세계 256개 (A 세계 시드 1000–1255, B 세계는 따로), 시드 1.

## m (B 구역 수) 정하기: 저장소 조건 전에

- 시험이 의미 있으려면 B가 시냅스를 넘쳐 A를 덮어야 한다. 더하는 Q의 도착 칸은 거의 잊지 않으므로 (1/q ≈ 5.5만 스텝) 시간이 아니라 용량 (주소 256차원, 선형)으로 덮여야 한다.
- 저장소 없이 (`STORE=0`) m ∈ {0, 1, 2, 4, 8, 16, 32}에서 시냅스만의 복귀 시도 수를 재고, **시도 수 ≥ 2.5가 되는 가장 작은 m**을 본 실험에 쓴다. 32에서도 2.5 미만이면 이 설계로는 시냅스가 넘치지 않는다고 기록하고 멈춘다.
- m = 0 (A → A, B 없음)은 상한 조건으로 본 실험에서도 함께 잰다.

## 사전 예측

| | 예측 |
|---|---|
| P1 m = 0, 시냅스만 | 시도 수 ≤ 1.5 (A를 2번씩 봤고 바로 복귀) |
| P2 m = 0, 합친 기억 | 시냅스만과 ±0.2 안 (12.16에서 합친 기억 = 12.13) |
| P3 정한 m, 합친 기억 | 시냅스만보다 0.5 이상 적음 (저장소가 A를 지킴) |
| P4 정한 m, 합친 기억 | 첫 시도 정답 ≥ 0.4 (우연의 2배) |
| P5 정한 m, 저장소만 | 합친 기억과 ±0.3 안 (시냅스가 넘친 뒤에는 저장소가 거의 다 답함) |
| P6 정한 m, 합친 기억 대 저장소만 | 합친 기억이 저장소만보다 나쁠 수 있다 (넘친 시냅스가 확신 있게 틀림, 토이 3.3). 방향만 기록 |

실패 기준: P3이 틀리면 (합친 기억이 시냅스만과 0.5 안), 이 저장소 (선형, φ 1024, 국소 델타 규칙)는 B 뒤에 A를 지키지 못한 것이다. 원인 후보는 저장소 용량 (B의 사실도 같은 S로 들어옴)과 잠의 이동량.

## 진단: 용량인가, 순차 학습 (망각)인가 (2026-11-16, 사용자 질문 뒤 추가)

m = 32, 나머지는 본 실험과 같음. `aba.py`의 `SMODE`. 기록 `results/aba_20261116/{ridge,raw}_m32.log`.
- **ridge (용량 상한)**: 깨어 있을 때·잠의 S 학습 없이, 세션 전체 (φ_j, r_j)로 S* = Rᵀ Φ (ΦᵀΦ + λI)⁻¹를 한 번에 풂. 같은 φ 1024. λ ∈ {0.001, 0.01, 0.1, 1}.
- **raw (날것 재생)**: 버퍼에 r_j도 두고 잠의 목표를 시냅스 몫 M_t z_j 대신 실제 관측 r_j로 (S ← S + η_s (r_j − S φ_j) φ_jᵀ). 깨어 있을 때 쓰기, 시냅스 cr, 잠 일정, η는 그대로.

| 저장소 학습 | 저장소만 | 합친 기억 |
|---|---|---|
| belief 재생 (본 실험) | 2.24 (41%) | 2.30 (37%) |
| **raw 재생** | **1.38 (76%)** | 1.56 (66%) |
| ridge 상한, λ = 1 | 1.32 (79%) | 1.99 (45%) |
| ridge 상한, λ = 0.1 | 1.39 (75%) | 1.59 (61%) |
| (시냅스만) | 2.60 (28%) | |

읽기:
- **용량이 아니다**: 같은 φ 1024에 세션 전체를 최적으로 담으면 B 구역 32개 뒤에도 A를 1.32회에 찾는다.
- **순차 델타 규칙도 아니다**: 같은 깨어 있을 때 쓰기와 같은 잠 일정에서 잠의 목표만 날것으로 바꾸면 1.38회로 상한에 가깝다.
- **원인은 교사 소실**: belief 재생의 목표는 시냅스 몫 M_t z_j = M_r z_j − S M_φ z_j다. 이 몫은 지금 S 기준이라, 시냅스가 A를 기억하는 한 저장소의 A가 흔들린 만큼 다시 커져 바로잡는다 (cr의 이동 자체는 교사를 비우지 않는다).
  그런데 B의 사실 약 320개가 256차원 시냅스를 넘쳐 M_r z_A, M_φ z_A가 망가지면, 잠이 A 입력을 다시 꺼내도 교사가 A의 정답을 말하지 못한다. 그 사이 B 쓰기 (ReLU 특징끼리 코사인 약 0.32로 겹침)가 저장소의 A를 흔든 것을 되돌리지 못한다.
  날것 재생의 교사는 세션 전체 (약 6,300스텝)를 담은 버퍼라 이 한계가 없다 (대신 메모리가 세션 길이에 비례, KV 캐시와 같음). 공고화 토이 3.3의 4와 같은 현상: 믿음 재생은 시냅스가 기억하는 동안만 옮긴다.
  (처음 쓴 문장 "cr이 옮긴 뒤 그 몫이 0에 가깝다"는 정확하지 않아 이렇게 고침, 2026-11-16.)
- 사람·LLM과의 대응: 섞어 재생할 때 옛 내용의 진짜 목표가 실려야 한다 (해마가 옛 일화를 들고 있음, LLM은 뒤섞인 데이터). belief 재생은 이동 (cr) 때문에 해마 쪽이 빈다.
- 합친 기억은 세 경우 모두 저장소만보다 나쁘다: 넘친 시냅스의 보정 M_t z가 확신 있게 틀림 (P6, 토이 3.3의 3). raw에서 시냅스 몫이 0.062로 belief (0.008)보다 크다.
- 남는 질문: 날것 재생은 옛 관측도 되풀이한다. 값이 바뀌는 경우 (errand의 b0: B → C)에서 날것 재생이 옛 B를 되살리는지는 재지 않았다 (12.16 설정에서 SMODE=raw로 잴 수 있음). 토이에서는 값 변화가 있어도 날것이 이겼다 (P7).
