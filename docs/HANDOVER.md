### 0.1 R1 → R3로 바로 넘어간 이유 (사용자 결정, 2026-11-14)

- R1 (MQAR 흐름판)에서 결과는 나왔지만, Craftax에서 돌아가는 형태로 넣으려 하니 MQAR에서 성공한 형태 중 어느 것도 그대로 옮길 수 없었다.
- 그래서 Craftax와 같은 꼴의 입력 (타일 단위 이미지 패치 + 행동 + 보상, 행동 4개, 에피소드마다 바뀌는 배치)을 쓰는 작은 과제 (forage 월드)에서 R3를 바로 한다.
- 모델 설계가 여기서 성공하면 R4 (Craftax)에서 달라지는 것은 실질적으로 **난이도와 학습 규모뿐**이다. 이것이 이 순서의 이점이다.
- 따라서 forage 월드의 설계 판단 기준은 "Craftax로 그대로 옮길 수 있는 형태인가"다.

### 0.2 곱하는 망각을 먼저 하는 이유와 시험 명세 (사용자 결정, 2026-11-16)

**이유: 사전학습에서의 병렬 학습**
- DreamerV3는 RSSM (GRU)을 64스텝 조각으로 순차 역전파한다. 순차 칼만 쓰기는 DreamerV3 대비 불리하지 않다.
- 문제는 요즘 흐름이다: 대량 모방·오프라인 사전학습 뒤 실제 환경에서 짧은 파인튜닝 (VPT, Dreamer 4). 기억을 낀 채 긴 궤적을 대량으로 학습하려면 시간 축 병렬이 돼야 한다.
  이 흐름에서 이 연구의 자리는 "짧은 파인튜닝을 세션 안 가소성으로 대신"이다. 후속 특징의 Ψ는 보상 없이 정의되어 모방 데이터로 사전학습할 수 있고, 세션 안에서는 u만 보상으로 배운다.
- **병렬이 되는 것**: 쓰기 이득이 주소 z에만 의존하고 M에 선형인 쓰기. 델타, RLS, 망각 계수 RLS, 후속 특징의 TD 쓰기 (부트스트랩이 있어도 M에 선형, LSTD 누적합). 칼만 + 일정 Q는 리카티 재귀가 z에만 의존해 결합 스캔은 되지만 조합마다 d³.
- **깨지는 것**: 쓰기·망각 세기가 기억 자신의 예측 오차에 의존하는 것. R1 ours (읽기 오차로 키별 잡음 추정), gdn_read, 증거 망각의 χ, 온라인 위험률.
  선형 가우시안 모델에서 칼만 이득은 관측값과 무관하다. 내용이 끼어드는 것은 변화의 증거 ("내가 기억한 것과 어긋남")와 세션 안에서 추정해야 하는 신뢰도뿐이다. 느린 월드 모델의 놀라움으로는 대신할 수 없다 (b0의 C는 첫 방문의 C와 같은 놀라움).
- 더하는 Q (P ← P + qI)는 정보형에서 선형 누적합이 아니다. 곱하는 망각은 누적합 두 개 (MesaNet과 같은 꼴)라 청크 병렬이 된다.
  이것이 84%를 지키면 쓰기와 시간 망각은 사전학습과 양립하고, 남는 병렬화 문제는 증거 망각 하나로 좁혀진다 (후보: 청크 시작 시점의 기억 기준으로 증거를 재는 TTT 층식 지연, 또는 게이트 없는 아래 단계 기억들의 오차로 증거를 만드는 단계형).

**명세**
- 출발: 12.13 구성 그대로 (`scripts/world/diag_20261115/eb_scale.py`의 `QN=1` 자리). 난수 키, 주소 [k; e], 키 128, 손 선호 판정, 시드 1, 세계 256개.
- 바꾸는 것: `write()`의 칸별 갱신 하나. 정보형으로
  - H ← λ_p H + z zᵀ / R_p, G ← λ_p G + r zᵀ / R_p, M = G (H + I)⁻¹. z = σ_p [e; k]는 그대로, 사전 M ~ N(0, I)는 감쇠하지 않는다.
  - 주변 우도용 예측은 감쇠 뒤·쓰기 전 상태로: 평균 M z, 분산 R_p + zᵀ (H + I)⁻¹ z.
  - λ_p는 q_p 자리에 칸별 하나, σ_p², R_p와 함께 같은 경험적 베이즈로 맞춘다.
  - 구현은 지금처럼 순차 scan으로 둔다. 이 시험은 형태가 되는지 보는 것이지 속도가 아니다.
- 쓰지 않는 판: 사전까지 감쇠시키는 공분산 팽창 (P ← P / λ). 관측 안 된 방향의 P가 끝없이 커진다 (windup).
- 비교: RLS (Q = 0) 73.4%, 더하는 Q 84.4% (12.9, 12.13).
- 함께 기록: 맞춘 λ_p와 유효 창 1/(1 − λ_p), 도착 순간 쓰인 몫, 그리고 **12.13 분해** (12.13에서 맞춘 σ², R은 그대로 두고 q만 0으로 한 판정).
  12.13에서는 Q를 넣으면서 도착 칸 σ²도 0.0005 → 0.0039로 같이 바뀌어, 73 → 84%가 과정 잡음 덕인지 σ² 재적합 덕인지 갈리지 않았다.
- 읽기: 84% 근처면 곱하는 망각으로 대체한다. RLS 쪽에 가까우면 더하는 Q의 무엇이 필요했는지 본다.
  더하는 Q는 P가 작은 (잘 정해진) 방향일수록 상대적으로 크게 불확실해지고, 곱하는 망각은 데이터가 정한 방향을 모두 같은 비율로 키운다.
- 12.13 기록의 단위 정정: "256스텝 동안 늘어나는 P (≈ 0.0046)가 사전 분산 σ² (0.0039)과 비슷"은 틀렸다. 코드에서 사전은 P₀ = I이고 σ는 z 안에 있다.
  Q가 256스텝에 더하는 0.0046은 사전의 0.46%이고, 사전 수준까지는 약 1/q 스텝 (도착 칸 약 5.5만, 도장 칸 약 1.4만, 지도 칸 20만–50만) 걸린다. 쓴 방향의 사후 P에 비해 얼마나 큰지는 재지 않았다.

**그 뒤 후보 (사용자 제안, 결정 안 됨)**: 긴 세션의 기억 한계를 다루는 두 방법.
- **대역폭 여러 개**: λ가 다른 시냅스 여러 개 (가장 긴 것은 수만 스텝). 각 시냅스는 게이트 없는 누적합이라 병렬이다.
  어느 대역을 믿을지는 읽을 때 각 대역의 순차 예측 우도로 정한다 (베이즈 모형 평균). 이 가중치는 쓰기로 되돌아가지 않으므로 증거를 쓰면서도 병렬이다 (위의 단계형 후보와 같은 꼴).
  한계: 긴 대역은 그동안의 모든 쓰기를 담아 선형 용량 (키 차원)에 걸린다 (R1 결과 5절, 키 64개에서 "확실한데 틀린" 읽기 7.6%). 흔적 극 늘리기 (12.10)는 주소 쪽 시간척도라 이것과 다른 축이다.
- **공고화**: 일정 간격으로 빠른 시냅스의 내용을 더 크고 느린 저장소로 옮긴다 (상보적 학습계의 해마 → 신피질).
  옮길 곳은 세계 공통인 느린 가중치가 아니라 세션 (세계) 전용 저장소여야 한다. 세계마다 다른 사실 ("b1에서 B")을 공통 가중치에 쓰면 다른 세계를 오염시키고, 이는 시험 때 가중치를 파인튜닝하는 것과 같다.
  무엇을 옮길지는 칼만 상태가 정한다 (사후 P가 작은 = 믿을 만한 내용). 용량 문제를 직접 다루는 쪽은 이것이다. **→ 다음 절차 2–3으로 채택 (0.3절).**
- 둘 다 기억 한계가 실제로 걸리는 과제 (세션 길이와 사실 수가 시냅스 용량을 넘음)에서 재야 한다. errand (보존 256스텝)에서는 보존 시간이 실패 원인이 아니었다.
- 문헌과 토이 (2026-11-16 자유연구): [`consolidation/README.md`](consolidation/README.md). 요지: 재생으로 옮길 때는 복사가 아니라 이동이어야 하고 (잔차를 쓰는 순간 기준으로 굳히면 이중 계산이 폭주), 시냅스를 "현재 느린 모델에 대한 잔차"로 유지하면 느린 쪽이 배운 만큼 시냅스가 저절로 빈다. 대역폭 여러 개는 Kording 외 2007의 다중 시간척도 칼만 필터와 같다 (결정 안 됨).

### 0.3 절차 2–4의 명세 (사용자 결정, 2026-11-16)

근거와 토이: [`consolidation/README.md`](consolidation/README.md) (2–4절). 토이 코드 `rltdp/consolidation/toy.py`.

**2. cr+replay (12.13 위에)**
- 출발: 12.13 구성 그대로 (더하는 Q, 난수 키, 주소 [k; e], 손 선호 판정, 시드 1, 세계 256개). 시냅스 M은 그대로 두고 **세션 저장소 S**와 **잠**을 더한다.
- S: 특징 φ(o, a) 위의 칸별 선형. 시냅스보다 용량이 커야 의미가 있다 (토이는 D = 4d). φ는 실행 전에 정하고 근거를 적는다 (후보: 시냅스 주소와 같은 입력의 더 큰 무작위 사영).
- 시냅스 쓰기: μ⁰ + S φ에 대한 잔차를 칼만으로. 더하는 Q는 누적합 꼴이 아니므로 cr은 **값 확장**으로 한다: 시냅스가 같은 이득으로 잔차 r과 함께 φ도 저장하고 (M_r, M_φ), 읽기는 M_r z − S M_φ z.
  근거: 칼만 평균은 관측값에 선형이고 이득은 z에만 의존한다 (식으로만 확인, `consolidation/README.md` 2.2와 같은 내용을 더하는 Q로 일반화).
- S 쓰기: 깨어 있는 동안 자기 오차로 델타 규칙 (η). 잠에서는 목표 = 지금의 믿음 μ⁰ + S φ + M z로 델타 규칙. 이 오차는 시냅스 읽기 M z 자체다 (시냅스가 교사).
- 잠: K스텝마다 지금까지의 교사 세션 입력 (o, a)를 작은 입력 버퍼에서 다시 꺼내 n번 훑는다. K, n, η는 errand 시간척도에 맞춰 실행 전에 고정하고 근거를 적는다 (토이 값 16, 5, 0.05를 그대로 쓰지 않는다).
- 판정: 12.13과 같은 손 선호 판정 b1을 세 가지로 읽는다. (i) 합친 기억 μ⁰ + S φ + M z, (ii) 저장소만 (M = 0), (iii) 시냅스만 (S = 0).
- 함께 기록: 도착 칸에서 시냅스 몫 크기 (잠 전후), 저장소가 맡은 몫.
- 대조 (선택): 시냅스가 쓰는 순간의 잔차를 굳히는 판 (naive+replay). 토이에서 이중 계산으로 폭주했다.
- 읽기: (i)이 12.13 (84.4%)보다 나빠지면 이중 계산이나 구현 문제. (ii)가 우연 (20%)보다 분명히 높으면 옮겨진 것. errand에서는 시냅스가 넘치지 않을 수 있어 b1 상승은 기대하지 않는다. 이 단계는 실제 파이프라인에서 옮기기가 해 없이 되는지 확인하는 것이다.

**3. 곱하는 망각 + cr+replay**
- 1단계의 곱하는 망각 정보형 위에 2단계를 얹는다. cr은 교차 통계로: C ← λ_p C + φ zᵀ / R_p, 시냅스 M = (G − S C)(H + I)⁻¹. 모두 누적합 (토이와 같은 꼴).
- λ_p, σ_p², R_p는 1단계에서 맞춘 값 그대로 (저장소 없이 맞춘 값, 다시 맞추지 않는다). S, 잠, 판정은 2단계와 같다.
- 읽기: 곱하는 망각에서는 잊힌 내용이 저장소 예측으로 돌아가므로 ("옮긴 뒤 잊기"), (i)과 (ii)의 차이가 2단계보다 작아야 한다.

**4. 후속 특징 쪽 설계 고민 (구현 전, 사용자 검토)**
1–3의 결과를 받아 `world/sf_architecture.md`에 다음을 따져 적는다. 이론 검토가 필요하면 Codex 프롬프트를 써서 사용자 검수 뒤 보낸다.
- **층 셋**: Ψ = Ψ⁰ (세계 공통, 세션 안 고정) + S φ (세션 저장소, 국소 규칙) + M z (시냅스). TD 목표에 다음 상태가 들어가 교차 통계가 둘 (φ_t, φ_{t+1})이 된다.
- **정밀도까지 옮기기**: 행동 점수의 정보 항 ½ log(1 + zᵀPz/R)이 옮긴 뒤 잊은 내용을 "모른다"고 보면, 이미 아는 곳을 다시 탐색한다.
  세션 저장소도 불확실성을 들어야 하고 (칼만/RLS형), 옮기기는 시냅스가 가진 정보만큼 저장소 정밀도를 늘리고 시냅스에서 덜어 내는 꼴이어야 한다. 재생 관측을 R짜리 새 증거로 넣으면 정밀도가 이중 계산된다. 정보 항은 합친 믿음의 불확실성으로.
- **재생 입력의 출처**: 작은 입력 버퍼, 또는 시냅스가 φ도 저장할 때 입력 없이 시냅스 상태만으로 닫힌 꼴로 옮기기 (확인 안 함).
- **믿음 재생의 근거**: 후속 특징의 Ψ는 흔적으로 퍼뜨린 값과 증거로 고친 믿음을 담는다. 날것 재생은 TD 목표를 재생 때마다 다시 계산해 가치를 다시 퍼뜨려야 한다. 토이에서 믿음 재생이 진 이유 (시냅스가 날것과 다른 것을 모름)가 여기서는 해당하지 않는다.
- **넘친 시냅스의 확신 있는 오답** (토이 3.3): 잠 빈도, 덜 쓰기 (R1), 더 큰·희소한 시냅스 주소 중 어디서 풀지.
- **시험 순서 다시 정하기**: `sf_architecture.md` 5절의 (1) γ > 0, (2) 세션 안 선호는 저장소 없이 할 수 있다. 그다음 순차 시험 (A 학습 → B 학습 중 시냅스가 넘침 → A로 복귀; 겉날개 → 드래곤 → 겉날개의 축소판)을 끼우고, (3)–(4) 자율 행동은 정보 항 문제 때문에 그 뒤.

## 4. (끝남) R1 계획 — 기록으로 남김. 결과는 `docs/memory/r1_results.md`

### 4.1 구현

새 패키지 `rltdp/memory/`에 둔다 (제안):

| 파일 | 내용 |
|---|---|
| `stream.py` | 과제 생성기. 손잡이: 중요 비율 ρ, 방해 구성 (잡음 / 반복 / 무관한 새것), 종류별 잡음 수준·중요도, 결과 (보상 토큰) 지연, 질의 지연 분포 (학습 길이의 수십 배까지), 흐름 길이 |
| `models.py` | 같은 상태 크기의 기억들: Hebb 덧셈, 델타 규칙, Gated DeltaNet (학습 게이트), 칼만 쓰기 (+ 관련성 흔적), 정답 게이트 |
| `train.py` | 느린 가중치 (키·값 사상, 종류 정밀도·관련성 예측기) 사전학습. Gated DeltaNet은 짧은 조각으로 학습 |
| `eval.py` | 지연별 회상 정확도, 회상 거리, ρ·방해 구성·기억 크기·흐름 길이 훑기, 제거 실험 |

참고할 기존 구현: Gated DeltaNet과 델타 쓰기 (`rltdp/icrl/arch.py`), 정밀도 가중 로그 우도비와 사건 뒤 흔적 (`rltdp/icrl/toy.py`).
외부 참고: MQAR 과제 정의 (Zoology), memax의 Gated DeltaNet (`memax/equinox/semigroups/gdn.py`, 결합 스캔).

### 4.2 순서

1. 선행 연구 확인: 연관 기억의 칼만 / RLS 해석 (ROADMAP 2절).
2. 사전 예측 문서 `docs/memory/r1_predictions.md`를 실행 전에 쓰고 고정한다 (ROADMAP 4절의 예측 표가 출발점).
3. **R1-a**: 관련성 방해 없이 잡음·반복만. 칼만 쓰기 대 Hebb·델타·Gated DeltaNet·정답 게이트.
4. **R1-b**: 무관한 새것을 더하고 관련성 흔적을 켠다. 회상 거리 ∝ 1/ρ와 정답 게이트 근접을 본다.
5. 제거 실험 (정밀도·새로움·관련성), 길이 불변성 (학습 길이의 수십 배).

### 4.3 성공 기준

- 잡음·반복 방해를 늘려도 칼만 쓰기의 회상 거리가 유지되고, 델타·Hebb은 예측대로 무너진다 (R1-a).
- 무관한 새것 속에서 회상 거리가 1/ρ에 비례하고 정답 게이트 상한에 가깝다 (R1-b).
- 각 인자를 빼면 해당 방해에서 무너진다.
- 학습 길이의 수십 배에서 곡선이 변하지 않고, Gated DeltaNet은 학습 길이 밖에서 회상 거리가 준다.

연산: 합성 과제라 CPU로 시작할 수 있다. 훑기 (ρ × 방해 × 기억 크기 × 시드)는 GPU에서 병렬로.
