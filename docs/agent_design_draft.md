# 에이전트 설계 초안: DreamerV3 구조 위의 기대 자유에너지 최소화

상태: 초안 (토론 전). 원칙: 모든 구성요소는 자유에너지 원리/능동적 추론에서 유도한다. 유도되지 않는 것은 **근사**(무엇을 근사하는지 명시) 또는 **선택**(상의 필요)으로 표시한다. DreamerV3는 구조의 출처일 뿐 근거가 아니다.

참고 문헌 표기: [DC20] Da Costa et al. 2020 (이산 능동적 추론, 식 번호는 원문), [F23] Friston et al. 2023, [M19] Millidge 2019 (Deep active inference as variational policy gradients), [이론] docs/handover/01-theory.md.

---

## 0. 무엇을 DreamerV3에서 빌리나

DreamerV3의 골격: (1) 월드 모델을 데이터로 학습, (2) 월드 모델 안에서 상상 궤적을 굴려, (3) 가치망(critic)과 정책망(actor)을 학습, (4) 실제 환경에서는 정책망으로 행동. 우리는 이 골격을 쓰되, (3)의 목적을 "보상 합 최대화"에서 "**기대 자유에너지 G 최소화**"로 바꾼다. 아래 1~7절은 이 교체가 각 구성요소에 무엇을 요구하는지 유도한다.

## 1. 생성 모델과 믿음 상태

세 월드 모델 공통: 관측 o_t = (x_t 격자, d_t 방향, y_t 결과 ∈ {진행, 성공, 실패}), 행동 a_t, 결정론적 기억 h_{t+1} = GRU(h_t, [emb(o_t), a_t]).

| 모델 | 숨은 확률변수 | 관측 모델 |
|---|---|---|
| M0F-S | 없음 | P(o_t \| h_t, o_{t−1}, a_{t−1}) 칸별 범주형 |
| M0-SQ | 흐름 잠재 z_t (들어 올린 v_t와 1:1) | v_t = f(z_t; h_t, 직전), x_t = argmax(v_t) |
| M1-S | s_t ~ p(s_t \| h_t) | P(o_t \| s_t, h_t, 직전) |

**믿음 상태**: 시점 t에서 o_t를 본 뒤 에이전트가 가진 것은 h_t와 o_t(와 M1이면 q(s_t | h_t, o_t))이다. q(s_t|·)도 (h_t, o_t)의 함수이므로 세 모델 모두 **b_t = (h_t, o_t)가 믿음의 충분통계량**이다. → 정책·가치망 입력은 f(b_t) = [h_t, emb(o_t)]. (유도됨: 믿음은 과거 관측·행동의 함수이고, 정책은 믿음의 함수다 [DC20 6절, F23 식 16의 "내부 상태 = 충분통계량"])

## 2. 기대 자유에너지의 시점별 분해

정책 π를 따랐을 때 미래 τ > t의 예측분포 Q(o_τ, s_τ | π). 선호를 결과(관측)에 두는 형태 [DC20 식 10의 관측 버전, 이론 5.1]:

  G(π) = Σ_τ g_τ,   g_τ = −E_{Q(o_τ|π)}[ln C(o_τ)] − E_{Q(o_τ|π)} D_KL[Q(s_τ | o_τ, π) ‖ Q(s_τ | π)]
                     = (실용 항의 음수) − (상태 정보 이득)

- 시점별 합 구조: 유도됨 [DC20 식 10, G(π) = Σ_τ G(π, τ)]
- 실용 항 E_Q ln C(o): 예측된 결과 분포로 **정확히 기댓값**을 낸다(결과 y는 3범주). 유도됨
- 항등식 위험 + 모호성 = −실용 − IG: [이론 V12]에서 수치 검증

## 3. 쟁점: 상태 정보 이득(IG)의 형태는 "무엇이 숨은 상태인가"에 달려 있다

IG_τ = I(s_τ; o_τ) = H[Q(o_τ)] − E_{Q(s_τ)} H[P(o_τ | s_τ)]. 여기서 s는 **생성 모델에서 관측을 일으키는, 에이전트가 믿음을 갖는 확률변수**다.

- **M1-S**: s_t가 그 변수다. IG = I(s; o) = E_{ô} KL[q(s | h, ô) ‖ p(s | h)]. 유도됨. 단, 정확한 사후 대신 인코더 q를 쓰므로 **근사**이고, 이 근사 오차가 바로 M1의 추론 간극이다.
- **M0F-S**: 숨은 확률변수가 없다. 에이전트는 h에 대해 불확실하지 않다(결정론적). 그러면 Q(s)가 한 점이고 IG = 0, 모호성 = H[P(o|h)] 전체. 즉 **G = −E ln C(o)** (탐색 항 없음). 유도됨.
  - 대안 해석: "관측 자체를 상태로 본다"(s ≡ o)면 IG = H[Q(o)]가 된다. 이건 [이론 5.3]의 결정론적 디코더 경우이며, 실험 2d 초안이 M0F-S에 쓴 −ln P(x̂|h)가 이 해석이었다. 그러나 M0F-S의 생성 모델에는 관측과 별개의 상태 변수가 없으므로, 이 해석은 **모델에 없는 변수를 상정한 것**이다. → 폐기 제안
- **M0-SQ**: z_t는 확률변수지만 들어 올림을 위한 **계산용 변수**다(범주 영역 안의 위치). 세계의 원인을 나타내지 않는다. 이를 상태로 치면 I(z; x) = H[P(x | h)](예측 엔트로피)가 되어 잡음 추구 보너스가 생기는데, 이는 세계 모델이 아니라 계산 장치에서 나온 항이다. → **z는 상태로 보지 않는다** 제안. 그러면 M0F-S와 같이 IG = 0.

**제안 결론**: 상태 정보 이득은 M1-S에만 있고, M0 계열에는 0이다. 이것이 [이론 3.3 P3] "가역 구조는 모호성 항(=탐색 신호)을 잃는다"의 실제 모습이며, 실험의 비교 대상이 된다.

## 4. 모든 모델에 공통인 탐색 항: 파라미터 정보 이득 (novelty)

[DC20]은 우도 파라미터 A도 잠재로 두고, G에 파라미터에 대한 정보 이득("novelty") 항을 포함한다. [F10 Box 1]도 원인 ϑ에 파라미터 θ를 포함한다. 같은 원리로:

  IG^θ_τ = I(θ; o_τ | π) = H[E_θ P(o_τ | θ)] − E_θ H[P(o_τ | θ)]   [이론 5.4, V15]

- 파라미터 사후 q(θ)를 **앙상블**로 근사한다(K개 모델). 근사: 앙상블 = 사후 표본
- 이 식은 **세 모델에 같은 형태로 정의**된다. 우도 P(o|θ)를 각 모델이 내므로
- 계산: 결과·방향 채널은 정확, 격자는 M0F-S에서 칸별로 정확, M1-S·M0-SQ에서는 표본 추정이 필요 → 비용과 분산 문제. 선택지: (a) 격자의 IG^θ는 공유 임베딩 공간에서 근사, (b) 처음에는 결과 채널만. **상의 필요**

전체: g_τ = −E ln C(o_τ) − IG^s_τ − IG^θ_τ  (IG^s는 3절, M1에만)

## 5. 선호 C, 종료, 수평선

- C는 결과에 대한 **확률분포**여야 한다(정규화). 상수를 더해도 한 시점의 argmin은 같지만, **에피소드 길이가 정책마다 다르면 시점당 상수가 누적되어 길이 선호가 생긴다**. → 종료를 흡수 상태로 다룬다: 성공·실패 후에는 결과가 그대로 유지되는 고정 수평선 T의 생성 모델. 그러면 모든 정책이 같은 수의 시점을 가지므로 상수 문제가 사라진다. 유도됨(생성 모델을 흡수 상태로 정의).
- C의 값: C(성공) > C(진행) > C(실패). 구체 값은 **선택**. 하나의 원칙: 환경 보상 r을 쓰는 관례 ln C(o) = r(o)/λ_C (λ_C는 선호의 정밀도) [Fountas 2020 관례, 인수인계서]. 흡수 상태라 성공 후 매 시점 ln C(성공)이 쌓이므로, 빨리 성공할수록 G가 작다(시간 항이 자동으로 생김).
- 수평선/할인: G는 유한 수평선 합이다. 무한 수평선 근사로 할인 γ를 쓰려면 근거가 필요하다. 하나의 유도: 수평선 길이에 대한 기하분포 사전(평균 1/(1−γ)) → 기대 G = 할인된 합. 이 경우 γ = 1 − 1/T_eff. **근사**(수평선의 불확실성 모델). T_eff는 선택
- λ-리턴: 목표(G)를 바꾸지 않는 **추정량 선택**(편향-분산). γ = 1이면 목표 불변

## 6. 정책: 정밀도와 상각

- 능동적 추론: Q(π) = σ(−γ_π G(π)) [DC20 식 10]. 닫힌 루프에서 상태별로: π(a | b) ∝ exp(−γ_π G(b, a)), G(b, a)는 행동 a 이후 정책 π를 따를 때의 G-to-go
- 벨만식: G(b, a) = E[g + G(b′)]이고, G(b) = E_π[G(b,a)] + (1/γ_π)·E_π[ln π(a|b)]가 위 softmax의 고정점이다 [M19의 EFE 부트스트랩, 최대 엔트로피 강화학습과 같은 형태]. → **actor 손실의 엔트로피 계수 = 1/γ_π** (G와 같은 nats 단위). 유도됨
- γ_π: 고정하면 **선택**, 추론하면 [DC20]처럼 감마 사전을 둔 갱신. 처음에는 고정 제안
- **DreamerV3의 리턴 정규화**(백분위 범위로 나눔)는 G의 단위를 바꿔 정밀도를 리턴 크기에 맞춰 바꾸는 것과 같다. 원리상 정밀도 추론과 비슷한 역할이지만 규칙이 다르다 → **빼거나, 정밀도 추론으로 대체** 제안
- 상각: 가치망 V(b) ≈ G(b), 정책망 ≈ softmax(−γ_π G). 이산 행동이므로 정책 기울기는 REINFORCE 또는 Q값 기반. **근사**(상각 오차)

## 7. DreamerV3에서 가져올지 검토할 기법

| 기법 | DreamerV3에서의 역할 | FEP와의 관계 | 제안 |
|---|---|---|---|
| symlog / twohot 가치 회귀 | 크기가 다른 보상에 강건 | G의 값을 바꾸지 않는 추정 기법 | 가져와도 됨 (확인 필요) |
| 느린 목표 가치망 (EMA) | 부트스트랩 안정화 | 추정 기법 | 가져옴 |
| 리턴 정규화 | 하이퍼파라미터 고정 | 정밀도를 암묵적으로 바꿈 | 6절 쟁점 |
| KL 균형, free bits | 잠재 붕괴 방지 | 목적함수 F를 바꿈 (보정) | **가져오지 않음** (이 PoC의 비교 대상을 오염) |
| 이산 범주형 잠재 32×32 | 표현력 | 월드 모델 설계 | 이번 범위 밖 |
| 상상 수평선 15 | 계산 절약 | 유한 수평선 + 가치망 부트스트랩 | 가져옴 (가치망이 나머지를 담당) |

## 8. 남은 쟁점 (토론 대상)

1. 3절: M0 계열의 상태 IG = 0이 정당한가? (z를 상태로 보지 않는 근거가 충분한가)
2. 4절: 파라미터 IG를 앙상블로 넣는 것이 비교에 공정하고 계산 가능한가. 격자 채널을 어떻게 다룰까
3. 5절: 흡수 상태 + 할인의 처리, C의 값
4. 6절: 리턴 정규화를 뺄 때의 학습 안정성, 정밀도 γ_π를 고정할지 추론할지
5. 실험 2d 스모크의 관찰: 무작위 정책 성공률 0% → 탐색 신호(4절)가 없으면 학습이 시작되지 않는다. M0 계열은 상태 IG가 0이라 파라미터 IG에만 의존한다
