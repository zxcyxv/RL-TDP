# 로드맵: 실시간으로 적응하는 에이전트 (마인크래프트)

## 0. 목표

구체적인 목표: 마인크래프트에서 실시간으로 적응하는 에이전트.

**실질 목표: DreamerV3의 마인크래프트 다이아몬드 설정에서 같은 조건으로 비교한다.**
- 환경: MineRL, 관측 64×64 이미지 + 인벤토리·장착·체력, 범주형 행동 25개 (제작·배치·장착·제련은 행동 하나), 블록 부수는 속도 100배.
- 보상: 원목 → 판자 → 막대 → 제작대 → 나무 곡괭이 → 조약돌 → 돌 곡괭이 → 철광석 → 화로 → 철괴 → 철 곡괭이 → 다이아몬드, 12단계를 에피소드에서 처음 얻을 때마다 +1, 체력 변화 × 0.01.
- 에피소드: 죽거나 36,000스텝 (30분)이면 초기화. 예산 1억 스텝.
- 주장할 형태: 같은 설정과 예산에서 기억 모듈을 넣은 에이전트가
  (a) 같은 환경 스텝에서 단계 달성률·다이아몬드 비율이 더 높거나,
  (b) 에피소드 안의 적응이 빠르다 (한 번 본 자원으로 돌아가기, 세계마다 다른 배치에 맞추기).
- 범위: 한 세션 (최대 36,000스텝) 안의 기억.

추상화한 목표:
> 끝없이 이어지고 계속 변하는 흐름 위에서, 고정된 기억 용량과 스텝당 고정된 계산만으로, 지금 저장한 것이 미래에 쓸모 있는 정도를 최대로 만든다.
> 적응 = 순전파 안의 기억 갱신 (추론 중 경사 갱신 없음).

이를 위해 기억이 내리는 결정은 셋이다.

| 결정 | 질문 | 기준 |
|---|---|---|
| 쓰기 | 이 입력을 넣을 가치가 있나 | 새로움 × 신뢰도 × 관련성 |
| 유지·망각 | 이미 쓴 것을 계속 둘 가치가 있나 | 지금도 미래를 설명하는가 (시간이 아니라 증거로) |
| 읽기 | 지금 무엇을 꺼낼까 | 현재 상황이 요구하는 것만 |

중요한 것만 쓰면 읽기 간섭이 저장한 중요 사건의 수에만 비례하므로, 같은 크기의 기억이 스텝이 아니라 사건 단위로 한계가 정해진다.

공통 지표 (모든 단계):
- **회상 거리**: 같은 기억 크기에서 얼마나 먼 과거의 중요한 정보까지 정확히 꺼내는가.
- **방해 불변성**: 중요하지 않은 입력의 비율을 늘려도 회상 거리가 줄지 않는다. 중요한 비율이 ρ라면 회상 거리는 약 1/ρ배.
- **길이 불변성**: 흐름을 학습 길이의 수십 배로 늘려도 위 곡선이 변하지 않는다. 학습 길이보다 먼 과거를 회상해야 하는 조건에서 잰다 (기억이 짧은 모델은 이 성질을 공짜로 얻는다).

## 1. 진행 방식

```
요구 k → 그 요구만 만족하는 가장 단순한 형태 → 그 요구를 겨냥한 실험으로 입증
       → 요구 k+1을 더한 형태 → 입증 → 앞 단계에서 필요한 것만 남겨 더 단순한 구조로 다시 짠다 → 반복
```

분별 원칙:
1. **필요성으로만 들어온다.** 모듈은 그 요구를 겨냥한 실험에서 빼면 나빠질 때만 남긴다. 나중의 더 단순한 구조가 같은 일을 하면 대체한다.
2. **원리로 정한 형태가 먼저다.** 자유 파라미터는 실험 전에 고정한다. 학습되는 부분은 원리로 정한 형태가 못 하는 것이 보였을 때만 넣는다.
3. **알려진 것과 주장할 것을 구분한다.** 알려진 결과는 빠르게 확인하거나 인용한다. 주장에는 사전 예측 (실행 전에 적어 둠), 시드 여러 개, 가장 강한 비교군을 붙인다.
4. **비교군은 둘 다 둔다.** 가장 단순한 것 (모든 입력을 쓰는 기억)과 가장 강한 것 (학습 게이트, 정답 게이트 상한).
5. **땜질 금지.** 실패하면 문턱·손실·머리를 덧붙이지 않고, 어떤 요구를 잘못 형식화했는지로 돌아간다.

## 2. 틀: 자유에너지원리와 능동적 추론

기억 = 생성 모델의 빠른 파라미터. 쓰기 = 그 파라미터에 대한 믿음 갱신, 읽기 = 추론, 행동 = 기대 자유에너지 최소화.

| 요구 | 자유에너지원리의 대응 |
|---|---|
| 신뢰도 (잡음은 쓰지 않음) | 감각 정밀도: 예측 오차를 정밀도로 가중 |
| 새로움 (아는 것은 쓰지 않음) | 기억 내용의 사후 불확실성: 확실한 방향일수록 갱신이 작다 |
| 관련성 (중요한 것만 씀) | 기대 자유에너지: 선호 (실용 가치)와 정보 이득 (인식론적 가치) |
| 변화 (낡은 것은 버림) | 변동성 (과정 잡음): 예측 오차가 예상 잡음보다 계속 크면 불확실성을 키움 |
| 선택적 읽기 | 숨은 원인 (맥락)에 대한 추론, 주의 = 정밀도 |

신뢰도·새로움·변화는 "기억 행렬에 대한 칼만 필터" 하나로 묶인다:
M ← M + (v − Mk)(Pk)ᵀ / (kᵀPk + σ²), P ← P − (Pk)(Pk)ᵀ / (kᵀPk + σ²) + Q.
σ² = 관측 잡음 (신뢰도), P = 기억 불확실성 (새로움), Q = 변동성 (변화).
- P를 스칼라 상수로 두면 학습률 β = P/(P + σ²)인 델타 규칙이다.
- 여기에 기억의 평균 회귀 (감쇠 α)를 더하면 Gated DeltaNet과 같은 꼴이다. 차이는 β_t, α_t가 입력에서 학습되는 대신 정밀도·불확실성·변동성으로 정해진다는 점이다.

기존 선형 순환 기억들이 이 식의 특수한 경우이고, 빠진 항 (키 방향별 P, 추정된 σ², 증거로 정한 Q)이 R1·R2의 요구를 채운다는 것이 출발 가설이다.
연관 기억의 칼만 / RLS 해석이 선행 연구에 이미 있는지는 R1 구현 전에 확인한다.

## 4. 단계

비교군 (R4, R5): **DreamerV3**. 공식 코드 (`danijar/dreamerv3`, JAX) 그대로를 기준으로 두고, 기억 모듈은 같은 코드의 RSSM 결정론 경로에 끼워 넣어
나머지 (인코더, 머리, actor-critic, 하이퍼파라미터)를 같게 둔다. 기억 구조끼리의 비교 (R2I, Drama)는 필요해질 때 추가한다.

| 단계 | 요구 | 최소 형태 | 입증 | 다음으로 넘길 것 |
|---|---|---|---|---|
| R1 | 쓰기: 새로움 × 신뢰도 × 관련성 | 키·값 외적 기억 + 칼만 쓰기 (σ² 추정, 키 방향별 P) + 관련성 흔적 (결과 신호 × 키 흔적, 감쇠 = 할인) | 아래 R1 과제 | 쓰기 규칙 |
| R2 | 유지·망각: 낡은 것만 버린다 (초기화 없이, 증거로) | 변동성 Q를 키 방향별로, 정밀도 가중 증거 (로그 우도비 > 사전 승산비)로 키운다 | R1 과제에 "일부 연합만 단서 없이 값이 바뀜"을 더한 흐름: 바뀐 것은 정답 초기화 상한에 가깝게 고치고 안 바뀐 것은 보존 | 키 단위 변동성 |
| R3 | 선택적 읽기 | 질의로 맥락을 추론해 해당 기억만 읽기 (선형 읽기 대 날카롭게 한 읽기) | 저장 항목이 많을 때의 읽기 간섭 | 읽기 규칙 |
| R4 | 기억이 예측에 쓰인다 | R1~R3 기억을 DreamerV3 월드 모델의 결정론 경로에. 관측 예측 오차가 쓰기 신호, 보상·가치 예측이 관련성 신호 | Crafter / Craftax-classic (100만 스텝, DreamerV3 대비): 성취도, 예측 정확도, 방해 (날씨·입자·무관한 몹)에 대한 불변성 | 월드 모델 |
| R5 | 마인크래프트 다이아몬드 | R4 에이전트를 DreamerV3 설정 그대로. 행동은 먼저 DreamerV3의 actor-critic, 다음으로 기대 자유에너지 | 0절의 주장 (a), (b) | 에이전트 |

### R1 과제: 방해가 섞인 흐름형 연상 회상

연관 기억 용량의 표준 과제 MQAR를 에피소드 구분 없는 흐름으로 만든 것. 하나의 과제에서 방해 종류의 손잡이로 세 인자를 따로 시험한다.

흐름:
- 매 스텝 (키, 값) 항목 하나가 관측 벡터로 들어오거나, 질의 (과거에 본 키)가 들어온다. 질의의 정답은 그 키의 값이다.
- 질의 지연은 짧은 것부터 학습 길이의 수십 배까지 고르게 (로그 균등) 둔다.
- 기억 크기 (상태 크기)는 모든 모델에 같게, 흐름 속 항목 수보다 훨씬 작게 둔다.

| 항목 종류 | 성질 | 시험하는 인자 |
|---|---|---|
| 중요 | 값이 일정하고 나중에 질의됨 | 회상 대상 |
| 잡음 | 같은 키가 올 때마다 값이 무작위 | 신뢰도 |
| 반복 | 이미 아는 연합이 그대로 다시 옴 | 새로움 |
| 무관한 새것 | 값은 일정하지만 질의되지 않음 | 관련성 |

- 키는 종류 (클래스)에서 뽑는다. 종류마다 고유한 잡음 수준과 중요도가 있어서, 한 번만 본 항목의 정밀도·관련성은 종류에 대한 사전 지식 (느린 가중치가 학습)으로 판단해야 한다.
- 관련성의 출처는 둘이다: 종류 사전 지식 (어떤 종류는 원래 중요하다)과 결과 (중요 항목 몇 스텝 뒤에 보상 토큰이 온다, 키 흔적 필요).
- 결정적 지점: 잡음 항목은 올 때마다 오차가 커서 델타 규칙에게는 가장 새로워 보인다. 새로움과 잡음을 가르는 것이 정밀도이고, 그 출처는 같은 키의 반복 관측 (항목 단위)과 종류 사전 정밀도 (느린 가중치)다.

진행: **R1-a** (관련성 방해 0: 잡음·반복만, 새로움과 신뢰도) → **R1-b** (무관한 새것을 더함, 관련성).

비교군:
- Hebb 덧셈 누적 (선형 어텐션): 모든 입력을 쓴다.
- 델타 규칙 (DeltaNet): 새로움만.
- Gated DeltaNet: 학습된 게이트, 짧은 조각으로 학습.
- 정답 게이트: 중요 항목만 정확히 쓰는 상한.

사전 예측 (실행 전에 별도 문서로 고정한다):

| 방해 | 무너지는 비교군 | 우리 쓰기 규칙 |
|---|---|---|
| 잡음 | 델타 규칙 | 회상 거리 유지 |
| 반복 | Hebb | 회상 거리 유지 |
| 무관한 새것 | 신뢰도·새로움만 보는 쓰기 | 회상 거리 ∝ 1/ρ, 정답 게이트에 근접 |
| 학습 길이 밖 지연 | Gated DeltaNet (회상 거리 감소) | 불변 |

제거 실험: 정밀도·새로움·관련성을 하나씩 빼서 위 표의 무너짐이 재현되는지 본다.
지표: 지연별 회상 정확도, 회상 거리 (정확도가 기준 아래로 떨어지는 지연)를 ρ·방해 구성·기억 크기·흐름 길이에 대해.

## 5. 설계 근거 (기존 실험, `docs/icrl/icrl_memory_gate.md`)

- 고정 크기 외적 기억이 흐름의 충분통계를 손실 없이 누적한다 (토이 1).
- 사건 뒤로 감쇠하는 흔적이 관련성을 실어 나르고, 그 감쇠는 할인과 같아야 한다. 생 게이트는 기억을 특이·불안정하게 만든다 (토이 3).
- 망각은 정밀도 가중 증거와 사전 승산비로 터뜨리고, 읽기가 아니라 기억 자체를 바꿔야 한다 (토이 4, 사전학습 비교 B).
- 전역 덮어쓰기는 변화의 약 40%를 놓치고, 일부만 바뀌는 흐름에서는 바뀌지 않은 기억까지 잃는다. 그래서 망각은 키 단위로 둔다 (R2).
- 상태 변수는 모두 시간상수가 유한해야 길이 불변이다 (B의 전환별 평가).
- 학습된 게이트는 이 규모에서 놀라움에 반응하지 않고 고정 시간척도 (약 70스텝)에 머물렀다 (B의 Gated DeltaNet 게이트 측정).
