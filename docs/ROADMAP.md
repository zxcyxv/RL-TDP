# 로드맵: 실시간으로 적응하는 에이전트 (마인크래프트)

## 0. 목표와 추상화

구체적인 목표: 마인크래프트에서 실시간으로 적응하는 에이전트.

**실질 목표 (첫 번째 도달점): DreamerV3의 마인크래프트 다이아몬드 설정을 그대로 쓴다.**
- 환경: MineRL, 관측 64×64 이미지 + 인벤토리·장착·체력, 범주형 행동 25개 (제작·배치·장착·제련은 행동 하나), 블록 부수는 속도 100배.
- 보상: 원목 → 판자 → 막대 → 제작대 → 나무 곡괭이 → 조약돌 → 돌 곡괭이 → 철광석 → 화로 → 철괴 → 철 곡괭이 → 다이아몬드, 12단계를 에피소드에서 처음 얻을 때마다 +1, 체력 변화 × 0.01.
- 에피소드: 죽거나 36,000스텝 (30분)이면 초기화. 예산 1억 스텝 (DreamerV3: GPU 1개로 약 9일).
- 기준: 공개된 DreamerV3 점수 (`danijar/dreamerv3`의 `scores/minecraft_diamond-dreamerv3.json.gz`).
- 주장할 형태: 같은 설정과 예산에서 기억 모듈을 넣은 에이전트가
  (a) 같은 환경 스텝에서 단계 달성률·다이아몬드 비율이 더 높거나,
  (b) 에피소드 안의 적응이 빠르다 (한 번 본 자원으로 돌아가기, 세계마다 다른 배치에 맞추기).
- 범위 밖: 에피소드를 넘는 장기 기억 (수십 시간 단위). 이 설정에서 필요한 기억은 한 세션 (최대 36,000스텝) 안이다.

추상화한 목표:
> 끝없이 이어지고 계속 변하는 흐름 위에서, 고정된 기억 용량과 스텝당 고정된 계산만으로, 지금 저장한 것이 미래에 쓸모 있는 정도를 최대로 만든다.
> 적응 = 순전파 안의 기억 갱신 (추론 중 경사 갱신 없음).

검증할 핵심 성질 (모든 단계의 공통 지표):
- **회상 거리**: 같은 기억 크기에서 얼마나 먼 과거의 중요한 정보까지 정확히 꺼내는가.
- **방해 불변성**: 중요하지 않은 입력의 비율을 늘려도 회상 거리가 줄지 않는다. 중요한 비율이 ρ라면 회상 거리는 약 1/ρ배 (스텝이 아니라 사건 단위의 기억).
- **길이 불변성**: 흐름을 학습 길이의 수십 배로 늘려도 위 곡선이 변하지 않는다. 학습 길이보다 먼 과거를 회상해야 하는 조건에서만 잰다 (기억이 짧은 모델은 이 성질을 공짜로 얻기 때문).

## 1. 진행 방식

```
요구 k → 그 요구만 만족하는 가장 단순한 형태 → 그 요구를 겨냥한 실험으로 입증
       → 요구 k+1을 더한 형태 → 입증 → 앞 단계에서 필요한 것만 남겨 더 단순한 구조로 다시 짠다 → 반복
```

분별 원칙:
1. **필요성으로만 들어온다.** 모듈은 그 요구를 겨냥한 실험에서 빼면 나빠질 때만 남긴다. 나중의 더 단순한 구조가 같은 일을 하면 대체한다.
2. **원리로 정한 형태가 먼저다.** 자유 파라미터는 실험 전에 고정한다. 학습되는 부분은 원리로 정한 형태가 못 하는 것이 보였을 때만 넣는다.
3. **알려진 것과 주장할 것을 구분한다.** 알려진 결과는 빠르게 확인하거나 인용하고 넘어간다. 주장에는 사전 예측 (실행 전에 적어 둠), 시드 여러 개, 가장 강한 비교군을 붙인다.
4. **비교군은 둘 다 둔다.** 가장 단순한 것 (모든 입력을 쓰는 기억)과 가장 강한 것 (학습 게이트 Gated DeltaNet, Titans, 문맥 창 Transformer, 정답 초기화 상한).
5. **땜질 금지.** 실패하면 문턱·손실·머리를 덧붙이지 않고, 어떤 요구를 잘못 형식화했는지로 돌아간다.

## 2. 틀: 자유에너지원리와 능동적 추론

기억 = 생성 모델의 빠른 파라미터. 쓰기 = 그 파라미터에 대한 믿음 갱신, 읽기 = 추론, 행동 = 기대 자유에너지 최소화.

| 요구 | 자유에너지원리의 대응 |
|---|---|
| 신뢰도 (잡음은 쓰지 않음) | 감각 정밀도: 예측 오차를 정밀도로 가중 |
| 새로움 (아는 것은 쓰지 않음) | 기억 내용의 사후 불확실성: 확실한 방향일수록 갱신이 작다 |
| 변화 (낡은 것은 버림) | 변동성 (과정 잡음): 예측 오차가 예상 잡음보다 계속 크면 불확실성을 키움 |
| 관련성 (중요한 것만 씀) | 기대 자유에너지: 선호 (실용 가치)와 정보 이득 (인식론적 가치) |
| 선택적 읽기 | 숨은 원인 (맥락)에 대한 추론, 주의 = 정밀도 |

신뢰도·새로움·변화 세 요구는 "기억 행렬에 대한 칼만 필터" 하나로 묶인다:
M ← M + (v − Mk)(Pk)ᵀ / (kᵀPk + σ²), P ← P − (Pk)(Pk)ᵀ / (kᵀPk + σ²) + Q.
여기서 σ² = 관측 잡음 (신뢰도), P = 기억 불확실성 (새로움), Q = 변동성 (변화)이다.
- P를 스칼라 상수로 두면 학습률 β = P/(P + σ²)인 델타 규칙이 된다.
- 여기에 기억의 평균 회귀 동역학 (감쇠 α)을 더하면 Gated DeltaNet과 같은 꼴이 된다.
- 차이는 β_t와 α_t가 입력에서 학습되는 대신, 정밀도·불확실성·변동성으로 정해진다는 점이다.

기존 선형 순환 기억들이 이 식의 특수한 경우이고, 빠진 항 (키 방향별 P, 추정된 σ², 증거로 정한 Q)이 R1~R3의 요구를 채운다는 것이 출발 가설이다. 이런 연관 기억의 칼만 / RLS 해석이 선행 연구에 이미 있는지는 R1 전에 확인한다.

## 3. 엔지니어링 참고

- **DreamerV3**: RSSM 월드 모델 + 상상 속 actor-critic, symlog 예측, two-hot 보상·가치 머리, KL 균형과 free bits, 백분위 수익 정규화, 도메인 간 고정 하이퍼파라미터. 마인크래프트 다이아몬드를 처음 푼 계열이라 R5~R6의 뼈대로 쓴다.
- **실시간 학습 계열**:
  - 스트리밍 강화학습 (Elsayed et al. 2024: 재현·목표망 없는 온라인 TD(λ), 안정화 기법)
  - 시험 시간 학습 (TTT, Titans: 놀라움으로 쓰고 모멘텀·감쇠로 망각)
  - 선형 순환 기억 (DeltaNet, Gated DeltaNet, Mamba 계열)
  - 강화학습용 순환 기억 (AGaLiTe, POPGym Arcade)
  - 연속 학습의 소성 손실 (Dohare et al. 2024)

## 4. 단계

공통 실험 환경 (R1~R4): **사건 흐름 생성기**. 연합 (키 → 값)이 관측 벡터 안에 섞여 끝없이 들어오고, 나중에 임의의 시점에 키로 질의해서 값을 회상하게 한다. 손잡이:
중요한 연합의 비율 ρ, 잡음 방해 (본질적 무작위), 새롭지만 무관한 방해 (나중에 질의되지 않음), 반복 (이미 아는 것), 일부 연합만의 값 변화 (단서 없음), 질의 지연 분포 (학습 길이보다 먼 지연 포함). 에피소드 구분 없음.

| 단계 | 요구 | 최소 형태 | 입증 실험 (예측) | 다음으로 넘길 것 |
|---|---|---|---|---|
| R1 | 쓰기 I: 신뢰도·새로움 (잡음과 이미 아는 것은 쓰지 않음) | 키·값 외적 기억 + 칼만 쓰기 (σ² 온라인 추정, 키 방향별 P) | 잡음·반복 방해 비율을 늘려도 회상 거리 일정 (게이트 없는 델타·학습 게이트는 줄어듦). 델타 오차만으로 충분한지, P가 필요한지 가림 | 칼만 쓰기 |
| R2 | 쓰기 II: 관련성 (나중에 중요해지는 것만) | 관련성 신호 (나중에 오는 결과) × 키 흔적, 사건 뒤로 감쇠하는 흔적 (토이 3: 감쇠 = 할인) | 새롭고 믿을 만하지만 무관한 방해 속에서 회상 거리 ∝ 1/ρ | 관련성 흔적. 관련성의 출처는 R5 전까지 과제가 준다 |
| R3 | 유지·망각: 낡은 것만 버린다 (초기화 없이, 시간이 아니라 증거로) | 변동성 Q를 키 방향별로, 정밀도 가중 증거 (로그 우도비 > 사전 승산비)로 키움. 전역 덮어쓰기 (토이 4)는 쓰지 않음 | 일부 연합만 바뀌는 흐름: 바뀐 것은 정답 초기화 상한에 가깝게, 안 바뀐 것은 보존. 길이 불변 | 키 단위 변동성 |
| R4 | 선택적 읽기 | 질의로 맥락을 추론해 해당 기억만 읽기 (선형 읽기 대 날카롭게 한 읽기) | 저장 항목이 많을 때 읽기 간섭. 선형 읽기 대비 회상 정확도 | 읽기 규칙 |
| R5 | 기억이 예측에 쓰인다 (중간 점검) | R1~R4 기억을 DreamerV3식 월드 모델의 결정론 경로에. 관측 예측 오차가 쓰기 신호, 보상·가치 예측이 관련성 신호 | Crafter / Craftax (DreamerV3 비교 가능, 100만 스텝 규모): 예측 정확도, 회상 거리, 방해 (날씨·입자·무관한 몹)에 대한 불변성, 성취도 | 월드 모델 |
| R6 | 마인크래프트 다이아몬드 (실질 목표) | R5 에이전트를 DreamerV3 설정 그대로. 행동은 먼저 DreamerV3의 상상 속 actor-critic, 다음으로 기대 자유에너지 (실용 + 인식론적 가치) | 0절의 주장 (a), (b). 기준: 공개된 DreamerV3 점수 | 에이전트 |

## 5. 지금까지의 근거와 버릴 것

- 남길 것: 충분통계·외적 기억 (토이 1), 사건 뒤 흔적의 감쇠 = 할인 (토이 3), 정밀도 가중 증거와 사전 승산비 (토이 4), 시간상수가 유한한 상태 변수만 쓰기 (길이 불변성, B의 전환별 평가).
- 고칠 것: 전역 덮어쓰기 → 키 단위 변동성 (R3). 변화 검출의 놓침 (전환의 약 40%) → R3에서 증거를 키 단위로.
- 근거가 생기기 전까지 쓰지 않을 것: TDP의 특정 대역 구조 (시간 창이 필요하다는 실험이 나올 때만), BTSP 용어 (동기 설명으로만).
- 정리된 계열: fep, btsp (`docs/README.md`). 계열 3 icrl의 결과는 R1~R3의 출발 근거로 쓴다.
