# errand 환경 명세

코드: `rltdp/world/errand.py` (JAX). 무늬 생성은 `rltdp/world/env.py`.

## 지금 있는 것

### 세계 (`gen_world`, 시드마다 새로 생성)

- 11×11 격자, 바깥 테두리는 벽. 바닥 무늬 12종이 칸마다 무작위.
- 보급소 1곳 (벽에서 2칸 이상 안쪽), 채집처 5곳 (서로 체비셰프 거리 3 이상, 보급소에서 맨해튼 거리 4 이상). 채집처는 겉모습이 모두 같다.
- 산출물 {A, A, B, B, C}를 채집처에 무작위로 배정한다. A, B, C는 산출물 그림 3종이다.

### 관측

- 자기 중심 3×3 세계 칸 + HUD 3칸 (의뢰 카드, 도착한 산출물, 완료 도장) = 12패치. 패치 하나는 7×7×3 픽셀 (147), 8비트 양자화.
- 의뢰 카드: 의뢰가 없으면 빈칸. 의뢰가 있으면 `PUBLIC = True`일 때 의뢰한 산출물 그림 (산출물 그림과 같은 무늬), `False`일 때 카드 뒷면.

### 행동과 전이 (`env_step`)

- 행동 6개: 동, 서, 남, 북, 상호작용, 대기. 벽으로는 움직이지 않는다.
- 채집처에서 상호작용 (진행 중인 작업이 없을 때) → 8스텝 (`D_DELAY`) 뒤 그 채집처의 산출물이 HUD 도착 칸에 나타난다. 출발지 표시는 없다. 작업이 진행 중이면 새 작업을 시작하지 않는다.
- 보상: 도착한 산출물이 현재 의뢰와 같고 그 의뢰에서 아직 도장이 없으면 +1, 도장을 찍는다. 의뢰당 한 번.
- 의뢰 번호가 바뀌면 도장을 지운다.

### 외부에서 받는 입력 (교사 의존)

`env_step(s, a, req_now, rid_now, change_now, b0)`는 다음을 환경 밖에서 받는다.

- `req_now`: 현재 의뢰 종류 (−1 없음, 0 A, 1 B).
- `rid_now`: 의뢰 번호 (보급소 상호작용마다 증가하도록 교사가 만든다).
- `change_now`, `b0`: 이 스텝에 채집처 b0의 산출물을 C로 바꿀지.

지금은 이 값들을 교사 일정 (`teacher`)이 만든다. 보급소에서 상호작용해도 환경이 스스로 의뢰를 만들지 않으므로, **교사 없이는 환경이 돌아가지 않는다.**

### 남아 있는 이전 코드

- `teacher`: 고정 교사 일정 (관찰 → A 의뢰 ×4 → B 의뢰 → 보존 중 b0 변경 → b0 재방문).
- `run_session`, `fixed`: 학습 없는 고정 난수 키 시냅스 에이전트.
- 파일 머리 주석이 이전 브랜치의 문서를 가리킨다.

## 정할 것

에이전트가 환경에서 직접 학습하려면 (`guidelines.md` 학습 방식) 교사가 만들던 값을 환경이 스스로 정해야 한다.

1. **의뢰 생성.** 보급소에서 상호작용할 때 의뢰 종류를 어떻게 정하는가 (예: 무작위, 이전 의뢰를 유지할 확률). 의뢰는 공개한다 (`guidelines.md` 실험 환경).
2. **산출물 변경 사건.** 채집처의 산출물이 바뀌는 사건을 둘지, 둔다면 언제 어디서 일으키는가.
3. **에피소드.** 길이, 초기화 시점, 에피소드마다 세계를 새로 만드는가.
4. **원리 1을 재는 보상 변화.** 의뢰가 공개되면 느린 보상 머리가 카드 규칙을 배울 수 있어 빠른 선호가 할 일이 없다 (`design_draft1.md` 정할 것 2). 관측으로 미리 알 수 없는 보상 변화를 무엇으로 넣는가.
5. **이전 코드 정리.** `teacher`, `run_session`, `fixed`와 머리 주석을 지울지.
