# 지침

## 최종 목표

1. 마인크래프트 다이아몬드까지는 DreamerV3의 프로토콜 그대로 학습한다.
2. 그 뒤로는 빠른 시냅스가 새 과제의 보상을 학습하고, 그것을 느린 가중치로 증류하는 과정을 반복한다.
3. 그러다 원래 과제를 다시 하면, 그때에도 느린 가중치가 여전히 그 과제를 잘 수행한다.

## 설계 원리

다음 넷을 지키는 것이 목표이자 원칙이다.

1. 역전파 없이 빠른 시냅스가 보상을 학습한다.
2. 시냅스를 느린 비선형 망으로 증류한다.
3. 자유에너지 원리와 능동적 추론에 부합한다.
4. DreamerV3의 공학 기법을 가져온다.

**실험 환경.** Craftax에서 바로 실험하는 것은 규모가 감당하기 어렵다. 그래서 errand에서, 의뢰가 공개된 과제로 학습한다.

**학습 방식.** 에이전트는 환경에서 직접 학습한다. 교사 학습, 무작위 특징, 인코더 사전학습처럼 논문에서 쓰지 않는 단계는 두지 않는다.

## 지표 제시

### 타당도

원인을 주장하는 데 쓰는 지표는 모델의 실제 계산이 그 양을 어떻게 쓰는지에서 도출한다. 계산과 다른 공간에서 잰 직관적 대리 지표는 원인의 필요조건도 충분조건도 아니다. 모델 출력의 정확한 분해가 있으면 그것을 쓴다.

- 예시: 칼만 기억에서 간섭을 원본 주소 코사인으로 쟀다. 그런데 칼만 기억은 주소를 P로 다시 잰 공간에서 읽으므로, 원본 코사인은 P ∝ I일 때만 간섭을 뜻한다. 대신 읽기 = Σ 쓰기 가중치 × 쓰기 내용의 분해를 썼다.

### 식별 가능성

서로 맞바꿔도 모델의 출력이 같은 파라미터들은 각각의 값이나 값의 변화를 원인으로 말하지 않는다. 그런 맞바꿈에서 변하지 않는 양만 해석한다. 함께 맞춘 파라미터 중 일부만 다른 값으로 바꿔 끼우는 개입은 학습된 적 없는 모델을 만들므로 시험으로 쓰지 않는다.

- 예시: 칼만 기억에서 z 크기 ↔ P·q, σ ↔ 키 크기, 느린 예측 ↔ 빠른 기억은 서로 맞바꿀 수 있었다. 그래서 "q가 4,500배"는 원인 근거가 아니었고, "q, R만 기준선으로" 바꿔 끼운 판은 정당한 시험이 아니었다. 해석에는 불변량(이득, 덮어쓰기 비율 zᵀP⁻z/S, q|z|²/(R + R₀), 쓰기 나이별 읽기 가중치)만 썼다.
