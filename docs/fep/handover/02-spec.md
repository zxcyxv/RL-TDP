## 범위와 전제

비교 대상은 하나다. 나머지 조건은 모두 같게 두고 **다음 관측의 밀도를 만드는 방식만 바꾼다.** M0는 조건부 정규화 흐름, M1은 확률적 잠재와 디코더다.

- **보여 줄 것**: 실험 1의 선택 편향, F 분해표, 샘플 산점도. 실험 2의 성공률 곡선, 월드 모델 지표(예측 로그우도, k스텝 예측 정확도), 실제 프레임과 상상한 프레임의 비교 영상.
- **주장하지 않을 것**: 성공률 우위. 비길 수 있고, 비기면 그대로 보고한다. 효과가 보이는 쪽으로 과제를 바꾸지 않는다.

용어: 이 문서에서 **흐름**은 정규화 흐름(normalizing flow)이다. 미분 가능하고 역함수가 있는 변환으로 기저분포를 관측 분포로 바꾸며, 변수 변환 공식으로 밀도를 정확히 계산한다. 1단계 문서의 "가역 인터페이스"가 이것이다.

1단계에서 가져오는 전제:
1. F = A + ℑ 분해 (1단계 2절)
2. G의 정의와 정보 이득 항등식. 계획은 G로 한다 (1단계 5절)
3. 탈양자화 간극의 성격 (1단계 4절). 이 실험은 argmax 들어 올림을 쓰고, 그때 남는 국소 간극을 감수한다

이전 판에서 바뀐 점:

| 항목 | 이전 판 | 이번 판 |
|---|---|---|
| 과제 | E0~E3 (해석 밴딧, 학습 밴딧, Mountain Car, noisy TV) | 실험 1: 고리 vs 가우시안 밴딧. 실험 2: MiniGrid-Memory 표준 설정 |
| 관측 | 연속값, 탈양자화 없음 | 이산 원-핫 + argmax 들어 올림 (Hoogeboom et al. 2021) |
| 흐름 | h와 무관한 고정 좌표 변환 | h를 조건으로 받는 조건부 흐름 |
| 앙상블 (M0-E) | E3에서 사용 | 보류 |
| 계산 | CPU 규모를 목표로 함 | GPU. 계산 비용은 감수하고 보고한다 |

## 한눈에: 두 모델의 데이터 흐름

두 모델은 기억 h_t까지 같고, o_t의 밀도를 재는 방식만 다르다. (원본 2쪽 그림을 옮김)

```
공유 골격 (두 모델 모두 같은 구조)
  이전 관측 o_{t-1}            임베더 emb                       기억 GRU 256
  격자 one-hot 20×7×7=980  →  3×3 합성곱 3층, 64채널        →  입력: emb(o_{t-1}), a_{t-1}
  + 방향 4                     → 선형 256, 방향 이어붙임         출력: h_t
                                                                    │ h_t
              ┌─────────────────────────────────────────────────────┴───────────────┐
  M0 · 정확한 우도 모델                                 M1 · RSSM-VAE 기준선
  들어 올림 (고정 q, 학습 없음)                          사전 p(s_t | h_t)
    대상 o_t: 묶음별 argmax 블록 980차원                   대각 가우시안 32차원, MLP 2×256
    v ~ q(v | o_t): N(0,I) + 임계값                            ↕ KL
        │ v                                            사후 q(s_t | h_t, emb(o_t))
  조건부 흐름 f(·; h_t)                                    o_t의 임베딩을 받는 인코더
    Glow 블록 (그림에는 8개로 표기*), 결합층 조건 = h_t       재매개화 샘플 1개로 기댓값 추정
    z = f⁻¹(v; h_t), 역변환이 정확하다                          │ s_t ~ q
        │ z                                            디코더 p(o_t | s_t, h_t)
  기저 밀도                                                격자 칸별 범주형 로짓
    z ~ N(μ(h_t), σ(h_t))                                 p(o_t | h_t)는 s_t 적분이라 닫힌 꼴이 없다
    야코비안으로 ln p(v | h_t)를 정확히 계산                       │
        │                                              추론 간극 A > 0
  전역 추론 간극 0                                        손실 = −ln P(o_t | h_t) + A
    손실 = −ln P(o_t | h_t) + 국소 간극
```
\* 본문 사양은 기본 4개, 수렴하지 않을 때 8개다. `review-notes.md` 참고.

두 모델은 같은 임베더와 GRU로 h_t를 만든다. 그 위에서 M0는 o_t를 연속 공간에 들어 올린 뒤 조건부 흐름으로 되돌려 밀도를 계산하고, M1은 잠재 s_t를 거쳐 ELBO로 근사한다. 그래서 M0의 손실은 놀람에 범주 영역 안의 국소 간극만 더한 값이고, M1의 손실은 놀람에 추론 간극 A를 더한 값이다. 방향과 결과의 범주형 머리는 두 모델에 모두 있어서 그림에서는 뺐다.

## 실험 1: 고리 vs 가우시안 밴딧

목적함수에 추론 간극이 있는지 없는지가 선택을 기울이는지를, 기억과 계획기 없이 가장 작은 형태로 보인다. 2차원이라 GPU에서 시드당 몇 분이면 끝나고, 결과가 산점도로 바로 보인다. **실험 2보다 먼저 끝낸다.**

### 과제

| 항목 | 설정 |
|---|---|
| 선택지 | 두 개. 하나를 고르면 2차원 관측 하나가 나온다 |
| 고리 | 반지름 r ∼ N(1, 0.1²), 각도 θ ∼ U[0, 2π). 관측 = r(cos θ, sin θ) |
| 가우시안 | N(0, σ²I), σ = 0.388854 |
| 엔트로피 | 둘 다 H = 0.9492 nats. 고리의 미분 엔트로피에 맞춰 σ를 정했다 |
| 기대 | 실제 놀람이 같으므로, 놀람을 정확히 아는 에이전트는 두 선택지를 같은 확률로 고른다 |

### 모델

| 모델 | 구조 | 목적함수 |
|---|---|---|
| M0 | 조건부 RealNVP. 결합층 12개, 결합 신경망 MLP 2층 × 128(ELU), 스케일 2·tanh(·/2), 조건 = 선택지 원-핫, 기저 N(0, I) | 정확한 −ln p(o \| 선택지) |
| M1-a | VAE. 잠재 2차원, 사전 N(0, I), 대각 가우시안 q와 가우시안 디코더(각각 MLP 2층 × 128), 디코더 분산 학습 | −ELBO, β = 1, 재매개화 샘플 1개 |
| M1-b | M1-a와 같고 디코더 표준편차를 0.1로 고정 | 위와 같음 |
| M1-a/b × IWAE | M1-a, M1-b 각각을 IWAE 하한으로 학습. k = 1, 5, 50 | −IWAE_k. k = 1이면 −ELBO |

학습 조건은 모든 모델이 같다. 두 선택지의 샘플을 반반 섞은 배치 512, 매 스텝 새 샘플, Adam 학습률 1e-3, 3만 스텝. 목적함수 보정은 없다.

### 선택 규칙

선택지 a마다 F̄_a = E_{o∼a}[F(o)]를 계산하고 P(a) ∝ exp(−F̄_a)로 고른다. F는 각 모델이 학습에 쓰는 값이다(M0는 −ln p, M1은 −ELBO 또는 −IWAE_k). 자유에너지원리의 "F를 최소화하는 선택"을 그대로 옮긴 규칙이며, 실험 2의 G 계획기와는 다르다.

| M0, 결합층 12개 | 20.7만 | 0.99 | 0.48 |
| M1-a, 은닉 128 / 320 | 3.5만 / 21.1만 | 2.16 / 2.16 | 0.22 / 0.23 |
| M1-b, 은닉 128 / 320 | 3.5만 / 21.1만 | 1.46 / 1.47 (Â 0.27 / 0.31) | 0.37 / 0.38 |

크기를 맞추면 M0도 치우친다. 차이는 크기를 키울 때 나타난다. M0의 오차는 모델 불일치라서 용량을 늘리면 사라지고, M1의 오차는 목적함수에서 나오므로 6배로 키워도 줄지 않는다. 본 실행에서 시드를 늘려 확인할 수 있으면 좋다.

## 실험 2: MiniGrid-Memory

실험 2는 두 부분으로 나뉜다. **2a**는 고정 데이터로 월드 모델만 비교한다(계획기 없음, 먼저 한다). **2b**는 계획기를 붙인 온라인 실험이고, 2a 결과를 본 뒤 진행 여부를 정한다. 아래 "환경과 관측", "공유 골격", "M0", "M1"은 둘 다에 쓰이고, "계획기"와 학습 루프는 2b에만 쓰인다.

### 환경과 관측

환경은 `MiniGrid-MemoryS13-v0`을 표준 설정 그대로 쓴다. 에이전트는 작은 방에서 물체를 보고, 좁은 복도를 지나, 갈림길 끝에 있는 두 물체 중 같은 것으로 가야 한다. 맞는 물체에 닿으면 성공, 틀린 물체에 닿거나 시간이 다 되면 실패로 끝난다.

| 항목 | 설정 |
|---|---|
| 행동 | 왼쪽 회전, 오른쪽 회전, 전진 (3개). 물체에 닿으면 종료되는 과제라 나머지 행동은 쓰지 않는다 |
| 격자 관측 | 자기중심 7×7. 칸마다 (물체, 색, 상태)를 원-핫으로 펼친다 → 20 × 7 × 7 = 980차원 이진값 |
| 방향 관측 | 4범주 |
| 결과 관측 | 진행 / 성공 / 실패, 3범주. 보상은 이 채널로만 들어온다 |
| 보상 크기 | 모델링하지 않는다. 성공 보상은 결과와 스텝 수로 결정되기 때문이다 |
| 미션 문자열 | 쓰지 않는다 |

격자는 속성 묶음(물체 11, 색 6, 상태 3)마다 argmax로 범주를 정하는 방식으로 연속 공간에 들어 올린다. 연속 공간의 모든 점이 유효한 원-핫 하나에 대응하고, 범주 번호에 순서를 강제하지도 않는다. 방향과 결과는 들어 올리지 않고 범주형 우도로 그대로 다룬다.

소스 코드에서 확인할 것은 세 가지이며, 확인한 값을 이 표에 적는다.

| 확인 항목 | 확인 값 (2026-11-08, `minigrid` 3.2.0 소스) |
|---|---|
| 범주 수: 물체 11, 색 6, 상태 3인지 (다르면 격자 차원을 고친다) | ✅ `OBJECT_TO_IDX` 11, `COLOR_TO_IDX` 6, `STATE_TO_IDX` 3 → 980차원 유지 |
| `max_steps` 기본값 | ✅ 845 (= 5 × 13², 격자 13×13) |
| 성공·실패 판정이 물체에 "닿음"인지, 특정 행동이 필요한지 (행동 3개로 충분한지) | ✅ `MemoryEnv.step`에서 `agent_pos == success_pos`면 보상 후 종료, `failure_pos`면 보상 0으로 종료. 위치 도달만으로 판정되므로 행동 3개로 충분하다 |

> 환경 단계(단계 0)에서 사용하는 minigrid 버전을 고정하고 위 값을 다시 확인한다.

### 공유 골격

기억을 만드는 부분은 두 모델이 완전히 같은 코드를 쓴다. 시점은 둘 다 "과거 (o_{<t}, a_{<t})로 o_t를 예측"으로 맞춘다.

$$
h_t=\mathrm{GRU}\big(h_{t-1},\ [\,\mathrm{emb}(o_{t-1}),\ \mathrm{onehot}(a_{t-1})\,]\big),\qquad h_0=0
$$

| 모듈 | 입력 → 출력 | 구조 |
|---|---|---|
| 격자 임베더 emb | 원-핫 격자 20×7×7 (들어 올리기 전) + 방향 4 → 256 | 3×3 conv 3층, 64채널, ELU → 펼침 → 선형 256. 방향은 펼친 뒤 이어 붙인다 |
| 기억 | [emb, 행동 원-핫 3], h_{t−1} → h_t | GRU, 256 |

o_0는 h_0 = 0에서 예측한다. 즉 초기 관측의 분포도 학습한다.

모델은 아래 인터페이스를 구현한다. 계획기와 학습 루프는 이 인터페이스만 부른다.

```python
class WorldModel:
    def init_state(self, batch) -> State
    def observe(self, state, a_prev, o_t) -> (State, F_t)    # 실제 관측으로 갱신 + 스텝별 F
    def imagine(self, state, a) -> (State, o_hat, logp)      # 상상 롤아웃 한 스텝
    def info_gain(self, state, a, o_hat) -> IG               # 모델마다 정의가 다름
    def loss(self, obs_seq, act_seq) -> sum_t F_t
```

믿음 상태는 M0가 h 하나, M1이 (h, s)다.

### M0: 조건부 흐름 모델

M0는 다음 관측의 밀도를 h_t를 조건으로 받는 흐름으로 직접 만든다. 숨은 상태에 대한 잠재가 없으므로 전역 추론 간극은 0이다. 이산 격자를 연속 공간에 들어 올리는 데서 생기는 국소 간극만 남는다.

$$
F_t=-\ln P(\text{방향}_t\mid h_t)-\ln P(\text{결과}_t\mid h_t)-\Big[\ln p_z\big(f^{-1}(v_t;h_t)\mid h_t\big)+\ln\Big|\det\frac{\partial f^{-1}}{\partial v}\Big|-\ln q(v_t\mid x_t)\Big],\qquad v_t\sim q(\cdot\mid x_t)
$$

대괄호 부분은 샘플 하나의 v_t ∼ q(·|x_t)로 계산한 이산 격자 로그우도의 하한(ELBO)이다. 참값과의 차이는 KL[q(v|x_t) ‖ p(v|x_t, h_t)]이고, 이것이 M0에 남는 유일한 간극이다.

| 모듈 | 구조 |
|---|---|
| 들어 올림 q(v\|x) | Hoogeboom et al.(2021)의 임계값 방식. 속성 묶음마다 u ∼ N(0, I)를 뽑는다. 정답 범주 성분은 T = u_x로 그대로 두고, 나머지는 v_i = T − softplus(T − u_i)로 T 아래로 내린다. ln q(v\|x) = ln N(u; 0, I) − Σ_{i≠x} ln sigmoid(u_x − u_i). 학습하는 파라미터는 없다 |
| 흐름 본체 | Glow형 블록 4개. 블록 = ActNorm → 가역 1×1 conv(20채널) → affine coupling. 7×7은 홀수 크기라 다중 스케일(squeeze)은 쓰지 않는다. 단계 2에서 로그우도가 수렴하지 않으면 8개로 늘리고, 늘린 사실을 보고한다 |
| coupling 마스크 | 채널 분할(10/10)과 체커보드 마스크를 블록마다 번갈아 쓴다 (각각 2번씩) |
| coupling 신경망 | 3×3 conv ResNet 1블록, 64채널, ELU. 입력에 조건 채널 16개를 붙인다. 조건 채널은 선형(h_t)를 7×7로 펼친 것이고, 이 선형층은 모든 블록이 공유한다. 스케일은 tanh로 제한한다 |
| 기저분포 | N(μ(h_t), σ(h_t)). MLP 2층 × 256이 980차원 평균과 로그 표준편차를 출력한다 |
| 보조 헤드 | MLP 2층 × 256(h_t) → 방향 4범주, 결과 3범주 |

**상상 롤아웃.** z ∼ p_z(·|h)를 뽑고 v = f(z; h)를 계산한다. 칸마다 물체·색·상태 묶음별로 argmax를 취하면 언제나 유효한 원-핫 x̂가 나온다. 방향과 결과는 범주분포에서 뽑는다. 기억에는 이 x̂를 넣는다. 실제 관측과 같은 형식을 유지하기 위해서다.

**오차 채널 선택지(D2).** 기억에 원래 관측 대신 z_t = f⁻¹(v_t; h_t)를 넣는 변형을 설정 플래그로 둔다. 실제 관측에서는 v_t ∼ q(·|x_t)를 쓴다. 기본값은 끄기다.

### M1: RSSM-VAE

M1은 가우시안 잠재를 쓰는 순차 VAE다. 사전분포, 사후분포, 디코더의 구성은 PlaNet/Dreamer v1의 RSSM과 같고, 기억의 입력만 공유 골격을 따른다. 디코더는 이산 관측에 대한 정확한 범주형 우도이고, 대신 잠재에 대한 추론 간극이 있다. 두 모델은 결국 같은 이산 로그우도의 하한을 최적화하며 간극의 성격만 다르다. M0의 간극은 범주 영역 안의 위치에 대한 국소 간극이고, M1의 간극은 숨은 상태에 대한 간극이다.

$$
F_t=-\mathbb E_{q(s_t\mid h_t,e_t)}\ln p(o_t\mid s_t,h_t)+D_{KL}\big[q(s_t\mid h_t,e_t)\,\|\,p(s_t\mid h_t)\big],\qquad e_t=\mathrm{emb}(o_t)
$$

| 모듈 | 구조 |
|---|---|
| 확률적 잠재 s | 32차원 대각 가우시안 |
| 사전분포 p(s_t \| h_t) | MLP 2층 × 256 → 평균, 로그 표준편차 |
| 사후분포 q(s_t \| h_t, e_t) | e_t는 공유 골격의 같은 임베더 출력. MLP 2층 × 256 |
| 디코더 | [s_t, h_t] → 선형 → 7×7×64 → 3×3 conv 2층 → 칸마다 물체·색·상태 범주형 로짓. 방향과 결과는 별도 MLP 헤드로 범주형 |
| 기대값 추정 | 재매개화 샘플 1개 |
| 보정 | KL 균형과 free nats를 쓰지 않는다 (β = 1). 학습이 불안정해서 쓰게 되면 반드시 보고한다 |

디코더는 (s_t, h_t)가 주어지면 칸들이 서로 독립인 범주형이다. 칸 사이의 의존성은 잠재 s가 담는다. M0에서는 흐름이 칸 사이의 의존성을 직접 모델링한다.

**기억의 입력.** 표준 RSSM은 기억에 잠재 s_{t−1}을 넣는다. 이 비교에서는 "다음 관측의 밀도를 만드는 방식만 다르다"는 원칙을 지키기 위해 M0와 같이 관측 임베딩 emb(o_{t−1})을 넣는다. 표준 RSSM 입력(s_{t−1}, 또는 둘 다)은 설정 플래그로 둔다.

**상상 롤아웃.** s ∼ p(s|h)를 뽑고, 디코더의 범주분포에서 칸마다 샘플링해 x̂를 만든다. 방향과 결과도 범주분포에서 뽑는다. 다음 기억 갱신에는 M0와 똑같이 x̂를 임베더에 넣는다.

### 실험 2a: 고정 데이터 월드 모델 비교

계획기 없이, 정해진 정책으로 모은 데이터로 두 모델을 학습하고 보류 집합에서 비교한다. 계획기 설정, 정보 이득의 크기, 에이전트의 배회가 결과에 섞이지 않으므로 목적함수와 모델의 차이만 보인다. 실험 2b보다 먼저 한다.

**데이터**

| 집합 | 구성 | 용도 |
|---|---|---|
| 학습용 | 스크립트 정책에 확률 0.2로 무작위 행동을 섞은 에피소드 500개 + 무작위 정책 에피소드 500개 | 학습 |
| 보류 | 무작위 정책 50개 + 스크립트 정책 50개 (공통 조건의 데이터 분할과 같음) | 평가 |

두 집합은 서로 다른 환경 시드로 모으고, 한 번 모은 파일을 모든 모델과 시드가 같이 쓴다. 스크립트 정책은 시작 방의 물체가 보일 때까지 뒤돌아본 뒤 갈림길로 가서 같은 물체 쪽으로 도는 정책이다(무작위 행동이 없으면 10~15스텝). 매 스텝 현재 상태에서 다시 계획하므로 무작위 행동이 섞여도 대부분 성공하고, 갈림길에서 무작위 행동이 나오면 실패 사례도 생긴다. 무작위 에피소드는 길어서(평균 약 390스텝, 최대 845스텝) 넓은 상태 범위를 덮는다.

**학습**
- 공통 조건 표를 따른다(Adam 3e-4, 기울기 클리핑 100, 시드 5개).
- 갱신 50,000회, 배치 32, 시퀀스 길이 32.
- 조각 뽑기: 에피소드를 길이와 무관하게 균등하게 고른 뒤, 그 안에서 시작점을 균등하게 고른다. 짧은 스크립트 에피소드가 긴 무작위 에피소드에 묻히지 않게 하기 위해서다. 에피소드가 32스텝보다 짧으면 처음부터 전체를 쓰고 나머지는 마스크한다.
- 기억은 조각 시작에서 h = 0으로 둔다. 따라서 32스텝보다 먼 기억 의존성은 배우지 못한다. 스크립트 에피소드는 대부분 한 조각에 통째로 들어가므로 "물체를 봄 → 결과" 의존성은 데이터에 들어 있다.

**측정**
- "측정과 산출물"의 그림 2(월드 모델 지표)와 그림 3(상상 영상)을 이 실험에서 만든다. 갱신 5,000회마다 보류 집합에서 잰다.
- M1의 Â와 M0의 Â_deq를 에피소드 구간(방, 복도, 갈림길)별로 나란히 둔 표를 만든다.
- 비용 표: 파라미터 수, 갱신당 시간.

**완료 기준**
- 시드 5개 모두에서 보류 집합 로그우도가 수렴한다. M0가 수렴하지 않으면 흐름 블록을 8개로 늘리고 보고한다.
- 1스텝 예측 정확도가 무작위 예측보다 높다.
- 그림 2, 그림 3, 구간별 간극 표, 비용 표를 만든다.

### 계획기 (실험 2b)

행동은 이산 행동열에 대한 CEM으로 G를 최소화해서 고른다. 계획기 코드는 두 모델이 공유하고, 정보 이득 계산만 모델에 위임한다.

$$
G(\pi)=\sum_{\tau=t}^{t+H-1}\Big[-\ln C(\text{결과}_\tau)-\mathrm{IG}_\tau\Big]
$$

| 항목 | 설정 |
|---|---|
| 방식 | 스텝마다 행동 3개에 대한 범주분포. 엘리트의 행동 빈도로 갱신하고 평활화 0.1을 준다. 매 스텝 재계획해서 첫 행동만 실행한다 |
| 크기 | 수평선 H = 20, 후보 1,000, 엘리트 100, 반복 5 |
| 롤아웃 종료 | 결과가 성공 또는 실패로 샘플되면 그 롤아웃은 거기서 끝나고, 이후 항은 더하지 않는다 |
| 선호 C | 결과 채널에만 건다. ln C = 환경의 표준 보상 r: 성공 1 − 0.9·t/T, 실패 0, 진행 0 (t는 에피소드 스텝, T = max_steps). 보상을 그대로 선호로 쓰는 Fountas et al.(2020)의 방식을 따른다 |
| 후보당 샘플 | 1개 (두 모델 동일) |

| 모델 | 정보 이득 IG_τ |
|---|---|
| M0 | 이산 예측 엔트로피 H[P(x_τ \| h_τ)]의 추정치를 쓴다. 흐름에서 v ∼ p(v \| h_τ)를 뽑아 x̂ = argmax(v)를 만들고, 같은 v로 −ln p(v \| h_τ) + ln q(v \| x̂)를 계산한다. ln p(v \| h_τ)는 샘플링 중에 log-det으로 함께 나오고, ln q(v \| x̂)는 임계값 변환을 거꾸로 푼 u(u_x = T = v_x, u_i = T − ln(e^{T−v_i} − 1))에서 닫힌 식으로 계산하므로 흐름을 한 번만 통과하면 된다. 기댓값은 H[P(x \| h_τ)] − E KL[p(v \| x, h_τ) ‖ q(v \| x)]로, 이산 엔트로피의 하한이다. p와 q의 비율이라 좌표에 무관하고, 전처리 좌표에서 생기던 상수 오프셋(약 957 nats)이 없다 |
| M1 | D_KL[q(s \| h, ê) ‖ p(s \| h)]. 상상한 관측 x̂를 임베더로 다시 인코딩해 계산한다 |

두 IG는 정의가 다르다. M0의 IG는 관측 수준의 예측 엔트로피이고, M1의 IG는 숨은 상태에 대한 정보 이득이다(1단계 5.3절). 이 차이 자체가 비교 대상의 일부다. 두 IG 모두 계수 1로 더한다. Tschantz et al.(2020), Fountas et al.(2020)과 같은 관례이고, 모델별로 조정하지 않는다.
