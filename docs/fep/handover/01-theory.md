# 인수인계서 1단계: 정확한 우도 월드모델 기반 자유에너지 에이전트 PoC

## 범위

이 문서는 이론 분석만 담는다. 모델 구조, 실험 사양, 완료 기준은 2단계 문서(`02-spec.md`)에서 정한다.

중심 명제: **확률적 상태와 관측 사이의 사상이 가역이고 결정론적이며 기억도 결정론적이면, 자유에너지 F는 정확한 음의 로그우도(놀람)와 같아지고 추론 간극은 0이 된다.**

PoC의 목적은 이 변화가 행동, 학습, 탐색에 어떤 차이를 남기는지 보이는 것이다. 과제 성능이 일반적으로 좋아진다고 주장하지 않는다. 시험 대상은 FEP 원리 자체가 아니라 능동적 추론이 처방하는 구조다. Friston et al.(2023)은 FEP가 수학적 명제로서는 반증 불가능하다고 명시한다.

## 1. 표기와 용어

아래 표기는 코드와 문서 전체에서 고정한다. 특히 A, B, p\*는 대화 중에 혼동한 적이 있는 기호다.

| 기호 | 뜻 | 주의 |
|---|---|---|
| `o_t` | 관측. 기본은 연속값 | 이산이면 4절 |
| `s_t` | 확률적 숨은 상태 (VAE의 잠재) | 사전분포와 동역학이 정의되는 변수 |
| `z_t = f^{-1}(o_t)` | 가역 인터페이스의 잠재 | 관측과 같은 정보, 같은 차원 |
| `h_t` | 결정론적 기억 (RNN/GRU 상태) | 확률변수가 아니다 |
| `q` | 근사 사후분포 (인코더) | |
| `p_θ` | 에이전트의 생성 모델 | |
| `p*` | 폐루프에서 실제로 방문하는 관측의 정상분포 | 환경과 에이전트의 행동이 함께 정한다 |
| `C` | 관측 위의 선호 분포 | 보상을 대신한다 |
| `F` | 변분 자유에너지 = −ELBO | |
| `ℑ(o)` | 놀람 = −ln p_θ(o \| 과거) | |
| `A` | 추론 간극 = D_KL[q ‖ p_θ(s \| o)] | 모델 기준이지 세계 기준이 아니다 |
| `B` | 모델–세계 불일치 = D_KL[p\* ‖ p_θ] | 밀도가 두 개인 틀에서만 정의된다 |
| `G` | 기대 자유에너지 (계획용) | 미래 F의 기댓값이 아니다 (5절) |

용어 고정:
- **가역**: 확률적 상태와 관측 사이의 사상이 전단사다.
- **결정론적**: 그 사이에 잡음이 끼지 않는다.

층위 구분: 생성 과정(환경)과 생성 모델(에이전트)은 별개다. "POMDP/MDP"라고 쓸 때는 어느 층위인지 항상 밝힌다. 이 문서는 밀도가 두 개인 틀(세계와 모델)을 쓴다. 정상 밀도 하나로 기술하는 Friston et al.(2023)의 틀과 섞지 않는다.

## 2. 기본 분해

F는 놀람과 추론 간극의 합이다. 이 분해가 문서 전체의 분석 틀이다.

$$
F(o;q,\theta)=\mathbb E_{q(s)}\big[\ln q(s)-\ln p_\theta(o,s)\big]
=\underbrace{D_{KL}\big[q(s)\,\|\,p_\theta(s\mid o)\big]}_{A}\;\underbrace{-\ln p_\theta(o)}_{\mathfrak I(o)}
$$

### 2.1 에르고딕 3항 분해

에르고딕 가정 아래에서 시간 평균은 p\* 위의 기댓값이 된다. 교차 엔트로피를 풀면 다음 항등식이 정확히 성립한다.

$$
\overline F=\lim_{T\to\infty}\frac1T\int_0^T F(t)\,dt
=\underbrace{\mathbb E_{p^*}\,D_{KL}\big[q\,\|\,p_\theta(s\mid o)\big]}_{(A)}
+\underbrace{D_{KL}\big[p^*\,\|\,p_\theta\big]}_{(B)}
+\underbrace{H[p^*]}_{(C)}
$$

시간 평균 놀람은 (B)+(C), 즉 교차 엔트로피다. 엔트로피와 같아지는 것은 p\* = p_θ일 때뿐이다. Friston(2010)의 "놀람의 장기 평균 = 엔트로피"에는 이 가정이 암묵적으로 깔려 있다.

### 2.2 변수별로 줄이는 항

| 변수 | 추론 간극 (A) | 모델–세계 불일치 (B) | 감각 엔트로피 (C) |
|---|---|---|---|
| φ / μ (추론) | 줄임 | – | – |
| θ (학습) | 줄임 | 줄임 | – |
| a (행동) | 영향 (p\*를 바꿈) | 줄임 | 줄임 |

사후분포 p_θ(s|o)가 θ에 의존하므로 학습의 기울기에는 추론 간극 항이 들어 있다.

$$
\nabla_\theta F=\nabla_\theta D_{KL}\big[q\,\|\,p_\theta(s\mid o)\big]-\nabla_\theta\ln p_\theta(o)
$$

학습이 (B)만 줄이는 것은 q = p_θ(s|o)인 순간뿐이다. 이때 KL은 최솟값 0이므로 θ 기울기도 0이다. EM의 E-step 직후와 같은 상황이다. 상각 VAE처럼 A > 0인 채로 θ를 갱신하면 디코더가 인코더의 한계에 맞춰 바뀐다.

### 2.3 "추론이 정확하다"의 뜻

q = p_θ(s|o)는 현재 모델이 함의하는 사후분포와 분포가 같다는 뜻이다. 세계를 맞힌다는 뜻도, 확신한다는 뜻도 아니다. 추론 간극은 다시 두 부분으로 나뉜다(Cremer et al., 2018).

$$
D_{KL}[q\,\|\,p]=\underbrace{D_{KL}[q^*\,\|\,p]}_{\text{근사 갭}}+\underbrace{\big(D_{KL}[q\,\|\,p]-D_{KL}[q^*\,\|\,p]\big)}_{\text{상각 갭}},\qquad q^*=\arg\min_{q\in\mathcal Q}D_{KL}[q\,\|\,p]
$$

- **근사 갭**: 근사족이 사후분포를 표현하지 못해서 생긴다. 정규화 흐름 q를 쓰면 줄어든다.
- **상각 갭**: 인코더가 q\*를 내지 못해서 생긴다. 샘플별 최적화를 수렴할 때까지 돌리면 0이 된다.

## 3. 가역 구조의 목적함수

F의 형태는 어느 층이 가역인지로 정해지지 않는다. **사전분포와 동역학이 정의된 확률적 상태와 관측 사이의 사상**이 가역이고 결정론적인지로 정해진다. 다른 곳에 있는 가역 층은 좌표 변환일 뿐이며 F에는 log-det 항으로만 들어간다.

### 3.1 정확한 우도의 조건

주변화해야 할 잠재변수가 없어야 한다. 구체적인 조건은 세 가지다.

1. 상태와 관측 사이에 차원 병목이 없다.
2. 상태와 관측 사이에 잡음이 끼지 않는다. 차원이 같더라도 p(z|c) 같은 확률적 잠재를 두면 ELBO로 돌아간다.
3. 기억은 결정론적이다 (h_t = RNN(h_{t−1}, z_t)).

이 조건에서 F는 정확한 로그우도가 된다. 자기회귀 모델과 같은 구조다.

$$
F_t=-\ln p_z\big(f_\theta^{-1}(o_t)\mid h_{t-1}\big)-\ln\left|\det\frac{\partial f_\theta^{-1}}{\partial o}(o_t)\right|,\qquad \ln p(o_{1:T})=-\sum_t F_t
$$

### 3.2 ELBO 형태로 구현하지 말 것

연속 변수에서는 q = δ(z − f⁻¹(o))이고 p(o|z) = δ(o − f(z))다. 정확도 항은 +∞, q의 엔트로피는 −∞로 발산하고, 둘의 합만 유한하다. 따라서 "복잡도 − 정확도" 분해는 의미가 없다. **반드시 3.1의 변수 변환 식으로 계산한다.**

### 3.3 따름정리

| | 내용 | 성격 |
|---|---|---|
| P1 | A ≡ 0. 행동 기울기가 ∇_a ℑ와 같다 (간극을 해킹하는 편향이 없음) | 이점 |
| P2 | 학습이 순수 최대우도다. 이 경우에는 "학습이 (B)만 줄인다"가 정확히 참이다 | 이점 |
| P3 | 모호성 항이 사라진다 (5절) | 대가 |
| P4 | 현재 z의 사후분포가 델타다. 중간층은 현재 관측의 해석을 바꾸지 못하고 예측과 평가만 한다 | 완전 관측에서는 무해 |
| P5 | 센서 잡음을 따로 설명하는 관측 우도 p(o\|s)가 없다. 잡음은 예측 밀도 p_z(z_t \| h_{t−1})의 분산으로 모델링된다 | 대가 |
| P6 | 압축이 없다. 중간층이 관측 차원 그대로 연산한다 | 비용 |

### 3.4 중간에 병목을 두면

가역 인터페이스 위에 z 공간의 VAE를 두면 ELBO로 돌아간다. 이때 가역 층은 우도 분포족을 재매개화하는 역할만 한다.

$$
F(o)=-\mathrm{ELBO}_z\big(f^{-1}(o)\big)-\ln\left|\det J_{f^{-1}}(o)\right|
$$

병목에서 결정론적으로 다시 펼치면 밀도가 저차원 다양체에 몰려 F를 정의할 수 없다. p(z|c) 같은 잡음 모델이 필요하다.

### 3.5 기억은 별개의 축이다

지금 같아 보이는 상황을 구분하지 못하는 문제(T자 미로)는 상태 설계의 문제이며 가역성과 무관하다. 두 축이 묶이는 것은 상태 전체를 가역으로 둘 때뿐이다. 기억이 필요한지는 압축률이 아니라 아래 양으로 판단한다.

$$
I\big(\eta_t\,;\,o_{1:t-1},a_{1:t-1}\mid o_t\big)>0\ \Rightarrow\ \text{기억 필요}
$$

### 3.6 구현 함정: 잡음 없는 채널

잡음 없는 연속 채널에서는 예측 분산이 0으로 가면 −ln p → −∞가 된다. **모든 모델에 똑같은 분산 하한을 둔다.** 하한이 공정하지 않으면 비교 전체가 무의미해진다.

## 4. 이산 관측과 탈양자화 간극

탈양자화한 흐름도 ELBO다. 다만 간극이 붙는 대상과 간극 크기의 상한이 VAE와 다르다. "이산이면 이점이 사라진다"는 틀린 요약이고, 정확히는 상한이 있는 국소적 간극에 오염된다.

### 4.1 형태: VAE의 특수한 경우

탈양자화한 흐름은 잠재가 y = x + u, 우도가 P(x|y) = 1[y ∈ B(x)], 사전분포가 p_flow(y)인 VAE다. B(x)는 x의 양자화 칸이다.

$$
F_{\text{flow}}(x)=D_{KL}\big[q(u\mid x)\,\|\,p(u\mid x)\big]-\ln P(x)
$$

### 4.2 항을 나누면 드러나는 차이

우도가 지시함수이므로 정확도 항은 항상 0이다. q가 균등이면 단위 칸의 엔트로피도 0이다. 따라서 F는 칸 안에서 평균한 연속 놀람이다.

$$
F_{\text{uniform}}(x)=\mathbb E_{u\sim U[0,1)^D}\big[-\ln p_{\text{flow}}(x+u)\big]
$$

P(x) ≤ sup p이고 −ln p(x+u) ≤ −ln inf p이므로, 간극은 한 칸 안의 로그밀도 출렁임으로 위에서 막힌다.

$$
0\ \le\ A_{\text{deq}}(x)=D_{KL}\big[U\,\|\,p(u\mid x)\big]\ \le\ \ln\frac{\sup_{B(x)}p_{\text{flow}}}{\inf_{B(x)}p_{\text{flow}}}
$$

| | 탈양자화 간극 | VAE 추론 간극 |
|---|---|---|
| 간극의 대상 | 칸 안의 위치 (양자화 잡음) | 숨은 원인 |
| 상한 | 칸 안 로그밀도 출렁임. 계산 가능 | 없음 |
| 0이 되는 조건 | 칸 안에서 밀도가 평평함. 해상도가 높을수록 0에 가까워짐 | 근사족이 사후분포를 포함하고 상각 오차가 없음 |
| 중간층 상태 추론 | z의 사후분포가 f⁻¹(B(x)) 안에 갇힘. 거의 정확 | 간극만큼 오차 |
| 모호성 항 | 0 (가역 구조의 성질 유지) | 있음 |
| 완전히 없애는 방법 | 부분집합 흐름, 자기회귀 이산 모델 | 일반적으로 없음 |

### 4.3 크기에 대한 주의

Nielsen & Winther(2020)가 보고한 PixelCNN 계열의 탈양자화 간극은 0.038–0.049 bits/dim이다. 차원당으로는 작지만 관측 하나 전체로 합치면 작지 않다. VAE 간극과는 데이터셋과 단위가 달라서 크기를 직접 비교하지 않는다.

### 4.4 설계 규칙

- 주 실험(MiniGrid-Memory)의 관측은 이산이다. 속성 묶음(물체·색·상태)마다 argmax로 범주를 정하는 방식으로 연속 공간에 들어 올리고(Argmax Flow, Hoogeboom et al. 2021), 밀도는 흐름으로 계산한다. 들어 올림 분포 q(v|x)는 고정 분포(N(0, I) + 임계값 변환)이고, 이때 남는 국소 간극은 감수한다(2단계 D4, D7).
- 이산 관측을 쓰면 간극 A_deq를 결과와 함께 보고한다. 균등 탈양자화에서는 4.2절의 상한을 쓸 수 있다. 하지만 argmax 들어 올림에서는 범주 영역이 무한히 뻗어 있어 상한이 없다. 그래서 **학습 손실과 중요도 가중 우도 추정치의 차이로 간극을 측정한다.** 간극 해킹 실험에서는 이 간극이 같은 형태의 교란 변수가 된다.
- 범주형 기호(MiniGrid의 물체 ID 등)를 정수 하나로 둔 채 탈양자화하지 않는다. 의미 없는 순서가 강제되기 때문이다. 원-핫 성분마다 균등 탈양자화하는 방식도 쓰지 않는다. 모델이 원-핫이 아닌 이진 벡터의 칸(예: 범주 두 개짜리 묶음의 (0,0), (1,1))으로 질량을 흘려서, 유효한 관측의 확률 합이 1보다 작아지기 때문이다. argmax 들어 올림은 연속 공간 전체를 유효한 범주들의 영역으로 나누므로 이 문제가 없다.

## 5. 기대 자유에너지와 탐색

G는 ELBO에서 유도되지 않는다. 가역 구조에서는 모호성 항이 사라져 탐색 항이 예측 엔트로피가 되므로 noisy TV에 취약해진다. 해법은 앙상블 파라미터 상호정보량이다.

### 5.1 위험 + 모호성 = −실용 가치 − 정보 이득

Q(o, s|π) = P(o|s)Q(s|π)로 두고 베이즈 정리를 쓰면 다음이 정확히 성립한다. 왼쪽은 Da Costa et al.(2020) 식 (13), (15)의 형태다.

$$
G(\pi)=\underbrace{D_{KL}\big[Q(o\mid\pi)\,\|\,C\big]}_{\text{위험}}+\underbrace{\mathbb E_{Q(s\mid\pi)}H\big[P(o\mid s)\big]}_{\text{모호성}}
=-\underbrace{\mathbb E_{Q(o\mid\pi)}\ln C(o)}_{\text{실용 가치}}-\underbrace{\mathbb E_{Q(o\mid\pi)}D_{KL}\big[Q(s\mid o,\pi)\,\|\,Q(s\mid\pi)\big]}_{\text{정보 이득}}
$$

### 5.2 G는 미래 F의 기댓값이 아니다

같은 Q 아래에서 다음 항등식이 정확히 성립한다. G는 Da Costa et al.(2020) 식 (10)의 형태다.

$$
\underbrace{\mathbb E_{Q(o,s\mid\pi)}\big[\ln Q(s\mid o,\pi)-\ln P(o,s)\big]}_{\text{미래 F의 기댓값}}
=\underbrace{\mathbb E_{Q(o,s\mid\pi)}\big[\ln Q(s\mid\pi)-\ln P(o,s)\big]}_{G(\pi)}
+\underbrace{\mathbb E_{Q(o\mid\pi)}D_{KL}\big[Q(s\mid o,\pi)\,\|\,Q(s\mid\pi)\big]}_{\text{정보 이득}\ \ge 0}
$$

미래 F를 그대로 최소화하면 정보 이득에 벌점을 주는 셈이 되어 탐색을 피한다. Millidge, Tschantz & Buckley(2021)의 지적과 같다. **계획기에는 반드시 G를 쓴다.**

### 5.3 결정론적 디코더에서의 G

이산 경우에 디코더가 결정론적이면 모든 상태에서 H[P(o|s)] = 0이다. G에는 위험 항만 남고, 정보 이득은 예측 엔트로피가 된다.

$$
G(\pi)=D_{KL}\big[Q(o\mid\pi)\,\|\,C\big]=-\mathbb E_{Q(o\mid\pi)}\ln C(o)-H\big[Q(o\mid\pi)\big]
$$

예측하기 어려운 관측은 무엇이든 정보 이득으로 계산되므로 순수한 잡음원에 끌린다. 비가역 모델에서는 정보 이득이 I(s; o) = H[Q(o|π)] − E H[P(o|s)]이어서 모호성 항이 잡음을 빼 준다.

연속 경우에는 델타의 미분 엔트로피가 −∞이므로 "모호성 = 0"이라는 표현이 성립하지 않는다. 분산 하한 σ_min을 두면 모호성은 모든 상태에서 같은 상수가 되어 상태를 구별하지 못한다. 결론은 같다.

### 5.4 가역 구조 안에서의 해법: 파라미터 상호정보량

앙상블 모델 θ에 대한 상호정보량을 탐색 항으로 쓴다. 둘째 항이 우연적 잡음을 빼 준다. 각 모델의 로그밀도가 정확하므로 멤버별 엔트로피를 편향 없이 추정할 수 있다.

$$
I(\theta;o)=H\big[\mathbb E_\theta\,p(o\mid\theta)\big]-\mathbb E_\theta\,H\big[p(o\mid\theta)\big]
$$

이 항이 noisy TV를 막는다는 것은 **아직 가설**이다. 다음 상태의 분산까지 예측해서 noisy TV를 피한 Mavor-Parker et al.의 결과와 같은 원리다.

## 6. 헷갈리면 안 되는 사항

논의 중에 실제로 혼동했거나 잘못 말했다가 바로잡은 항목이다. 코드, 주석, 보고서에서 왼쪽처럼 쓰지 않는다.

| 틀린 서술 | 올바른 서술 |
|---|---|
| 학습은 (B)만 줄인다 | θ 기울기에 (A)가 들어 있다. (B)만 줄이는 것은 q가 정확한 사후분포일 때와 가역 구조일 때뿐이다 |
| VAE 학습은 q와 p의 차이만 줄인다 | φ는 (A)만, θ는 (A)와 우도를 함께 움직인다 |
| 행동은 (B)와 (C)만 바꾼다 | 행동은 p\* 자체를 바꾸므로 세 항 모두에 영향을 준다 |
| 시간 평균 놀람 = 엔트로피 | 교차 엔트로피다. 엔트로피가 되려면 p\* = p_θ여야 한다 |
| Friston(2023)에서는 B = 0이다 | 그 틀에는 밀도가 하나뿐이라 B가 정의되지 않는다. B = 0은 Friston(2010)의 암묵적 가정이다 |
| 2023 정식화는 디코더가 필요 없다 | 구현에는 인코더와 디코더 학습이 필수다. 그 정식화를 구현 설계의 근거로 쓰지 않는다 |
| 추론이 정확하다 = 세계를 맞힌다 | 현재 모델의 사후분포와 분포가 같다는 뜻이다 |
| 가역이면 기억을 못 둔다 | 상태 전체를 가역으로 둘 때만 그렇다. 디코딩되지 않는 h를 따로 두면 된다 |
| 가역이면 POMDP가 MDP가 된다 | 환경은 그대로다. 바뀌는 것은 에이전트 모델이고, 그 결과 모델이 잘못 지정된다 |
| 가역이면 추론 능력이 막힌다 | 완전 관측에서는 델타 사후분포가 정답이다. 예측과 계획은 중간층에서 제약 없이 돌아간다 |
| 가역이면 추상화가 없다 | z 수준에서만 맞다. 중간층 네트워크는 결정론적 특징을 내부에서 계산할 수 있다 |
| 부분 관측 문제는 압축을 못 해서 생긴다 | 현재 관측에 없는 정보를 담을 자리(기억)가 없어서 생긴다 |
| 중간 병목 구조도 정확한 우도다 | 병목이나 잡음 잠재가 있으면 ELBO로 돌아간다 (3.4절) |
| 이산이면 가역 구조의 이점이 사라진다 | 범주 영역 안의 국소 간극에 오염될 뿐이다. 전역 추론 간극은 여전히 0이다 (4절) |
| G는 미래의 F다 | 미래 F = G + 정보 이득이다 (5.2절) |

다음 두 가지도 지킨다.
- 잡음 없는 연속 채널에는 모든 모델에 같은 분산 하한을 둔다 (3.6절).
- 7절에서 유도, 근사, 가설로 분류한 항목은 검증 전까지 사실로 취급하지 않는다.

## 8. 출처와 신뢰도

아래 문헌은 모두 웹 도구가 PDF 텍스트를 추출·요약한 결과로 확인했으며, PDF를 직접 읽지는 않았다. 식의 형태와 번호는 맞을 가능성이 높지만, 도구가 두 곳에서 문제를 보고했다.
