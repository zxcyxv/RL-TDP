# 실험 2e: 같은 DreamerV3 에이전트, 월드 모델만 교체 — 사전 예측

작성: 2026-11-08, 본 실행 **전**. 결과를 본 뒤 수정하지 않는다.

## 조건

- 환경: MiniGrid-Dynamic-Obstacles-8x8-v0. 시간 초과는 실패가 아닌 절단(DreamerV3와 같음)
- 에이전트: `rltdp/fep/agent/dv3.py` (DreamerV3 공식 레포 기본값, 차이는 파일 상단에 명시). 세 모델에 완전히 동일
- 월드 모델: M1-S, M0-SQ, M0F-S (실험 2c와 같은 코드·설정, 온라인으로 처음부터 학습)
- 환경 20,000스텝, 버퍼 시작 무작위 100 에피소드, 환경 2스텝마다 갱신 1회, 시드 0
- 참고: 스모크에서 M1-S는 9,000~12,000스텝 사이에 탐색 구간을 벗어나 성공률 0.96에 도달했다

## 측정

- 성공률·충돌률·에피소드 길이 (최근 50 에피소드), 1,000스텝마다
- "탈출 시점" = 최근 50 에피소드 성공률이 처음 0.5 이상이 된 기록 시점
- 정책 엔트로피 (앞이 빈 상태 / 막힌 상태)

## 예측 (확신 낮음)

| ID | 예측 | 틀렸다고 볼 기준 |
|---|---|---|
| P1 | 세 모델 모두 20,000스텝 안에 탈출한다 | 어느 하나라도 탈출 시점이 없음 |
| P2 | M0F-S의 탈출이 가장 늦다. 칸별 독립 샘플이라 상상 속 공 배치가 뒤섞여 가치 추정이 더 시끄러울 것이므로 | M0F-S의 탈출 시점이 다른 둘 중 하나보다 빠르거나 같음 |
| P3 | M0-SQ와 M1-S의 20,000스텝 시점 성공률 차이는 0.1 이내다. 이 환경에서 행동에 결정적인 정보(바로 앞 칸)는 거의 결정론적이라, 실험 2c의 우도 차이가 행동 차이로 크게 이어지지 않을 것이므로 | 차이 > 0.1 |
| P4 | 20,000스텝 시점 충돌률은 M0F-S가 가장 높다 | M0F-S의 충돌률이 다른 둘 중 하나보다 낮거나 같음 |

시드가 1개라 어떤 결과든 경향으로만 해석한다.

**보충 (같은 날, 결과를 보기 전)**: P1 중 M1-S 부분은 스모크(15,000스텝까지)에서 이미 관찰한 사실이므로 예측이 아니다. P1의 실질적인 예측은 M0-SQ와 M0F-S에 대한 것이다.

**판정 시점 변경 (사용자 결정, 결과를 보기 전)**: 비교 길이를 환경 20,000스텝에서 **15,000스텝**으로 줄인다. M1-S는 다시 돌리지 않고, 같은 설정·시드로 먼저 돌린 실행(15,036스텝까지)의 기록을 쓴다. P3·P4의 "20,000스텝 시점"은 "15,000스텝 시점"으로 읽는다.
