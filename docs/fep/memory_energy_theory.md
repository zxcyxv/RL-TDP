## 0. 위치

"F를 에너지 함수로 두고, 학습과 추론이 같은 연산이 되게 한다"는 방향을 정리한 문서다. 조건은 네 가지다.
- 배치 1로, 환경 흐름 위에서 온라인으로 돈다.
- 관측 분포를 범주형으로 두지 않는다. 연속 관측(예: Minecraft 픽셀)으로 옮길 수 있어야 한다.
- 정규화 흐름(가역 사상)을 쓰지 않는다.
- tdp-reasoner의 기억(STDP 이중적분 M)과 이어진다.

## 1. 출발점: EBM 학습으로는 배치 1의 학습 = 추론이 안 된다

정규화되지 않은 에너지 E_θ의 우도 기울기 [표준]:
```
∇θ [−ln p(o)] = ∇θ E_θ(o) − E_{o′ ∼ p_θ}[ ∇θ E_θ(o′) ]
```
둘째 항은 분배함수 Z(θ)에서 나온다. 모델에서 뽑은 표본의 평균이라 표본 하나로는 계산할 수 없다. MCMC나 NCE가 배치를 필요로 하는 이유가 이것이다.

## 2. 원칙: 에너지를 국소적으로 정규화된 조각의 합으로 둔다

생성 모델을 각각 정규화된 조건부 분포의 곱으로 두면 Z가 생기지 않는다 [표준].
```
−ln p(o, s) = −ln p(o | s) − ln P(s)        각 항이 정규화되어 있음
```
그러면 관측 하나로 F와 그 기울기를 정확히 계산할 수 있다. 상태에 대한 기울기는 추론, 가중치에 대한 기울기는 학습이 된다. 같은 F를 쓰고 배치는 1이다.

## 3. 생성 모델: 토큰 단위, 관측 공간, 숨은 변수 = "어느 기억에서 왔는가"

시점 t, 토큰 τ(칸 또는 패치) 하나 기준이다. 맥락으로 만든 질의를 q, 저장된 기억 j의 키와 값을 (k_j, v_j)라 하자. v_j는 시점 s_j에 그 토큰 다음에 나온 관측이다.

숨은 변수는 s ∈ {0, 1, …, N}이다. s = 0은 느린 신경망(기본 성분)이고, s = j는 기억 j다.
```
사전:  P(s = 0 | q) = α / (α + Σ_j κ_j),     P(s = j | q) = κ_j / (α + Σ_j κ_j),     κ_j = exp(β k_jᵀ q)
우도:  p(o | s = 0, q) = N(o; μ_θ(q), Σ_θ),    p(o | s = j) = N(o; v_j, Σ_m)
주변:  p(o | q) = Σ_s P(s | q) · p(o | s, q)
```
- 사전 P(s | q)가 곧 어텐션 가중치다. 관측 전, "지금 맥락이 어느 기억과 닮았는가"에 대한 믿음이다.
- 관측 공간에 직접 둔다. 흐름도, 범주형 분포도 쓰지 않는다.
- 토큰 단위로 두면 조각끼리 다시 조합해서 일반화한다. 장면 전체를 한 덩어리로 기억하면, 매번 새로운 조합(예: 공의 배치)에서 기억이 쓸모없어진다. 이 단위는 tdp-reasoner의 토큰별 흔적과 같다. 대가로 토큰 사이 상관은 키(맥락)를 통해서만 들어온다.

## 4. 에너지와 F의 관계

**에너지(깁스 에너지)**:
```
U(o, s) = −ln P(s | q) − ln p(o | s, q)
```

**F (에너지 − 엔트로피 형태)**. q(s)는 숨은 변수에 대한 믿음이다.
```
F[q] = E_q[ U(o, s) ] − H[q] = KL[ q(s) ‖ P(s | o, q) ] − ln p(o | q)
```

**q에 대한 최소화** [표준]:
```
q*(s) = exp(−U(o, s)) / Σ_s′ exp(−U(o, s′)) = P(s | o, q)       볼츠만 분포 = 정확한 사후분포
F*    = −ln Σ_s exp(−U(o, s)) = −ln p(o | q)                       정확한 놀람
```
- s는 유한한 이산 변수다. 그래서 s에 대한 분배함수가 유한합이고 정확히 계산되며, 추론 간극은 0이다.
- o 쪽의 정규화는 각 성분이 가우시안이라 저절로 성립한다. 이 두 성질 덕분에 1절의 Z 문제가 생기지 않는다.

**현대 홉필드 에너지는 F*다** [유도]. 기억 가중치가 균등하고 크기가 같으면 U(ξ, s) = (β/2)|ξ − x_s|² + 상수이므로
```
F* = −ln Σ_s exp(β x_sᵀ ξ) + (β/2)|ξ|² + 상수 = β · E_홉필드(ξ) + 상수
```
E_홉필드는 Ramsauer et al. 2021의 형태다 [기억]. 정리하면 에너지 모델은 U이고, F는 U를 "어느 기억인가"에 대해 정확히 주변화한 자유에너지이며, 홉필드 에너지가 그 F다.

## 5. 세 과정이 같은 F 위에 있다

| 과정 | 하는 일 | 형태 |
|---|---|---|
| 예측 | 관측 전 p(o \| q) | 혼합분포. 평균 Σ_s P(s \| q)·(성분 평균) = 어텐션 읽기 |
| 추론(지각) | 관측 후 q*(s) = P(s \| o, q) | 실제 관측으로 어텐션 가중치를 다시 매긴다. 정확하고 한 번에 끝난다 |
| 빠른 학습 | 쓰기: (k_t, o_{t+1})을 성분 하나로 추가 | (α·기본 + Σ 커널) / (α + n). 디리클레 과정 사후 예측(폴리아 항아리)을 커널로 평활하고, 키로 가중한 형태 [표준: Blackwell & MacQueen 1973, 기억] |
| 느린 학습 | θ(키 사상, μ_θ, 공분산, β, α)를 F*의 기울기로 갱신 | 하이퍼파라미터의 경험적 베이즈. 배치 1 |

- 빠른 학습은 정확한 베이즈 갱신이다. 저장된 데이터 자체가 사후분포를 표현하므로, 쓰기(학습)와 읽기(추론)가 같은 모델 위의 연산이 된다.
- 부산물: 기본 성분의 사후 가중치 α / (α + Σ_j κ_j)는 "지금 맥락과 닮은 기억이 얼마나 적은가"를 잰다. 낯섦의 척도가 모델 안에서 나온다. 정보 이득을 다시 다룰 때의 후보다.

## 6. tdp-reasoner의 기억 M과의 관계

- M = Σ_{s,t} Λ(t − s)·v_t k_sᵀ는 STDP 시냅스 변화를 시차 창으로 이중적분한 형태다. 헤브식 외적을 쌓은 연상기억이므로 홉필드 계열이다.
- 그 안에서는 **고전(선형) 홉필드** 쪽이다. softmax가 없으므로 현대(조밀) 홉필드가 아니다.
- 그리고 **시간 연상 기억**이다. 창이 비대칭이라 앞선 키와 뒤따른 값을 묶는다. 비대칭 헤브 규칙으로 패턴의 순서를 저장하는 갈래와 같다(Sompolinsky & Kanter 1986, Kleinfeld 1986) [기억].
- 스칼라 에너지를 갖는 것은 M의 대칭 부분뿐이다. 비대칭 부분은 다음 패턴으로 넘어가게 한다.
- 4절의 혼합과의 관계 [유도]: β가 작을 때 exp(β kᵀq) ≈ 1 + β kᵀq로 펼치면 가중합이 v kᵀ의 누적이 된다. 즉 선형 M은 혼합의 1차 근사(고전 영역)다. 정확한 F* = −ln p를 내려면 softmax(lse)가 살아 있어야 한다.
- 시차 창 Λ는 어떤 키와 어떤 값을 묶을지 정한다. 키를 바로 다음 값(시차 +1)과 묶으면 4절의 "맥락 → 다음 관측" 기억이 된다. 대역 감쇠는 오래된 기억을 잊는 역할로 쓸 수 있다.

## 7. 실무 조건

- **분산 하한**: 이산 관측이나 8비트 픽셀에서는 분산을 0으로 줄여 밀도를 발산시킬 수 있다. 모든 성분에 같은 하한을 둔다.
- **공분산**: 대각 + 저순위로 두면 행렬식과 역행렬이 싸게 계산된다.
- **일반화의 깊이**: 기억 성분은 관측 공간의 거리로만 비교하므로 일반화가 얕다. 깊은 일반화는 기본 성분(느린 신경망)이 맡는다.
- **두 번 세기**: 기억에 쓴 데이터를 느린 가중치가 다시 배우면 이중으로 센다. 기억 감쇠나 느린 쪽으로의 통합 규칙이 필요하다 [선택].
- **배치 1 온라인 학습의 불안정**: 재현 버퍼 없이 느린 가중치를 갱신하면 직전 상황에 과적합하고 예전 것을 잊기 쉽다. 빠른 기억(즉시 쓰기)과 느린 가중치(천천히 통합)를 나눈 것이 이에 대한 대응이지만, 충분한지는 미지수다.
- **학습된 임베딩 공간에 두지 않는 이유**: 가역이 아닌 인코더의 공간에 기억을 두면 에너지가 −ln p(o)가 아니게 된다. 또 인코더가 모든 것을 한 점으로 보내 에너지를 0으로 만드는 붕괴를 막는 장치가 따로 필요하다. 그 경우는 F가 아니다.

## 8. 열린 결정

1. **키 사상**: q를 무엇에서 만들지 정한다. 원천 후보는 GRU 상태 h나 TDP 토큰 상태이고, 시야 토큰을 그대로 쓰면 일반화가 거의 없다.
2. **기억의 길이와 감쇠**: 모두 저장할지, 감쇠시킬지(TDP의 대역 주기)를 정한다.
3. **β(정밀도)와 α(기본 성분의 세기)**: 고정, 학습, 매 스텝 추론 중에서 정한다.
4. **기본 성분 μ_θ의 구조**: 지금의 디코더를 쓸지 새로 둘지 정한다.

## 10. 검토와 결정: softmax를 넣지 않고 대각 가우시안으로 간다 (2026-11-12)

### 10.1 흔적 슬롯 위 softmax 읽기를 검토한 결과
TDP의 토큰별 흔적 (E_K,r, E_V,r)을 기억 슬롯으로 보고 softmax로 읽는 안(4절의 혼합을 TDP에 얹는 안)을 검토했다 [유도].
- **엄밀한 STDP 해석이 깨진다.** TDP의 M에서는 (앞선 키, 뒤따른 값) 쌍마다 창 가중치 L(Δ)가 한 번씩 더해진다. softmax에서는 가중치가 exp(β q·E_K) = Π_s exp(β z^{n−s} q·k_s)라서 과거 키들이 곱으로 얽힌다. β가 작을 때의 1차 근사에서만 M이 다시 나온다. 결과는 STDP 시냅스가 아니라 "흔적 위의 현대 홉필드 검색"이다.
- **불편한 점 세 가지.**
  - 복소 흔적: 실수부를 취해야 하고, 진동(음의 가중) 흔적이 exp 안에 들어간다. 값 흔적은 과거 관측의 볼록 결합이 아니다.
  - 쌍 정보: 슬롯이 키의 합과 값의 합을 따로 들고 있어서 "어느 키 다음 어느 값"이 흐려진다.
  - 5절의 "쓰기 = 정확한 베이즈 갱신"이 성립하지 않는다.
- **모순은 없다.** 혼합이 정규화되어 있으므로 F*는 그 모델 아래에서 정확하다. 비대칭 창도 관측에 대한 에너지와 모순되지 않는다.

### 10.2 정정
정확한 F*에 필요한 것은 softmax가 아니라 **정규화된 출력 분포**다. softmax는 "기억들 위의 혼합"이라는 특정 형태일 때의 정규화일 뿐이다. 흐름도 정확성의 조건이 아니다. 흐름은 정확성을 지키면서 여러 봉우리와 상관을 표현하는 수단 중 하나다.

### 10.3 결정: TDP 선형 읽기 + 대각 가우시안 출력
토큰 τ마다, 관측 차원 i마다:
```
m_τ      = μ_θ(맥락)_τ + W · (M_t q_τ)_τ           M_t: TDP의 STDP 기억 (선형 읽기 그대로)
σ_τ,i    = max(σ_min, σ_θ(맥락)_τ,i)               모든 모델에 같은 하한 σ_min
p(o | 맥락) = Π_τ Π_i N(o_τ,i; m_τ,i, σ_τ,i²)

F*_t = Σ_τ Σ_i [ (o_τ,i − m_τ,i)² / (2σ_τ,i²) + ln σ_τ,i + ½ ln 2π ]     정확한 −ln p
```
- **유지되는 것**
  - STDP 해석: M은 시냅스 이중적분 그대로이고, 읽기도 선형 그대로다.
  - 정확한 F*: 출력이 정규화된 가우시안이라 Z 문제가 없다. 흐름도, 범주형 분포도, 기억 위 softmax도 쓰지 않는다.
  - 학습의 두 시간 척도: M(시냅스)은 매 스텝 흔적으로 기울기 없이 갱신된다(빠름). θ(투영, μ_θ, σ_θ, W, 극점과 계수)는 F*_t의 기울기로 갱신된다(느림, 배치 1 가능).
- **잃는 것**
  - 숨은 변수 "어느 기억인가"와 그 사후분포, 그리고 5절의 낯섦 척도.
  - 상태가 결정론적이라 지각(q에 대한 최소화)이 할 일이 없다. M0와 같은 성질이다. "추론"은 기억을 읽어 m을 내는 계산이 된다.
- **한계**
  - 봉우리가 하나다. 다음 관측이 갈리면(공이 왼쪽/오른쪽) 사이에 질량을 두어 예측이 흐려지고, F*는 정확하지만 크다.
  - 대각이라 차원 사이 상관이 없다.
  - 정확한 F*는 추론 간극 0이라는 뜻이지 모델과 세계의 불일치가 작다는 뜻이 아니다.
- **올릴 길(흐름 없이)**
  - 대각 + 저순위 공분산: 선형 상관을 담는다.
  - 가우시안 혼합 출력: 여러 봉우리를 담는다.
  - 토큰 순서 자기회귀: 상관과 여러 봉우리를 둘 다 담고, 인과 마스크를 건 TDP 블록으로 구현할 수 있다.

  어느 쪽이든 M q는 조건으로 들어가므로 STDP 해석은 유지된다.
- **이산 관측**: MiniGrid의 원-핫 관측에는 연속 밀도를 그대로 쓸 수 없다(분산을 0으로 줄여 발산). 탈양자화(원-핫에 작은 균등 잡음)와 σ_min을 함께 둔다. Minecraft의 8비트 픽셀에도 같은 처리를 한다.
