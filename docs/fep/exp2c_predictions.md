# 실험 2c: MiniGrid-Dynamic-Obstacles — 사전 예측

작성: 2026-11-08, 데이터 수집과 학습 **전**. 결과를 본 뒤 이 문서는 고치지 않고, 결과는 별도 문서에 적는다.

## 왜 이 과제인가

실험 2a(MiniGrid-MemoryS13)에서는 기억이 있으면 다음 시야가 거의 결정되어, M1-S의 추론 간극이 보통 스텝에서 0.001~0.003 nats였다. 정확한 우도 모델이 줄일 간극 자체가 거의 없었다. 이 실험의 질문은 **"과거를 다 알아도 다음 관측이 불확실한 환경에서는 간극이 커지고, 그때 정확한 우도 모델이 이점을 갖는가"**이다. 실험 2a의 결과를 바꾸려는 것이 아니라 별개의 질문이다.

## 환경

- `MiniGrid-Dynamic-Obstacles-8x8-v0` (minigrid 3.2.0), 표준 설정 그대로
- 시작 위치 (1,1) 동쪽, 목표 (6,6). 공 4개가 처음에 무작위 위치에 놓이고, **매 스텝 공마다 주변 3×3 칸 중 무작위 빈칸으로 옮긴다**. 공에 부딪히면 보상 −1로 종료(실패), 목표 도착은 성공, 시간 제한 256스텝
- 관측 형식은 실험 2a와 같다(7×7 자기중심 격자, 방향, 결과). 벽 너머도 보인다(가림 없음)
- 무작위 정책은 평균 8.7스텝 만에 충돌한다(시드 0~299 확인)

## 비교 모델 (실험 2a와 같은 코드·설정)

- M0F-S: 칸별 독립 범주형 + 직전 시야 연결 (잠재 없음, 정확한 우도)
- M0-SQ: 조건부 흐름 + 학습되는 들어 올림 q(u|x) + 직전 시야 연결 (전역 추론 간극 0, 이산화 간극 있음)
- M1-S: RSSM-VAE + 직전 시야 연결 (추론 간극 있음)
- 학습 설정은 실험 2a와 같다(Adam 3e-4, 클리핑 100, 배치 32×32, 시간 평균 손실, 시드 0)

## 측정

- 보류 집합의 스텝당 F, ℑ(M0F-S는 정확값, 나머지는 중요도 가중 S=1000), 간극 하한 F − ℑ̂
- 스텝을 **현재 시야에 보이는 공의 수(0 / 1 / 2개 이상)**와 조각 첫 스텝으로 나눠 집계한다

## 예측

| ID | 예측 | 틀렸다고 볼 기준 |
|---|---|---|
| P1 | M1-S의 추론 간극(F − ℑ̂)이 공이 보이는 스텝에서 공이 안 보이는 스텝보다 크다 | 공 1개 이상 스텝의 간극 평균 ≤ 공 0개 스텝의 간극 평균 |
| P2 | M1-S의 보류 집합 전체 간극이 실험 2a(0.053 nats/스텝)보다 크다 | 전체 간극 ≤ 0.053 |
| P3 | 공이 보이는 스텝에서 M0F-S의 ℑ가 M0-SQ와 M1-S보다 크다 (공 하나가 움직이면 두 칸이 함께 바뀌는 상관을 칸별 독립 모델이 표현하지 못하므로) | 공 1개 이상 스텝에서 M0F-S의 ℑ가 둘 중 하나 이하 |
| P4 | 공이 2개 이상 보이는 스텝에서 M1-S와 M0-SQ의 ℑ 차이가 실험 2a보다 줄어든다 (M1-S의 간극이 커지므로) | 공 2개 이상 스텝에서 ℑ(M0-SQ) − ℑ(M1-S)가 실험 2a 전체 차이(0.45 − 0.24 = 0.21) 이상 |

전체 ℑ에서 어느 모델이 이길지는 예측하지 않는다. P1~P4가 모두 맞더라도 M1-S가 전체적으로 이길 수 있다.
