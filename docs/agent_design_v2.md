# 에이전트 설계 2판: DreamerV3 골격 위의 기대 자유에너지 최소화

1판(`agent_design_draft.md`)을 두 검토(능동적 추론 이론, 모델 기반 강화학습 실무)로 고친 판이다. 표기: **[유도]** 이론에서 나옴, **[근사]** 무엇을 근사하는지 명시, **[선택]** 이론이 정하지 않음, 사용자 결정 필요.

문헌: [DC20] Da Costa et al. 2020, [M19] Millidge 2019, [SI21] Friston et al. 2021 (Sophisticated Inference, 원문 미확인), [이론] docs/handover/01-theory.md.

---

## 1. 골격

DreamerV3와 같다: 월드 모델 학습 → 월드 모델 안에서 상상 → 가치망·정책망 학습 → 정책망으로 행동. 바뀌는 것은 상상 속 목적: 보상 합 대신 기대 자유에너지 G.

## 2. 실험에서 먼저 확인된 사실 (설계의 전제)

- 이 환경에서 **제자리 회전은 100% 안전하다**: 공은 에이전트 칸으로 옮겨지지 않는다(`MiniGridEnv.place_obj`가 에이전트 위치를 거부, 소스 확인).
- 따라서 성공을 본 적 없는 에이전트에게 실용 항(−E ln C)만 주면 최적해는 "계속 회전"이다. 1판 스모크의 엔트로피 붕괴와 에피소드 길이 증가는 버그가 아니라 이 해에 수렴한 것이다.
- 시간 초과(256스텝)를 실패로 기록하고 있는데, 경과 시간은 관측에 없다. 에이전트의 생성 모델로는 예측할 수 없는 사건이다.

→ 탐색 항이 없으면 학습이 시작되지 않는다. 그리고 그 탐색 항은 세 모델에 같은 의미여야 한다.

## 3. 믿음 상태

b_t = (h_t, o_t). 세 모델 모두 사후분포가 (h_t, o_t)의 함수이므로 충분통계량이다. 정책·가치망 입력 = [h_t, emb(o_t)]. **[유도]**

## 4. 실용 항

g^prag_τ = −E_{Q(y_τ)}[ln C(y_τ)], 결과 y ∈ {진행, 성공, 실패}의 예측분포로 **정확히** 기댓값을 낸다.

- 선호를 결과(관측)에 두는 것: [DC20 식 15–16]의 표준 결과-선호 형태. 상태 위의 위험에서 출발한 근사이며, M0 계열에는 관측과 별개인 상태가 없으므로 결과 선호가 유일한 선택지다. **[근사, 표준]**
- **C를 격자·방향에 대해 어떻게 두는가** (이론 검토 2번):
  - (A) 기대 효용 형태: C = C(y)·균등(x, d). 그러면 격자 항은 상수이고 g^prag = −E ln C(y).
  - (B) 위험(KL) 형태: g = KL[Q(o) ‖ C] = −E ln C − H[Q(o)]. 격자 예측 엔트로피가 보너스가 된다(공의 무작위 움직임에 끌리는 noisy TV).
  - 둘 다 [DC20 식 38–39] 계열의 정당한 구성원이다. **[선택]** 제안: (A). 근거: (B)의 엔트로피 보너스는 세 모델에서 크기가 다르고(실험 2c의 예측 엔트로피 차이) 잡음원을 보상한다.
- **시간 초과의 처리** (실무 검토 0번): 에이전트의 생성 모델에 시간이 없으므로, 시간 초과는 "실패"가 아니라 관측 밖 절단으로 다룬다(결과 = 진행으로 기록하고 가치망으로 부트스트랩). **[유도: 생성 모델에 없는 사건]** 대안으로 남은 시간을 관측에 넣으면 시간 초과를 실패로 둘 수 있다.

## 5. 탐색 항

### 5.1 상태 정보 이득(salience): 주 비교에서 제외

- **원칙**: 모든 미래 관측의 예측분포를 바꾸지 않는 재매개화에 대해 G는 불변이어야 한다. (이론 검토 3번)
- 이 비교에서 M1의 s_t는 기억 h로 들어가지 않는다. 그러면 s_t는 시점마다 국소적인 잠재이고, I(s; o | h)는 같은 예측분포 P(o|h)를 놓고도 불확실성을 s와 디코더 잡음에 어떻게 나누느냐에 따라 0부터 H[P(o|h)]까지 아무 값이나 될 수 있다. **식별되지 않는 양**이다. M0-SQ의 z도 같은 이유로 제외된다.
- 결론: 세 모델 모두 salience = 0. **[유도]** 1판의 "M1에만 IG가 있다"와 "이것이 P3의 실제 모습"은 철회한다.
- M1의 salience는 절제 실험으로만 다룬다. s를 기억에 넣는 표준 RSSM 설정에서만 s가 미래로 이어지는 상태가 된다.

### 5.2 파라미터 정보 이득(novelty)

- [DC20 식 16, C.3]의 novelty: E KL[Q(A | o, s) ‖ Q(A)] — 우도 파라미터에 대한 정보 이득. salience를 제외하면 g^epi = −I(θ; o_τ | b). **[유도]**
- 1판의 IG^s + IG^θ는 결합 정보량이 아니라 중복이었다. 연쇄법칙으로는 I(s, θ; o) = I(θ; o) + E_θ I(s; o | θ)다. salience를 빼면 문제가 사라진다.
- **구현 문제**: 월드 모델 전체를 K개 두는 앙상블은 (1) 980차원 격자에서 예측 엔트로피를 표본으로 추정해야 해서 M1·M0-SQ에 분산이 크고, (2) 모델마다 ln P 추정 편향이 달라 불공정하며, (3) 구성원마다 자기 기억 h를 굴려야 해서 비싸다.
- **제안: 공통 novelty 모듈** (실무 검토 2번). 세 에이전트에 똑같이 붙는 작은 앙상블이다.
  - 입력: 원-핫 격자 x_t와 행동 a_t (월드 모델과 무관한 입력)
  - 출력: 다음 격자의 칸별 범주형 예측 K개 (K = 5)
  - 칸 독립 가정 아래 I(θ; x_{t+1}) = Σ_칸 JSD로 정확히 계산된다. 실제 버퍼로 학습한다.
  - 이것은 "월드 모델 파라미터의 novelty"를 "공통 대리 모델 파라미터의 novelty"로 **대체**한 것이다. **[근사(대체), 명시]** 대가: 에이전트 자신의 모델에 대한 정보 이득이 아니다. 이득: 탐색 항이 세 모델에서 동일해져, 행동 차이가 월드 모델 차이에서만 온다.
- 기타 **[근사]**: 앙상블은 디리클레 켤레 사후의 대용물이다. 상상 중 q(θ)를 갱신하지 않고 시점별 정보 이득을 더하면 과대 추정이다(Σ_τ I(θ; o_τ) ≥ I(θ; o_{1:T})).
- 결과 채널만의 novelty는 쓰지 않는다. 성공을 본 적 없으면 앙상블이 "성공 확률 0"에 합의해 신호가 0이다.

## 6. 수평선, 종료, 할인

- **기하분포 수평선**: 정책과 무관한 위험률 1−γ로 끝나는 생성 모델 → 기대 G = Σ γ^τ g_τ. **[근사: 정책 사후는 엄밀히 수평선별 softmax의 혼합]** 할인은 실용 항과 탐색 항에 똑같이 적용한다. γ(평균 수평선 1/(1−γ))는 **[선택]**
- **종료(성공/실패)는 흡수 상태를 해석적으로 넣는다**: 종료 시점에 ln C(y)·1/(1−γ)를 더하고 그 뒤는 마스킹한다. 월드 모델이 종료 이후를 굴리게 하지 않는다(학습한 적 없는 전이). 흡수 이후에는 novelty = 0. **[유도: 흡수 상태의 기하 합]**
- **계속 확률은 샘플 대신 P(진행)으로 가중한다**(라오-블랙웰). M0 계열은 결과를 격자와 독립으로 샘플링해서 "충돌했는데 진행" 같은 상상이 생기는데, 가중을 쓰면 이것이 줄어든다. **[추정량, 목적 불변]**

## 7. 정책과 가치

- 정책 = argmin_π KL[π(·|b) ‖ σ(−γ_π G(b, ·))] → actor 손실의 엔트로피 계수 = 1/γ_π. **[유도, M19 계열]**
- 가치망 목표(다음 상태의 값): 두 갈래가 있다. 제안은 **정교한 추론 형태** E_{a′∼π}[G(b′, a′)]이고, 이 형태는 엔트로피 항이 가치에 쌓이지 않는다. [SI21] 다른 갈래인 자유에너지 형태 −(1/γ) ln Σ exp(−γG)는 최대 엔트로피 강화학습과 같다. **[선택, 제안: 정교한 추론]** 이 선택은 "오래 살수록 엔트로피 보너스를 더 받는" 길이 선호도 막는다.
- γ_π: 고정하고 몇 값으로 훑는다. 추론은 다음 단계로 미룬다. **[선택]**
- **리턴 정규화는 쓰지 않는다**: 데이터에 의존하는 정밀도 γ/S와 같다. [DC20]의 감마 사전 갱신과 다르다. **[유도: 목적을 바꾸는 요소 제거]**
- 실용 항의 온도는 γ_π/λ_C(ln C = r/λ_C), 탐색 항의 온도는 γ_π다. 둘을 따로 보고한다.

## 8. DreamerV3에서 가져오는 것 / 가져오지 않는 것

| 기법 | 성격 | 결정 |
|---|---|---|
| 느린 목표 가치망 (EMA 0.98) | 추정량 | **넣음** (1판 구현에 빠져 있었음) |
| symlog / twohot | 추정량 | 리턴이 \|ln C\|/(1−γ) 규모로 커지면 넣음 |
| λ-리턴, 상상 수평선 15 + 부트스트랩 | 추정량 | 넣음 |
| 리턴 정규화 | 목적(정밀도)을 바꿈 | 뺌 |
| KL 균형, free bits | 월드 모델 목적 F를 바꿈 | 뺌. M1의 KL 추이를 기록 |

## 9. 비교 설계

- **주 비교**: 세 월드 모델 × 같은 목적(실용 항 (A) + 공통 novelty, salience 없음) × 같은 actor-critic·하이퍼파라미터
- **대조군**:
  1. 파이프라인 검증: 성공이 일부 포함된 데이터로 시작해(휴리스틱 정책 prefill) novelty 없이 실용 항만으로 목표를 학습하는지 확인한다. 탐색 문제와 실용 학습을 분리한다.
  2. M1 salience 절제
  3. novelty 계수(=정밀도 비율) 훑기
- 월드 모델 품질은 공통 고정 데이터셋(실험 2c 보류 집합)에서 따로 평가한다. 온라인 루프에서는 붕괴한 모델의 데이터도 빈약해지기 때문이다.
- 시드: 처음 1개, 결과 확인 후 5개 이상. 고정 평가 시드에서 확률적 정책과 탐욕 정책을 둘 다 평가한다.

## 10. 계산 비용 (목적 불변)

- 손실 계산의 기억 h를 상상 시작점에 재사용한다(지금은 한 번 더 굴림).
- `.item()` 동기화를 N 갱신마다로 줄인다.
- 갱신 빈도를 2스텝에서 4~8스텝마다로 바꾸고 배치를 키운다(재현 비율 유지).
- 월드 모델과 actor-critic 시간을 따로 잰다.

## 11. 사용자 결정이 필요한 선택

1. 실용 항의 형태: (A) 기대 효용 [제안] / (B) 위험(KL)
2. 시간 초과: 관측 밖 절단으로 처리 [제안] / 남은 시간을 관측에 추가
3. 탐색 항: 공통 novelty 모듈(대체) [제안] / 월드 모델별 앙상블
4. 가치망 목표: 정교한 추론 형태 [제안] / 자유에너지(최대 엔트로피) 형태
5. 수치: γ(할인), γ_π(정책 정밀도), λ_C(선호 정밀도), novelty 앙상블 크기 K — 처음 값을 정하고 훑기
