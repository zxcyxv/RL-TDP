## 0. 요약

TDP를 환경 시간 축에서 돌리면(`rltdp/fep/wm/tdp.py`) 토큰마다 두 종류의 흔적이 생긴다. 시냅스전(키) 흔적과 시냅스후(값) 흔적이다. 3요소 학습과 BTSP가 필요로 하는 적격 흔적이 바로 이것이다. 두 규칙은 같은 흔적을 쓰고, **결합하는 방식**만 다르다.

- **제안 A, TDP-DA (3요소)**
  - 키 흔적이 시냅스전 적격이고, 행동 토큰의 표본 편차(efference copy)가 시냅스후 신호다. 둘의 "키 선행" 쌍이 적격 흔적이 되고, TD 오차(도파민)가 그것을 장기 시냅스로 옮긴다.
  - 가소 경로에 대해 **정확한 액터-크리틱 + 적격 흔적**이 된다 [유도].
  - 조건이 맞으면 TDP의 빠른 기억 자체가 적격 흔적이다.
- **제안 B, TDP-BTSP (플래토)**
  - 키 흔적이 ET, 플래토 흔적이 IS다. 시냅스마다 ET·IS의 순간 겹침에 대한 독립적인 강화·약화 함수와 현재 가중치가 변화의 방향을 정한다.
  - 한 번의 플래토가 "사건 직전 상황의 틀"을 덮어쓴다. 결과는 사건 근접장(event field)이고, 이를 비교해 행동을 고른다.
  - 부호가 없고 지시 신호로 움직이는 한 번 학습이다.

## 1. 공통 바탕: 환경 시간 TDP의 흔적

환경 한 스텝에 블록 한 번을 돈다. 토큰 τ(칸 49개 + 방향·행동·결과), 대역 r마다 다음과 같다 [코드 rltdp/fep/wm/tdp.py].
```
E_K,r(t, τ) = z_r·E_K,r(t−1, τ) + γ_r·k̃_t(τ)        시냅스전(키) 흔적
E_V,r(t, τ) = z_r·E_V,r(t−1, τ) + γ_r·v_t(τ)        시냅스후(값) 흔적
z_r = |z_r|·e^{iθ_r} (학습),   γ_r = √(1 − |z_r|²)
```
지금 TDP는 이 흔적을 **토큰에 대해 합친 쌍선형 외적**으로 결합한다(M, STDP 이중적분). 키 선행 시차 Δ ≥ 0의 창은 l(Δ) = Σ_r γ_r Re(a_r z_r^Δ)다 [코드 tdp-reasoner sudoku/model.py:36-41].

| | 3요소 (제안 A) | BTSP (제안 B) |
|---|---|---|
| 시냅스전 흔적 | 키 흔적 E_K (그대로) | 키 흔적을 실수 극점으로 = ET |
| 시냅스후 신호 | 행동 표본 편차 u_t (부호 있음) | 플래토 p_t (0/1) → 흔적 IS |
| 결합 | 쌍 STDP 외적을 적격 흔적으로 누적 | 시냅스마다 순간 곱 ET·IS |
| 게이트 | 도파민 δ_t (부호 있음, 전역) | 플래토 자체가 지시 신호 |
| 변화의 방향 | δ의 부호 | 현재 가중치 W와 겹침의 크기 |
| 누적 방식 | 더해 간다 (점진) | 평형값으로 덮어쓴다 (한 번) |
| 배우는 것 | 정책·가치 (가소 경로) | 사건 근접장 (표상) |

## 2. 제안 A: 도파민 게이팅 TDP (TDP-DA)

### 2.1 원리
TDP의 키 흔적은 시냅스전 적격이고, 행동 토큰의 표본 편차는 시냅스후 신호다. 둘의 키 선행 쌍을 누적한 것이 적격 흔적이고, 도파민(TD 오차)이 문을 열면 그것이 장기 시냅스로 옮겨진다. 3요소 규칙의 표준 형태 Δw = η·M(t)·e(t)를 따른다(Izhikevich 2007, Frémaux & Gerstner 2016, Gerstner et al. 2018 [기억]).

### 2.2 대응
| 생물 | TDP-DA |
|---|---|
| 시냅스전 활동 | 행동 토큰의 키 k̃_t(τ_act) |
| 시냅스전 흔적(커널) | m_t = Σ_r Re(a_r E_K,r(t, τ_act)). 커널 h(Δ) = Σ_r γ_r\|z_r\|^Δ Re(a_r e^{iθ_rΔ}) |
| 시냅스후 신호 | u_t = Uᵀ(e_{a_t} − π_t): 실제로 한 행동 − 예상한 행동 (efference copy) |
| 적격 흔적 | C_t (쌍 STDP의 키 선행 반창을 감쇠 누적) |
| 도파민 | δ_t = r_{t+1} + γ·V_{t+1} − V_t |
| 장기 시냅스 | W_L (정책), w_L (가치) |

### 2.3 식 (매 환경 스텝)
```
정책:    ℓ_t = ℓ^느림(H_t) + U·W_L·m_t,      π_t = softmax(ℓ_t),     a_t ~ π_t
가치:    V_t = V^느림(H_t) + w_Lᵀ·m_t
시냅스후: u_t = Uᵀ(e_{a_t} − π_t)
적격:    C_t = (1 − η)·C_{t−1} + η·u_t m_tᵀ,     c_t = (1 − η)·c_{t−1} + η·m_t
도파민:  δ_t = r_{t+1} + γ·V_{t+1}·(1 − 종료_{t+1}) − V_t
쓰기:    W_L ← W_L + κ_π·δ_t·C_t,               w_L ← w_L + κ_V·δ_t·c_t
```
U는 가치 공간에서 행동 로짓으로 가는 고정(또는 느린) 사상이다. 같은 δ 하나가 정책과 가치를 함께 가르친다.

### 2.4 정확한 액터-크리틱이다 [유도]
∂ ln π_t(a_t)/∂W_L = Uᵀ(e_{a_t} − π_t)·m_tᵀ = u_t m_tᵀ이고, ∂V_t/∂w_L = m_t다. 따라서 2.3절의 갱신은 특징 m_t 위의 선형 정책·가치에 대한 **누적 적격 흔적을 쓰는 액터-크리틱**과 같다. 이 알고리즘은 표준이다(Sutton & Barto 2018 13장 [기억]). 대응 관계는 다음과 같다.
- γλ = 1 − η
- 학습률 = κ·η
- 특징 m_t = TDP가 만든, 학습된 커널 h로 거른 키 이력

시간 척도는 두 개로 나뉜다.
- **커널 h(대역 극점)**: 몇 스텝 전의 관측까지 지금의 결정에 쓸지 정한다. 기억의 역할이다.
- **η(적격 감쇠)**: 행동 뒤 몇 스텝 늦게 온 보상까지 그 행동의 공으로 돌릴지 정한다. 보상 지연의 역할이다.

### 2.5 TDP의 빠른 기억이 곧 적격 흔적이 되는 조건 [유도]
TDP의 bands-EMA 기억은 W^TDP ← (1 − η)W^TDP + η·S_t, S_t = Σ_r Re(a_r v_tᵀE_K,r + b_r D_V,rᵀk̃_t)다 [코드 tdp-reasoner arc/model.py:13-14]. 다음 세 조건에서 S_t = u_t m_tᵀ이므로 **W^TDP_t = C_t**다.
1. 전용 헤드에서 행동 토큰의 값 v_t를 표본 편차 u_t로 둔다.
2. b_r = 0으로 둔다. 키가 앞선 쌍만 남기는 것이다. 값이 앞선 쌍은 정책 기울기에 대응하지 않는다.
3. S를 행동 토큰에서만 모은다.

그러니 3요소 학습에 새로 필요한 것은 장기 시냅스 W_L 하나뿐이다. 도파민은 "TDP의 단기 기억 → 장기 시냅스" 복사 문이다: W_L ← W_L + κ·δ_t·W^TDP_t.

band_product 형태(a = c̄, b = c로 묶임)에서는 값 선행 반창을 끌 수 없다. 그래서 이 대응에는 bands 형태가 필요하다. 덧붙여 실수 극점 대역 하나의 곱 기억에서는 쌍 (s ≤ t)의 가중치가 |z|^{2(n−t)}·|z|^{t−s}로 분해된다. 이것은 적격 감쇠 γλ = |z|²와 기억 커널 |z|^Δ가 한 극점에 묶인 액터-크리틱의 키 선행 부분과 같다. 복소 극점이어도 위상은 시차에만 의존하므로 같은 분해가 성립한다.

### 2.6 tdp-reasoner의 `three_factor`와 다른 점
기존 구현: W̃_n = (1−η)W̃_{n−1} + ηS_n + ηβδ_n C_{n−1}, C_n = λC_{n−1} + (1−λ)S_n. δ는 칸별 비용 예측 Ĉ와 가치 V로 만든 재귀 축의 TD 오차다 [코드 tdp-reasoner sudoku/model.py:983-1013, 1304-1327].

TDP-DA가 바꾸는 것은 다음과 같다.
1. **축**: 재귀 깊이 대신 환경 시간을 쓴다. δ는 환경 보상의 TD 오차다.
2. **시냅스후 신호**: 상태 투영 v 대신 행동 표본 편차 u를 쓴다. 기존의 잡음 섭동 판(`tf_elig_noise`)이 연속 출력에서 하던 일을 이산 행동에서 한다.
3. **창**: 키 선행 반창만 쓴다(b = 0).
4. **장기 시냅스 분리**: 기존 구현에서는 도파민이 쓴 내용이 작업 기억 W̃와 같은 속도(1 − η)로 사라진다. 강화된 변화는 오래 남아야 하므로 W_L을 따로 두고, 감쇠는 없거나 매우 느리게 둔다.

### 2.7 느린 가중치와의 분업
두 방식이 있다.
- **(권장) 규칙이 강화학습을 전담한다.**
  - 느린 가중치(투영, 극점 z_r, 계수 a_r, U, 디코더)는 다음 관측 예측으로 학습한다. 이미 구현한 M0-SQ-T의 손실을 그대로 쓸 수 있다.
  - 정책과 가치는 W_L, w_L의 3요소 쓰기로만 배운다. 강화학습 목적이 역전파로 흐르지 않는다. 이 모드에서는 2.3절의 ℓ^느림 ≡ 0, V^느림 ≡ V_0(상수, 2.8절의 낙관적 초기값)로 둔다.
  - 표상은 예측으로, 행동은 도파민으로 배운다는 분업이다. 피질과 기저핵의 분업에 대응한다.
- **(무거움) 메타 학습.** 에피소드를 가로질러 역전파해서 η, κ, 극점까지 학습한다(Miconi et al. 2019 Backpropamine 계열 [기억]).

### 2.8 탐색
- 시냅스후 신호 u_t 자체가 탐색의 흔적이다. 확률적 정책에서 뽑은 행동과 기대의 차이다.
- 낙관적 가치 초기값(V^느림의 편향 > 0)을 두면, 보상 없는 스텝마다 δ < 0(도파민 감소)이 되어 방금 한 행동이 억제된다. 반복 행동(회전 고착)을 완화하는 방향이지만, 충돌 벌점이 크면 회전이 여전히 가장 덜 나쁜 선택일 수 있다. 해결이 아니라 완화다.

### 2.9 위험
- 고정된(예측으로 학습한) 특징 위의 선형 액터-크리틱은 표현력이 제한된다.
- 느린 가중치가 변하면 m_t의 의미가 바뀌어 W_L이 낡는다. 두 학습률의 분리가 필요하다.
- 보상 지연이 길면(수백 스텝) η를 아주 작게 둬야 하고, 분산이 커진다.
- δ의 크기 정규화가 필요하다. 기존 `tf_unit_scale`처럼 RMS로 나누는 방식이 있다.

## 3. 제안 B: 플래토 게이팅 TDP (TDP-BTSP)

### 3.1 원리
키 흔적이 ET, 플래토 흔적이 IS다. 시냅스마다 둘의 순간 겹침 ET·IS에 대해 독립적인 강화 함수와 약화 함수가 작동하고, 변화의 방향은 현재 가중치가 정한다. 그래서 한 번의 플래토가 그 단위의 시냅스를 "플래토 직전(과 직후) 상황의 틀"로 덮어쓴다.

### 3.2 BTSP 규칙 [확인: Milstein et al. 2021, eLife 10:e73046, 식 1과 맞춤값]
```
dW/dt = (W_max − W)·k₊·q₊(ET·IS) − W·k₋·q₋(ET·IS)
τ_ET·dET/dt = −ET + λ_ET·R(t)        시냅스전 발화율 R의 누설 적분
τ_IS·dIS/dt = −IS + plateau(t)        이진 플래토 신호의 누설 적분
```
- q₊, q₋는 순간 곱 ET·IS의 시그모이드다(적분하지 않는다).
- 맞춤값: τ_ET ≈ 0.86초, τ_IS ≈ 0.54초, k₊ ≈ 2.27/초, k₋ ≈ 0.33/초, W_max ≈ 4.0.
- 문턱과 기울기: q₊는 α₊ ≈ 0.24, β₊ ≈ 30이고, q₋는 α₋ ≈ 0.09, β₋ ≈ 2260이다. 약화가 더 낮은 문턱에서 계단처럼 켜진다.
- 핵심 관찰: 변화의 방향은 쌍 상관이 아니라 현재 가중치가 정한다. 약한 입력은 강화되고, 강한 입력은 약화된다.

### 3.3 대응
| 생물 | TDP-BTSP |
|---|---|
| 시냅스전 발화율 R | x_t(τ) = softplus(W_x·H_t(τ)) ≥ 0, 토큰별 |
| ET | 키 흔적을 실수 극점 ρ_ET로: ET_t = ρ_ET·ET_{t−1} + (1 − ρ_ET)·x_t (토큰·차원별) |
| 플래토 | p_t ∈ {0,1}^N: 사건 i에 배정된 시냅스후 단위의 플래토 |
| IS | 값 흔적 자리, 값 = 플래토: IS_t = ρ_IS·IS_{t−1} + (1 − ρ_IS)·p_t |
| 시냅스 | W ∈ [0, W_max]^{N × (토큰·차원)}. 토큰에 대해 합치지 않는다 |

TDP의 흔적 기계는 그대로 쓰고, 결합만 바뀐다. M처럼 토큰에 대해 합친 쌍선형 외적이 아니라, **시냅스마다의 순간 곱 + 비선형 + 가중치 의존**이다.

### 3.4 식 (매 환경 스텝, Δt = 1)
```
Ω_t = IS_t ⊗ ET_t                                            시냅스별 겹침
W   ← W + k₊·(W_max − W) ⊙ q₊(Ω_t) − k₋·W ⊙ q₋(Ω_t)
q±(Ω) = 0에서 0이 되도록 옮기고 정규화한 시그모이드, 문턱 α± · 기울기 β± (독립)
y_t = W·x_t                                                   사건 근접장의 활동 (시냅스후 단위 N개)
```

### 3.5 무엇을 계산하는가 [유도]
**순간 평형.** 같은 겹침 Ω가 유지되면 W는 다음 값으로 간다.
```
W_eq(Ω) = W_max·k₊q₊(Ω) / (k₊q₊(Ω) + k₋q₋(Ω))
```
세 영역이 생긴다.
- Ω < α₋: 변화 없음.
- α₋ < Ω < α₊: 약화. W_eq가 작아서 기존에 강했던 시냅스가 깎인다.
- Ω > α₊: 강화. W_eq ≈ W_max·k₊/(k₊ + k₋), 맞춤값으로 약 3.5.

방향은 "현재 W가 W_eq(Ω)보다 큰가 작은가"로 정해진다. 약한 입력이 강화되고 강한 입력이 약화된다는 관찰과 맞는다.

**한 번의 플래토 = 틀 덮어쓰기.** 시점 t_p의 플래토 하나가 지나간 뒤를 보자.
- 플래토 직전 약 τ_ET(그리고 직후 약 τ_IS) 안에 활동한 입력은 강화 영역에 들어간다.
- 그보다 오래전에 활동해 겹침이 약한 입력 가운데 기존에 강했던 것은 약화된다.
- 활동이 없던 입력은 그대로다.

그래서 단위 i의 시냅스는 "사건 직전 상황"의 틀로 다시 쓰이고, y_i(x) = W_i·x는 지금 상황이 그 틀과 얼마나 닮았는지를 낸다. 이것이 사건 근접장이다. 누적되지 않고 덮어쓰기라서, 사건 위치가 바뀌면 한 번에 다시 매핑된다.

**강화학습으로 읽으면.** 겹침이 작은 선형 영역(q₊가 지배하는 영역)에서는 다음과 같이 근사된다.
```
y_i(x) ≈ k₊W_max·Σ_s κ(t_p − s)·x_sᵀx,     κ(Δ) ≈ e^{−Δ/τ_ET} (Δ > 0, 사건 이전)
```
사건 i에 대한 **한 번짜리 커널 몬테카를로 가치**이고, 할인율은 γ = e^{−1/τ_ET}이다. 실제 맞춤값의 가파른 문턱에서는 이보다 이진 틀에 가깝다. 할인된 합이 아니라 포화된 "곧 사건" 검출기가 된다.

### 3.6 플래토의 출처
- 결과 사건마다 시냅스후 집단을 배정한다.
  - 목표 집단 G: 성공 시점에 플래토가 난다.
  - 위험 집단 D: 실패(충돌, 틀린 물체) 시점에 플래토가 난다.
- CA1처럼 플래토를 확률적으로 띄울 수 있다. 사건 시점에 확률 π_p로 띄우고, 새로운 환경에서 확률을 높이는 식이다. CA1에서는 내후각피질 3층의 입력이 플래토를 이끌고 보상 위치를 과다 표상하게 만든다고 보고되었다(Bittner et al. 2017, Grienberger & Magee 2022 [기억]).
- 3요소와 달리 부호가 없다. 위험은 위험 집단의 장으로 따로 학습된다.

### 3.7 행동 선택
시냅스전 입력에는 행동 토큰이 들어 있다. 이 TDP에서 행동 토큰은 직전 행동을 담으므로, 후보 행동 a의 평가는 다음 스텝의 주입 (o_t, a)로 블록을 한 번 통과해 얻은 입력 x_{t+1}(a)로 한다. 다음 관측을 예측하지는 않는다. 플래토 시점의 입력에도 사건 직전의 행동이 담기므로, 장은 "이 상황에서 이 행동"의 근접도를 낸다.
```
π(a | H_t) ∝ exp( β·[ Σ_{i∈G} y_i(x_{t+1}(a)) − λ_D·Σ_{i∈D} y_i(x_{t+1}(a)) ] )
```
행동이 3개면 블록 3번 통과로 끝난다. 월드 모델의 예측은 쓰지 않는다. 대신 느린 정책 머리가 y를 읽게 해도 된다.

### 3.8 지평 연장: 연쇄 플래토 [가설]
한 번의 플래토는 약 τ_ET 스텝 앞까지만 장을 만든다. 더 먼 지평으로 넓히는 방법은 이렇다.
- 사건이 없더라도 근접장이 이미 강하게 활동하면(y_i(t) > θ) 낮은 확률로 플래토를 띄운다.
- 그러면 에피소드를 거듭할수록 장이 뒤쪽(사건에서 더 먼 상황)으로 자란다. TD의 부트스트랩에 해당한다.
- W_max와 약화 문턱이 무한 성장을 막는다.

다만 자기 강화로 장이 퍼지거나 떠다닐 수 있다. 안정성은 확인해야 한다.

### 3.9 위험
- 이진에 가까운 틀이라 "얼마나 가까운가"의 해상도가 낮다.
- 덮어쓰기라서 확률적 사건(공이 무작위로 움직이는 환경)에서는 장이 마지막 사건에 과적합하고 흔들린다.
- 생물학적 시간 상수(초 단위)를 환경 스텝으로 옮기는 비율은 정해져 있지 않다. 학습하거나 훑어야 한다.
- 행동 선택은 사건장의 질에 달려 있다. 성공 사건이 한 번도 없으면 목표 장이 없다. 탐색 문제는 그대로 남는다.

## 4. 두 제안의 비교와 결합

| | TDP-DA (3요소) | TDP-BTSP |
|---|---|---|
| 학습 신호 | 부호 있는 TD 오차 (전역) | 부호 없는 플래토 (단위별, 지시) |
| 학습 속도 | 점진적 | 한 번 |
| 안정화 | 학습률·감쇠 | 가중치 의존 + W_max |
| 정확한 대응 | 선형 특징 위의 액터-크리틱 + 적격 흔적 | 겹침이 작으면 커널 몬테카를로 사건 가치 |
| 탐색 | 표본 편차 + 낙관적 가치 | 없음 (사건이 일어나야 배움) |
| TDP 흔적의 결합 | 토큰 합 외적 (키 선행 반창) | 시냅스별 순간 곱 + 비선형 |

두 제안은 서로를 보완한다. BTSP가 한 번에 사건 근접장(표상)을 만들고, 3요소가 그 장 위에서 정책을 다듬는 결합이 자연스럽다. 해마와 선조체의 분업에 대응한다. 결합은 각각을 확인한 뒤에 다룬다.

## 5. 최소 첫 실험 (설명만)

- **A0 (수치 확인)**: 2.4절과 2.5절의 동치를 작은 예시로 확인한다. TDP 흔적으로 만든 C_t와 액터-크리틱의 적격 흔적이 같은지 본다.
- **A1**: Dynamic-Obstacles에서 다음을 비교한다.
  - 느린 가중치는 예측으로, 강화학습은 W_L만으로 학습하는 TDP-DA
  - 기존 dv3 에이전트
  - 측정: 탈출 여부와 탈출 시점, 커널 h를 끈 판(η만 남김)과의 차이
- **B1 (한 번 학습)**: MemoryS13의 스크립트 에피소드에서 성공 플래토 한 번이 직전 약 τ_ET 스텝을 덮는 목표 장을 만드는지 본다. 장의 활동을 남은 스텝 수의 함수로 그린다.
- **B2 (연쇄)**: 에피소드 수에 따라 장이 어디까지 넓어지는지 본다.
- **B3 (다시 매핑)**: Dynamic-Obstacles에서 충돌 플래토로 위험 장을 만들고, 공이 움직일 때 장이 얼마나 빨리 다시 매핑되는지와 충돌률이 줄어드는지 본다.

## 6. 열린 결정

1. 환경 스텝 대 시간 상수의 비율. τ_ET, τ_IS, η를 몇 스텝으로 둘지 정한다.
2. 시냅스전 특징: TDP의 키를 그대로 쓸지, 별도 투영(softplus)을 둘지 정한다. BTSP는 음이 아닌 발화율이 필요하다.
3. 느린 가중치의 학습 신호: 예측(권장)으로 할지 메타 학습으로 할지 정한다.
4. BTSP 사건 집단의 크기, 플래토 확률, 연쇄 문턱 θ.
5. A의 U(가치 공간 → 행동 로짓)를 고정할지 느리게 학습할지 정한다.
