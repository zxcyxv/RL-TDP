# 계열 2 (btsp): TDP + BTSP 에이전트 결과 정리 — 정리됨

환경: MiniGrid-LavaGapS5-v0 (5×5, 용암 벽에 틈 하나, 성공 +1, 용암 −1, 시간 초과 0). CPU, 시드 0 하나씩.
제안 배경: `tdp_plasticity_rl.md` (B. TDP-BTSP), `m1_tdp_btsp_design.md`. 재현: `scripts/btsp/run.sh`.

## 1. 소형 BTSP 에이전트 (`rltdp/btsp/tiny.py`, `analyze_tiny.py`)

Milstein et al. 2021의 문턱 규칙 (가중치 의존 양방향, 행동 × 3×3 국소 시냅스 전 입력).
무작위 정책 성공 0.06~0.16, 가치 기준선 약 0.20, BTSP 2k 스텝 0.44 후 0.20으로 하락.
장 해석: 목표·위험 장(G, D)이 모든 자세에서 0.7~0.8로 포화, 플래토가 사건보다 훨씬 많이 남. 문턱·포화 문제를 땜질하지 않고
구조를 델타 규칙으로 바꿈.

## 2. 플래토 게이팅 델타 규칙 W + 순환 DQN (`rltdp/btsp/delta.py`, `analyze_delta.py`)

W ← W + β p_t (1/T) Σ_τ (v* − W ê_τ) ê_τᵀ (TDP 키 흔적 ê, 성공·실패 사건에서만, 0 < β < 2에서 유계). Q는 DQN 머리가 읽음.

| 스텝 | 2k | 3k | 4k | 5k | 6k | 7k | 10k |
|---|---|---|---|---|---|---|---|
| 플래토 성공 | 0.12 | 0.16 | 0.14 | 0.14 | 0.40 | 1.00 | 0.92 |
| 게이트 끔 (= DQN) 성공 | 0.32 | 0.46 | 0.68 | 0.60 | 0.96 | 1.00 | 0.96 |

장 해석: 장(성공 − 실패 투영)이 모든 자세에서 양수이고 목표까지 거리에 평평 (+1.22 안팎), ΔQ = Q_W − Q_0 ≈ 0.02~0.04.
W는 "어떤 키든 성공"이라는 상수 사상이 되었고 DQN이 그것을 무시했다. 원인 (설계 실수): DQN을 비교군이 아니라 뼈대로 둠,
W가 에피소드를 넘어 옵티마이저 스텝을 가로지르는 상태라 표류하고 경사를 받지 못함, 과제가 기억을 요구하지 않음.

## 3. BTSP로 구현한 DQN (`rltdp/btsp/replay.py`, `analyze_replay.py`)

Q-net = TDP 블록 θ (역전파) + 출력층 W (델타 규칙). 재현 = 에피소드 단위 해마 재생 (방금 에피소드는 역순), 벨만 목표로 W에 쓰고
같은 TD 오차로 θ를 학습.

- v1 (지각 블록·목표망 없음): 델타·Adam 모두 실패 (성공 0.02 / 0.04, 제자리 회전 → 시간 초과).
  델타: φ(키 흔적을 이어 붙인 것)가 거의 평행 (쌍 코사인 0.79, 유효 차원 8/1664) → β = 1 쓰기가 Kaczmarz 꼴로 폭주
  (‖W‖ 521, 손실 34) → max 편향이 1/(1−γ)로 누적되어 Q ≈ +4에 정착. Adam: 재생이 에피소드 끝에만 있어 업데이트 188번 (DQN 2,108번).
- v2 (TDP 앞에 같은 스텝 softmax 어텐션 + FFN 지각 블록, EMA 목표망 τ = 0.05, Double Q, 재생 일정은 그대로): 델타 1만 스텝 성공 0.94.
  장 해석: Q 대 가치 반복 Q* 상관 0.94, 용암 앞 전진 Q −0.92 (참 −1), 목표 앞 +1.06 (참 +1), 거리에 따라 단조 감소,
  탐욕 정책이 무작위 배치 100개에서 성공 1.00, 평균 6.10스텝 = 최단 경로. Adam 대조는 돌리지 않음.

## 결론

기존 DQN 변형 (NEC, LS-DQN, EBU)을 넘는 기여가 없다. 고정 특징 위에서 델타 규칙은 선형 회귀 / 선형 TD(λ)와 같고,
‖φ‖ = 1일 때 델타 규칙은 학습률 β의 SGD와 식이 같다. 이 계열은 정리하고, 질문을 "지속 기억의 관리"로 바꿔 계열 3(icrl)으로 넘어갔다.
