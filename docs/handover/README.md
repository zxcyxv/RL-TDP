## 한 줄 요약

확률적 상태와 관측 사이를 가역·결정론적으로 두면 F = 정확한 −ln p(추론 간극 A = 0)가 된다. 조건부 정규화 흐름 월드 모델 **M0**와 RSSM-VAE **M1**을 "다음 관측의 밀도를 만드는 방식"만 다르게 두고 비교해서, 이 차이가 선택·학습·탐색에 남기는 흔적을 보인다. 성공률 우위는 주장하지 않는다.

## 작업 순서 (2단계 문서 기준)

0. 1단계 7절 검증 항목(V1–V15)을 작은 수치 예시로 확인한다
1. **실험 1**: 고리 vs 가우시안 밴딧 (M0, M1-a, M1-b, IWAE k = 1/5/50, 시드 ≥ 5)
2. **실험 2a** 단계 0: 환경 래퍼, 원-핫, 렌더러, 스크립트 정책, 데이터 수집 (보류 100개 + 학습 1,000개)
3. 단계 1: 흐름과 들어 올림 단위 테스트
4. 단계 2: 고정 데이터 학습 → 그림 2·3, 구간별 간극 표, 비용 표
5. (2a 결과를 본 뒤 결정) **실험 2b** 단계 3–5: 참 시뮬레이터로 계획기 점검 → 온라인 학습 → 그림 1

앞 단계의 완료 기준을 만족하기 전에는 다음 단계로 넘어가지 않는다. 한 모델을 위해 바꾼 설정은 다른 모델에도 똑같이 적용하고, 그 사실을 기록한다.
