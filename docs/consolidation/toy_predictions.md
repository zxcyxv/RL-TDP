# 공고화 토이: 사전 예측 (실행 전 고정, 2026-11-16)

코드: `rltdp/consolidation/toy.py` (numpy). 배경과 문헌: [`README.md`](README.md).

## 묻는 것

빠른 시냅스 (칼만, 용량 d)가 느린 저장소 (선형, 작은 학습률, 용량 D)의 잔차만 쓸 때,
1. 잔차를 **쓰는 순간의 느린 모델** 기준으로 굳히면 (naive), 느린 쪽이 같은 내용을 배우는 순간 이중 계산이 생기는가.
2. 잔차를 **현재 느린 모델** 기준으로 유지하면 (cr: 교차 통계 C = Σ λ^Δ φ zᵀ / R를 같이 들고 G = G_y − S C), 재생으로 느린 쪽에 옮겨도 합친 믿음이 유지되고 빠른 쪽이 비는가.
3. 재생 목표를 날것의 관측 (DQN식)이 아니라 지금의 믿음 (Sφ + Mz)으로 하면, 값이 바뀐 항목에서 차이가 나는가.

## 설정 (기본값)

d = 32, D = 128, 값 차원 m = 8. A 항목 32개, 그다음 B 항목 32개, 각 3번씩 섞어 제시 (모두 192스텝). λ = 0.98, p0 = 1, R = 0.01, η = 0.05.
재생: 16스텝마다, 본 항목 전부를 5번 훑음. 독립 시행 64개 평균. 지표: 상대 제곱 오차 (‖예측 − 값‖² / ‖값‖²), B 끝 시점.

## 예측

| | 예측 |
|---|---|
| P1 | fast만: A ≥ 0.5 (B가 A를 덮음), B ≤ 0.3 |
| P2 | slow만: A, B 모두 0.6–0.85 (3번 제시, η = 0.05) |
| P3 | 재생 없이는 naive와 cr의 차이 < 0.05 (두 군 모두) |
| P4 | naive+replay의 B가 cr+replay보다 0.1 이상 나쁨 (이중 계산) |
| P5 | cr+replay: A ≤ 0.4, 느린 쪽만 읽은 A ≤ 0.4 (옮겨짐). B ≤ fast의 B + 0.05. B 항목의 빠른 몫 크기가 cr보다 작음 (용량이 빔) |
| P6 | cr_total (느린 쪽이 전체 오차로 배움): 느린 쪽만 읽은 A가 cr보다 좋지 않음 (빠른 쪽이 설명해 버려 느린 쪽이 굶음) |
| P7 | `--change` (A의 절반이 첫 제시 뒤 값이 바뀜): raw+replay의 A가 cr+replay보다 0.05 이상 나쁨 |

실패 기준: cr+replay의 A가 fast의 A보다 0.2 이상 좋지 않으면, 이 설정에서 "현재 느린 모델 기준 잔차 + 믿음 재생"으로 공고화된다는 주장은 기각.
