# 실험 2d 설계: 상상 속 actor-critic으로 기대 자유에너지 최소화

작성 2026-11-08. 인수인계서 2b(CEM 계획기)를 대체한다. 사용자 결정.

## 왜 바꾸나

- CEM은 매 스텝 상상 10만 프레임을 새로 계산하고, 수평선(20) 너머를 보지 못한다. Craftax처럼 행동이 많고 긴 과제로 확장하기 어렵다.
- 상상 속 actor-critic(DreamerV3 계열)은 행동 시 정책망 1회 통과로 끝나고, 가치망이 수평선 너머를 부트스트랩한다. DreamerV3는 고정 하이퍼파라미터로 Crafter·Minecraft를 학습했다고 보고한다.
- 능동적 추론과의 관계: 스텝 보상을 −G(π, τ) = ln C(o_τ) + IG_τ로 두면 정책이 최대화하는 누적 보상이 −G다(위험 + 모호성 = −실용 가치 − 정보 이득, 1단계 V12). 행동 선택 Q(π) = σ(−G)를 가치망·정책망으로 상각 근사한 것이다(Millidge 2019의 EFE 부트스트랩). 원 이산 정식화의 열린 루프 행동열 대신 닫힌 루프 정책을 평가한다. 정책 사전분포(습관)와 정밀도 추론은 생략한다.

## 구성

- 환경: MiniGrid-Dynamic-Obstacles-8x8-v0 (실험 2c와 같음)
- 월드 모델: M0F-S, M0-SQ, M1-S (실험 2c와 같은 코드·설정). 온라인으로 처음부터 학습
- 정책·가치 입력: f_t = [h_t, emb(o_t)] (현재 관측을 본 뒤의 상태). 세 모델에 공통
- 정책: MLP 2층 × 256 → 행동 3개 범주분포. 가치: MLP 2층 × 256 → 스칼라
- 상상: 버퍼에서 뽑은 실제 상태에서 출발, 수평선 15
  - a_k ~ π(f_k) → h_{k+1} = GRU(h_k, [emb(o_k), a_k]) → 월드 모델이 ô_{k+1} 샘플 → 보상
  - 결과가 성공/실패로 샘플되면 그 상상은 종료(이후 스텝 가중치 0)
- 스텝 보상 r = Σ_y P(y | ·) ln C(y) + β · IG
  - ln C: 성공 +1, 실패 −1, 진행 0 (환경 보상의 부호와 맞춤. 시간 항은 상상에서 알 수 없어 뺐다)
  - IG (모델별, 인수인계서 정의를 따름)
    - M1-S: KL[q(s | h, emb(ô)) ‖ p(s | h)] — 숨은 상태에 대한 정보 이득
    - M0-SQ: −ln p(v | h) + ln q(v | x̂), v ~ p(v | h), x̂ = argmax(v) — 이산 예측 엔트로피의 샘플 추정(하한)
    - M0F-S: −ln P(x̂ | h), x̂ ~ P(x | h) — 이산 예측 엔트로피의 샘플 추정
    - 세 경우 모두 격자 관측에 대해서만 계산한다
- actor-critic (DreamerV3 단순판): γ = 0.985, λ = 0.95, λ-리턴. 리턴 정규화는 리턴의 5~95 백분위 범위(EMA 0.99, 최소 1). 정책은 REINFORCE + 엔트로피 3×10⁻⁴. 학습률 3×10⁻⁵(정책·가치), Adam, 클리핑 100. 정책 기울기는 월드 모델로 흐르지 않는다
- 온라인 루프: 무작위 정책 100 에피소드로 버퍼 시작 → 환경 2스텝마다 갱신 1회(월드 모델 배치 32×32 + 상상 시작점 256개). 환경 스텝 총량은 스모크 후 정한다

## 조건

- β = 0 (실용 항만): 월드 모델의 질이 행동에 주는 영향
- β = 1: 정보 이득의 영향. 1단계 5.3절 예측: 잠재가 없는 모델(M0F-S, M0-SQ)의 IG는 예측 엔트로피라서 무작위로 움직이는 공(잡음원)에 끌릴 수 있다. M1-S의 IG는 숨은 상태에 대한 정보라 덜 끌릴 것으로 예상한다

## 측정

- 성공률, 충돌률, 에피소드 길이 (최근 50 에피소드 이동 평균)
- 상상 보상의 두 항 크기, 정책 엔트로피
- 월드 모델 F (학습 배치)
