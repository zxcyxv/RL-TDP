# 실험 2f 설계: 선호분포 C + 기대 자유에너지 G (ActorCriticKL + 공통 novelty)

작성 2026-11-10. 구현만 해 둔 상태이고, 아직 실행하지 않았다. 표기: **[유도]**, **[근사]**, **[선택]**은 설계 2판과 같다.

## 무엇이 새로운가

`ActorCriticKL`(`fepoc/agent/ac.py`)은 이미 설계 2판 6·7절의 G 형태(흡수 종료, KL 정책, 정교한 추론형 가치)이고, 결과 채널의 선호도 흡수 종료 덕분에 상수 차이로 정확하다. `ActorCriticEFE`(`fepoc/agent/efe.py`)는 이것을 상속하고 두 가지를 더한다.

1. **선호분포를 명시한다 (부수 정리)**: C(y) = softmax(c/λ_C), y ∈ {진행, 성공, 실패}, 격자·방향은 균등. 진행 스텝마다 ln C(진행)을 더한다(ActorCriticKL은 ln C(진행) = 0을 가정하고 뺐다). 흡수 종료에서는 ln C 전체에 상수를 더하면 모든 Q가 같은 양만큼 움직이므로, **기본값(c = [0, 1, −1], λ_C = 1)이고 β = 0이면 ActorCriticKL과 같은 목적이다.** c(진행) ≠ 0을 줄 때만 결과가 달라진다. **[유도]**
2. **탐색 항: 공통 novelty (실질적인 차이)**: 설계 2판 5.2절의 제안. β·I(θ; x_{t+1} | x_t, a)를 Q에 더한다. **[근사(대체)]**

M0-SQ 쪽 코드는 바꾸지 않았다. M0-SQ는 결과 확률 P(y | b, a)(범주형 머리, 정확)와 다음 관측 샘플(V̄(b′)의 입력)을 공급한다.

## Q의 식 (−G 단위)

```
Q(b, a) = Σ_{y 종료} P(y | b, a)·ln C(y)/(1−γ) + P(진행 | b, a)·[ln C(진행) + γ·V̄(b′)] + β·I(θ; x_{t+1} | x_t, a)
정책: min KL[π(·|b) ‖ softmax(Q(b,·)/α)],  α = --ent = 1/γ_π
가치: V(b) ← E_{a∼π}[Q(b, a)]
```

## 공통 novelty 모듈 (`fepoc/agent/novelty.py`)

- 앙상블 K = 5. 멤버 입력은 실제 격자 원-핫 x_t와 행동 a_t(월드 모델과 무관), 출력은 다음 격자의 칸별·속성 묶음별 범주형. 구조: 국소 3×3 합성곱 2층 + 전역 경로(회전하면 칸이 시야 반대편으로 옮겨 가므로) + 출력 합성곱 2층
- 학습: 월드 모델과 같은 재현 배치의 (x_t, a_t) → x_{t+1} 쌍, Adam 3e-4, 클리핑 100. 멤버는 초기화만 다르다(부트스트랩 없음) **[선택]**
- 정보 이득 추정 (θ는 멤버 위의 균등 분포):
  - `joint` (기본): I(θ; x) = E_k E_{x∼p_k}[ln p_k(x) − ln p̄(x)]의 몬테카를로. 멤버별 로그밀도가 정확해서 불편이고, 값은 [0, ln K] 안에 있다
  - `cellsum`: Σ_칸 Σ_묶음 JSD. 닫힌 식이지만 결합 정보량의 **상한**이다(H[p̄(x)] ≤ Σ_칸 H[p̄(x_칸)]). 설계 2판 5.2절의 "칸 독립 가정 아래 Σ_칸 JSD로 정확히 계산된다"는 정확히는 이 상한이다
- 기타 근사: 앙상블 = 파라미터 사후의 대용물. 한 스텝 정보 이득만 직접 계산하고 이후는 가치망이 부트스트랩한다. 상상 중 q(θ)를 갱신하지 않는다 **[근사]**

## 열린 선택 (실행 전에 정할 것)

- **α (`--ent`)**: run.py 기본값 3e-4를 그대로 쓴다. Q의 크기(성공과 실패의 차이 약 133)에 비해 매우 작아 정책이 거의 탐욕적이다. 이때 탐색은 novelty 항으로만 생긴다. 훑기 후보
- **β, λ_C, K**: 처음 값 1, 1, 5. joint 정보 이득은 스텝당 최대 ln 5 ≈ 1.6 nats이고, 기하 합으로 최대 약 107까지 쌓인다(성공 항 66.7과 비슷한 규모)
- 사전 예측 문서(실험 2c·2e처럼)는 아직 쓰지 않았다

## 확인한 것 / 하지 않은 것

- `tests/test_efe_agent.py`: 선호 정규화와 상수 불변, ActorCriticKL과의 상수 차이 동치, joint 추정 = 열거한 정확값, 0 ≤ I ≤ ln K, cellsum ≥ joint, 같은 멤버면 0, β = 0일 때 초기값이 ActorCriticKL과 같음. 전체 테스트 34개 통과(CPU)
- CPU(4코어) 측정: novelty 없는 ActorCriticKL 경로에서 M0-SQ 갱신 1회 1.06초(월드 모델 0.89 + actor-critic 0.17). novelty 포함 시간과 GPU 시간은 재지 않았다
- 스모크 실행은 하지 않았다(중간에 중단). 첫 GPU 실행에서 `--env_steps 3000` 정도로 먼저 확인하기를 권한다
