# R1 사전 예측 (실행 전에 고정)

작성: 2026-11-14. 이 문서는 학습을 한 번도 돌리기 전에 썼다. 결과는 `r1_results.md`에 따로 적고, 이 문서는 고치지 않는다.

## 0. 인수인계서의 R1에서 바꾼 것과 이유

- **칼만 쓰기 자체는 주장하지 않는다.** Kalman Delta Networks (arXiv:2609.07816), Gated KalmaNet (arXiv:2511.21016),
  Kalman Linear Attention (arXiv:2602.10743)이 이미 다뤘다. KDN을 비교군에 넣는다.
- **주장할 것은 정밀도 추론이다.** 기존 모델은 관측 잡음 σ²와 변동성 Q를 현재 토큰에서 예측한다 (사전만 있음).
  우리는 같은 자유에너지에서 σ²를 키별 오차 이력으로 추론하고 (사후), 그 σ²로 정규화한 증거로 변화를 감지한다.
- **관련성은 이 단계에서 뺀다.** MQAR에서는 질의 전에 관련성을 알 수 없다. "읽힘으로 굳히기" (조건 D)는 A~C 뒤에 따로 붙인다.
- **과제는 용량 이하 영역으로 둔다.** 키가 반복해 나오고 키마다 신뢰도가 다른 흐름이다. 용량 초과 영역 (회상 거리)은
  망각 없이는 어떤 칼만 쓰기도 성립하지 않으므로 (정상성 가정이 깨짐) 관련성과 함께 뒤로 미룬다.
- 실행 규모: 시드 1개, 학습 모델 4개 (GDN, KDN, ours, ours_fix)를 한 묶음으로 돌린다. 시드가 하나라 작은 차이는 읽지 않는다 (2절의 문턱).

## 1. 과제

한 흐름마다 키 어휘 128개 중 K = 8개를 뽑는다. 매 스텝 그중 하나가 (키, 관측값) 토큰으로 들어온다. 값 어휘는 64개.

- 키마다 오염률 η가 있다: 절반은 0 (믿을 만한 키), 절반은 η_hi (못 믿을 키). 어느 키가 어느 쪽인지는 흐름마다 무작위라서
  토큰만 보고는 알 수 없다. 오염되면 관측값이 무작위 값으로 바뀐다.
- 키의 참값은 단서 없이 바뀔 수 있다 (자기 관측 한 번당 확률 hz).
- 질의: 매 스텝 쓰기 뒤에 흐름의 키 8개를 모두 읽어 현재 참값을 맞힌다 (읽기는 상태를 바꾸지 않는다).
  값이 바뀐 뒤 한 번도 다시 관측되지 않은 키는 채점에서 뺀다.

| 조건 | η_hi | hz | 시험하는 것 |
|---|---|---|---|
| A | 0 | 0 | 표준 연상 회상. 구현 검증 |
| B | 0.4 | 0 | 잡음 평균 (신뢰도) |
| C | 0.4 | 1/16 | 변화와 잡음의 구별 |

학습 길이 256, 배치 128. 평가는 길이 256과 8,192 (32배), 같은 고정 시드 흐름.
상한: 키별 η와 hz를 아는 정확한 베이즈 필터 (학습 없음).

## 2. 모델 (한 층, 키 64차원, 값 64차원, 기억 행렬 64×64)

| 이름 | 쓰기 | 이득의 출처 |
|---|---|---|
| gdn | M ← α(M − β(Mk)kᵀ) + βvkᵀ | α, β를 토큰에서 예측 |
| kdn | 대각 P 칼만 (KDN 대각 변형, μ = d_k) | α, ω, r을 토큰에서 예측 + P |
| ours | M ← M + β(k)(v − Mk)kᵀ, β = τ²u/(τ²u + σ²) | 키별 불확실성 u(k)와 잡음 σ²(k)를 64차원 벡터 두 개에 연상 저장. σ²는 ε² − τ²u로 갱신, 변화 확률 c = sigmoid(로그 우도비 + logit h)로 u를 초기화 |
| ours_fix | ours에서 σ²(k)를 상수 σ₀²로 고정 | 정밀도 추론을 뺀 제거 실험 |

ours의 학습 파라미터: 키·값 임베딩, 출력층, 스칼라 7개 (τ², σ₀², h, ν, η_s, ρ, 그리고 고정 하한). 게이트 신경망은 없다.

2단계 (1단계 결과를 본 뒤): gdn과 kdn의 게이트 입력에 쓰기 직전의 읽기 Mk와 오차 v − Mk를 더한 변형 (`+read`).
깊게 쌓은 모델에서 아래층이 문맥을 실어 주는 경우를 한 층에서 흉내 낸 가장 강한 비교군이다.

## 3. 예측

정확도는 길이 256 평가 기준. "차이가 있다"의 문턱은 절대 0.03 (시드 1개).

### 1단계

| 조건 | 예측 |
|---|---|
| A | 네 모델 모두 > 0.99 |
| B | ours ≈ kdn (차이 < 0.03). gdn은 못 믿을 키에서 둘보다 0.05 이상 낮다 |
| C 전체 | ours > kdn + 0.05, ours > gdn + 0.05. ours는 베이즈 상한에서 0.08 이내 |
| C 믿을 만한 키, 변화 뒤 첫 관측 직후 | ours > 0.9. kdn과 gdn은 그보다 0.1 이상 낮거나, 이것을 맞추는 대신 못 믿을 키의 정상 상태가 ours보다 0.1 이상 낮다 (한 맞교환 곡선) |
| C 제거 실험 | ours_fix는 kdn과 ours 사이, ours보다 0.05 이상 낮다 |
| 길이 8,192 | ours는 길이 256 대비 전체 정확도 변화 < 0.02. kdn과 gdn에 대해서는 예측하지 않는다 (이 과제는 학습 길이 밖의 지연을 요구하지 않는다) |

### 2단계 (+read)

확신이 낮다. 못 믿을 키는 저장된 값의 크기 |Mk|가 작아서, 읽기를 본 게이트는 신뢰도를 알아낼 수 있다.
- 예측: gdn+read와 kdn+read가 C에서 ours와의 격차를 0.03 이내로 좁힌다.
- 그 경우 남는 주장: 같은 성능을 게이트 학습 없이 스칼라 7개로 낸다는 것과 길이 불변성뿐이다.
- 예측이 틀려 격차가 0.05 이상 남으면: 정밀도 추론이 읽기를 본 학습 게이트로도 얻기 어렵다는 근거가 된다.

## 4. 실패 기준

- 1단계 C에서 kdn이 ours와 0.03 이내면: 한 층에서도 쓰기 규칙에 새로움이 없다. KDN을 그대로 쓰고 기여를 R4로 옮긴다.
- ours가 베이즈 상한에서 0.15 넘게 떨어지면: 형식화 (가우시안 σ², 스텝별 로그 우도비)가 이 과제의 잡음 구조와 맞지 않는 것이다.
  문턱이나 손실을 덧붙이지 않고 생성 모델로 돌아간다.
- ours가 길이 8,192에서 0.02 넘게 변하면 길이 불변성 주장을 내린다.
