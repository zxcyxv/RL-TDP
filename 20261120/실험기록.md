- 과제: `navix_DoorKey-8x8-v0`, 관측 `rgb_first_person` 56×56을 64×64로 0 채움.
- 크기: `size1m`. `train_ratio` 64, `run.steps` 1e6, `replay.size` 1e6, envs 16, batch 16×64.
- x를 자기 RMS로 나눈다 (`agent.q.xnorm`). 근거: 월드모델이 학습되며 h 크기가 바뀌므로 W_g 초기화 크기만으로는 silu 입력 스케일을 고정할 수 없다. 첫 짧은 실행에서 x RMS는 0.074(초기)에서 0.21(8만 스텝)으로 바뀌었다.
- W_o와 dsyn의 갱신은 둘을 합친 기울기 크기로 나눈다 (NLMS): Δ = rate · δ · e / (|g_o|² + |g_d|²). 근거는 아래 11:59 Q 실행의 발산.
- 상상 갱신: 리플레이 배치의 posterior 1024개에서 시작, 15스텝, 행동은 softmax(Q/τ), 보상은 보상 헤드, 계속 확률은 con 헤드. λ-return을 고정 타깃으로 W_o와 W_g를 갱신한다. 상상 궤적 하나를 에피소드로 보고 그 dsyn을 끝에 W_g로 옮기는 것과 같은 꼴이다 (궤적 안에서는 dsyn을 Q 계산에 반영하지 않는 오프라인 판).
- 초기값: τ 0.05, γ 0.99, λ 0.9, β 0.3, η 0.02, 상상 β 0.05, 상상 η 0.05, W_g 초기화 표준편차 1/√d.

## 검토 요청 (제안, 확인 전)

### A. 1단계 비교에서 볼 숫자 (Q 에이전트 vs 기준선, 판정 기준은 정해 주셔야 함)

1. 수치 발산: Q의 NaN 여부, W_g·W_o 노름, silu 입력 표준편차의 시간 변화.
2. 성공 에피소드 비율: 10만 스텝 구간별, 두 실행 나란히.
3. 월드모델 손실 (image, dyn, rew, con): Q 에이전트는 다른 정책으로 데이터를 모으므로 월드모델 학습이 달라질 수 있다. 같은 스텝에서 나란히 적는다.
4. 판정 칸: "학습을 망치지 않았다"를 무엇으로 볼지 (예: 구간 N에서 성공 비율이 기준선의 몇 % 이상) — 비움.

### B. 10번: 맥락이 옛 과제를 얼마나 보호하는지 재는 방법

guidelines.md의 타당도·식별 가능성 원칙에 맞추려고, 모델이 실제로 계산하는 양과 별도로 학습한 대조 모델만 쓴다. 학습된 모델의 일부 파라미터를 바꿔 끼우는 개입은 쓰지 않는다.

1. 행동 지표: 새 과제 단계 뒤 원래 과제로 돌아왔을 때의 성공 비율. 새 과제 전의 성공 비율과 같은 에피소드 수로 잰다.
2. Q 변화 지표: 고정한 옛 과제 상태 집합(리플레이에서 뽑아 저장)에서 새 과제 단계 전후의 Q(s, a | c) 변화 |ΔQ_old|와, 새 과제 상태 집합에서의 |ΔQ_new|. 비율 |ΔQ_old| / |ΔQ_new|.
3. 분해: 전이로 W_g가 ΔW_g만큼 바뀌었을 때 옛 상태의 1차 변화는 ΔQ_old ≈ Σ_i W_o,i · c_old,i · silu′(u_i) · (ΔW_g,i · x_old). 유닛별 기여로 나눠서, 변화가 맥락 c_old,i가 큰 유닛에서 오는지 적는다. 이것은 실제 계산식의 분해다.
4. 대조 모델: 맥락 게이트가 없는 판 (c 자리에 상수 1, 나머지 동일)을 처음부터 따로 학습해 같은 지표를 잰다.
5. 판정 칸: 보호가 "있다"를 무엇으로 볼지 (예: 1의 성공 비율 하락 폭 ≤ X%p, 2의 비율 ≤ Y, 4보다 작은지) — 비움.
